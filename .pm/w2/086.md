# Check that non-English ledger requests route to the right skill

**Idea · skills · ~1h · A1/A3.** From the skills research, 2026-10-18.

Every prompt in `skills/evals/routing.json` is English, and every skill description is English. Other published suites put non-English trigger words in their descriptions: Chinese in [song-jia/beancount-query-skills](https://github.com/song-jia/beancount-query-skills), German in [levino/german-finances-template](https://github.com/levino/german-finances-template). Much of the open-source Beancount community writes in Chinese.

Add a small set of positive and `none` prompts in Chinese, Japanese, German, Spanish, and French to the routing set: one ask, one import, one add, one reconcile, and one hosted-ledger hand-off per language. Run `skills/scripts/run-routing.py` on Claude Code and Codex. Change a description only where a prompt misroutes, and keep `check_routing()` green. Record the runs in `skills/docs/routing-rehearsal.md` with versions and dates.

Promote this to a milestone if more than a couple of descriptions need changes.
