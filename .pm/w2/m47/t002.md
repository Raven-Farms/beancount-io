## Objective

Implement the PDF statement path in the skill t001 chose. Each extracted row comes with its page and line, so the review table shows exactly where it came from. The skill proposes nothing until the statement ties out. The batch carries t001's ids and goes through the dedup layers, including the cross-source review, with categories drawn from the ledger's own history. Success requires a passing `balance` assertion. After a yes, the statement file is linked to the account with a `document` directive.

## Context

- Extraction guidance already exists in reconcile's `references/statement-formats.md`: period, opening and ending balances, transaction lines, wrapped descriptions joined to their dated row, and no ending balance inferred by summing.
- Write primitives: `bea --file "$ledger" --json --no-input add transactions --from - --into "$target"`, then `add balance --date "$assertion_date" --account … --amount … --into "$target"`, the same sequence reconcile uses. `bea add document --date … --account … --filename <path relative to the destination file's directory> [--link …]` appends a `document` directive (`cli/src/cli/commands/add.py`).
- Upstream Beancount's `verify_document_files_exist` reports a `document` whose file is missing, so the root `bea check` confirms the attachment.
- When the ledger declares `option "documents"`, Beancount already discovers dated files in account-named folders under that root. Use that layout rather than inventing a second one.

## Steps

1. Add PDF to the chosen skill's input detection, and point to the shared extraction reference. Skip page subtotals, carried-forward lines, and balance lines; none of them is a transaction.
2. Run the sanity walk before proposing anything. If opening + movements does not equal closing, stop, show the gap, and ask the user to check the misread figure. Write nothing.
3. Propose the batch with t001's `import-id`s and each row's page and line. Run Layer 1, Layer 2, Layer 2b, and the cross-source review, and categorize as the skill already does (existing accounts only, `Expenses:Uncategorized` when unsure).
4. After a yes, write the batch and the balance assertion, then offer to attach the statement. Propose where the file goes. Never move or copy the user's file without a separate yes. Finish with the root `bea check`.
5. Update the skill's description with the new input, and add routing entries: positives, plus near-misses against reconcile.

## Files

- `skills/beancount-reconcile/references/statement-formats.md` (shared extraction, if t001 chose to share it)

## Acceptance criteria

- [ ] The skill never proposes rows from a statement that does not tie, and never reports success without a passing assertion.
- [ ] Re-running the same PDF writes nothing. A later overlapping CSV shows every overlapping row as a suspected duplicate.
- [ ] `python3 scripts/skills/ci-check.py` passes with the new routing entries.

## Out of scope
