# The first-month guide never records a manual entry, the most common thing a newcomer does next

**Minor · skills · 1h · A2.** Found in the [w2/m40](./m40/README.md) t007 adoption check, 2026-10-19.

[`skills/docs/first-month.md`](../../skills/docs/first-month.md) composes init → import → reconcile → ask → close on one synthetic ledger and is verified checkpoint by checkpoint by `scripts/verify-first-month.py` against `docs/examples/first-month/expectations.json`. It has no step where the user records something by hand, which `beancount-add` now covers ("I paid cash for parking", "open a savings account"). Add one short step after initialization — a cash or card purchase proposed, confirmed, and written through `beancount-add` — with its expected ledger effect in `expectations.json` and a verifier check, so the guide shows all nine skills' everyday path. Changing the journey also needs a fresh rehearsal on both clients (`skills/docs/first-month-rehearsal.md`); Codex was at its usage limit on 2026-10-19, so schedule the rehearsal when Codex is available.
