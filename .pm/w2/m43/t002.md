## Objective

Find out exactly which rule of the Agent Skills specification our customer frontmatter breaks, then move to one form that passes `skills-ref validate` and that every host we target still reads. If no such form exists, record the conflict rather than silently picking a side.

## Context

- The [specification](https://agentskills.io/specification) requires `name` (1–64 lowercase letters, digits, and hyphens, no consecutive hyphens, matching the folder) and `description` (1–1024 characters). It allows `license`, `compatibility` (at most 500 characters), `metadata` ("a map from string keys to string values"), and `allowed-tools`. Validation uses [skills-ref](https://github.com/agentskills/agentskills/tree/main/skills-ref).
- Each customer skill carries `metadata: {"openclaw": {...}, "hermes": {...}}` on one line, shipped in [w6/m6](../../w6/blocked/m6/README.md) t004. OpenClaw parses frontmatter as YAML and re-reads `metadata` as JSON5. Hermes reads it with PyYAML. `ci-check.py` `check_metadata` requires a single-line JSON object because `beancount-skills.py` and `ci-check.py` skip indented lines.
- A research run on 2026-10-18 reported that `skills-ref validate` rejects all nine skills, and that block-style YAML passes. The nested objects may also break the string-values rule, so establish the actual failure before choosing a fix.
- Run the validator from a scratch environment under `scripts/skills/tmp/`. This task adds no repository dependency (t003).

## Steps

1. Run `skills-ref validate` on each `skills/beancount-*` folder and record the errors.
2. Try the candidate forms. For each, check `skills-ref`, PyYAML, OpenClaw's documented parsing (re-read `docs.openclaw.ai/tools/skills`), `npx skills add . --list`, and both clients' skill listing. Re-run `beancount-skills.py bundle` into a scratch folder.
3. Apply the form that passes everywhere, and update `check_metadata` and the comment above it. If none does, keep ClawHub's form, name the failing rule and the validator output in `skills/AGENTS.md`, and leave the choice to w6/m6's owner decision.
