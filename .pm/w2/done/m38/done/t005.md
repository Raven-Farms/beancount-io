## Objective

Fix the baseline misroutes in the descriptions: name the confusable skips, and use the words users type for each skill's triggers.

## Context

- `beancount-close` has no skip for closing one account with a `close` directive. `beancount-options` has no skip for ledger `option` settings. `beancount-ask` does not mention `bea ask`, which hands the question to another model (`beancount-ask/SKILL.md` says not to use it).
- Several descriptions read in the skill's own vocabulary ("Normalize signs, suggest categories from existing accounts"). The `skills/AGENTS.md` Skills table quotes trigger phrases ("close the month", "import this CSV") that the descriptions no longer carry.
- Keep `metadata` one line of JSON (`ci-check.py` rejects a multi-line block).

## Steps

1. For each misroute in t004, change the description of the skill that won wrongly or lost wrongly, not every skill at once.
2. Add the missing skip clauses above.
3. Add two or three literal user phrasings per skill where the baseline shows under-triggering.

## Files

- `skills/.claude/skills/*/SKILL.md` (frontmatter only), `skills/AGENTS.md` Skills table

## Acceptance criteria

- [x] Each description change cites the routing entries it targets.
- [x] Descriptions stay under 1024 characters and `ci-check.py` passes.

## Out of scope

- Skill names (m39) and skill bodies beyond t006's hand-off line.

## Result

Description changes, each tied to routing entries: `beancount-import` adds "single manual entries, and ledger `option` settings" to its skips (it won `none-operating-currency-option` once on Codex; also guards `none-dinner-on-amex`, `none-rent-transaction`); `beancount-importer-author` adds two literal phrasings ("write a beangulp importer for my bank's CSV", "my importer broke after the bank renamed its columns") (it lost `author-schwab-importer` once on Codex); `beancount-close` adds "Skip closing a single account (a `close` directive)" (`none-close-amex-account`, `none-mark-account-closed`); `beancount-options` adds "ledger `option` settings such as operating_currency" (`none-operating-currency-option`, `none-which-options-to-set`, `none-rename-account-roots`); `beancount-ask` adds `bea` documentation "(including what `bea ask` does)" (`none-what-is-bea-ask`). Those three skip clauses guard pairs that already routed correctly at baseline; they are the confusable skips the definition of done requires. Under-triggering phrasings were added only where the baseline showed it (importer-author). Descriptions are 379–478 characters and parse as YAML. The `skills/AGENTS.md` table rows for close and options name the same skips. Hosted ledgers are t006.
