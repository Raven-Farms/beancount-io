## Objective

Write a local script that installs the suite into a scratch workspace, sends each routing prompt to Claude Code and Codex, records the skill each client actually chose, and scores the result per skill and per near-miss pair.

## Context

- `skills/scripts/beancount-skills.py install <dir>` links the suite into a workspace; `skills/docs/installation.md` step 3 lists both clients' non-interactive commands (`claude -p`, `codex exec`).
- Scratch output goes under `skills/tmp/` (gitignored).
- Rehearsal evidence is kept apart from deterministic tests (see `skills/docs/first-month-rehearsal.md`).

## Steps

1. Verify how each client's machine-readable output shows that a skill was chosen (for example a skill tool call, or a read of that skill's `SKILL.md`) before trusting it. Record the method in the script's docstring.
2. Run every prompt in a scratch workspace with a synthetic ledger, using each client's read-only or sandboxed mode so nothing outside the workspace can change. Record the first skill chosen, or none.
3. Print per-skill precision and recall, the near-miss confusion pairs, and a per-prompt table.

## Files

- `skills/scripts/run-routing.py` (new)

## Acceptance criteria

- [x] One command produces a per-prompt result for each installed client and a summary, and skips a client that is not installed.
- [x] A run leaves the repository's working tree unchanged except under `skills/tmp/`.

## Out of scope

- Wiring the runner into CI.

## Result

`skills/scripts/run-routing.py` (stdlib only) creates one scratch workspace per client in the system temp directory — a fresh Git repository with a synthetic ledger and the suite linked into `.claude/skills` and `.agents/skills` — runs each prompt with `--jobs` concurrency, stops the client at its first skill choice, and writes `results.json` and `summary.md` under `skills/tmp/routing/<UTC stamp>/`. Detection, verified on Claude Code 2.1.289 and Codex 0.163.0: Claude's first `Skill` tool call (`--strict-mcp-config`, Edit/Write disallowed); Codex's first shell command reading `<skill>/SKILL.md` (`--sandbox read-only`). Skills outside the suite score as `none`. `--score` re-scores a recorded run; `--suite` points at another skill directory (for m39 t001). Deviation: workspaces live outside the repository (not under `skills/tmp/`), because inside it both clients would also load this repository's instructions and development skills. Smoke run of three prompts per client: 3/3 on each, workspaces removed, repository tree unchanged. Codex 0.163.0 here rejects the configured default model on a ChatGPT account, so runs pass `--codex-model gpt-6-luna`.
