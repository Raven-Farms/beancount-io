## Objective

Put the commands the skill relies on into `<!-- recipe: <name> -->` blocks. `TestBeaRecipes` in `scripts/skills/test_beancount_skills.py` runs those blocks against isolated synthetic ledgers, so a `bea` change that breaks a recipe fails CI rather than a user's ledger.

## Context

- `TestBeaRecipes` finds recipes by name (`<!-- recipe: NAME -->` followed by a fenced block) in the listed reference files, then runs them through `recipe()` and `query_recipe()`. Add the new reference file to its list.
- Recipes to cover:
  - locate entries with source locations (`bea --json list transaction --search … --on-disk`);
  - list every occurrence of an account across directives and included files;
  - confirm the root check after a rename and a move;
  - undo by revert.

## Steps

1. Write each recipe block in the skill's references.
2. Add tests that run them on a multi-file ledger with includes. Assert the located files and lines, and that the root check passes after the edit.
