## Objective

Settle which skill refreshes `price` directives and how: a user (or agent) can bring ledger prices current through the documented `bea` path, and ask's missing-price report points at exactly that step.

## Context

- Today `bea engine enable beanprice` is an orphan line in `skills/README.md`; `beancount-add` can write a single user-supplied `price`, and no skill owns bulk refresh.
- `bea --file "$ledger" price status` already reports freshness (cited in beancount-ask).

## Steps

1. Rehearse the `bea price` path on a synthetic ledger with priced commodities; record what it writes, how stale prices are detected, and what a user must configure.
2. Write the refresh procedure into the owning skill's text (or its references), with propose-then-confirm before any `price` write, and point ask's unpriced-commodity output at it.

## Files

- Owning skill's `SKILL.md`/`references/`, `skills/beancount-ask/SKILL.md` pointer

## Acceptance criteria

- [ ] A fresh agent session following only the shipped text brings a stale fixture's prices current (or states precisely why it cannot), with no price written before confirmation.
