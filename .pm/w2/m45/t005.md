## Objective

Write behavior evals and synthetic fixtures that catch the mistakes hand-written investment entries make. Complete the routing entries, so the trade boundary is measured on every later description change.

## Context

- Skill evals live in `<skill>/evals/evals.json` with fixtures under `evals/files/`. `ci-check.py` validates them and runs `bea check` on `*ledger.beancount` fixtures.
- Cases to cover: a partial sell across two lots under `STRICT` (ambiguous unless the lot is named); a lot transfer that must keep cost and date; a 4-for-1 split; a reinvested dividend; an RSU vest; a crypto transfer between the user's own wallets; an average-cost request (t004); and the realized-gains report with its tie-out (t003).
- Routing near-misses: "I paid $42 for dinner" (add), "sell a covered call" (options), "import my brokerage CSV" (import).

## Steps

2. Finish the routing entries and run `python3 skills/scripts/ci-check.py`.
