## Root cause and repair

src/features/ledger/utils/report-summaries.ts::summarizeIncomeStatement (around line277) passes conversion unchanged into resolveCurrency. With no balance-map currency keys, resolveCurrency starts its fallback at the requested value, so at_cost/units become the label. The same file already has requestedCurrency, used by interval and balance-sheet summaries to distinguish strategies from real currencies; the income caller still bypasses it.

summarizeOverview also passes the raw conversion value to resolveCurrency. Its shared overview descriptor in analysis-handler.ts serves REST/MCP; the GraphQL overview resolver returns raw data. Both remaining summary callers require the existing strategy normalization policy.

The shared statements descriptor in src/features/ledger/api/rest/v1/reports-handler.ts::getStatement dispatches both modern REST and MCP through summarizeIncomeStatement. GraphQL ledger-finance-resolver.query.ts returns raw service maps and bypasses this projection. Native ledger data is correct; no engine upgrade is needed. Apply the existing strategy-versus-currency normalization policy to the income summary, retaining observed currency precedence, real explicit currency selection and the empty default. Preserve raw/GraphQL payloads, correct zero amounts, the nonzero loss/profit controls and account rows. No hardcoded replacement of an observed ledger currency and no multi-currency addition.

Acceptance: actual REST/MCP adapters return USD rather than units/at_cost/at_value for an empty income statement and empty overview, while explicit EUR remains EUR; non-USD observed balances keep their real currency, and existing zero-net and nonzero statements keep amounts/accounts. Cover native data shapes, actual empty maps, explicit currency and strategy choices, and raw GraphQL/fava passthrough with behavioral adapter tests. Run backend-v2 typecheck, tests and OpenAPI generation without drift when implementing. at_value, explicit EUR and a non-USD empty fixture are acceptance work, not claimed live coverage.
