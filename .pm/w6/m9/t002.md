## Objective

Distribute the existing hosted endpoint through Docker's remote-server catalog path.

## Context

- `backend-cluster/backend-v2/server.json` already publishes `io.beancount/beancount` in the official MCP Registry (w2/m36, complete).
- Use the existing hosted endpoint `https://beancount.io/api-gateway/mcp`, OAuth, the dedicated QA account, and synthetic ledgers; record client versions, dates, and the deployed revision when available.
- ADR 019 D1 preserves one endpoint and one capability set across hosts. Keep reviewer credentials and account tokens outside tracked files.
- Source: approved pm-brainstorm items 3–7, user request 2026-10-20. Claude/ChatGPT milestones were explicitly excluded.

## Steps

1. Follow https://github.com/docker/mcp-registry/blob/main/CONTRIBUTING.md#-adding-a-remote-mcp-server for a remote entry, dynamic tool discovery, and documentation.
2. Stage the public submission payload under the backend package and validate it through the documented catalog tools; add no new package dependency without the user's approval.
3. Test Docker's gateway against the hosted QA endpoint with OAuth, a query, and a write preview; then complete the documented contribution route or record the operator/reviewer gate.
