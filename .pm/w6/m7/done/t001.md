## Objective

Record first-hand what each host sends to our authorization server. For OpenClaw's CLI login, OpenClaw's per-requester gateway mode, and Hermes Agent, that means: CIMD `client_id` URL or DCR body, `application_type`, `redirect_uris`, `token_endpoint_auth_method`, requested scopes, and the `resource` parameter.

## Context

- Both hosts are open source. Read the OAuth client code at a tagged release, and confirm against a real attempt. The consent page (`/oauth/consent`) shows the redirect, the client's self-given name, and the CIMD domain (ADR 019 D4).
- Use the hosted endpoint and the QA account only ([DO_NOT_DO](../../../DO_NOT_DO.md)).

## Steps

1. Note each host's version and the source file that builds the registration.
2. Start a sign-in from each host against `https://beancount.io/api-gateway/mcp`. Capture what the consent page shows, and stop before approving if t003 or t004 will do the full run.
3. Write the findings into the milestone `README.md` under `## Host captures`, with the date.
