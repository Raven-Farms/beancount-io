## Objective

Complete a real OpenClaw sign-in on the hosted endpoint with the QA account, then one read and one `dry_run` write on a synthetic ledger. Record the result.

## Context

- Commands as documented: `openclaw mcp add beancount --url https://beancount.io/api-gateway/mcp --transport streamable-http`, then `auth: "oauth"`, then `openclaw mcp login beancount` and `openclaw mcp doctor beancount --probe`. Confirm the exact flags with `openclaw mcp add --help`.
- The probe lists capabilities without a model. The read and the write need an agent turn, and so a model provider key. If the worker has none, block this task on that with the probe results recorded.

## Steps

1. Add, log in, and approve on `/oauth/consent`, selecting one synthetic ledger.
2. Probe, then ask the agent for one read (for example, a balance) and one `dry_run` write.
3. Record the date, OpenClaw version, deployed backend revision, the tools the host loaded, and whether it read any resources.
