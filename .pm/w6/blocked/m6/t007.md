## Objective

The operator claims the handle chosen in t001, creates an API token, stores it as the `clawhub-publish` environment secret, and dispatches the first publish.

## Context

- This repository cannot do this step. The account and token belong to the operator.
- The token never enters the repository or the board.

## Steps

1. The operator signs in to ClawHub with the project's GitHub account and confirms the handle with `clawhub whoami`.
2. The operator creates a token in the ClawHub web UI and adds it as `CLAWHUB_TOKEN` on the `clawhub-publish` environment, restricted to `main` with a required reviewer.
3. The operator dispatches `Publish (clawhub)` with `publish`.
4. Record the run ID and each listing's version in the milestone `README.md`.
