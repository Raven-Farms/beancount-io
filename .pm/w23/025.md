# Adding or removing the ledger's owner as a collaborator reports success but does nothing

Found by MCP QA on 2026-10-20 against `https://beancount.io` (OAuth `ledger.read ledger.write ledger.admin` token pinned to the QA account's synthetic ledger, whose collaborator list is empty). Verified before and after: the owner keeps `permission: "owner"`, and `collaborators` stays `[]`.

**Repro:**

```text
setLedgerCollaborator    {collaborator:"<owner>", permission:"read"} → {ok:true, result:{success:true, message:"Collaborator added/updated successfully"}}
beancount://<owner>/<name>/collaborators                            → []
beancount://<owner>/<name>/collaborators/permission?collaborator=<owner> → {"permission":"owner", …}
removeLedgerCollaborator {collaborator:"<owner>"}                    → {ok:true, result:{success:true, message:"Collaborator deleted successfully"}}
```

Controls: an unknown user gets `BAD_USER_INPUT` "No such user", and `permission:"owner"` is refused by the schema.

**Why it matters:** an agent asked to give the owner read access, or to "remove `<owner>`" from a ledger, is told it succeeded. Nothing changed, and nothing could: an owner's access isn't a collaborator grant. A user who thinks they removed themselves still owns the ledger.

**Expected:** naming the ledger owner (case-insensitively, as the limit check already compares logins) is refused before the host call, e.g. `OPERATION_NOT_ALLOWED` "`<owner>` owns this ledger; an owner's access can't be granted or removed as a collaborator", on REST `PUT`/`DELETE …/collaborators/{collaborator}`, GraphQL and MCP alike.

**Root cause:** `backend-cluster/backend-v2/src/features/ledger/workflow/ledger-collaborators-workflow.ts`. `addOrUpdateCollaborator` (`~:196-214`) and `deleteCollaborator` (`:226-251`) pass any existing login to the repository host, which no-ops for the owner and still reports `success`. The limit check at `:178-183` already excludes the owner from the count, but nothing refuses them as a target.

**Fix:** add the owner guard in both methods and a parity test on the three surfaces. Owner: backend-v2. Estimate: ~20m.
