# Journal `directiveTypes` is case-sensitive and unvalidated: `["transaction"]` silently returns nothing

Found by MCP QA on 2026-10-20 against `https://beancount.io` (OAuth `ledger.read` token pinned to a synthetic QA ledger with 16 transactions and 12 opens).

**Repro (MCP):**

```text
listLedgerEntries {directiveTypes:["Transaction"], limit:1}  → total 16
listLedgerEntries {directiveTypes:["transaction"], limit:1}  → total 0, ok: true
listLedgerEntries {directiveTypes:["open"], limit:1}         → total 0, ok: true   (["Open"] → 12)
listLedgerEntries {directiveTypes:["Txn"], limit:1}          → total 0, ok: true
resources/read beancount://<owner>/<name>/journal?directiveTypes=%5B%22Nope%22%5D → {"total":0,"data":[]}
```

**Why it matters (A1):** the same server spells directive kinds in lowercase on writes: `addLedgerEntries` takes `type: "transaction" | "open" | …`. An agent that reuses that spelling to read back what it wrote gets an empty success and concludes the entries are missing. The MCP input schema publishes `directiveTypes` as a free `string[]`, so nothing tells it the valid spelling.

**Expected:** `directiveTypes` accepts the eleven `DirectiveType` kinds (`Transaction`, `Balance`, `Commodity`, `Close`, `Custom`, `Document`, `Event`, `Note`, `Open`, `Pad`, `Price`).

- Normalize them case-insensitively, so `"transaction"` and `"Transaction"` match the same entries.
- Refuse anything else with `BAD_USER_INPUT`, naming the valid kinds.
- Apply the same rule to `transactionSubtypes`, `documentSubtypes` and `customSubtypes`.
- Publish the MCP input schema as an enum.
- Empty arrays keep their documented meaning.

**Root cause:** no layer validates the values.

- `backend-cluster/backend-v2/src/features/ledger/api/rest/v1/journal-reads.ts:73-78` casts `string[]` to `DirectiveType[]`, with the comment "the ledger service owns subtype validation".
- `src/features/ai-agent/api/mcp-list-tools.ts:99` and `:143` do the same cast, as does GraphQL `JournalQueryInput` (`ledger-journal-resolver.query.ts:76`, `[String]`).
- `backend-cluster/ledger/src/api/journal.ts:33` passes the list on, and `journal-serialize.ts:345` filters by exact match.

**Fix scope:** one shared normalizer in backend-v2, used by REST `journal`/`account-journal`, GraphQL `getLedgerJournal`/account journal, MCP `listLedgerEntries`, and the `journal`/`account-journal` resources. Add parity tests: a lowercase kind returns the same entries on all three surfaces, and an unknown kind is `BAD_USER_INPUT` on all three. Owner: backend-v2. Estimate: ~50m.
