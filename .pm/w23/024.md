# Bank-account tools look the account up before authorizing: a `ledger.read` token gets "Account not found" from admin tools

Found by MCP QA on 2026-10-20 against `https://beancount.io` (OAuth tokens pinned to a synthetic QA ledger with no linked banks: one `ledger.read`, one `ledger.read ledger.write`; neither holds `ledger.admin`). This is the account-level sibling of `w23/004`, which `cc57dc6dd` fixed for `banks/{itemId}` only.

**Repro (account id `nope`, which exists nowhere):**

| Call | Token | Result | Expected |
| --- | --- | --- | --- |
| `mapBankAccount {account_id, ledger_account}` (admin) | read, read+write | `BAD_USER_INPUT` "Account not found" | `FORBIDDEN` (needs `ledger.admin`) |
| `setBankAccountCurrency {account_id, currency}` (admin) | read, read+write | same | `FORBIDDEN` |
| `listStagedBankTransactions {accountId}` | read | `BAD_USER_INPUT` "Account not found" | concealed `NOT_FOUND` "Bank connection not found" |
| `…/bank-transactions/suggested-categories?accountId=nope` | read+write | same | same |

The hint on all of them, "Fix the named argument…", sends the agent to fix an argument when the real problem is a missing scope.

**Root cause:** `backend-cluster/backend-v2/src/features/plaid/service/plaid-item-service.ts` loads `plaidAccount.getById(accountId)` globally and throws `BadUserInputError("Account not found")` before `authorizeBankAction`, at `getUnsyncedTransactionsForScope` (`:388-395`), `updateAccountMapping` (`:999-1002`) and `updateAccountCurrency` (`:1040-1043`). `plaid-sync-service.ts:624-627` (`getUnsyncedTransactionsForCategorization`, "PlaidAccount not found") does the same. When the id does exist but belongs to someone else, these paths answer with "Unauthorized access to account" or the concealed `NOT_FOUND` instead, so the answer reveals whether an account id exists. That branch was traced in code, not exercised: the QA account has no banks.

**Fix:** as in `cc57dc6dd`, authorize `BANK_*` against the route's ledger first, so a missing scope is `FORBIDDEN` before any lookup. Then answer a missing account, or one on another ledger or user, with the same concealed `NOT_FOUND` "Bank connection not found". REST (`banks-handler.ts`), GraphQL (`plaid-resolver`) and MCP share these methods. Extend the plaid parity test with a missing account id and an under-scoped token on all three surfaces. Owner: backend-v2. Estimate: ~45m.
