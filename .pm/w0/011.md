# Turn the Ask AI tool-activity counts into real plural messages

**Severity:** minor (i18n). **Estimate:** 35–50 minutes for 4 keys × 15 locales plus a test. **Owner:** `dashboard` (ai-agent). **A1:** the Ask AI transcript is the first agent surface many users see, and `Ran 1 query or queries` reads as unfinished.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `575a8798`. QA-owned headless Chromium, en-US, authenticated owner on a synthetic ledger. Non-agent writes were guarded.

Open `/ledger/<owner>/<ledger>/agent` and ask "what were my total expenses in August 2026, in USD?". The answer (`$2,095.60`) is correct. The tool summary above it reads **"Ran 1 query or queries"**. The Russian catalog renders the same key as `Выполнил запрос или запросы {count}`, which is ungrammatical and doesn't inflect.

## Root cause

`dashboard/src/features/ai-agent/locales/en.ts:196–218` defines count messages as workarounds instead of plural families: `aiAgent.checkedFiles` ("Checked {count} file(s)"), `aiAgent.ranQueries` ("Ran {count} query or queries"), `aiAgent.usedTools` ("Used {count} tool(s)"), and `aiAgent.editApproval.appliedOperations` ("Applied {count} operation(s)"). These are consumed by `pages/agent/agent-message-list/tool-activity-group.tsx:85–88` and the edit-approval status. `dashboard/AGENTS.md` (Internationalization) requires counts as plural messages: `{ one, other }` in English, `{ one, few, many, other }` in ru/uk/sk, `{ other }` in zh/ja/ko, called as `t(key, { count })`.

## Fix

Convert the four keys to plural families in all 15 `features/ai-agent/locales/*.ts` files, using the form `src/i18n/plural.ts` expands, and keep the call sites passing `count`. Let `src/i18n/__tests__/plural.test.ts` and `src/test/translations.test.ts` enforce the categories.

Acceptance: English renders "Ran 1 query" / "Ran 3 queries", "Checked 1 file" / "Checked 2 files", "Used 1 tool", and "Applied 1 operation". Russian inflects 1/3/5 correctly. Plural and translation tests pass along with the dashboard gates.

## Dedupe

Searched `.pm/**` for `(s)`, `query or queries`, plural, and the key names. Only CLI items mention "file(s)". See also w0/012 for the same pattern in Settings and Plaid.
