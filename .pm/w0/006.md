# Make the Journal "New Entry" button's accessible name contain its visible label

**Severity:** minor (WCAG 2.2 SC 2.5.3 Label in Name). **Estimate:** 15–25 minutes. **Owner:** `dashboard`. **A2:** voice-control users say what they see ("click New Entry"). That command fails when the control's name is something else.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `575a8798`. QA-owned headless Chromium at 1440×1000, en-US, authenticated owner on a synthetic ledger. Read-only.

Open `/ledger/<owner>/<ledger>/journal`. The toolbar link visibly reads **New Entry**, but its accessible name is `Add new journal entry` (from `aria-label`), which doesn't contain "New Entry". `getByRole('link', { name: 'New Entry' })` finds nothing in `main`. A DOM sweep of 14 ledger routes for `aria-label`s that omit their visible text found this as the only button/link mismatch. Comboboxes that show their current value ("Monthly", "At Cost", the ledger name) were excluded, since a selected value isn't part of the label.

## Root cause

`dashboard/src/features/journal/pages/journal-page.tsx:274–288` puts `aria-label={t("journal.addNewJournalEntry")}` on a link whose visible `<span className="hidden sm:inline">` is `t("journal.newEntry")`. The label exists for the icon-only narrow layout, but at `sm` and wider it overrides the visible text.

## Fix

Name the control from its text in every layout: drop the `aria-label` and render the label as `sr-only` below `sm` (`<span className="sr-only sm:not-sr-only">`). Alternatively, make the label start with the visible words ("New entry"). Keep the icon-only sidebar action (`common/components/ledger-layout/add-directive-button.tsx`) labelled as it is. Update `features/journal/pages/__tests__/journal-actions.test.tsx`, which queries the link by the translation key.

Acceptance: at 1440 and 390 widths, the link's accessible name contains "New Entry" in English (and the visible label in other locales), and it still opens `?action=new-entry&directive=transaction`. Dashboard gates pass.

Searched `.pm/**` for label in name, 2.5.3, accessible name, and `addNewJournalEntry`. w4/221 named the Accounts table; no item covers this control.
