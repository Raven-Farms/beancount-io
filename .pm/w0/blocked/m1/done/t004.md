## Objective

Close the guard gap that let 619+ English copies ship: a test that fails when a non-English message is byte-identical to its English source.

## Context

- `dashboard/src/test/locale-scan.ts` `untranslatedEnglishTail` returns `[]` when `message === english`. `locale-stray-english.test.ts` only finds English stranded in mixed-script messages. `translations.test.ts` checks shape.
- Legitimate identical messages exist (brand names, `BQL`, `CSV`, code samples, placeholders), so the test needs a reviewed allowlist keyed by locale and key, with a reason per entry. Follow `KNOWN_DEVIATIONS`' "list shrinks as fixed" pattern.

## Steps

1. Add a test that compares every non-English catalog entry to `en` and flags identical messages containing at least two English words (tune the threshold against the catalogs, as w4/m25/t001 did).
2. Seed the allowlist only with genuine invariants, each commented.
3. Make it part of `yarn test` (and `yarn test:translations` if that alias is meant to cover catalogs).

## Files

- `dashboard/src/test/locale-scan.ts`, a new or extended test in `dashboard/src/test/`

## Acceptance criteria

- [ ] The test fails on today's main (before t001–t003) and passes after them.
- [ ] Every allowlist entry has a reason, and the test fails if an allowlisted entry stops being identical (stale allowlist).

## Out of scope
