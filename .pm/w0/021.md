# Pluralize the profile follower count and call ledgers "ledgers" on profiles

**Severity:** minor (copy/i18n). **Estimate:** 30–40 minutes (one plural family, 3–4 copy keys × 15 locales). **Owner:** `dashboard` (user-profile). **A3:** public profiles such as `/ledger/open_ledger` are a community surface. A profile with one follower reads "1 Followers", and the empty Starred tab talks about "repositories".

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `575a8798`. QA-owned headless Chromium, 1440×1000, en-US, authenticated QA owner. Read-only.

1. Open your own profile via **User menu → Stars** (`/ledger/<username>?tab=starred`). The header reads **"1 Followers"**. The tab strip reads "Starred (0) | Following (1) | Followers (1)", and the empty state says **"No starred repositories"**.
2. `/ledger/open_ledger` reads "401 Followers", which is correct only because the count is plural.

Everywhere else the product calls these **ledgers**, including the profile's own "Ledgers" tab.

## Root cause

- `features/user-profile/pages/user-profile-page.tsx:203–207` renders `{profile.followersCount}` followed by the tab label `t("userProfile.tabs.followers")` ("Followers") instead of a count message. `dashboard/AGENTS.md` requires counts as plural families via `t(key, { count })`.
- `features/user-profile/locales/en.ts`: `userProfile.noStarredRepos` "No starred repositories", `userProfile.repositories` / `userProfile.noRepositories` "No repositories", and the profile SEO description "View {username}'s profile, repositories, and activity…".

## Fix

Add a plural `userProfile.followersCount` (`{ one: "{count} follower", other: "{count} followers" }`, with the right categories for all 15 locales) and render it in the header. Keep the tab labels as they are. Reword the repository copy to "ledgers" ("No starred ledgers", etc.) in all locales. Leave SSH/Git copy that genuinely refers to Git repositories unchanged.

Acceptance: a 1-follower profile reads "1 follower", and 0 or 401 read "0 followers" / "401 followers". The Starred empty state says "No starred ledgers". Plural and translation tests pass along with the dashboard gates.

Searched `.pm/**` for followers, starred, repositories, and profile plural. w4/111 translated the social tabs/empty states, and w4/154 covered tab search params. Neither covers the count grammar or the "repositories" term. Related plural work: w0/011 and w0/012.
