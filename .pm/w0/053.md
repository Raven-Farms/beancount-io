# Google Analytics records the full URL of the password-reset and one-time-login pages, tokens included

**Minor · dashboard · 50–60m · A3.** From a security review of `main` (2026-10-18).

The reset email links to `/auth/reset-password/?token=…` (`backend-cluster/backend-v2/src/features/auth/service/auth-service.ts:357`), and the legacy redirect and admin login-as send users to `/auth/callback?oneTimeToken=…` (`features/v1-compat/api/redirect-handler.ts:71`, `features/admin/service/admin-service.ts:234`). The root shell renders `<GoogleAnalytics />` on every route (`dashboard/src/common/root-route/shell-component.tsx:21`), and its bootstrap calls `gtag("config", id, {})` with the automatic `page_view` left on (`dashboard/src/common/analytics/google-analytics.tsx:28-36`). Its comment even asks for Enhanced Measurement page views. gtag attaches `document.location` as `page_location` to that page view and to every later event, including the custom `route_view` (`src/common/analytics/track.ts:48`). Nothing strips the query string. So the configured GA property receives live reset and one-time-login tokens.

Both tokens last 5 minutes. The reset token stays valid until the form is submitted (`auth-service.ts:370,407`). The callback page redeems the one-time token only when the browser is not already signed in (`dashboard/src/features/auth/pages/auth-callback-page/index.tsx:33`), so otherwise it stays live for its full 5 minutes.

`dashboard/docs/event-taxonomy.md` §6.1 describes the intended setup: `send_page_view: false` plus a `trackPageView()` that sends a sanitized location. That code was never written, so the docs and the code disagree.

**Fix:**
- In the bootstrap, set `send_page_view: false` and a `page_location` of origin + pathname (no query or hash). Update it on every route change through the existing route tracker, and send the one page view §6.1 describes.
- Replace the component comment: Enhanced Measurement page views must be **off**, since they read the raw URL.
- On the reset and callback pages, `history.replaceState` the token out of the address bar once it is read. On the callback, discard (or redeem) the token when already signed in instead of leaving it live.
- Tests: on `/auth/reset-password/?token=x` and `/auth/callback?oneTimeToken=x`, no `dataLayer` entry contains `token=` or `oneTimeToken=`.

The GA property's own settings (Enhanced Measurement, query-parameter redaction) are outside this repository; the closing record should say what each stream needs.

**Dedupe:** none open.
