# Account deletion leaves the user's OAuth grants and refresh tokens working

**Minor · backend-v2 · 15–20m · A3.** Found during w0/m4/t002 (2026-10-18).

`AccountService.deleteAccount` (`backend-cluster/backend-v2/src/features/auth/service/account-service.ts`) deletes sessions, the user row and the rest in one transaction, but not the OAuth provider's rows. The provider's `findAccount` (`features/oauth/api/oidc-route.ts:274`) returns an account even when the user is gone, so a deleted account's refresh token still mints access tokens for a user id that no longer exists, until the grant expires (up to a year for mobile).

**Fix:**
- Call `models.oauthGrant.revokeAllForUser(tx, userId)` inside the existing deletion transaction, beside `jwt.deleteByUserId`. The model shipped in w0/m4/t002.
- Test: after deletion the user's grants are gone, and another user's survive.

**Dedupe:** w0/m4 covers password reset only.

---

**Resolved 2026-10-18** — Deleting an account now revokes its OAuth grants, refresh tokens and provider sessions with everything else (`backend-v2`).

`AccountService.deleteAccount` (`backend-cluster/backend-v2/src/features/auth/service/account-service.ts`) calls `models.oauthGrant.revokeAllForUser(tx, userId)` inside the existing deletion transaction, beside `jwt.deleteByUserId`. A deleted account's refresh token is refused at the token endpoint, and a failed deletion rolls back the revocation with the rest.

Tests:
- `service/__tests__/account-service.test.ts`, new "revokes the user's OAuth grants in the deletion transaction": checks the user id and the same transaction as the user row's deletion. Removing the call fails it.
- `api/__tests__/account-deletion-parity.test.ts` (real REST and GraphQL transports) now records the `oauth` cleanup: in order after the sessions on success, not reached when billing cancellation fails, and restored when ledger-user deletion rolls the transaction back.

Gates: backend-v2 typecheck, eslint and knip pass; the auth suites pass. The full suite passes apart from the known environmental `upstream-survival.test.ts`.
