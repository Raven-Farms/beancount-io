# Meet the 24px target size for the ledger sidebar's inline actions and switcher

**Severity:** minor (accessibility; WCAG 2.2 SC 2.5.8 Target Size (Minimum), AA; axe `target-size`). **Estimate:** 40–55 minutes including a layout check at 390px. **Owner:** `dashboard` (`common/components/ui/sidebar.tsx`, `common/components/ledger-layout/ledger-switcher.tsx`). **A2:** the add-entry, account-search, and Reports-expand controls sit in every ledger page's sidebar and are hard to hit on touch and for users with limited dexterity.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `575a8798`. QA-owned headless Chromium, 1440×1000, light and dark, authenticated owner on a synthetic ledger. axe-core 4.13 `target-size` fails on all 16 ledger routes scanned (Overview, Journal, Accounts, all reports, Query, Files, Settings, Import, Budget, Ask, account page), with the same five nodes:

| control | size | note |
| --- | --- | --- |
| Journal row "+" (`aria-label="Add new journal entry"`, `data-sidebar="menu-action"`) | 20×20 | overlaps the Journal link row |
| Accounts row "Search accounts..." action | 20×20 | same |
| Reports row expand ("Reports") action | 20×20 | same |
| Ledger switcher combobox ("Select a ledger") | 199×20 | stacked against the owner link |
| Owner link (`/ledger/<owner>`) | 199×16 | 16px tall, adjacent to the switcher |

axe reports "insufficient size … and insufficient space to its closest neighbors" (safe clickable diameter 16–20px) for each.

## Root cause

`common/components/ui/sidebar.tsx:804` `SidebarMenuAction` uses `absolute top-1.5 right-1 … aspect-square w-5` (20px), inside a menu row whose own button fills the remaining width, so the spacing exception doesn't apply. `ledger-switcher.tsx:77` and `:230` render the owner as a bare `text-xs` link (16px line box) directly above a 20px-tall switcher trigger.

## Fix

Raise the menu-action hit area to at least 24×24: `size-6` with the icon at `size-4`, or an invisible padded hit area with `after:` inset, and adjust `top`/`right` and the row's `pr-8` padding so labels don't collide. Give the owner link and switcher a ≥24px block size (padding/min-h), or enough vertical spacing to satisfy the 24px-circle spacing exception. Keep collapsed icon mode (`group-data-[collapsible=icon]`) and the w5/m2 dashboard-sidebar targets unchanged.

Acceptance: axe `target-size` passes on the 16 ledger routes in both themes. The sidebar still fits at 390px and in collapsed icon mode. Keyboard focus rings remain visible. Dashboard gates pass.

## Dedupe

w5/m2 (done) brought the `/ledger` dashboard home's ledger rows to 24px, not the per-ledger layout sidebar. w4/223 (forced-colors focus) and w3/m39 (landmark/skip link) cover other sidebar concerns. Searched `.pm/**` for target size, 2.5.8, 24px, menu-action, and ledger-switcher: no item.
