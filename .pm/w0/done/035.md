# New Transaction's "Add posting" row shows two plus signs: an add icon followed by a literal "+ " in the label

**Minor · mobile · 10–15m · A2.** Native mobile QA, 2026-10-15, `main` at `22aec290`, development build `io.beancount.ios` (JS `1.20261002.50`) on iPhone 17e / iOS 26.5, light theme, English, default text size. Authenticated production session at `https://beancount.io/` with the dedicated QA account, on a synthetic ledger the account can write. The form was opened and discarded; nothing was saved.

## Repro

1. Select a ledger you can write, then on **Home** tap **+** → **Enter new transaction**.
2. Below the postings, the action row reads **⊕ + Add posting**: a green `add-circle-outline` icon, then a second "+" typed into the text.
3. With VoiceOver, the row's name is announced as "plus Add posting", because the accessibility label reuses the same string.

**Expected:** one plus mark. The icon is enough, as on the app's other add actions (for example the drawer's **+ New**, which draws its plus as an icon and has no plus in its text).
**Actual:** icon plus "+ " prefix, in every locale.

## Root cause

- `mobile/src/screens/multi-postings-transaction/multi-postings-transaction-screen.tsx:685–698` renders `<Ionicons name="add-circle-outline" …/>` and then `<Text>{t("addPosting")}</Text>`, with `accessibilityLabel={t("addPosting")}`.
- `addPosting` begins with `"+ "` in all 13 locale files (`mobile/src/translations/{en,zh,bg,ca,de,es,fa,fr,nl,pt,ru,sk,uk}.ts`), e.g. `en.ts:171` `addPosting: "+ Add posting"` and `zh.ts:160` `"+ 添加分录"`. The icon was added to the row, but the old text prefix stayed.

## Fix

Drop the leading `"+ "` from `addPosting` in all 13 locales. The icon stays the only plus, and the accessibility label becomes "Add posting". Optionally extend `src/__tests__/accessibility-labels.test.ts`, or add a small translation test, asserting that action labels paired with an add icon do not start with `+`. Mobile only.

## Blast radius

`addPosting` has one consumer: the row above, which renders in both New Transaction and Edit Transaction (same screen component). No other key starts with `"+ "` next to an add icon (`grep '"+ ' src/translations/en.ts` returns only this key).

## Dedupe

Searched `.pm/**` for "Add posting", `addPosting` and "plus". [w3/156](../../w3/done/156.md) touches the same screen (the auto-balance toggle), not this label. No open or completed item covers it.

## Unverified

Edit Transaction (same component, not opened); RTL layout in Persian; VoiceOver speech was inferred from the label string, not listened to.
