## Objective

Make the script idempotent: on a tree that is already in sync it writes no file, so running it produces an empty diff.

## Context

- Today a run rewrites catalogs wholesale; the output formatting differs from the repository's Prettier style.

## Steps

1. Write a catalog only when its keys or messages change.
2. Emit Prettier-compatible output (or run Prettier on written files).
3. Check by running it twice on `main`: no diff.

## Files

- dashboard/scripts/prepare-translations.ts

## Acceptance criteria

- [x] `yarn i18n:prepare` on `main` leaves `git status` clean.

## Out of scope

- Changing catalog formatting conventions.

## Done (2026-10-17)

A run on `main` already wrote nothing after t001, because a catalog with no key changes is skipped. The run that does change something was the problem: `writeTranslations` regenerated each touched catalog alphabetically in its own format. 497 of 645 catalogs are not alphabetical, so one new key would have rewritten whole files.

Writes are now surgical (`scripts/lib/sync-locale.ts` `editCatalogSource`, the script's `saveCatalog`):
- Removed entries are cut out.
- Added entries are inserted after their nearest neighbour in the locale's expected order, at the file's own indent (including catalogs Prettier wrapped to 4 spaces).
- Every other byte stays as it was, and the result goes through the repository's Prettier config. A missing catalog is still generated, now in English order.
- Aggregate catalogs (`ledger-editor`, `reports`, …) spread sub-feature catalogs in. The sync now considers only the keys a file writes out itself (`ownCatalogKeys`), so a spread-in key is added to its sub-feature's file, not inlined into the aggregate.
- The English step (`addMissingKeysToEnglish`) writes the same way.

Checked on the real tree:
- Clean `main`: no file changed.
- With one new English journal key and one Russian `_few` deleted, the run added exactly one 5-line entry to each of the 14 locales and restored the Russian `_few` as `[TODO]` in its original slot. Nothing else moved, and every written file is Prettier-clean.
- A third run wrote nothing.

`scripts/__tests__/sync-locale.test.ts` adds 5 cases: cut, neighbour insert, first-in-object, wrapped indent, and own keys of an aggregate. Disabling neighbour insertion fails 2 of them.

Gates: dashboard `format:check`, `lint`, `test` and `build` pass.
