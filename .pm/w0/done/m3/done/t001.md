## Objective

Teach the sync step that a key family with plural suffixes expands per locale: keep each locale's CLDR categories, never delete `_few` / `_many` where the language has them, and never add `_one` where it does not.

## Context

- `dashboard/scripts/prepare-translations.ts` `syncTranslations` (~:175–230) adds missing and removes extra keys by comparing against `en.ts` key sets.
- English plural families use `_one` / `_other`; `Intl.PluralRules(locale).resolvedOptions().pluralCategories` gives each locale's categories (ru, uk, sk: one/few/many/other; zh, ja, ko: other).

## Steps

1. Group keys by plural family (base + CLDR suffix).
2. Compute each locale's expected keys from the family and its plural categories.
3. Add and remove only against that expected set.
4. Unit-test: Russian keeps few/many, Chinese gets no `_one`, a non-plural key still syncs.

## Files

- dashboard/scripts/prepare-translations.ts
- dashboard/scripts/__tests__/ (or the package's script test location)

## Acceptance criteria

- [x] Running the sync on `main` neither removes Russian/Ukrainian/Slovak plural keys nor adds Chinese/Japanese/Korean `_one` keys.
- [x] Tests cover each case.

## Done (2026-10-17)

The sync now lives in `dashboard/scripts/lib/sync-locale.ts` (`syncLocaleEntries`). It builds each locale's expected keys from English. A plural family (`<base>_<category>` with a `<base>_other`) expands into the categories the locale uses, from `src/i18n/plural.ts`'s `pluralCategories` (`Intl.PluralRules`) and `PLURAL_SUFFIX`, the same source `plural.test.ts` checks catalogs against. The script adds and removes only against that set:
- Russian, Ukrainian and Slovak keep `_few` and `_many`.
- Chinese, Japanese and Korean get only `_other`, and a stray `_one` is removed.
- A missing form is added as `[TODO] <English _other>`.
- A suffix-like key without an `_other` sibling stays a plain key.

Deviation: the script's hand-kept `TARGET_LOCALES` had fallen behind `src/i18n/config.ts` and never synced or reported Japanese or Korean. It is now derived from `SUPPORTED_LANGUAGES`.

Evidence:
- Running `scripts/prepare-translations.ts` on `main` now reports every catalog in sync and leaves `git status` clean (before: 88 rewritten files).
- `scripts/__tests__/sync-locale.test.ts` (10 cases) covers Russian, Ukrainian and Slovak keeping their forms, a missing Russian form, Chinese, Japanese and Korean, a stray Chinese `_one`, plain keys and the sibling rule. Comparing key sets with English again fails 8 of them.

Gates: dashboard `format:check`, `lint`, `test` and `build` pass.
