## Objective

Make sure the refusal is covered by meaningful tests: each surface refuses a write that adds an error, commits it with `allowInvalid`, and leaves clean writes unchanged; client forms show the refusal. Tests must fail if the refusal is removed.

## Done (2026-10-17)

Coverage of the refusal, by layer. Each test was checked against a reverted or weakened fix and fails there.

- **Ledger service** (`src/api/__tests__/entries-new-errors.test.ts`, `utils/__tests__/new-ledger-errors.test.ts`):
  - A duplicate `open` is refused with nothing committed.
  - `allowInvalid` commits it.
  - A clean write commits without a second parse of today's ledger.
  - Errors the ledger already had are not blamed on the write.
- **backend-v2** (`structured-entry-parity.test.ts`):
  - Refusal on REST, GraphQL and MCP, with `newLedgerErrors` in REST `error.metadata` and in the GraphQL error metadata Apollo merges into `extensions`. MCP carries the hint naming `allowInvalid`.
  - `allowInvalid` records the write on each surface.
  - Clean writes are unchanged ("builds identical directives across surfaces").
  - New in t006: `mcp-errors.test.ts` pins the mapping's metadata, and the count taken from the ledger's details (plural wording for two errors). `directive-text-contract.test.ts` pins the text path's `newLedgerErrors`.
- **Mobile** (`src/common/__tests__/ledger-refusal.test.ts`):
  - `describeLedgerRefusal`, and `runLedgerWrite` toasting it, for New Transaction, Edit Transaction, Add Transaction and Transaction Detail.
  - New in t006: `ledgerWriteFailureMessage`, now the one failure line of the Open Account and Add Budget hooks. jest-lite cannot load the hooks themselves; this keeps their logic under test.
- **Dashboard:**
  - `error-message.test.ts` covers the detail reader and `useErrorMessage`.
  - New in t006: `open-account-would-break.test.tsx` renders both Open Account surfaces (the Accounts page dialog and New Entry's Account tab) against a refusing mutation. Each shows "This would add an error to your ledger: …", keeps the draft and does not close.
