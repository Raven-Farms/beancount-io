## Objective

Check the change is usable everywhere it shows: the dashboard login, and any other password sign-in page (including the OAuth sign-in the mobile app opens), shows the new refusal as a readable, translated message (not a generic error); Git clients get a 429 with a plain-text reason; `deploy/AGENTS.md` and each shipped target's env example document `TRUSTED_PROXY_HOPS` with the right value for its proxy. Flag drift as follow-up work.

## Done (2026-10-18)

Walked every surface the change shows on:
- **Dashboard password sign-in.** The login page, both OAuth consent pages and the mobile consent page, which is the OAuth sign-in the app opens, all go through `useLoginForm`. A `RATE_LIMITED` refusal there used to show the shared "Too many requests. Please wait a moment and try again.", which understates a 15-minute account budget and does not name the way out. It now shows the new `auth.loginRateLimited`: "Too many sign-in attempts. Wait a few minutes and try again, or reset your password." The message is in all 15 locales, in each catalog's own login and reset wording. The decision is the new pure `signInRefusalKey` (`dashboard/src/features/auth/hooks/use-login-form.ts`), tested in `hooks/__tests__/use-login-form.test.ts`. Other refusals still go through the shared messages.
- **Git clients** get `429` with the plain-text reason "Too many failed sign-in attempts for this account. Try again later, or reset your password." (t002).
- **Deploy.** `TRUSTED_PROXY_HOPS` is set in each Compose target's backend-v2 environment and documented in its `.env.example`:
  - `1` behind Caddy (`docker`, `docker-single-psql`);
  - `0` where browsers reach the published backend port directly (`docker-mac`, `dev-sandbox`).

  bex (Traefik) uses the default of 1. `deploy/AGENTS.md` explains the setting and what one too many or one too few hops does. `docker compose --env-file .env.example config --quiet` passes for all four targets, and `scripts/check-agent-guidance.py` passes.

Gates: dashboard `format:check`, `lint` (including `i18n:check`), `test` (6088) and `build` pass.
