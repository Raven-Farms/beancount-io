# Name each Budget history Delete button after the directive it removes

**Severity:** minor (accessibility; WCAG 2.4.6 Headings and Labels). **Estimate:** 15–25 minutes. **Owner:** `dashboard` (`features/ledger-data/budget/budget-history-table.tsx`). **A2:** a screen-reader or voice-control user on a ledger with several budgets hears a list of identical "Delete" buttons, with nothing to tell them which budget each one removes.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `575a8798`. QA-owned headless Chromium, owner of a ledger with two budget cards and three dated budget directives. Read-only: no Delete was activated.

`/ledger/<owner>/<ledger>/budget` exposes three buttons whose accessible name is exactly **"Delete"** (`aria-label="Delete"`, no `aria-describedby`), one per history row across two cards. The accessibility tree gives no account, date, or amount for any of them. `getByRole('button', { name: 'Delete' })` matches all three.

## Root cause

`budget-history-table.tsx:~111` sets `aria-label={t("common.delete")}` on every row action.

## Fix

Use a localized, row-specific name such as "Delete budget for Expenses:Health:Life:GroupTermLife, 2026-08-27, 122 USD monthly" (a new interpolated key in all 15 locales), or keep "Delete" and reference the row's cells via `aria-describedby`. Keep the visible icon/label and the confirmation dialog unchanged.

Acceptance: each Delete control's accessible name identifies its directive, and names are unique on a page with duplicate-looking rows (append the row index if the account, date, and amount repeat). A component test asserts the names. Dashboard gates pass.

## Dedupe

w4/m20 (done) named the Budget history *tables*, and its public-reader repro saw no Delete controls. Searched `.pm/**` for budget delete, row action names, and `common.delete`: no item.

---

**Resolved 2026-10-15** — Each Budget history Delete button is now named after its directive ("Delete budget: <account>, <date>, <amount>, <interval>"), with the row's position appended when other rows read the same, in all 15 locales; the visible icon and confirmation dialog are unchanged. A component test asserts the names, their uniqueness, and that the named button deletes its own row; it fails on the previous table.
