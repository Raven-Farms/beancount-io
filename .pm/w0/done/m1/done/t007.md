## Objective

Make sure the new guard asserts real behavior: synthetic catalogs with an identical English message, an allowlisted invariant, a stale allowlist entry, and a correctly translated message.

## Acceptance criteria

- [x] Unit tests for the scan helper cover each case and fail if the identical-message check is removed.
- [x] Dashboard gates pass.

## Done (2026-10-17)

New `dashboard/src/test/locale-scan.test.ts` runs the whole-copy guard's helpers on synthetic catalogs.

`untranslatedAgainstEnglish` with `untranslatedWholeMessage`:
- A message copied from English whole is reported with its English words.
- A correctly translated message passes.
- A copy that is only brand, format or notation (`Plaid`, `CSV · PDF`) passes.
- An allowlisted invariant is skipped, and only that key.
- Keys English lacks and a missing catalog are ignored.

`staleIdenticalEntries`:
- A still-identical entry is kept.
- An entry the locale now translates is reported.
- An entry whose key or locale no longer exists is reported. That last case was a gap: a key removed from both the locale and English compared `undefined === undefined` and lingered. The helper now treats a missing message as stale.

Neutralising the identical-message check in `untranslatedWholeMessage`, together with the stale-check fix, fails 4 tests (both synthetic whole-copy cases, the removed-key case, and the existing unit test). With the code restored, all pass. Dashboard format, lint, test (5818) and build pass.
