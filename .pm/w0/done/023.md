# Explain that ledger names need Latin letters or digits when a non-Latin name is rejected

**Severity:** minor (i18n). **Estimate:** 20–30 minutes (copy in 15 locales, plus an optional example of the derived name). **Owner:** `dashboard` (`features/ledger-list/components/ledger-form.tsx`). **A2:** the app ships in Chinese, Japanese, Korean, Russian, Ukrainian, Bulgarian, and Persian. A user in any of them who names a first ledger in their own script is told the name has "no letter or number", which is false.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `575a8798`. QA-owned headless Chromium, en-US, authenticated owner on `/ledger` → **Create Ledger**. A request guard aborted every mutation, so no ledger was created.

- Name `ÄÖÜ` → Save shows **"Name must contain at least one letter or number"**. No repository-name preview is shown and no request is sent.
- The same rule rejects any all-non-ASCII name (`我的账本`, `Счета`, `دفتر`). It's source-traced to the same function; only `ÄÖÜ` was typed live.
- Control: `Café Ledger` → preview "Repository name: `caf-ledger`" (the é is silently dropped but visible).

## Root cause

`ledger-form.tsx:32–43` `slugifyLedgerName` keeps only `[a-z0-9_-]`, mirroring the backend's repository-name rule. The schema at `:66–80` rejects an empty slug with `page.dashboard.nameInvalid` ("Name must contain at least one letter or number"). The rule is ASCII-only, but the message says "letter".

## Fix

Change `page.dashboard.nameInvalid` in all 15 locales to say what is actually required, e.g. "Use at least one Latin letter (a–z) or digit — the name becomes the ledger's web address", ideally with an example. Optionally show the derived address for partial matches (already done) and suggest a romanized name. Don't change the backend slug rule here.

Acceptance: an all-non-ASCII name shows the accurate message in English, Chinese, and Russian. `Café Ledger` still previews `caf-ledger`. A form test covers the empty-slug case. Dashboard gates pass.

## Dedupe

Searched `.pm/**` for ledger name, slug, `nameInvalid`, repository name, and create ledger. w4/041 (mobile create-ledger preview) and w4/136 (signup username limits) are different forms. No item covers this message.

---

**Resolved 2026-10-15** — `page.dashboard.nameInvalid` now states the real rule — "Use at least one Latin letter (A–Z) or digit: the name becomes the ledger's web address." — in 15 locales, instead of telling a Chinese, Russian or Persian name it has no letters. The slug rule is unchanged. `ledger-form.test.tsx` adds an all-Chinese-name case. Shipped in the commit that moved this note to `done/` (`dashboard`).
