## Objective

Add meaningful tests for what this milestone shipped: pre-reset sessions and OAuth tokens are refused after a reset, post-reset ones work, other users are unaffected, and a failed password update revokes nothing. Reverting the revocation calls must fail them. No tautological or snapshot-everything tests.
