# Give the Upload Receipt route a document title

**Severity:** minor. **Estimate:** 30–40 minutes (15 locale entries, route wiring, a stronger route test). **Owner:** `dashboard`. **A2:** every ledger tab, history entry, and screen-reader page announcement should name the page and ledger. Receipt upload is the only ledger leaf page that doesn't.

## Live reproduction

Production `https://beancount.io`, 2026-10-15. Local main `575a8798`. Headless isolated Chromium, 1440×1000, English, authenticated QA owner, synthetic ledger, read-only.

Open `/ledger/<owner>/<ledger>/receipt`. The page renders "Upload Receipt", yet `document.title` is the site default `Beancount.io`. Reproduced on two fresh loads. Controls on the same ledger: `/import` → `Smart Import - <ledger>`, `/link` → `Connected Accounts - <ledger>`, `/files/upload/main` → `Upload Files - <ledger>`, `/entry/<hash>` → `Entry - <ledger>`, `/pull/1` → `Pull Request #1 - <ledger>`. A sweep of every other ledger route found no further title gaps.

## Root cause

`dashboard/src/routes/ledger.$ledgerOwner.$ledgerName.receipt.tsx` sets `head: createNoIndexHead`, which emits only a robots meta and no `title`. The completed route-metadata regression test (`routes/__tests__/ledger-route-head-metadata.test.ts`, from w3/m38) only checks that a `head:` property exists, so a robots-only head passes.

## Fix

Add `seo.ledgerReceipt.title` (`Upload Receipt - {ledgerName}`) and a description to all 15 SEO locale files. Wire the route through `createHeadMeta(getSEOMetadata(…))` like `import.tsx`/`link.tsx`, and keep `noindex` (this is an owner-only upload screen). Tighten the regression test so each leaf ledger route's head produces a `title` entry, not just a `head:` key.

Acceptance: `/receipt` shows `Upload Receipt - <ledger>` in the tab and keeps `robots: noindex`. The strengthened route test fails if any leaf ledger route omits a title. Locale shape tests and dashboard gates pass.
