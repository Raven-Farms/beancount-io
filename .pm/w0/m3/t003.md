## Objective

## Context

- Dashboard CI: `.github/workflows/ci-dashboard.yml` runs `yarn format:check`, `yarn lint`, `yarn test`, `yarn build`.

## Steps

1. Implement `--check` with no writes and a readable list of offenders.
2. Wire it into an existing CI step (a script in `yarn lint` or a vitest wrapper).
3. Add fixtures that fail each way.

## Files

- dashboard tests

## Acceptance criteria
