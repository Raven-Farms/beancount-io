# Budget "This year" headline describes a future month, and "Last 12 months" prorates the current one

**Severity:** minor. **Estimate:** 40–55 minutes. **Owner:** `dashboard` (`features/ledger-data/budget/budget-chart-card.tsx`, `index.tsx`). **A2:** each Budget card's headline (current budget / latest actual / variance and badge) should describe the current period. It currently depends on which time-span pill is selected, and with "This year" it describes December.

## Live reproduction

Production `https://beancount.io`, 2026-10-15 (today), local main `575a8798`. QA-owned headless Chromium, en-US, the QA owner's own ledger, which has a `Monthly 122 USD` budget dated 2026-08-27. Read-only.

On `/ledger/<owner>/<ledger>/budget`, the same card under each **Time span** pill reads:

| pill | Current budget | Latest actual | Variance |
| --- | --- | --- | --- |
| All time / This year | 122 USD | 0 USD | Below target −122 USD |
| Last 12 months | **59.032 USD** | 0 USD | Below target **−59.032 USD** |

API control, using the card's own `getLedgerIntervalTotals` (monthly, at_cost):

- `time: "year"` returns 12 buckets ending **2026-12-31**. The headline uses the last bucket, so "latest actual" and variance describe **December 2026**, a month that hasn't started. Any October spending never reaches the headline.
- The "Last 12 months" range (`2025-10-16 - 2026-10-15`) returns 13 buckets, the last ending **2026-10-15**. `calculateBudgetForInterval` prorates that bucket by day (15/31 × 122 = 59.032) and labels it "Current budget", next to a history row that says `Monthly 122 USD`. The first bucket (2025-10-16..31) is partial too.

## Root cause

`budget-chart-card.tsx` (~157–193) takes `chartData[chartData.length - 1]` as the "latest" period for both `latestActual` and `comparisonBudgetValue`. For the calendar-year filter (`index.tsx:154–164`, `"year"`) that bucket is in the future. For the rolling range, the window clips the last bucket, so the daily proration in `budget-utils.ts:166–195` yields a partial-month target presented as the period budget.

## Fix

Define the headline period explicitly: the interval containing today, clipped to the selected span. For a past span (Last year), use the span's last full interval, as w4/184 already handles. Never choose a bucket that starts after today. Show the full period target ("122 USD / month") with a "to date" qualifier when comparing partial-period actuals against a prorated target, rather than a bare 59.032. Format amounts at currency precision (see w0/010). Align the rolling window to interval boundaries, or label the partial edges.

Acceptance: on 2026-10-15, This year, All time, and Last 12 months all headline **October 2026** for a monthly budget, with the same target semantics. Last year headlines its final period. Unit tests pin the headline period for calendar-year, rolling, and past ranges with a fixed "today". Dashboard gates pass.
