# Sign-in discovery has no timeout: Sign In spins for about 60 s on an unreachable server, and fixing the URL meanwhile doesn't release it

**Severity:** minor-to-moderate. Test connection gives up after 8 s and says the URL can still be saved and tried. Sign In then waits about 60 s with Sign In and Sign Up disabled. Changing the server during the wait doesn't help, and the late failure ("Could not reach that server") refers to the old URL. **Estimate:** 20 minutes. Owner: mobile. A3: `discoverOAuthServer` runs with no abort signal (React Native's XHR timeout is 0), and `running.current` and the in-flight launcher promise block new attempts.

Code-level at `main` `709af935d`. A repro is `docker compose pause backend-v2` on docker-mac.

## Where (`mobile/src/`)

- `common/oauth/start-authorization.ts:17`
- `common/oauth/discovery.ts:97`
- `…/use-native-sign-in.ts:33`
- `app/auth/welcome/index.tsx:124`

## Fix

Give discovery the same 8 s `AbortController` timeout as Test connection. Abort an in-flight attempt when the server URL changes, and attribute errors to the URL they were for.

**Acceptance:** with backend-v2 paused, Sign In fails within about 8 s with a timeout message. Changing the server re-enables Sign In immediately.
