# Commit detail has no "commit not found" state, and a missing sha renders a blank title over "No diff available"

**Severity:** minor. **Estimate:** 15 minutes. Owner: mobile.

Code-level at `main` `c3ec33b97`: `mobile/src/screens/commit-detail-screen/commit-detail-screen.tsx:210-237`.
- With no `sha` (for example `beancount:///commit-detail`), the query is skipped. The title is `""` and the body says "No diff available.", which looks like a real empty commit.
- An unknown or rewritten sha (a stale Latest Updates row after a force push) shows a generic `CardLoadFailure` whose Try Again can never succeed.

The server's exact answer for an unknown sha wasn't checked.

## Fix

Redirect when `!sha`, as w4/034 did for the file editor. Map NOT_FOUND to a "This commit no longer exists" state, as w21/013 did for entries.

**Acceptance:** a missing sha redirects, and an unknown sha shows the not-found state. Unit or source checks cover both.

w4/034 covers missing params for the file editor and add-transaction-next only, and w2/049 the ledger binding. Searched `.pm/**` for commitDetailNoDiff, and getCommitDetails together with NOT_FOUND.
