# Browse ledgers' "Try again" after a failed load shows "Your ledgers will appear here…" (a false empty state) while the retry runs

**Severity:** minor. **Estimate:** 10 minutes. Owner: mobile. A3: with the real `DiscoveryStore` under `tsx`, a failed first load gives `{loading:false, error:true, items:0}`. The footer's Try again calls `load(tab, q, true)`, and in flight the snapshot is `{loading:false, refreshing:true, error:false, items:0}`, so `ListEmptyComponent` (`ledger-selection/index.tsx:368-389, 404-414`) shows the empty copy and an Explore link. On Yours that reads "Your ledgers will appear here. Explore public ledgers to get started." for the whole retry, with no client timeout. A failed pull to refresh with rows already shown leaves only a bare "Try again" link, with no message.

Code-level at `main` `c8b7b6ea2` (`discovery-store.ts:94-101`). Not run natively.

## Fix

Show the skeleton while `items` is empty and `refreshing` is true, or keep `error` until the retry settles. Show the load-error text beside the footer Retry.

**Acceptance:** a retry from the error state never shows the empty-state copy.
