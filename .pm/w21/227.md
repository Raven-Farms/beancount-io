# Once the persisted cache passes 1 MiB, it is deleted and never saved again for the rest of the session

**Severity:** moderate. The next offline or failing launch has nothing cached: "Failed to load" and an empty drawer. That undoes what w21/006 and w21/066 rely on. **Estimate:** 30 minutes. Owner: mobile. A3: `apollo3-cache-persist` 0.15 deletes the stored cache and sets `paused = true` when a write pushes it past `maxSize`. Nothing in the app ever calls `resume()` or `persist()` afterwards, so even after the large entry is evicted, nothing is written again until the app restarts. A single large read is enough: the file editor caches `getLedgerFile` content, and w21/186 notes that `main.bean` naturally grows past 1 MiB.

Code-level at `main` `7e42f850e`. A reviewer reproduced it in Node with a real `InMemoryCache` and `CachePersistor` using the app's options, on a Map-backed store:
- small cache: saved (150 bytes)
- after a 1.1 MB `getLedgerFile` write: storage deleted
- after evicting it, cache back to 243 bytes: storage still empty, `paused: true`
- after `purge()` and new writes: still empty

## Root cause

`mobile/src/common/apollo/cache-persist.ts:14` and `:55-59` set `maxSize: APOLLO_CACHE_MAX_SIZE` (1 MiB) with no `persistenceMapper` and no resume path.

## Fix

Keep large fields out of the persisted snapshot, using a `persistenceMapper` that drops `getLedgerFile` content and other oversized fields, so the cap is never hit by one file. If the cap is still exceeded, call `persist()` again once the cache shrinks, or `resume()` after a successful write below the cap. Check the escaped size inside the server-scoped wrapper against Android's AsyncStorage row limit.

**Acceptance:**
- After opening a 1.1 MB file and going back, the cache is saved again on the next write.
- A relaunch with the network off renders Home from the cache.
- A unit test with the real persistor covers this.

## Dedupe

w21/blocked/065 mentions the 1 MiB cap only as a guessed cause of a UI stall, and doesn't cover persistence stopping. w21/006 and 066 rely on the persisted cache. Searched `.pm/**` for maxSize, "1 MiB", paused and cache-persist.
