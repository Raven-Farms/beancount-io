# Create Ledger's opening balance hinges on a hidden account choice: silently dropped under "Decide later", or carried over from a previous preset

**Severity:** moderate. A typed opening balance is lost without a word, or creation fails with a raw English server error the user can't fix from the form. **Estimate:** 45 minutes. Owner: mobile.

Code-level at `main` `cd02f5446`. Not exercised natively: the in-form "Back" button sits below the fold, and the automation has no scroll. The header back exits the flow, and the resumed draft keeps `openingAccount` while clearing the amount.

## Scenario

- **A:** Preset → Personal, leave "Decide later" (the default), type 2500 → Next → Create. The amount is discarded because no account was chosen, and Review never shows it.
- **B:** Personal → Assets:Cash + 1000 → Back, Back → Portfolio → Next. No opening account is highlighted, but `openingAccount` is still `Assets:Cash`. Review shows the raw server text `Account "Assets:Cash" is not part of preset…`, and Create gives "Couldn't create the ledger. Please try again." on every retry.
- **C:** the same steps, but choose Blank. The opening section is hidden, yet the ledger is created with Assets:Cash, Equity:OpeningBalances and the 1000 opening balance.

## Root cause

- `mobile/src/screens/create-ledger-screen/create-ledger-screen.tsx:307` sends accounts only if `amount && values.openingAccount`.
- `:479` changes the preset without resetting `openingAccount`.
- `:640-665` always shows the amount field, even under "Decide later".
- `backend-cluster/backend-v2/src/features/ledger/setup/build-ledger.ts:113-118` rejects an account outside the preset.

## Fix

- Reset `openingAccount` (and the amount) whenever the preset or template changes.
- Disable or hide the amount field until an account is chosen, or require one when an amount is typed.
- Show the chosen account and amount on Review.
- Map the "not part of preset" error to a localized message.

**Acceptance:** none of A, B or C can reach Create with a hidden or stale opening account. Review lists the opening line when one will be written.
