# A file app link that names a branch other than main opens main's file, editable

**Severity:** minor. **Estimate:** 10 minutes. Owner: mobile. A3: `resolve-app-link.ts` drops the branch segment of `files/blob/<branch>/<path>`. `…/files/blob/feature-x/main.bean` resolves to `/ledger-file-editor?path=main.bean`, and Save is enabled when the ledger is writable. The dashboard deliberately 404s any branch other than main (`supported-branch.ts`, w4/281), so that it never shows main's content, or writes to main, under a URL naming another branch.

Code-level at `main` `99c937e0e`. Not run natively.

## Fix

When the branch is not `main`, open the link in the browser, matching the dashboard.

**Acceptance:** a `files/blob/feature-x/…` link never opens the editor on main's file.

## Dedupe

Not w21/199, which is about a different ledger, not a different branch. Related to w4/281. Searched `.pm/**` for "SUPPORTED_BRANCH" and "files/blob".
