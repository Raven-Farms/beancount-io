# The README's "Try the live demo — no sign-up" link sends a signed-out app user to sign in, although the app can show that ledger as a guest

**Severity:** moderate (A2: the first-run demo path). **Estimate:** 30 minutes. Owner: mobile. A3: `README.md` links `https://beancount.io/ledger/open_ledger/example/income-statement?…`, which rewrites to `/reports`. While signed out, `pending-app-link.ts` stashes the link and `app/(app)/_layout.tsx` redirects to `/auth/welcome`. The link only replays after the user signs in. Yet `open_ledger/example` is a curated guest example (`src/common/guest/guest-state.ts`) that the `/examples` routes show without an account (w4/m29).

Code-level at `main` `99c937e0e`. Not run natively; see w21/344 for why.

## Fix

When the user is signed out and the target is a curated guest example on the hosted server, open the matching `/examples/(tabs)/…` route in guest mode instead of stashing the link.

**Acceptance:** with the app signed out, the README demo link opens the example's Reports in guest mode.
