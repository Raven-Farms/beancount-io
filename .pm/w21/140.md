# VoiceOver on transaction rows omits the narration line and always says "Pending" in English

**Severity:** minor-to-moderate (accessibility). Rows that look different (same payee, different narration) sound identical, which undoes w4/048 for VoiceOver users, and German VoiceOver says "Pending" instead of "Offen". This affects Transactions, Home Recent Transactions, the Reports account card and merchant detail. **Estimate:** 15 minutes. Owner: mobile. A3: the label builder takes name, amount and pending only. The narration line was added a day before the label shipped and wasn't included, and `EntryRow` never passes `pendingLabel`, so the English fallback is used. `AccountEntryRow` already passes `t("pending")`.

Code-level at `main` `aa4a9793a`.

## Where

- `mobile/src/screens/transactions-screen/entry-row/entry-row-accessibility-label.ts:16` (`options.pendingLabel ?? "Pending"`)
- `entry-row/index.tsx:236-244`, with no narration and no `pendingLabel`

## Fix

Add the narration (when present and different from the name) to the label, and pass `pendingLabel: t("pending")`. Remove the English default so a missing label fails type-checking.

**Acceptance:**
- In de, a pending row reads "…, Offen".
- Two rows with the same payee and different narrations are read differently.
- Update the label builder test.
