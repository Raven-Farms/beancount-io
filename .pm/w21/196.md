# Create file, then switch ledger before it finishes: the editor opens that path in the other ledger

**Severity:** minor-to-moderate. The "Created qa-race.bean" toast fires, then the editor shows "File unavailable" in ledger B, while the file exists in ledger A. If B has a file at the same path, the user edits and saves *B's* file. **Estimate:** 15 minutes. Owner: mobile. A3: the create completion pushes the editor with only `path`. The editor takes its ledger from the global selection, and nothing checks whether the selection changed while the request was in flight.

Code-level at `main` `7fa4c4682`.

## Where

`mobile/src/screens/ledger-file-browser-screen/index.tsx:391-435` (push at `:421-427`) and `mobile/src/screens/ledger-file-editor-screen/index.tsx:300, 317-324`.

## Fix

Capture the ledger ID when the create starts. On completion, skip the navigation if the selection changed, or pass the ledger ID explicitly to the editor route.

**Acceptance:** with a 3 s delay, Create → switch ledger: no editor opens in the new ledger, and the toast names the original ledger.
