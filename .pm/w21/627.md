# At AX2, New Transaction's posting accounts wrap mid-word ("Assets:Bank:Checkin / g", "Expenses:Food:Groc / eries"), the follow-up named in w21/029

**Severity:** low (readability at the supported AX2 ceiling). **Estimate:** 15 minutes. Owner: mobile. A3: w21/029 let the stacked `PostingRow` account wrap onto two lines. Each account name is one unbroken token, so iOS breaks it at the line end, mid-word. w21/029's 2026-10-21 recheck suggested a follow-up (zero-width break opportunities after each `:`, or the last component on its own line), but nothing was filed.

Native (iPhone 17e at `92911d8be`, AX2 `accessibility-large`, restored to `large`): Home ▸ + ▸ Enter new transaction shows "Assets:Bank:Checkin" / "g" and "Expenses:Food:Groc" / "eries".

## Fix

Insert `\u200B` after each `:` in the displayed name (keeping the stored name unchanged), so lines break at component boundaries.

**Acceptance:** at AX2 the names wrap as "Assets:Bank:" / "Checking" and "Expenses:Food:" / "Groceries". A unit case covers the display helper.
