# Open Account and Add Budget drop typed input on Back without asking (New Transaction, Edit and the file editor ask first)

**Severity:** low, product call. **Estimate:** 15 minutes. Owner: mobile. A3: only `multi-postings-transaction-screen.tsx`, `edit-transaction-screen.tsx` and `ledger-file-editor-screen/index.tsx` register an unsaved-changes guard (`usePreventRemove`). `open-account-screen.tsx` and `add-budget-screen.tsx` don't.

Native (iPhone 17e at `47c043676`): Accounts ▸ + ▸ type an account name ▸ Back returns to Accounts at once, with no "Discard your changes?". Code-level for Add Budget. Both forms are short, so this may be intended. It's inconsistent with the other write forms.

## Fix

Either add the same guard when the form is dirty, or record that short forms deliberately skip it.

**Acceptance:** dirty Open Account and Add Budget forms ask before discarding (or a recorded decision says they don't).
