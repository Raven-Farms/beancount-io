# A signed-out journal link with filters (?account=, ?time=) opens the guest example unfiltered (w21/344 + w21/345 gap)

**Severity:** low-to-moderate. **Estimate:** 15 minutes. Owner: mobile. A3: `guestLinkVisit` (`mobile/src/common/app-links/guest-link-visit.ts:24-30`) returns only `{ ledgerId, view }`, and `use-app-link-handler.ts:118` passes just that to `updateGuestVisit`; the guest session starts its filters empty (`screens/examples/example-ledger-provider.tsx:81`). Signed-in links apply them (`open-app-link.ts:106-107`, w21/344), but w21/345's guest path never received them.

Code-level at `main` `e8b5e15a8`. In the reviewer's tsx run, `resolveAppLink` on `https://beancount.io/ledger/open_ledger/example/journal?account=Expenses:Food` gives `filters: {account: "Expenses:Food", …}`, but `guestLinkVisit` returns `{"ledgerId":"open_ledger/example","view":"transactions"}`. Not exercised natively (deep links can't be opened on this simulator).

## Fix

Return `target.filters` from `guestLinkVisit`, keep them on the visit, and seed the guest session's filter var with them.

**Acceptance:** that link opens the example's Transactions filtered to Expenses:Food. A unit case is added.
