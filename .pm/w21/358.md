# The legacy keypad's Delete key has no accessible name, and the label guardrail can't catch Feather icons

**Severity:** minor (the route is reachable only by deep link). **Estimate:** 10 minutes. Owner: mobile. A3: in `add-transaction-screen.tsx:186, 228-229`, the `Del` key is a `Pressable accessibilityRole="keyboardkey"` that renders only `<Feather name="delete" />`, with no `accessibilityLabel`, so VoiceOver says "key". `__tests__/accessibility-labels.test.ts:230` flags only `Ionicons` or `<Image`, so the other `@expo/vector-icons` families slip through.

Code-level at `main` `5a4e27da4` against React Native 0.86 (Fabric) sources in `mobile/node_modules`. Not exercised with VoiceOver, which this simulator setup can't drive.

## Fix

Add `accessibilityLabel={t("delete")}`, and widen the guardrail to every vector-icon family.

**Acceptance:** the key reads "Delete", and the guard test fails on an unlabeled icon-only Feather `Pressable`.

## Dedupe

w4/052 widened the guardrail to the app's `Button`, not to icon families. Searched `.pm/**` for keypad, Feather, keyboardkey and "Del".
