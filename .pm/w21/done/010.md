# Budget's ALL range stops at the ledger's last posting, so it drops the current period that YTD and 1Y show

**Severity:** minor. **Estimate:** 30–45 minutes. Owner: mobile. A2: ALL should be the widest view of a budget. Instead it is the only range that loses the months the budget was active but nothing was spent, and its header then reports an older month as the current one.

Environment: `main` at `ab6f2adf7`, dev build `io.beancount.ios` 1.20261002.50 on iPhone 17e (iOS 27.0), light, English, "today" = 2026-10-20. QA account on `https://beancount.io`, synthetic disposable ledger `mcp-agent-eval`, whose last posting is 2026-08-28. The budget was added through the app and the file restored byte-for-byte afterwards (sha256 checked, clean ledger check).

## Repro

1. Home → Budget card → **See all** → **Add your first budget**: 2026-08-01, `Expenses:Food:Groceries`, Monthly, 300 USD → **Done**. The app writes `2026-08-01 custom "budget" Expenses:Food:Groceries "monthly" 300 USD`.
2. **YTD** (and **1Y**): bars run through **SEP, OCT**. The header reads **Budget $193.55 · Actual $0.00 · Variance −$193.55**: October prorated to the 20th, 300 × 20/31. Correct.
3. **ALL**: the axis ends at **AUG**, so September and October are gone. The header reads **Budget $300.00 · Actual $180.85 · Variance −$119.15**, which is August's figures, presented as the current state of the budget.

## Root cause

`mobile/src/screens/budget-screen/selectors/budget-labels.ts:98-122` (`timeSpanToFilter`): `this-year` and `last-12m` send a window ending `today`. The `all` span returns `undefined`, so `getLedgerIntervalTotals` (`hooks/use-budget-actuals.ts:57-79`) returns only the periods that contain postings. The card's header stats come from the series' last point (`selectors/select-budget-card-stats.ts`), so they change meaning with the range.

## Fix

Make ALL end today like the other open-ended spans. Either send a window from the earliest of the first budget date and the first posting, through `today`, or pad the returned series with empty periods through the current one before computing stats. Keep the `budgetForInterval(…, today)` proration, so the current period is still prorated. Keep `last-year` (`year-1`) as it is, since it is a closed past window.

**Acceptance:** with the repro budget, ALL shows the same SEP and OCT points and the same header ($193.55 / $0.00) as YTD, plus every earlier period. The Home budget panel, which shares these variables through `budgetTotalsVariables`, is unchanged or matches. A unit test pins `timeSpanToFilter("all", today)` ending at `today`, and the stats for a series whose last posting predates today.

## Dedupe

Searched `.pm/**` (including `done/`) for budget ranges, `timeSpanToFilter`, ALL and last posting. Open w4/232, w4/233 and w4/235 are dashboard Budget issues (same-date update, delete errors, journal paging), and w4/130 (done) was proration round-off. No mobile item covers the ALL window.

## Not verified

The LY span (no 2025 data on this ledger), multi-currency budgets, and Android.

---

**Resolved 2026-10-20** — I took the note's second option and pad the series rather than widen the query window. `useBudgetActuals` appends empty periods to an unwindowed (ALL) series from `periodsThrough(lastDate, interval, today)`: the period ends after the last returned one, through the period containing today, stepping by the budget's own interval and never looping on a malformed date. `budgetForInterval(…, today)` still prorates the current period. With the repro budget, ALL now ends SEP, OCT, and its header reads Budget $193.55 · Actual $0.00, like YTD. Windowed ranges (YTD, 1Y, LY) and the Home panel, which uses YTD's variables, are unchanged.

`budget-all-range.test.ts` covers the padding (monthly, mid-period last posting, current period, weekly, quarterly, malformed date), the card stats for the repro series, and the hook's wiring. `budget-actuals-as-of.test.ts`'s source guard was updated for the new call shape. Mobile gates pass: format, tsc, eslint, knip, and 2395 unit tests. Not checked on the simulator, for LY or multi-currency budgets. A budget with no postings at all still shows no series under ALL. Shipped in `96087d9d6` (`mobile`).
