# Posting metadata on transaction detail is cut to 2 lines and can't be selected (a long-press opens the account instead)

**Severity:** low. **Estimate:** 10 minutes. Owner: mobile. A3 (code-level at `main` `dbe9b0144`): `transaction-detail-screen/components/posting-row.tsx:194` uses `numberOfLines={2}` with no `selectable`, inside a `TouchableOpacity` that opens the account. Entry metadata in Details (`transaction-detail-screen.tsx`, about `:826`) shows in full and is selectable. A posting's `receipt: "https://…"` of 120 characters ends in "…", and only VoiceOver gets the full value.

## Fix

Show posting metadata in full (or expandable) and selectable, outside the row's touch target.

**Acceptance:** a long posting metadata value is readable and copyable. A render test covers it.

## Dedupe

w21/162 added posting metadata, and w21/432 made errors and the source copyable; neither covers truncation. Searched `.pm/**` for posting-row together with numberOfLines.

---

**Resolved 2026-10-22** — a posting's metadata lines are shown whole (no line limit) and `selectable`, so a long `receipt` link can be read and copied; they stay in the row's spoken label. They remain inside the row's touch target (a tap still opens the account; a long press now selects the text). Source-level cases in `posting-meta.test.ts` (`mobile`); not run natively.
