# Create file, then switch ledger before it finishes: the editor opens that path in the other ledger

**Severity:** minor-to-moderate. The "Created qa-race.bean" toast fires, then the editor shows "File unavailable" in ledger B, while the file exists in ledger A. If B has a file at the same path, the user edits and saves *B's* file. **Estimate:** 15 minutes. Owner: mobile. A3: the create completion pushes the editor with only `path`. The editor takes its ledger from the global selection, and nothing checks whether the selection changed while the request was in flight.

Code-level at `main` `7fa4c4682`.

## Where

`mobile/src/screens/ledger-file-browser-screen/index.tsx:391-435` (push at `:421-427`) and `mobile/src/screens/ledger-file-editor-screen/index.tsx:300, 317-324`.

## Fix

Capture the ledger ID when the create starts. On completion, skip the navigation if the selection changed, or pass the ledger ID explicitly to the editor route.

**Acceptance:** with a 3 s delay, Create → switch ledger: no editor opens in the new ledger, and the toast names the original ledger.

## Dedupe

w4/051 is folder state; w4/304 is the dashboard Create File redirect. Searched `.pm/**` for createLedgerFile, "ledger switch" and "Create File" together with leave.

**Resolution (2026-10-21):** when a file create lands, the browser compares the selected ledger with the one the create started in (`ledgerVar() === ledgerId`) and checks that the screen is still the one on top (`useIsHere`, w21/194). If either changed, the editor is not opened, since it takes its ledger from the selection and could have edited another ledger's file of the same name. The toast names where the file went instead ("Created {name} in {ledger}", `ledgerCreateFileSuccessIn`, 13 locales). The files list is still refreshed. The create's in-flight flag is cleared in both cases. Tests: `ledger-file-browser-screen/__tests__/create-file-ledger.test.ts` (fails with the browser reverted). Deviation: the toast shows the ledger's id rather than a friendlier name. Not exercised with a 3 s delay.

**Recheck (2026-10-21, `main` `5637b7c63`): not exercised natively.** It needs a ledger switch while a create is in flight, which serialized Expo MCP taps cannot drive. I only confirmed that `ledgerCreateFileSuccessIn` exists in all 13 locale files and is used by the file browser. Needs a run with a slowed network.
