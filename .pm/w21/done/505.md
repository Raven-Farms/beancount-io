# Edit and Delete vanish from an ordinary entry whose narration spans two lines, or that uses the old "Payee" | "Narration" header (w21/443 false positive)

**Severity:** minor. **Estimate:** 15 minutes. Owner: mobile. A3: `isPluginCopy` reads only the slice's first line (`select-plugin-copy.ts:10-21`):
- a narration that continues onto the next line never closes there, so the loop keeps one string, takes it as the narration with payee `""`, and the entry's real payee then "differs";
- the `QUOTED` loop also stops at `|` (`:19`), so the legacy `"Payee" | "Narration"` form yields one string.

Either way, the entry is treated as a plugin copy and loses Edit and Delete.

Reproduced natively for the multi-line case (iPhone 17e, fresh Metro at `9e5987d07`): `2026-08-30 * "QA Multi" "qa line one⏎line two"` (disposable ledger, restored) renders "qa line one / line two" with no Edit pencil. The pipe case is from the reviewer's tsx run with rustledger 0.24 (`2026-06-01 * "Cafe" | "Coffee"` → `true`). Multi-line narrations are supported on purpose (w4/m34).

## Fix

Read the header across lines until its strings close (and return null, meaning "not judged", if one never closes), and skip a `|` token between strings.

**Acceptance:** both entries keep Edit and Delete. Unit cases are added.

## Dedupe

False positive of w21/443's fallback (done). Searched `.pm/**` for isPluginCopy, multi-line narration and the pipe separator.
