# On a ledger with renamed roots, Open Account's root button reads the English root to VoiceOver ("Account type: Assets" beside a visible "Activos:")

**Severity:** low. **Estimate:** 5 minutes. Owner: mobile. A3 (code-level at `main` `47c043676`): `open-account-screen.tsx:432` sets `accessibilityLabel={`${t("accountType")}: ${t(rootKey)}`}` with the canonical name, while the visible prefix (`:443`) and the picker rows (`:318`) use `ledgerRootName` (w21/073). With `option "name_assets" "Activos"`, VoiceOver says "Account type: Assets" next to "Activos:". Not run with VoiceOver.

## Fix

Use `ledgerRootName` in the label too.

**Acceptance:** the label reads the ledger's root name. A unit or render case is added.
