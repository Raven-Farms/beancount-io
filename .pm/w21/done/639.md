# Scan Receipt's decorative icons (the denied screen's camera, the reveal's sparkles) are their own VoiceOver stops (same class as w21/141 and w21/605)

**Severity:** low. **Estimate:** 5 minutes. Owner: mobile. A3 (code-level at `main` `5867356e4`): `receipt-capture-screen/camera-view.tsx:156` (`camera-outline`) and `reveal-view.tsx:87-89` (`sparkles`) are standalone Ionicons Text with no `accessible={false}` or `importantForAccessibility="no"`, so VoiceOver stops on a private-use glyph. Not run with VoiceOver.

## Fix

Hide both icons from accessibility.

**Acceptance:** VoiceOver goes straight to the explanation or the "Receipt read" header. The a11y guardrail covers these screens.

## Dedupe

Same class as w21/141 (done) and w21/605. Searched `.pm/**` for camera-outline and sparkles.
