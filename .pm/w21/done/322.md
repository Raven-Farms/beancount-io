# After w21/160 and w21/162: an exact written price with 9+ decimals shows as "≈" and rounded, and a bare metadata key reads "key: null"

**Severity:** low. **Estimate:** 15 minutes. Owner: mobile (or the ledger for the preferred fix).

Code-level at `main` `3e830700b`, run under Node:
- **Prices (w21/160):** `DERIVED_SCALE = 8` treats any per-unit figure with more than 8 decimals as derived from a total. `@ 1.123456789 USD` shows "@ ≈$1.1235", and `@ 0.000000012` shows "@ ≈$0.000000012", an exact value marked approximate. Precise FX rates and tiny crypto prices are hit. See `select-transaction-detail.ts:157, 170`.
- **Metadata (w21/162):** a bare `key:` line renders "key: null". See `select-transaction-detail.ts:139`.

## Fix

- Have the ledger send the written `@@` / `{{}}` totals (w21/160's optional fix) so derived figures are known, or raise the threshold to about 12 decimals.
- Render a null metadata value as the bare key, or "key: —".

**Acceptance:** `@ 1.123456789 USD` shows exactly, and a bare key shows no "null". Unit cases are added.

## Dedupe

These are follow-ups to w21/160 and w21/162 (done). Searched `.pm/**` for DERIVED_SCALE, roundDerivedPerUnit, and "null" together with metadata.

Fixed, with the note's simpler option on each point. Prices: the threshold at which a per-unit figure counts as derived from a total is raised from 8 to 12 decimals (`DERIVED_SCALE`), so `@ 1.123456789 USD` and `@ 0.000000012` show exactly as written, up to twelve decimals; a division carried out at full precision (the decimal context runs to twenty-odd digits) is still caught and shown rounded with "≈", so the w21/160 cases (`3.3333…`, `33.3333…`, the dust price) are unchanged. Metadata: a bare `key:` line (null or undefined value) renders as just the key, not "key: null". Deviation: the ledger sending the written totals (w21/160's optional fix) was not done; a figure between 13 and 20 decimals that was written exactly is still rounded, which is the trade-off of any threshold. Tests added to `select-transaction-detail.test.ts` (both fail with the selector reverted). Mobile gates and deadcode green.
