# More errors iOS VoiceOver never announces: Profile save errors, Server settings validation and Test Connection, budget history Delete failure (w21/354 sibling)

**Severity:** minor-to-moderate (accessibility). **Estimate:** 20 minutes. Owner: mobile. A3: `accessibilityRole="alert"` does nothing on iOS (`react-native/React/Views/RCTViewManager.m:31` maps it to `UIAccessibilityTraitNone`), and w21/354's guard only flags files that use `accessibilityLiveRegion` without an announcement. These sites slip past it:
- `profile/profile-screen.tsx:197` (save failed), `:360` (name) and `:421` (username taken);
- `welcome/server-settings-screen.tsx:294` (validation) and `:301` (Test Connection result);
- `budget-screen/components/budget-history-rows.tsx:208` (Delete failure, a plain `Text`).

Code-level at `main` `f8222c71e`; not exercised with VoiceOver.

## Fix

Render each with `InlineError`, and extend the guard to flag `accessibilityRole="alert"` without an announcement.

**Acceptance:** each error is announced on iOS, and the guard catches a bare `accessibilityRole="alert"`.

Siblings: w21/354 (done), w21/454 (Welcome), w21/479 (Create Ledger). Searched `.pm/**` for InlineError, accessibilityRole alert together with iOS, profile error and test connection.
