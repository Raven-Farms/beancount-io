# The iOS camera permission prompt's explanation is English in every language

**Severity:** minor-to-moderate. The first prompt a non-English user sees when scanning a receipt mixes a translated title and buttons ("„Beancount“ möchte auf die Kamera zugreifen", "Erlauben") with an English body. **Estimate:** 30 minutes. Owner: mobile. A3: `ios.infoPlist` sets one base-language `NSCameraUsageDescription`, and there's no `expo.locales` map, so prebuild writes no `<lang>.lproj/InfoPlist.strings`. `CFBundleLocalizations` declares all 13 languages (w4/063), so iOS localizes everything around the purpose string except the string itself.

Code-level at `main` `55e5919a6`. The installed dev build on the iPhone 17e simulator has no `*.lproj` folders at all, and its camera string is older wording ("Allow Beancount to access your camera"), so it predates the current `app.json`. That's consistent with the cause; a fresh build is needed to see the current text.

## Where

- `mobile/app.json:37` (`NSCameraUsageDescription`) and `:44` (`NSPhotoLibraryUsageDescription`, probably latent because PHPicker shows no prompt)
- `mobile/src/__tests__/permission-strings.test.ts:27-28` pins the English text.
- The prompt fires from `receipt-capture-screen/camera-view.tsx:95-106`.

## Fix

Add `expo.locales` with per-language JSON files that provide `NSCameraUsageDescription` (and the photo string) for all 13 app languages, and extend the permission test to require each.

**Acceptance:** a rebuilt app contains `de.lproj/InfoPlist.strings` (and the other 12). With iOS app language Deutsch, the camera prompt body is German.

## Dedupe

w21/done/016 is the string's wording; w4/063 is `CFBundleLocalizations`. Searched `.pm/**` for NSCameraUsageDescription, InfoPlist.strings, "purpose string" and "expo locales".

**Resolution (2026-10-21):** `app.json` now has an `expo.locales` map for all 13 `CFBundleLocalizations` languages, each pointing at `mobile/locales/ios/<lang>.json`. Each file gives that language's `NSCameraUsageDescription` and `NSPhotoLibraryUsageDescription`, which prebuild writes as `<lang>.lproj/InfoPlist.strings`. English repeats the base strings. `npx expo config` resolves all 13. `src/__tests__/permission-strings.test.ts` now requires a file per bundle language with both strings, and the English base. It fails with `app.json` reverted. Not verified with a rebuilt app or a German device prompt, since prebuild was not run because `ios/` holds the local dev build. That and the camera prompt need the next native build.
