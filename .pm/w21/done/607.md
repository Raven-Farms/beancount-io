# Android: the keyboard accessory bar is partly or fully hidden behind the keyboard (the navigation bar inset is subtracted twice)

**Severity:** minor on Android. **Estimate:** 15 minutes. Owner: mobile. A3: `components/keyboard-accessory-bar/utils.ts:15-20` (`getKeyboardOverlap = keyboardHeight - insets.bottom`), fed by `use-keyboard-height.ts:17-19` and used by the file editor (`index.tsx:913, 1114`), Edit Transaction (`:450, 587`) and others. On Android, React Native's keyboard height already excludes the navigation bar (`ReactRootView.java:961-962`), so subtracting `insets.bottom` removes it twice. Under `tsx`, the overlap is 252 instead of 300 with 3-button navigation, which hides the whole 44dp bar; with gesture navigation, 24 of 44dp are hidden. Code-level at `main` `ac126c6ae`; Android not exercised (no emulator in this QA run).

## Fix

Subtract the bottom inset on iOS only (or measure the keyboard's top against the window on Android).

**Acceptance:** the insert bar sits just above the keyboard on Android with either navigation mode. A unit case covers the platform split.

## Dedupe

The keyboard-accessory items (w21/144, 339, 340, 342) are iOS behavior or labels. Searched `.pm/**` for getKeyboardOverlap.
