# Some placeholders and labels use the light theme's hairline-border color as text, at about 1.34:1 (Create Ledger fields, New Transaction's empty "Account" rows, the inactive "Auto" tag)

**Severity:** minor-to-moderate (accessibility). Placeholders like Create Ledger's `YYYY-MM-DD`, the only format hint for "Books begin", are close to invisible in light mode. **Estimate:** 15 minutes. Owner: mobile. A3: `theme.black40` (`#e0dfd3`) is the light theme's border and hairline color. Every other input uses `theme.controlPlaceholder` (4.74:1).

Seen natively on the iPhone 17e simulator (iOS 27.0) at `main` `c26bdfe94`, in light mode, during the w21/104 probe: Create Ledger step 2's Description "Optional" and Opening balance "0" placeholders are barely distinguishable from the white field. Dark mode is 4.07:1.

## Where (`mobile/src/screens/`)

- `create-ledger-screen/create-ledger-screen.tsx:513, 540, 599, 654`: `placeholderTextColor={theme.black40}` on Name, Description, History start and Opening amount.
- `multi-postings-transaction/multi-postings-transaction-screen.tsx:141-144`: the "Account" placeholder on empty posting rows.
- The same file, `:178-180`: the inactive "Auto" tag.

## Fix

Use `theme.controlPlaceholder` for these placeholders and an existing secondary-text token for the Auto tag. Add them to the contrast test.

**Acceptance:** each listed element is at least 4.5:1 (placeholder: at least 3:1 per the app's input rule) in light and dark.
