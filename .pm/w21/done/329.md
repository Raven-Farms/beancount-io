# Leftovers from recent fixes: amber warning text still fails contrast; shell query sums still print "5e-7"; a normal Log out can say "Your session ended"

**Severity:** minor (three small follow-ups found by the fix audit). **Estimate:** 30 minutes. Owner: mobile (1, 3) and ledger (2).

Code-level at `main` `3e830700b`:
1. **w21/127:** amber `theme.warning` used *as text* still fails contrast in light mode, at 2.36:1 and 2.68:1. See the Pending chip (`transaction-detail-screen.tsx:173`) and the stale-price text (`valuation-sheet/index.tsx:105`). Fix: use a darker warning-text token.
2. **w21/125:** `ledger-shell-mappers.ts:54` (`unitsToCurrencyMap`) still sums with `BigNumber.toString()`, so shell query results show `"5e-7"` and `"1250.5"`. Fix: use the same `toFixed(scale)` as the tree and series serializers.
3. **w21/119:** a normal Log out can still show "Your session ended" when a token refresh races it. The terminal callback in `token-manager.ts:172-174` doesn't check `refreshGeneration`; this was proved with the real `OAuthTokenManager`. Fix: ignore a terminal failure from a superseded generation.

**Acceptance:** each has a unit case that fails before its fix.

## Dedupe

These are follow-ups to w21/119, 125 and 127 (done). Searched `.pm/**` for theme.warning, unitsToCurrencyMap and refreshGeneration.

All three fixed, one unit case each that fails before its fix. (1) Amber warning as text (mobile): a new `warningText` theme token, #935300 in light (6.0:1 on white, 5.3:1 on the Pending chip's 14% tint; the old `warning` was 2.7:1 and 2.4:1) and the unchanged amber in dark (9.4:1), used by the Pending chip's status text and the valuation sheet's stale-price text; `control-contrast.test.ts` asserts 4.5:1 against the surface, the inset fill and the chip tint in both themes, and that those two styles use it. (2) Shell query sums (ledger): `unitsToCurrencyMap` sums a repeated currency with `toFixed` at the widest written scale instead of `toString()`, so 0.0000003 + 0.0000002 prints "0.0000005" not "5e-7" and 1250.25 + 250.25 keeps "1250.50"; a single position stays as written and a zero net is still dropped (`ledger-shell-sums.test.ts`). (3) Log out race (mobile): the OAuth token manager runs `onTerminalFailure` only for a refresh that is still current (`isCurrentRefresh`), so an `invalid_grant` that arrives after a sign-out superseded the refresh no longer shows "Your session ended"; the caller still gets the terminal error. The test reproduces it with the response in hand and its body still being read when the user logs out (fails with `token-manager.ts` reverted).
