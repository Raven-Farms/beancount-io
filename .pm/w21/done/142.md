# Several VoiceOver labels drop the text that tells options apart: file vs folder, Create Ledger template descriptions, unavailable example ledgers, and which budget an "Update" or "Delete" acts on

**Severity:** minor-to-moderate (accessibility). **Estimate:** 45 minutes. Owner: mobile.

Code-level at `main` `aa4a9793a`.

## Sites (`mobile/src/`)

- **Files:** `screens/ledger-file-browser-screen/index.tsx:242` labels a row with `entry.name` only. A folder and a file both read "imports, button".
- **Create Ledger:** `screens/create-ledger-screen/create-ledger-screen.tsx:448, 464, 486`. Template and preset choices read "Starter, selected, button" and never read their description.
- **Drawer:** `components/ledger-drawer/ledger-drawer.tsx:927` (caption at `:941`). Signed-out example rows read "open_ledger/x, dimmed" without the visible reason ("Unavailable" or "Connection error").
- **Budget:** `screens/budget-screen/components/budget-group-card.tsx:243` and `budget-history-rows.tsx:179`. Every card reads just "Update" and every history row just "Delete", with no account or entry. The file browser already does this right with `ledgerDeleteFile {name}`.

## Fix

- Add the kind to file rows ("Folder", "File").
- Put descriptions into `accessibilityHint` or the label.
- Add the caption reason to dimmed drawer rows.
- Interpolate the account and currency (and the entry's date and amount) into the Update and Delete labels, all translated.

**Acceptance:** Accessibility Inspector shows the differentiating text for each site, and each label is unique among its siblings.

## Dedupe

w3/213, w2/071 and w21/128 cover layout and contrast. Searched `.pm/**` for create-ledger together with accessibility, TemplateStarterHint, "file browser" together with folder and VoiceOver, and statusLabel.

**Resolution (2026-10-21):** Files rows read "{name}, folder" or "{name}, file" (`ledgerFilesFolderLabel`/`ledgerFilesFileLabel`). Create Ledger's template, sample and preset choices carry their description as `accessibilityHint`. A dimmed drawer row's label appends its caption reason (`statusLabel`). Budget cards' Update reads "Update budget for {account}, {currency}" (`budgetUpdateNamed`), and history Delete buttons read "Delete budget entry of {date}, {amount}" (`budgetDeleteNamed`).
