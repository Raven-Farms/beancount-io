# Light-mode code editor colours strings (3.13:1) and currencies (3.49:1) below 4.5:1, in the File editor and Edit Transaction

**Severity:** minor (accessibility). **Estimate:** 10 minutes. Owner: mobile. A3: the light editor theme in `common/theme/palette.ts:138, 142` uses `string: "#28a745"` (3.13:1 on white, 2.84 on the gutter) and `currency: "#e36209"` (3.49:1), applied at `components/code-editor/code-editor.tsx:165, 169`. Dark passes (6.65 and 12.44). Code-level at `main` `f8222c71e`; the green payees and orange USD were visible in this session's editor screenshots.

## Fix

Darker light-mode hues, around `#1a7f37` and `#b35000`, plus a contrast test over the editor palette.

**Acceptance:** every light editor token colour is at least 4.5:1 on the editor background.

## Dedupe

Searched `.pm/**` for lightEditorTheme, editor together with contrast, `#28a745` and `#e36209`. No hits.

Resolved. The light editor theme's string colour moves from #28a745 (3.13:1 on white) to #1a7f37 (5.08:1) and its currency colour from #e36209 (3.49:1) to #b35000 (5.17:1), used by the File editor and Edit Transaction through the shared editor palette. `text-style-contrast.test.ts` now checks every token (foreground, comment, keyword, string, number, account, tag, currency) on the editor background and the line numbers on the gutter, in both themes; the two light cases fail against the old hues. Deviation: the hues are the note's suggestions, chosen for contrast and for staying near the originals, not re-reviewed on a device.
