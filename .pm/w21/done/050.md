# Account detail shows Note, Balance and Document rows as just "Assets:Cash · Note", without the note text, asserted amount or file, and they can't be opened

**Severity:** minor. **Estimate:** 30–45 minutes. Owner: mobile. A2/A3: notes ("called bank about fee"), balance assertions and attached documents are how users annotate and reconcile an account. On mobile's account detail, each one is a row titled with the account name, a type chip and **$0.00**, with nothing else. The row isn't tappable, so the note text, the asserted amount (or a failed assertion's difference) and the document's file can't be read anywhere in the app. The journal API already returns all three. w3/556 fixed the dashboard's Balance rows and listed the mobile side as unverified.

Environment: `main` at `badebff53`, dev build `io.beancount.ios` 1.20261002.50 on iPhone 17e (iOS 27.0). QA account, synthetic disposable ledger `mcp-agent-eval` with `2026-10-11 note Assets:Cash "qa-20261020 note \"quoted\" text"`, `2026-10-14 document Assets:Cash "qa-20261020/receipt.pdf"` and `2026-10-15 balance Assets:Cash 49.75 USD` (restored byte-for-byte afterwards).

## Repro

1. Accounts → **Cash**.
2. The rows read **Assets:Cash [Balance] $0.00 · Balance: $49.75**, **Assets:Cash [Document] $0.00** and **Assets:Cash [Note] $0.00**. None shows the note's text, the asserted 49.75 USD or `receipt.pdf`.
3. Tapping a row does nothing.

`getLedgerAccountJournal` returns everything needed: `{"directive_type":"Note","comment":"qa-20261020 note \"quoted\" text"}`, `{"directive_type":"Balance","amount":{"number":"49.75","currency":"USD"},"diff_amount":null}` and `{"directive_type":"Document","filename":"qa-20261020/receipt.pdf"}`.

## Root cause

- `mobile/src/screens/account-detail-screen/selectors/select-account-journal.ts:165-172` (`entryTitle`) falls back to `entry.account` for non-transactions, and `selectAccountJournalRows` (around line 255) copies no directive-specific field (`comment`, `amount`, `diff_amount`, `filename`) into the row. `components/account-entry-row.tsx` therefore has nothing to show beyond the type chip.
- `account-detail-screen.tsx:362-365` gives an `onPress` only when `isJournalTransaction(entry)`.

## Fix

Carry a `detail` line into `AccountJournalRow`: the Note's `comment`; the Balance's asserted amount, plus "off by X" from `diff_amount` styled as an error; the Document's filename. Render it as the row subtitle, where a transaction shows its narration, with `numberOfLines` and an accessibility label that includes it. Showing a failed assertion's difference matters most. Optionally make Document rows open the file in Files when it exists.

**Acceptance:** with the fixture above, the rows read "qa-20261020 note "quoted" text", "Balance 49.75 USD" and "qa-20261020/receipt.pdf". A failing assertion shows its difference. Transactions are unchanged. Selector tests cover the three types and a failing Balance.
