# Browse ledgers' search icon touches its placeholder text

**Severity:** minor (visual). **Estimate:** 10–20 minutes. Owner: mobile. A2: Browse ledgers is where a new user goes to find and switch ledgers. Its search field is the only one in the app whose magnifier sits flush against the text.

Environment: `main` at `ab6f2adf7`, dev build `io.beancount.ios` 1.20261002.50 on iPhone 17e (iOS 27.0), light, English, default (`large`) text.

## Repro

1. Open the drawer → **Browse ledgers**.
2. Look at the search field: the magnifier and "Search ledgers" are about 1 pt apart (about 2 px at 3×). The placeholder reads as "🔍Search ledgers".

Controls: Merchants ("Search 10 merchants…") and Transactions ("Search") leave about 8 pt between icon and text.

## Cause

`mobile/src/screens/ledger-selection/index.tsx:59-73`: the hand-rolled `search` row (`flexDirection: "row"`) has no `gap`, and the input has no leading margin. The shared `mobile/src/components/search-bar/index.tsx:38` and `merchants-screen.tsx:63` both use `gap: space.sm`.

## Fix

Add `gap: space.sm` to `styles.search`. Better, render the shared `SearchBar` if it supports the same controlled value and accessibility label, so the two can't drift again. Check light and dark, and Persian, where the row mirrors.

**Acceptance:** the icon and the placeholder or typed text have the same spacing as Merchants' search at default and AX2 text sizes, in LTR and RTL.

## Dedupe

Searched `.pm/**` (including `done/`) for Browse ledgers / `ledger-selection` together with icon, gap or SearchBar. w4/049 (search kept across tabs), w4/007 (row description) and w0/045 (RTL input alignment) touched this screen but not this spacing. No open item.
