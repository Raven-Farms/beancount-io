# Update Budget's amount field shows a stock "500" placeholder that reads as the current budget

**Severity:** minor. **Estimate:** 10–15 minutes. Owner: mobile. A2: Update Budget prefills account, interval and currency from the card, so a grey "500" in the Amount field reads as the budget's current value. The budget being updated is **900.50 USD quarterly**, and the placeholder is just the Add Budget example.

Environment: `main` at `f22b25107`, dev build `io.beancount.ios` 1.20261002.50 on iPhone 17e (iOS 27.0). QA account, synthetic disposable ledger `mcp-agent-eval` with `2026-08-01 custom "budget" Expenses:Food:Groceries "quarterly" 900.50 USD` (restored afterwards). Nothing was saved.

## Repro

1. Budget → the Groceries card (Quarterly · USD) → **Update Budget**.
2. The form shows Account `Expenses:Food:Groceries`, Interval `Quarterly`, Currency `USD`, and Amount **"500"** in placeholder grey.

## Root cause

`mobile/src/screens/add-budget-screen/add-budget-screen.tsx`: `amount` starts as `""` (line 200), deliberately so that an update requires a new value, and the `TextInput` has a fixed `placeholder="500"` (line 341). `budget-screen.tsx:128-140` (`openAdd`) passes account, interval and currency, but not the current amount.

## Fix

Pass the group's current amount in `openAdd`'s params. In update mode, use it as the placeholder (`900.50`), or show "Current: 900.50 USD" under the field, and keep the field empty so the user still types the new amount. Leave Add Budget's example placeholder unchanged.

**Acceptance:** Update Budget on the repro card shows `900.50` (or "Current: 900.50 USD") instead of `500`. Add Budget still shows `500`. A unit or param test covers the update-mode placeholder.

## Dedupe

Searched `.pm/**` for Update Budget, placeholder and prefill. w0/038 (amount parsing), w0/040 (Done font cap) and w3/206 (picker accessibility) cover other parts of this form.

---

**Resolved 2026-10-20** — `openAdd` passes the card's `currentAmount` (`group.amount`, for example `900.50 USD`). Add/Update Budget sets its Amount placeholder through `budgetAmountPlaceholder`: the current amount's number (`900.50`) when updating, otherwise Add Budget's `500` example, which also covers a missing or unreadable amount. The field still starts empty, so an update needs a newly typed value. `amount-placeholder.test.ts` covers update, add and unreadable input, plus the wiring from the card. Mobile gates pass: format, tsc, eslint, knip, and 2469 unit tests. Not checked on the simulator. Shipped in `df8f07ab7` (`mobile`).
