# Commit diffs of CRLF files show every line double-spaced, and every diff ends with a blank row

**Severity:** minor (readability). It's reachable on every edit to a Windows-line-ending ledger now that w21/062 keeps CRLF on save. **Estimate:** 10 minutes. Owner: mobile.

Code-level at `main` `7f85628b8`. `parseDiff` under Node on a CRLF hunk returns `" 2024-01-01 open Assets:Cash\r"`, `"-old\r"` and `"+new\r"`, plus a trailing `""` row. iOS text layout treats `\r` as a paragraph break, so each row gets an extra line, and the empty row is a blank band at the end.

## Root cause

`mobile/src/screens/commit-detail-screen/diff-utils.ts:16` (`split("\n")`), rendered at `commit-detail-screen.tsx:164-166`.

## Fix

Split on `/\r?\n/`, and drop the final empty element when the diff ends with a newline.

**Acceptance:** a CRLF hunk renders one row per line with no `\r`, and no diff ends with an empty row. Unit cases are added.
