# A gateway 5xx now says "You're offline. Nothing was saved." even though the write may have committed (w21/117)

**Severity:** minor-to-moderate. "Nothing was saved" invites a retry, which can write a duplicate budget directive or hit a confusing "already exists". **Estimate:** 15 minutes. Owner: mobile. A3: w21/117 maps every non-2xx response to the offline copy. A 502 or 504 means the server was reached, and the write may have committed.

Code-level at `main` `3e830700b`. Run under Node, `ledgerWriteFailureMessage(new ApolloError({ networkError: ServerError(status) }))` returns `ledgerWriteOffline` for 400, 413, 500, 502 and 504.

## Root cause

`mobile/src/common/ledger-refusal.ts` (`TRANSPORT_FAILURE`, `isTransportFailure`).

## Fix

Keep "offline" for real fetch or OAuth-refresh failures. Give non-2xx responses their own copy, such as "The server didn't confirm the save — check before trying again", in 13 locales. Callers such as budget save can refetch before offering a retry.

**Acceptance:** a 502 shows the unconfirmed-save copy, and a network failure still shows the offline copy. Unit cases are added.

## Dedupe

This is a follow-up to w21/117 (done). w21/182 and w21/250 are unrelated. Searched `.pm/**` for ledgerWriteOffline, "Nothing was saved" and isTransportFailure.

Fixed. `ledgerWriteFailureMessage` now separates a response from a dropped connection: a non-2xx response (a ServerError's `statusCode`, or "Received status code N" in the text; 400, 413, 500, 502, 504 all checked) reads "The server didn't confirm the save. Check before trying again." (`ledgerWriteUnconfirmed`, 13 locales), because the server was reached and the write may have committed; "You're offline. Nothing was saved." is kept for what never arrived (a failed fetch, "Network request failed", a failed OAuth refresh). Deviation: the optional "callers such as budget save can refetch before offering a retry" is not done; the copy tells the user to check first. Tests in `common/__tests__/ledger-refusal.test.ts` (the new case fails with `ledger-refusal.ts` reverted). Mobile gates and deadcode green.
