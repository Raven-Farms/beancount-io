# Entry Context's location line truncates the line number first for entries in nested included files

**Severity:** low. **Estimate:** 5 minutes. Owner: mobile. A3: `entry-context/index.tsx:278` renders the location with `numberOfLines={1}` and the default tail ellipsis, so the `:lineno` suffix is the first thing cut. At 390 pt the header leaves about 260 pt, roughly 36 characters of 12 pt monospace, so `imports/2026/chase-sapphire-checking.bean:1042` (46 characters) shows as `imports/2026/chase-sapphire-checkin…`. That estimate comes from layout constants under `tsx`, not a rendered measurement. Notifications shows the full location, and the header isn't tappable.

Code-level at `main` `3440909ec`.

## Fix

Set `ellipsizeMode="head"` or `"middle"`, or give the line number its own non-shrinking `Text`.

**Acceptance:** that location always shows `:1042`.
