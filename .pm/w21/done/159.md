# New Transaction's amount fields start with a real "0.00" that a tap doesn't select, so typing "12.50" produces "0.0012.50" and an error

**Severity:** major. This is the app's main entry path. Typing an amount after a normal tap gives an unparseable value ("Use digits and one decimal point, like 1234.56"). The user has to notice, delete four characters, and type again, every time. **Estimate:** 30 minutes. Owner: mobile. A3: `makePosting` seeds `amountInput: "0.00"` as the field's **value**; the `placeholder="0.00"` behind it never shows. The input relies on `selectTextOnFocus` to replace that text, but on iOS a tap focuses the field and leaves the caret at the end with nothing selected, showing the "Select / Select All / AutoFill" menu, so typed digits are appended.

Reproduced natively on the iPhone 17e simulator (iOS 27.0) at `main` `b6d99a180`, with nothing saved (the form was discarded):
1. Home → + → Enter new transaction → Payee "qazx".
2. Tap the Assets:Bank:Checking amount once. The caret sits after "0.00", the edit menu shows "Select / Select All / AutoFill", and nothing is selected.
3. Type `1`, `.`, `2`, `3`. The field reads **"0.001.23"** in red, Remainder shows "—", and "Use digits and one decimal point, like 1234.56" appears.
4. A second single tap on the field again leaves the caret at the end with no selection.

Taps were driven by expo-mcp's XCUITest tap, which is a real touch event.

## Where (`mobile/src/screens/multi-postings-transaction/`)

- `postings-utils.ts:144-149` (`makePosting`: `amountInput ?? "0.00"`) and `:134-136` (the auto leg "0.00")
- `multi-postings-transaction-screen.tsx:394-403` (`value={absValue}`, `placeholder="0.00"`, `selectTextOnFocus`)

## Fix

Seed non-auto postings with `amountInput: ""`, so the placeholder shows and the first digit starts a fresh value, and treat `""` as zero in balance math, as it already parses to null. Keep "0.00" only as the auto leg's computed display. Alternatively, clear a value equal to "0.00" in `onFocus`. Don't rely on `selectTextOnFocus` on iOS.

**Acceptance:**
- On iOS, tapping the first posting's amount and typing `12.50` gives "12.50", and the auto leg shows −12.50.
- An edited amount is never cleared on refocus.
- Add a unit test for the seed.
