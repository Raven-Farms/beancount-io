# The Transactions filter's account picker offers "Create", which opens Open Account and writes an `open` to the ledger from a filter

**Severity:** minor (an unintended ledger write from a read-only control). **Estimate:** 15 minutes. Owner: mobile. A3: `account-picker-screen/picker-sections.ts:135-143` (`showCreateAccountRow`) and `:155-160` (`showCreateBelowResults`) don't check the picker type. The filter screen opens the picker with `type: "filter"` (`transaction-filters-screen.tsx:245`).

Native (iPhone 17e at `52a06aa36`; nothing saved): Transactions ▸ filter ▸ Account ▸ paste "QaTravel". The picker shows "No matching accounts" and **Create "QaTravel"**. Tapping it opens Open Account prefilled "Assets:QaTravel" (filter pickers default to Assets), with Done enabled. Done would commit `open Assets:QaTravel` and then filter to that empty account.

## Fix

Hide the Create rows when the picker type is `filter` (and in any other read-only picker, such as the budget account filter, if it shares the path).

**Acceptance:** the filter's picker never offers Create. A unit case is added for `showCreateAccountRow` and `showCreateBelowResults` with `type: "filter"`.
