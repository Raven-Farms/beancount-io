# Help Center always opens the English page, whatever language the app is in

**Severity:** minor-to-moderate (localization). The site has the page translated in all 12 other app languages. **Estimate:** 10 minutes. Owner: mobile.

Code-level at `main` `567bd1801`: `mobile/src/screens/setting/main-content.tsx:167` hard-codes `https://beancount.io/docs/help-center`, although `localeVar` is in scope at `:39`. A reviewer fetched `https://beancount.io/<l>/docs/help-center` for bg, ca, de, es, fa, fr, nl, pt, ru, sk, uk and zh: every one returns 200 with a translated page (`de` "Beancount-Hilfecenter…", `zh` "Beancount 帮助中心…"). The unprefixed URL stays English even with `Accept-Language: de-DE`, so the app must build the prefix itself.

## Fix

Build the URL from the live locale: `/docs/help-center` for en, `/${locale}/docs/help-center` otherwise, in a small helper shared with the feed work. The dashboard has the same hard-coded URL (`dashboard/src/common/components/ledger-layout/layout-header.tsx:176`); that's a separate package.

**Acceptance:** in Deutsch, Settings → Help Center opens `/de/docs/help-center`. A unit case covers the helper.

## Dedupe

w21/136 (done) is the same defect for the Latest Updates feed, and w4/044 (done) checked only that the row opens. Searched `.pm/**` for help-center and helpCenterUrl.
