# All four Home "See all" buttons have the same VoiceOver name

**Severity:** minor (accessibility). Voice Control's "Tap See all" and the rotor's button list can't tell the charts, Recent Transactions, Spending and Budget apart. **Estimate:** 10 minutes. Owner: mobile.

Code-level at `main` `26fb7ee69`: `mobile/src/components/dashboard-card/index.tsx:139-140` and `account-charts-card.tsx:198-199` both use `accessibilityLabel={t("seeAll")}`.

## Fix

Include the card title in the label ("See all Recent Transactions"), and use "See all accounts" on the chart card, in 13 locales.

**Acceptance:** each See all button's label names its card, and a source check covers both components.
