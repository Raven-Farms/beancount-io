# The Notifications bell never tells VoiceOver its error count

**Severity:** minor (accessibility). Sighted users see a red "3" or "99+" badge, while VoiceOver says only "Notifications, button". **Estimate:** 15 minutes. Owner: mobile.

Code-level at `main` `cd02f5446`.

## Root cause

`mobile/src/components/ledger-drawer/ledger-drawer-header.tsx:113-128` gives the TouchableOpacity a fixed `accessibilityLabel={t("notificationsBell")}`. On iOS that label replaces the subtree, including the badge's `<Text>`, and there is no `accessibilityValue`.

## Fix

Set `accessibilityValue={{ text: t("notificationsBellCount", { count }) }}` when `count > 0`, with plural forms in all 13 locales, or fold the count into a pluralized label.

**Acceptance:** with one ledger error, the bell's accessibility value reads "1 error" (in ru, "1 ошибка"). It is empty with no errors.
