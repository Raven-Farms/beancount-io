# The first offline launch after w21/244 shows "Couldn't load ledgers" in the drawer instead of the cached list

**Severity:** minor (once per device, offline only). **Estimate:** 10 minutes. Owner: mobile. A3: w21/244 added `description` to `ledgerDirectory.graphql:6`. `ledger-directory.ts:88-91`'s `readQuery` misses on lists cached before the field existed, and `revalidate()` (`:55-63`) then throws before it saves the cached list. Under `tsx`, with a real `InMemoryCache` restored from an old-shape page and a network link that always fails, the drawer ends as `{ledgers:[], error:true}`; before the commit the same cache loaded. 244's note says only the description search misses briefly, but in fact the whole cached list is dropped, so switching ledgers offline is impossible until the device is back online.

Code-level at `main` `62533363c`.

## Fix

Read with `returnPartialData: true` and treat a missing description as null. Add a test with an old cache and an offline link.

**Acceptance:** with an old cache and no network, the drawer lists the cached ledgers.

## Dedupe

This is a follow-up to w21/244 (done); w21/054 and 066 differ. Searched `.pm/**` for "missing field", "persisted cache", "schema change" and LedgerDirectory.

Fixed. The directory reads a cached page with `cache.diff({ returnPartialData: true })` instead of `readQuery`, so a list cached before `description` joined the query still counts as cached: its rows are used (a missing description reads as null) and the drawer lists them offline without an error. A page whose rows lack an id, name, full name or privacy flag, or that is not cached at all, still falls through to the network, and with nothing cached a failed read still reports the failure. The online revalidation then replaces the list with the full-shape pages, as before. Tests (`ledger-directory.test.ts`, with a real `InMemoryCache` written by the old query and a link that always fails: the cached ledgers are listed with no error and null descriptions, and the empty-cache failure is still reported; the first fails with the directory reverted). Not run natively.
