# Home's Latest Updates card always requests the English feed, whatever language the app is in

**Severity:** minor-to-moderate. With the app in German, the card's title and dates are German but every Blog and Release row is an English title, and tapping a row opens `/blog/…` instead of `/de/blog/…`. **Estimate:** 10 minutes. Owner: mobile. A3: the backend resolves the feed language as the client's `locale`, then the profile language, then `"en"`, and it ships feeds for all 13 app languages. Mobile hard-codes `locale: "en"`, so the other two are never used. The dashboard passes `i18n.language`.

Code-level at `main` `5793e4e95`.

## Where

- `mobile/src/screens/home-screen/components/feed-card.tsx:102`
- The backend side is `backend-cluster/backend-v2/src/features/gitea/feed/service/feed-service.ts:35,154`.
- The dashboard is `dashboard/src/features/ledger-list/components/activity-feed.tsx:57`.

## Fix

Pass the current app `locale` from `useTranslations()`, and include it in the query variables so a language change refetches.

**Acceptance:** in Deutsch, the card's Blog and Release rows have German titles and open `/de/…` URLs, matching GraphQL `getFeed(locale: "de")`.

## Dedupe
