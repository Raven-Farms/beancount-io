# Receipt capture prefills the amount at 2 decimals, so 3-decimal currencies (KWD, BHD, JOD, OMR) lose precision

**Severity:** minor. **Estimate:** 15–20 minutes. Owner: mobile. A3: the parsed receipt total is passed to New Transaction as `Math.abs(amount).toFixed(2)`. A 12.345 total becomes "12.35", 0.125 becomes "0.13", and 1.005 becomes "1.00" (binary rounding inside `toFixed`). That rounded figure is what gets saved, in a ledger whose currency has three decimals.

Environment: `main` at `8d4d672f9`. Code-level: the expression was evaluated under Node. Receipt capture needs a camera or image, so it wasn't exercised natively.

## Root cause

`mobile/src/screens/receipt-capture-screen/receipt-capture-screen.tsx:146` (and the on-screen reveal around `:200`) formats with a fixed 2 decimals. The parse result carries no currency (`ParseReceiptMutation`), so the form also assumes the ledger's first currency.

## Fix

Pass the parsed number through without `toFixed`, as an exact decimal string from the parser: format with `Math.abs` but keep the original scale. Or round to the target currency's precision when it's known. Avoid `toFixed` on binary floats (1.005). Optionally carry the receipt's currency once the parser returns it.

**Acceptance:** a parsed 12.345 prefills "12.345", and 1.005 prefills "1.005". USD receipts still show 2 decimals.

**Resolved 2026-10-21** — Shipped in the commit that moved this note (`mobile`). The new `receiptAmountText` in `receipt-utils.ts` replaces `Math.abs(amount).toFixed(2)` for both the prefill and the reveal. It keeps the parser's own precision via the shortest round-trip decimal, made positive and padded to two places. A parsed 12.345 prefills "12.345", 1.005 prefills "1.005", and USD totals still read "42.50" / "12.00". Tests in `src/__tests__/receipt-utils.test.ts` cover these cases plus a wiring check, which fails with the screen change reverted. The receipt's currency is still not carried, because the parse result has none. Not exercised natively: it needs a camera or an image.
