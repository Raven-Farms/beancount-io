# The account picker offers "Create" for the short name of a closed (or not-yet-open) account, then Open Account refuses it (w21/122 and w21/374 cover only full names)

**Severity:** low. **Estimate:** 15 minutes. Owner: mobile. A3 (code-level at `main` `52a06aa36`, proven under `tsx`): `account-picker-screen.tsx:517-552` and `common/account-close-dates.ts:160-167, 186-191`. `closedAccountNamed` and `notYetOpenAccountNamed` match only the full typed name, but `onCreate` (`:496-512`) prefixes the row's root, so `gym` becomes `Expenses:Gym`. The tsx run gave `closedRow:false, createOffered:true, alreadyOpen:true, canSubmit:false`.

Scenario: with `Expenses:Gym` opened 2026-01-01 and closed 2026-09-01, go to New Transaction ▸ expense posting's account and type `gym`. It shows "No matching accounts" and Create "gym". Tapping it opens Open Account prefilled `Expenses:Gym`, which says it was closed and can't be reopened, with Done disabled. The picker should have said "Expenses:Gym was closed on September 1, 2026" with no Create.

Native (iPhone 17e, disposable ledger, restored): Create opens Open Account with `Expenses:` plus the capitalized query ("qagym" became "Expenses:Qagym", Done enabled). The fixture's mixed-case closed name (`QaGym`) didn't match that capitalization, so the closed-name refusal itself wasn't shown natively.

## Fix

Also check the composed `<prefillRoot>:<Capitalized query>` name with `closedAccountNamed` and `notYetOpenAccountNamed`.

**Acceptance:** typing `gym` shows the closed row with its date and no Create. Unit cases are added.

## Dedupe

Gap in w21/122 and w21/374 (done; full names). Searched `.pm/**` for closedAccountNamed, notYetOpenAccountNamed, and "Create" together with closed.

---

**Resolved 2026-10-22** — the picker also checks the name Create would compose (`createdAccountName`: the query capitalized and rooted as Open Account does, with the ledger's root names) against the closed and not-yet-open lookups, so `gym` shows "Expenses:Gym was closed on …" and no Create. Cases in `create-account-prefill.test.ts` (`mobile`); not run natively.
