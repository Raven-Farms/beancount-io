# On Accounts, a category holding a single commodity reads in units and drops its stale-price warning, which Home shows

**Severity:** minor-to-moderate. It affects a crypto-only or one-fund ledger, or one where every account holds one priced foreign currency. **Estimate:** 15 minutes. Owner: mobile. A3: the root's valuation is attached only when the root displays a money figure, so a units root falls back to the plain "at market" note.

Code-level at `main` `4bbc36785`. Run under Node with Assets holding only Broker 10 HOOL (last price 2026-08-01, today 2026-10-21):
- **Root:** headline "10 HOOL", notes `["atMarket {$1,500.00}"]`, with no stale warning.
- **Add $1 of cash:** the root becomes money, with "At market value · 1 price not updated since Aug 1, 2026".
- **Home:** `selectSeriesValuation` always attaches the valuation, so Home warns while Accounts doesn't.

## Root cause

`mobile/src/components/account-list/select-trial-balance.ts:184-198`.

## Fix

Attach `selectValuation` to root rows whatever the display kind, and append its status after the units note.

**Acceptance:** the HOOL-only root shows "1 price not updated since Aug 1, 2026". A unit case is added.
