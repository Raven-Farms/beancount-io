# After a successful pull to refresh, Transactions and Account detail still show "Couldn't load more entries" and won't page on their own (w21/353 follow-up)

**Severity:** minor. **Estimate:** 10 minutes. Owner: mobile. A3: `loadMoreFailed` is `loadMoreFailedFor === listKey` (`mobile/src/screens/transactions-screen/transactions-screen.tsx:191-201`), and only `loadMore` clears it (`:201`). `onRefresh` (`:257-266`) calls `refetch()`, which resets the list to page 1 so `hasMore` is true again, but never clears the failure. The footer keeps the error, and scrolling to the end doesn't load (`:199`). `account-detail-screen.tsx:325-336, 399-413, 549` has the same pattern.

Code-level at `main` `bed2252b0`; not exercised on the device (a page failure can't be induced here, as noted on w21/353).

## Fix

Clear `loadMoreFailedFor` when a refresh succeeds, or whenever a new page-1 result arrives, on both screens. Extend `load-more-failed.test.ts`'s wiring checks.

**Acceptance:** after a successful refresh the footer is normal, and scrolling to the end loads the next page.
