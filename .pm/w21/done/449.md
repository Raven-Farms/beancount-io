# VoiceOver reads a parent's "(own)" row with the parent's name ("Assets:Bank, $10,000.00"), so two rows sound like the same account

**Severity:** minor (accessibility). **Estimate:** 10 minutes. Owner: mobile. A3: `mobile/src/components/account-table/account-table.tsx:409-413` builds the row's label from `row.account`, and the own row's `account` is its parent's (`flatten-rows.ts:124`). The visible "(own)" label (`:520`) never reaches the accessibility label.

Code-level at `main` `17da1541a`. The reviewer's tsx run of `selectTrialBalanceCategories` and `flattenRows` gives a parent row `Assets:Bank` at 28100 and an own row `Assets:Bank` at 10000. VoiceOver would read "Assets:Bank, $28,100.00" and then "Assets:Bank, $10,000.00". Not exercised with VoiceOver.

## Fix

For `row.own`, use the same "(own)" text the row shows (`accountOwnPostings`) as the label's name.

**Acceptance:** the own row's label says it is the parent's own postings. A unit or source test is added.

## Dedupe

This is a follow-up to w21/174 and w21/331, which built the own row. w21/356 covers expandable announcements. Searched `.pm/**` for "(own)", own row, accountOwnPostings and VoiceOver.
