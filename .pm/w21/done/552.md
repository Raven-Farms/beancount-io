# `previewLedgerSetup` and `createLedger` with an explicit null on a nullable GraphQL field: `title: null` is a 500, and null `amount`/`currency` are wrongly refused (REST and MCP give a clean 400)

**Severity:** low. **Estimate:** 15 minutes. Owner: backend-v2. A3: `LedgerSetupInput.title` and `LedgerSetupAccountInput.currency`/`amount` are nullable in the schema (`ledger-resolver.types.ts:58-97`), and null reaches the builder unchanged. `build-ledger.ts:120` runs `setup.title !== undefined && setup.title.length`, a TypeError on null. `:204` refuses `amount: null` ("must not carry an amount unless…"), and `:210` refuses `currency: null` as "Unsupported currency \"null\"". REST and MCP use `.optional()` (`lifecycle-handler.ts:49, 66, 71`) and return a field-level 400.

Production (2026-10-22, read-only): `query { previewLedgerSetup(setup: {preset: PERSONAL, title: null}) { preset } }` returns `INTERNAL_SERVER_ERROR` ("Internal server error"). Mobile always sends a string, so the app isn't affected today. Any GraphQL client that sends null for a field the schema marks nullable is.

## Fix

Treat GraphQL nulls as omitted for these fields (the entries handler's convention), or make them non-null in the schema, with a parity test.

**Acceptance:** `title: null` previews like an omitted title, and null `amount`/`currency` behave as omitted, on all three surfaces.

## Dedupe

None found. Searched `.pm/**` for "explicit null", setup.title and previewLedgerSetup together with null.

---

**Resolved 2026-10-22** — `previewLedgerSetup`, the one builder REST, GraphQL and MCP share (it also runs inside `createLedger`), now takes every explicit `null` in the setup as an omitted field, so GraphQL's `title: null` previews like an omitted title and null `amount`, `currency` and `openingState` behave as omitted; REST and MCP never carried one. Cases in `build-ledger.test.ts` (`backend-cluster/backend-v2`, full suite green), including that an amount on a not-known account is still refused. A backend-v2 deploy carries it to production.

Production recheck (2026-10-22 14:42 PDT, read-only): not deployed yet. `previewLedgerSetup(setup: {preset: PERSONAL, title: null})` still returns `INTERNAL_SERVER_ERROR`. Recheck after backend-v2 deploys.
