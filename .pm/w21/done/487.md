# Recent changes and commit detail show a commit's day but never its time, so same-day commits differ only by SHA

**Severity:** minor. **Estimate:** 15 minutes. Owner: mobile. A3: `formatFeedDate` (`mobile/src/common/date-format.ts:138-143`) asks only for month, day and year, and `formatCommitAuthorLine` (`notifications-screen/formatting.ts:47-54`) uses it for the commit row (`notifications-screen.tsx:408-413`), its accessibility label (`formatting.ts:25-40`) and commit detail (`commit-detail-screen.tsx:288-294`).

Seen natively this session (iPhone 17e): Notifications ▸ Recent changes on the disposable ledger lists a run of rows reading "qa-20261020: restore snapshot / puncsky · Oct 21, 2026 <sha>" and "qa-20261020: mobile append / … · Oct 21, 2026 <sha>", told apart only by SHA, and the commit detail header reads "Author: puncsky · Oct 21, 2026". The reviewer's tsx run (TZ America/Los_Angeles) of two same-subject commits at 09:05Z and 17:40Z gives identical visible lines and labels apart from the SHA.

## Fix

Add a time (`hour: "numeric", minute: "2-digit"`, in the device's zone), or the time alone for today's commits, to the row, its label and the commit detail.

**Acceptance:** same-day commits show distinct times in the row, the label and the detail. Unit cases are added.
