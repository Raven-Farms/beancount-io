# Files sorts names as plain text, not numbers: "qa-10.bean" lists before "qa-2.bean"

**Severity:** low. **Estimate:** 5 minutes. Owner: mobile. A3: `ledger-file-browser-screen/utils.ts:129` uses `a.name.localeCompare(b.name)` without `{ numeric: true }`. The dashboard has the same code (`ledger-directory-view.tsx:261`). Under `tsx`, `1.bean | 10.bean | 11.bean | 12.bean | 2.bean | 3.bean`.

Native (iPhone 17e at `b1ba52fcd`, disposable ledger; the probe files were deleted and the ledger is identical to its snapshot): Files lists "main.bean", "qa-10.bean", "qa-2.bean", in that order. Month-numbered books (`books/2026/1.bean` … `12.bean`) read 1, 10, 11, 12, 2, 3 …

## Fix

Use `localeCompare(b.name, undefined, { numeric: true, sensitivity: "base" })`, in the dashboard too.

**Acceptance:** 1 … 12 sort numerically, with folders still first. A unit case is added.

## Dedupe

None found. Searched `.pm/**` for localeCompare, "natural sort" and numeric.
