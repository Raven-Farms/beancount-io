# Regression from w21/420: account detail's chart runs past today, and one future-dated entry anywhere moves every account's 1M onto next month

**Severity:** moderate. **Estimate:** 30 minutes. Owner: mobile. A3: `select-account-balance-series.ts:138` now prefers `accountBalanceData`, whose rows are dated at period end (`backend-cluster/ledger/src/foundation/rustledger/interval-series.ts:401`) and span the ledger's first to last transaction or price, regardless of the account (`firstAndLastDate`, `:201-214`). The `:146` guard (`if (!last || last.date > current.today) return series;`) then skips today's trial-balance value.

## Fix

In `selectAccountBalanceSeries`, drop `accountBalanceData` rows dated after the current month, re-date the current month's row to today before the `current` splice, and trim leading empty rows before the account's first posting.

**Acceptance:** each case above ends at today, 1M stays on the current month with a future entry elsewhere, and ALL starts at the account's first posting. Unit cases use period-end rows.
