# A quarterly budget's last bar is labelled "OCT" on YTD and 1Y but "DEC" on ALL, so the axis looks like monthly bars with a gap

**Severity:** minor. **Estimate:** 15 minutes. Owner: mobile. A3: `periodAxisLabel` labels a bar from the date the server sends, which is the period's end. On a windowed span (YTD, 1Y) the server's last range ends today rather than at the period's end, so the current quarter reads as the current month. Weekly bars have the same problem: the last bar reads `10/21` on YTD and `10/25` on ALL.

Reproduced natively on the iPhone 17e simulator (iOS 27.0) at `main` `24a2d3f2c`, today 2026-10-21, on the disposable QA ledger (restored byte-for-byte to `f1a0b83c`). The fixture `; qa-20261020-budq` was `2026-01-01 custom "budget" Expenses:QaBudQtr "quarterly" 900 USD` with 250 USD spent on 5 October.
- **YTD:** axis `MAR JUN SEP OCT`.
- **ALL:** axis `MAR JUN SEP DEC`, for the same four quarters.

## Root cause

`mobile/src/screens/budget-screen/selectors/budget-labels.ts:31-44`: quarterly falls through to the month-abbreviation branch, and weekly prints `M/D` of the received date. The ledger's interval series uses `complete=false` on a windowed span, so its last date is today.

## Fix

Label from the period's real end, `addDaysISO(nextIntervalStartISO(date, interval), -1)`, or give quarters their own label ("Q4"). The spoken summary built in the same file should use the same date.

**Acceptance:** with the fixture, YTD, 1Y and ALL all label the current quarter the same way, and the current week's bar reads the same on YTD and ALL. Add a unit case for each.

## Dedupe

w21/096 is the US-only `M/D` format, and w21/102 the clipped *first* period's budget. Neither covers the last label. Searched `.pm/**` for periodAxisLabel, quarterly, "last bar" and "axis label".

Fixed in mobile: `periodAxisLabel` labels a quarterly or weekly bar by the period's own last day (`addDaysISO(nextIntervalStartISO(date, interval), -1)`) instead of the date the server sent, which on a windowed span (YTD, 1Y) ends today. The current quarter now reads "DEC" and the current week "10/25" on every span, matching ALL; daily, monthly and yearly labels are unchanged. The spoken chart summary is built from the same labels, so it agrees. Tests: a new case in `period-axis-label.test.ts` (any date in Q4 gives the quarter-end month, any date in the week of Oct 19 gives 10/25); the existing weekly case now passes a week's Sunday, the date the server sends for a finished week. The new case fails with the change reverted. Deviation: an alternative "Q4"-style label was not chosen (the month-abbreviation keys are reused); no simulator run.
