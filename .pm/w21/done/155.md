# On a non-default server, the app still sends the user's merchant list to the hosted logo service

**Severity:** minor-to-moderate (privacy). A user who points the app at their own server still has every brand-matched payee (`chase.com`, `coinbase.com`, `cvs.com`, …) requested from `opengraph-image.blockeden.xyz`, revealing their IP and which institutions are in their private ledger. **Estimate:** 20 minutes. Owner: mobile. A3: the logo proxy URL is fixed at build time (`EXPO_PUBLIC_LOGO_PROXY_URL`, defaulting to the hosted service) and ignores the server the user selected. w4/031 judged the proxy acceptable from a hosted user's point of view only.

Code-level at `main` `bca6a678c`.

## Where

- `mobile/src/config.ts:15-19`
- `mobile/src/components/account-type-icon/index.tsx:101-103`
- `mobile/src/common/brand-matcher/index.ts:283`

## Fix

Use the hosted logo proxy only when the selected server is the default managed server; otherwise fall back to glyphs, as an empty `logoProxyUrl` already does. This doesn't bridge a split deployment (`.pm/DO_NOT_DO.md`). It only stops data leaving a self-hosted setup.

**Acceptance:** with a custom server URL, Transactions shows glyphs and a traffic capture shows no requests to the logo host. The default server is unchanged.

## Dedupe

w4/031 is the earlier proxy review. Searched `.pm/**` for blockeden, logoProxyUrl, logo.dev, "brand logo" and self-host.

**Resolution (2026-10-21):** `AccountTypeIcon` builds logo URLs from `logoProxyForServer(selected, build default, config.logoProxyUrl)` (`common/brand-matcher`). The proxy is used only when the selected server is the build's own default (case and trailing slash ignored); on any server the user chose themselves the icon falls back to glyphs, so no payee domains leave a self-hosted setup. It reacts to `serverUrlOverrideVar`. Test: `brand-matcher/__tests__/logo-proxy-server.test.ts` (the wiring case fails with the icon reverted). No traffic capture was taken.

**Native recheck 2026-10-21:** not exercised. Pointing the app at a non-default server signs the shared QA session out, and no traffic capture is set up. Covered by `logo-proxy-server.test.ts` only.
