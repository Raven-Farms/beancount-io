# New File's name check accepts names the server's new portable-path rule refuses (":", "?", "con", a trailing dot or space), so the dialog closes and a raw English toast appears (w23/054)

**Severity:** minor once deployed. **Estimate:** 15 minutes. Owner: mobile. A3: `693b56898` (w23/054) adds `backend-v2/src/features/ledger/utils/safe-repo-path.ts:45` (applied at `ledger-workflow.ts:902` and in the ledger service's `api/files.ts`), which refuses `<>:"|?*`, Windows device names, and parts ending in a dot or space. Mobile's `ledger-file-browser-screen/utils.ts:49-75` (`checkLedgerFileName`) checks only backslashes, control characters, empty or `.`/`..` segments, and the extension.

Native (iPhone 17e at `7bdc974f6`, disposable ledger): Files ▸ New File, paste "Q1: taxes". **Create file** is enabled. Production still accepted it (backend-v2 isn't deployed with w23/054 yet): "Q1: taxes.bean" was created and opened, then deleted through the API, and the ledger is identical to its snapshot. After the deploy, the same tap closes the dialog (`index.tsx:526`) and shows the server's English text ("…contains one of <>:\"|?*, which Windows cannot store").

## Fix

Mirror the portable-path rule in `checkLedgerFileName` (shared rule or a pinned copy) and show it inline with Create disabled, as w21/222 set up.

**Acceptance:** "Q1: taxes", "con" and "a?b" show an inline error, translated. A unit case pins the client rule to the server's.

## Dedupe

w21/222 is the same symptom for another cause. Searched `.pm/**` for checkLedgerFileName, assertPortableRepoPath and "Windows cannot store".

**Resolved 2026-10-22** — `checkLedgerFileName` carries a copy of backend-v2's portable-path rule (`<>:"|?*`, control and bidirectional characters, a part ending in a dot or space, Windows device names, a part over 255 UTF-8 bytes, counted with the added `.bean`), so "Q1: taxes", "con" and "a?b" show an inline error with Create disabled, in all 13 languages (`ledgerFileNamePortable`). The cases in `check-ledger-file-name.test.ts` (`mobile`) restate the server's; names the server accepts, such as "contacts" and "console.bean", stay accepted. The translations are mine.
