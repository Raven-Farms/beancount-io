# "Load more" fails silently on Transactions and Account detail: the list just ends, with no error or retry

**Severity:** minor. **Estimate:** 20 minutes. Owner: mobile. A3: the `fetchMore` failure handler in `transactions-screen.tsx:226-228` and in `account-detail-screen.tsx:359-361` only logs. The query's `error` stays unset, so no stale-data banner shows, and the footer (about `transactions-screen.tsx:362-372`) renders nothing: no spinner, no "No more entries", no error. `VirtualizedList` asks for the next page again only after the user scrolls out of range and back. Offline or on a dropped connection, the list ends partway through and looks like the full history.

Code-level at `main` `7280ccceb`. Not run natively.

## Fix

Keep a load-more-failed state and render an error footer with a Retry button.

**Acceptance:** with the network off, scrolling to the end of a paged list shows an error footer, and Retry loads the next page once the network is back.
