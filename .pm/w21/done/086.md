# Cancelling the RTL restart prompt leaves the layout and the language mismatched, and later language changes decide the prompt from saved languages, not the live layout

**Severity:** minor. A cold launch heals it. **Estimate:** 20–30 minutes. Owner: mobile. A3: choosing a language saves it before the "restart for layout" alert, and the alert can be cancelled. From then on, whether to prompt is decided by `layoutDirectionChanges(oldSavedLocale, newLocale)`, never by the direction actually applied:

- **Scenario A.** English → فارسی, then **Cancel**. The text is Persian, laid out left to right. Picking فارسی again returns early because it equals the saved locale, so the prompt can't be brought back. Only a force-quit fixes the layout.
- **Scenario B.** While running in Persian (RTL), switch to English and **Cancel**: still RTL. Then switch English → Deutsch. There's no prompt, because neither saved locale is RTL, so German shows mirrored until the next cold launch.
- **Scenario C.** After Scenario A, switching فارسی → English prompts for a restart even though the layout is already left to right.

Environment: `main` at `33dc9729d`. Code-level. Native repro is possible by switching language in Settings and cancelling. It wasn't driven, to keep the shared device in English and LTR for the other QA runs.

## Root cause

`mobile/src/screens/setting/main-content.tsx:234-262`:
- the early return at `:236` (`changeTo === locale`);
- `localeVar`, `i18n.locale` and `setLocale` are applied at `:239-241`, before the alert;
- `:248` compares saved locales.

`src/common/rtl.ts` exposes the live `isRtlLayout()`. `splash-provider.tsx:102` repairs the mismatch only on a cold launch.

## Fix

Decide the prompt from `isRtlLayout() !== isRtlLocale(changeTo)`, and don't early-return when that mismatch exists. Picking the current language while its layout is pending then re-offers the restart. Alternatively, offer the restart again from Settings while a mismatch exists.

**Acceptance:** unit tests on the decision function:
- A: a mismatch with the same locale prompts.
- B: LTR → LTR with a live RTL layout prompts.
- C: no prompt when the live layout already matches.
