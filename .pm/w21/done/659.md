# Mobile shows the ledger's entry-token refusal as raw English API text with field paths ("entry 0: postings[0].account … is not a valid account") (split from w21/649)

**Severity:** minor (every non-English locale). **Estimate:** 45 minutes. Owner: mobile. `mobile/src/common/ledger-refusal.ts:209-211` passes any `BAD_USER_INPUT` message through unchanged. The ledger's structured-entry validator (`backend-cluster/ledger/src/features/ledger/utils/entry-tokens.ts`, `assertEntryTokens`) answers in the form `entry <n>: <field path> "<value>" is not a valid <kind>`, so New Transaction, Open Account and Add Budget show English text naming wire fields (`postings[0].account`, `tags[0]`) in any language. w21/649 fixed the ZWNJ account that hit this most often; an account name the editor wrote that the validator still refuses, a non-ASCII tag (w21/653) or a `%` flag (w21/650) reach the same raw text.

## Fix

Recognize the validator's `is not a valid <kind>` refusal and show translated copy naming the kind (account, tag, link, currency, flag) and the value, in all locales, falling back to the generic failure for anything else.

**Acceptance:** a refused account or tag shows translated copy without the field path in a non-English locale. A unit case covers each kind and the fallback.

**Resolved 2026-10-22** — mobile's write-failure copy (`common/ledger-refusal.ts`) now recognizes the ledger's `entry <n>: <field> "<value>" is not a valid <kind>` refusal on a `BAD_USER_INPUT` error and shows translated copy naming the value, not the wire field: "Assets:Bank:x y isn't a valid account name.", "#旅行 can't be used as a tag. Use only the letters A–Z, digits and - _ . /", and the same for a currency, a link and a flag (a `%` flag's reason included). All 13 locales are translated. A token refusal of a kind with no copy (a date, a metadata key) shows the screen's generic failure; other bad-input text is unchanged. Unit cases in `common/__tests__/ledger-refusal.test.ts` cover each kind, the fallback and other text (two fail without the change) (`mobile`). Not checked in the simulator: provoking the refusal means sending a write to production.
