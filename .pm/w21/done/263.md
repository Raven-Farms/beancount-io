# Spending's "Not in total" nets the two months together, so a refund last month hides spending this month

**Severity:** minor. **Estimate:** 15 minutes. Owner: mobile. A3: `select-spending-compare` sums the foreign-currency amounts from both months into one entry per currency and drops zeros.

Code-level at `main` `26fb7ee69`. Run under Node:
- September `{USD 1200, EUR −50}` (a refund) plus October `{USD 300, EUR 50}` gives `notInTotal: []`, so no note at all.
- 80 EUR spent against a 30 EUR refund reads "50 EUR", which neither month spent.

## Root cause

`mobile/src/screens/home-screen/selectors/select-spending-compare.ts:76-88`.

## Fix

Keep the omissions per month, and show this month's (or label both: "This month: 50 EUR · Last month: −50 EUR").

**Acceptance:** the first case reads "Not in total: 50.00 EUR" for this month. Unit cases are added.
