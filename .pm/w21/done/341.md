# The file editor's text ignores the system text size on iOS (fixed 14 px, pinch-zoom disabled), including at AX2

**Severity:** minor (accessibility). It reproduces at AX2, within `.pm/DO_NOT_DO.md`'s ceiling. **Estimate:** 20 minutes. Owner: mobile. A3: the editor hard-codes `fontSize: "14px"` for the code and the gutter, and no `fontScale` reaches it. WKWebView doesn't apply Dynamic Type to px sizes, and Expo's DOM page template sets `user-scalable=no`. At AX2, where native body text is about 33 pt, ledger source stays at 14 px with no way to enlarge it.

Code-level at `main` `57826d105`: `mobile/src/components/code-editor/code-editor.tsx:94-100`, and `node_modules/@expo/cli/build/src/start/server/middleware/DomComponentsMiddleware.js:113`. Consistent with this session's AX2 screenshots, where the editor text didn't grow; that wasn't measured.

## Fix

Pass `useWindowDimensions().fontScale` as a prop and scale the editor font (and gutter) through a compartment, as the theme already is, with a sensible cap.

**Acceptance:** at AX2, the editor text is visibly larger than at the default size. A source check covers the prop.

## Dedupe

w2/044 and w2/m37 noted the fixed 14 px as out of scope without filing it. Searched `.pm/**` for "14px", fontScale together with editor, and Dynamic Type together with editor.

Fixed from the source; not measured on a device (consistent with the note's AX2 screenshots, where the text did not grow). `CodeEditor` takes the platform's `fontScale` as a prop (both screens that mount it, the file editor and Edit Transaction, pass `useWindowDimensions().fontScale`) and sizes the code and the gutter from it: `editorFontSize` is 14 px at the default size, grows with the text size and is capped at 2.4x (about iOS's AX2), so AX2 reads about 33 px instead of 14. The size lives in the theme compartment, so a text-size change while the editor is open reconfigures it without touching the document, selection or undo history (the reconfigure compares the size as well as the theme by value). Tests in `code-editor/__tests__/editor-font.test.ts` (the sizing rule, and source checks of the prop on both screens, the gutter and the compartment; the wiring fails with the three files reverted). Mobile gates and deadcode green.
