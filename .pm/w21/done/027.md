# At AX2, Budget card titles shrink to "Ex…ing" and "Ex…ries", so budgets can't be told apart

**Severity:** minor (readability at a supported size). **Estimate:** 20–30 minutes. Owner: mobile. A2: at `accessibility-large` (AX2, the supported ceiling in `.pm/DO_NOT_DO.md`), each Budget card's account name shares one row with the "Update Budget" action. The name is middle-ellipsized to a few letters, so two budgets read "Ex…ing" and "Ex…ries".

Environment: `main` at `1f0c3856d`, dev build `io.beancount.ios` 1.20261002.50 on iPhone 17e (iOS 27.0), `content_size accessibility-large`, cold launch. QA account, synthetic ledger `mcp-agent-eval` with `custom "budget"` directives for `Expenses:Food:Groceries` (300 USD) and `Expenses:Entertainment:Streaming` (20 USD). Restored afterwards.

## Repro

1. Set AX2, launch, Home → Budget → **See all**.
2. The first card's title is **"Ex…ing"** and the second's **"Ex…ries"**. "Update Budget" fills most of the row. At the default size the titles read `Expenses:Food:Groceries` / `Expenses:Entertainment:Streaming` in full.

## Root cause

`mobile/src/screens/budget-screen/components/budget-group-card.tsx:194-207`: `titleRow` is a single `flexDirection: "row"` holding `<Text numberOfLines={1} ellipsizeMode="middle">{group.account}</Text>` and the `updateText` button. There is no stacked layout for large text. Control: `DashboardCard` stacks its title above its action when `prefersStackedLayout(fontScale)` (`components/dashboard-card/index.tsx:114-132`), as fixed for Home in `d0c2ab216`.

## Fix

Reuse `prefersStackedLayout(useWindowDimensions().fontScale)`. When stacked, put the account name on its own line (allow 2 lines, or `ellipsizeMode="head"` so the leaf survives) and move "Update Budget" below it. At default sizes keep the current row. Key the title Text on `fontScale` for live changes (see w21/015).

**Acceptance:** at AX2, both cards show enough of the account to tell them apart, at minimum the leaf (`…Groceries`, `…Streaming`), with "Update Budget" fully visible. Default size is unchanged. A layout test asserts the stacked branch at fontScale ≥ the shared threshold.

## Dedupe

Searched `.pm/**` for Budget with truncation, enlarged text and AX2. w4/050 fixed the account picker's truncation direction, `d0c2ab216` stacked Home card titles, and w3/m-series AX fixes covered other screens. No item covers Budget card titles.

---

**Resolved 2026-10-20** — `budget-group-card.tsx` stacks its title row from `prefersStackedLayout(fontScale)`, the same threshold `DashboardCard` uses, which AX2 crosses. The account takes the full width on up to two lines, with `ellipsizeMode="head"` so `…Groceries` and `…Streaming` survive. `flex: 0` keeps it from collapsing in the column. Update Budget moves under the account. The title is keyed on `fontScale` for live size changes, and the default-size row is unchanged. `budget-card-title-layout.test.ts` pins the stacked branch, the line and ellipsis rule, the button move and the key on the source, since the card runs queries the unit runner can't execute. Mobile gates pass: format, tsc, eslint, knip, and 2450 unit tests. Not checked at AX2 on the simulator. Shipped in `13dc031c3` (`mobile`).
