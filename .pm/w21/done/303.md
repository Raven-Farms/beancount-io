# Update Budget can save an income target with the wrong sign while the ledger's options are still loading

**Severity:** minor. It's a narrow race, but the favourability flips silently. **Estimate:** 10 minutes. Owner: mobile. A3: in update mode the currency comes from route params, so `canSubmit` doesn't wait for ledger metadata. The save passes `incomeRoot: ledgerMeta?.options.name_income`, which is `undefined` until metadata arrives, and `buildBudgetEntry` then skips the income sign. Metadata is evicted by every entries write and missing on a cold link or a failed read.

Code-level at `main` `10857997b`: `buildBudgetEntry({ account: "Income:Salary", number: "5000", incomeRoot: undefined })` returns `{ number: "5000" }`, so the target then reads as a spending cap.

## Root cause

`mobile/src/screens/add-budget-screen/add-budget-screen.tsx:217-228` (`canSubmit`) and `:253` (`incomeRoot`).

## Fix

Require ledger metadata to be loaded without error in `canSubmit`, or derive the income root from the account name's first component as a fallback.

**Acceptance:** with metadata pending, Done is disabled; once it lands, an income update saves a negative number. A unit or source check covers it.

## Dedupe

w4/039's resolution leaves any budget as typed when the root is unknown, but no item covers this race. Searched `.pm/**` for incomeRoot, name_income and metaLoading.

Fixed. Add Budget's `canSubmit` now waits for the ledger's options: Done is disabled until the metadata has loaded (`ledgerMeta` present, cached copies count) or its read has failed (`metaSettled`). Once they land, an income update goes out negative; if the read failed the wait ends and the amount goes as typed, since a Done that could never enable would be a dead end (the other option in the note, deriving the root from the first account component, was not used because a renamed income root would then be misjudged). Source checks in `add-budget-screen/__tests__/meta-before-save.test.ts` (the gating case fails with the screen reverted), plus the sign contract of `buildBudgetEntry` with and without the root. Mobile gates and deadcode green.
