# Narration suggestions get the keyboard inset twice on iOS after w21/145 (a blank band below the last suggestion)

**Severity:** minor (layout). Confidence is medium: it's proved from React Native's source, not on a device. It's the same class as w21/247, a manual adjustment on top of one iOS already makes. **Estimate:** 10 minutes. Owner: mobile.
