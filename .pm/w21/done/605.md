# Transaction detail's decorative icon glyphs are their own VoiceOver stops: hero icon, calendar, error, tag, link and metadata icons (w21/141 fixed only account rows)

**Severity:** low. **Estimate:** 10 minutes. Owner: mobile. A3 (code-level at `main` `dbe9b0144`): `transaction-detail-screen.tsx:679` (hero `AccountTypeIcon`), `:697` (the calendar before the date), `:713` (the warning icon on each error row) and `:766, :791, :817` (tag, link and metadata icons) aren't hidden from accessibility. Vector icons render as Text, so each glyph is a stop, and w2/069 heard such glyphs read as "U+F…". Not run with VoiceOver.

## Fix

Hide decorative icons (`accessibilityElementsHidden` / `importantForAccessibility="no-hide-descendants"`), as w21/141 did in account-entry-row.

**Acceptance:** VoiceOver goes title → amount → date → Details with no glyph stops. The a11y guardrail covers this screen.

Same pattern as w21/141 (done) and w21/558. Searched `.pm/**` for AccountTypeIcon and "glyph".
