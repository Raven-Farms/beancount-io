# When Create Ledger's preview fails, Review shows raw English transport text ("Network request failed") with no Retry, and Create stays enabled

**Severity:** minor-to-moderate. **Estimate:** 20 minutes. Owner: mobile. A3: `create-ledger-screen.tsx:788-789` renders `{previewError.message}` directly. w21/117's `no-raw-error-message.test.ts` guard only matches `? x.message` fallbacks, so it misses this JSX render.

Code-level at `main` `dcac808bc`. In the reviewer's tsx run, `ApolloError({networkError: TypeError("Network request failed")}).message` gives "Network request failed", and a 502 gives "Response not successful: Received status code 502", untranslated in all 13 locales. There's no Retry (the preview re-runs only on Back then Next), and Create stays enabled, so the user creates without seeing the accounts. Not exercised (the network can't be failed here).

## Fix

Map transport and 5xx failures to a localized message (the w21/117 mapper or a new `createLedgerPreviewError` key), add a Retry that re-runs `runPreview`, and widen the guard to catch `{…Error.message}` in JSX.

**Acceptance:** an offline preview shows a translated message with Retry. The guard test fails on the old line.
