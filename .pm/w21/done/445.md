# Money flow pads decimals only for USD, so "4.5 EUR" rows sit under a "-4.50 EUR" headline

**Severity:** minor. **Estimate:** 10 minutes. Owner: mobile. A3: `transaction-detail-screen/selectors/select-transaction-detail.ts:104-107` pads to two places only when `currency === "USD"`. The headline uses `formatAmount`, which pads to each currency's minor units (w21/070), so on a non-USD entry the posting rows contradict the headline right above them. The same applies to the cost and price line ("Cost 100 EUR · Price 120 EUR") and to three-decimal currencies such as KWD.

Code-level at `main` `a69419ae4`, from the reviewer's tsx run: for `4.5 EUR` the headline is `-4.50 EUR` and the rows are `+4.5 EUR` / `-4.5 EUR`; for `5 EUR`, `-5.00 EUR` against `+5 EUR`.

Reproduced natively (iPhone 17e, `ffbbd7881`) with a `4.5 EUR` transaction written to the disposable ledger and restored. The detail headline reads "-4.50 EUR", and the Money flow rows below it read "+4.5 EUR" (Expenses:Food:Coffee) and "-4.5 EUR". The Transactions list row also reads "-4.50 EUR".

## Fix

Pad to `currencyMinorUnits(currency)` from `common/currency-util`, keeping longer source decimals as now.

**Acceptance:** `4.5 EUR` renders as `4.50 EUR` in Money flow, and `1500 JPY` stays `1500 JPY`. Unit cases are added.

## Dedupe

w21/070 fixed the shared money formatter only; w21/160 covers per-unit digits, and w21/231 and w21/389 cover JPY writes. Searched `.pm/**` for padEnd, minor units, Money flow and EUR.

Resolved. Money flow's amounts pad like the headline above them: `formatPostingUnits` pads to the currency's own minor units (EUR to two, KWD to three, JPY none) instead of only for USD, keeping longer recorded digits. The cost and price lines go through the same formatter, so they follow. Deviation from the note's wording: the padding applies to known currencies only (those `getCurrencySymbol` knows, the test the app already uses for "a stock ticker is not one"), because a commodity such as a share count would otherwise read "-4.00 QAX"; an existing test pins "-4 QAX". Tests cover EUR, KWD, USD, JPY, a longer scale and a non-currency commodity; they fail against the old formatter. No native run.

Native recheck (iPhone 17e, fresh Metro `--clear` at `152ec1714`): the same `4.5 EUR` fixture (disposable ledger, restored) now shows Money flow rows "+4.50 EUR" and "−4.50 EUR" under the "−4.50 EUR" headline. Fixed.
