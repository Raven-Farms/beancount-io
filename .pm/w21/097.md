# The Delete Budget alert inserts a standalone adverb as an adjective, so it is ungrammatical in de, nl, ru, uk, sk and bg

**Severity:** minor. It appears on a destructive confirmation. **Estimate:** 30 minutes. Owner: mobile. A3: the message assumes English word order. One interval label serves both as a picker value ("Monatlich") and as the attributive adjective in a sentence.

Code-level at `main` `89ddcfe9e`.

## Scenario

- de: "Das monatlich Budget von … löschen?" should use *monatliche*.
- nl: "Het maandelijks budget…" should use *maandelijkse*.
- ru: "Удалить ежемесячно бюджет…" uses an adverb where an adjective is needed.
- sk and bg have the same problem.

## Where

`mobile/src/screens/budget-screen/components/budget-history-rows.tsx:121` passes `t(intervalLabelKey(interval)).toLowerCase()` as `{{interval}}` into `budgetDeleteMessage` (for example `translations/de.ts:560-561`).

## Fix

Use one message key per interval, such as `budgetDeleteMessageMonthly`, or a dedicated adjective key set (`budgetIntervalAdjMonthly`, …) translated with the right agreement. Drop the `toLowerCase()`.

**Acceptance:** in de and ru, the alert for a monthly budget reads grammatically ("Das monatliche Budget…", "ежемесячный бюджет"). The locale key-parity test passes.
