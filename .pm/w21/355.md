# Text fields are named only by their placeholder or example value, so VoiceOver reads "500, text field" or just the value

**Severity:** minor-to-moderate. **Estimate:** 30 minutes. Owner: mobile. A3: these fields have no `accessibilityLabel`, and the visible label is a sibling `Text`:

| Field | Only name |
|---|---|
| Add Budget amount (`add-budget-screen.tsx:338-357`) | `EXAMPLE_AMOUNT` "500" |
| Open Account name (`open-account-screen.tsx:426-438`) | "Bank:Checking" |
| New Ledger File, via `text-input-modal/index.tsx:232` | "investments.bean" |
| Delete-account confirm (`setting/main-content.tsx:312-316`) | "Type the phrase here" |
| Payee / Narration (`text-input-screen/index.tsx:288-299, 308-318`) | "Please input..." |

iOS stops reading the placeholder once the field has text, so on Update Budget, or when editing a payee, VoiceOver reads only the value. An empty budget amount reads "500", which sounds like the current budget.

Code-level at `main` `5a4e27da4` against React Native 0.86 (Fabric) sources in `mobile/node_modules`. Not exercised with VoiceOver, which this simulator setup can't drive.

## Fix

Pass `accessibilityLabel`: `t("budgetAmount")`, `t("account")`, the modal `title`, or the screen title, through `TextInputModal` and `TextInputScreen`. Extend `__tests__/accessibility-labels.test.ts` to cover `TextInput`.

**Acceptance:** every listed field reads its label before its value.
