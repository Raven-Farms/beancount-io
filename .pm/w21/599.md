# Latest Updates shows every save as an identical "Committed to books" row, dropping the commit message and author the query already fetches

**Severity:** low. **Estimate:** 15 minutes. Owner: mobile. A3 (code-level at `main` `c9cda71b9`, proven under `tsx`): `home-screen/components/feed-card.tsx:61-115` (`FeedRow`) drops the `summary` and `author` that `getFeed.graphql` fetches, and the title is only `repo.name` (`activity-transformer.ts` `titleTemplates`). The dashboard shows both (`dashboard/.../feed-card.tsx:62-64`). Several saves in a day give identical rows ("Committed to books · Ledger · Oct 22, 2026"), so they look duplicated, and a collaborator's commit to a shared ledger can't be told from yours.

Not run natively: the feed card is below Home's fold.

## Fix

Show the commit message as the row's subtitle and the author when it isn't the current user, as the dashboard does.

**Acceptance:** two saves show their two messages, and a collaborator's commit names them. A render test covers it.
