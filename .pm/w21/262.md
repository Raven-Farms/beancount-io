# Until the ledger's read context loads, or if its first load fails, a non-USD ledger's Home shows net worth and spending as $0 in USD

**Severity:** minor-to-moderate. A wrong headline flashes on every cold start, and on a failed first load it stays with no error. **Estimate:** 20 minutes. Owner: mobile. A3: Home takes `getPrimaryCurrency(currencies)`, which falls back to "USD" while `useLedgerReadContext` has no data. `isLoading` and `chartError` never wait on it, and Spending treats a context error as settled.

Code-level at `main` `26fb7ee69`. A reviewer's Node run on a EUR ledger:
- **Context not loaded or failed:** currency USD, headline 0, "1 not in total", and Spending this month 0 with "Not in total: 300 EUR".
- **Loaded:** EUR, headline 17,200, Spending 300.

## Root cause

`mobile/src/screens/home-screen/home-screen.tsx:72` (`getPrimaryCurrency`) and `:164-170` (`isLoading`, `chartError`). `isShowingStaleDataFromQueries` ignores a failure with nothing cached.

## Fix

Hold the chart and Spending skeletons until the read context settles. If it failed, show the card failure state (`CardLoadFailure`) instead of rendering with the "USD" fallback.

**Acceptance:** on a EUR ledger, Home never renders a USD headline. A failed context read shows the failure card with Retry. A unit or source check covers it.
