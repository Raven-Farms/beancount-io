# Profile Save silently does nothing when a first or last name is over 100 characters

**Severity:** minor. Save looks enabled, tapping it sends nothing and shows nothing. **Estimate:** 10 minutes. Owner: mobile.

Code-level at `main` `9c7878b18`.

## Root cause

`mobile/src/screens/profile/profile-screen.tsx:232-233` validates `firstName` and `lastName` with `z.string().max(100)`, but only `errors.username` is ever rendered (`:366-371`). react-hook-form blocks submit on the hidden error. The server (`account-service.ts`, a `text` column) has no such limit.

## Fix

Render `errors.firstName` and `errors.lastName` under their fields with a translated "At most 100 characters" message, or set `maxLength={100}` on the inputs.

**Acceptance:** pasting 101 characters into First name shows the message (or is capped at 100), and Save then works.

## Dedupe

Searched `.pm/**` for "profile name length", `max(100)` and firstName.
