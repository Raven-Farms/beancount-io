# Settings' Invite Friends row is read by VoiceOver as "Invite Friends" twice, and its summary is never spoken

**Severity:** minor (accessibility). **Estimate:** 5 minutes. Owner: mobile. A3: `referral-screen/components/invite-section.tsx:67` renders the title `t("inviteFriends")` as its own focusable `Text`, and the button at `:71-72` sets `accessibilityLabel={t("inviteFriends")}`, which replaces its children, so the summary (`t("inviteSummary")`, `:78`) is never spoken. This is the defect w21/287 fixed for the Settings list rows (`setting/list-item-label.ts`); this row was missed.

Code-level at `main` `1984ae57d`; not exercised with VoiceOver. The row ("Invite Friends / Share this professional financial management tool…") is the first section of Settings in this session's screenshots.

## Fix

Label the button `${t("inviteFriends")}, ${t("inviteSummary")}`, or drop the explicit label and hide the duplicate title from accessibility.

**Acceptance:** VoiceOver reads the row once, with its summary. A label test is added.
