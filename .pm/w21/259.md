# In New Transaction, Create from any posting's picker prefills the Assets root, even on the expense row

**Severity:** minor. One tap on Done books "groceries" to `Assets:Groceries`. **Estimate:** 10 minutes. Owner: mobile. A3: multi-posting is the default New Transaction, and every row pushes the picker with `type: "posting"`. `push-account-picker.ts` maps `posting` to `"from"`, and the picker picks the Expenses root only for `"to"`.

Code-level at `main` `26fb7ee69`. On the second posting, search `groceries` (with no such account) and tap Create: Open Account opens with **Assets:** selected and "Will be created as Assets:Groceries", with Done enabled.

## Root cause

- `mobile/src/screens/account-picker-screen/push-account-picker.ts:13`.
- `account-picker-screen.tsx:494`.
- `multi-postings-transaction-screen.tsx:681-689`.

## Fix

Pass a root hint per row: Expenses for non-first rows or rows with a positive amount, Assets for the first. Or leave the root unselected for `posting` pickers so the user chooses.

**Acceptance:** Create from the second posting prefills `Expenses:Groceries`. A unit case covers the mapping.

## Dedupe

w21/008 is the new account's open date, and w21/103 the closed default. Searched `.pm/**` for prefillRoot, rootless, and `posting` together with "from".
