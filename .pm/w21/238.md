# Create Ledger keeps a field's error after you correct it: a fixed currency still says "Choose a currency code like USD or EUR"

**Severity:** minor. The form looks broken after the user has fixed it, until they try Next again. **Estimate:** 10 minutes. Owner: mobile. A3: w21/105 made Next validate the whole form with `trigger()`. `useForm` keeps react-hook-form's defaults (`mode: "onSubmit"`, `reValidateMode: "onChange"`), and re-validating on change only starts after a real *submit*. `trigger()` isn't one, so an error set by Next stays on screen while the user types a valid value.

Reproduced natively on the iPhone 17e simulator (iOS 27.0) at `main` `4ba42392a`, with nothing created:
1. Create Ledger, step 2: replace Operating currency with `US` and tap Next. The field shows "Choose a currency code like USD or EUR." This is w21/107 working.
2. Replace it with `USD`. The field reads **USD**, with the red message still under it.
3. Tap Next. The form moves to Review, so the value was valid all along.

## Root cause

`mobile/src/screens/create-ledger-screen/create-ledger-screen.tsx:243-255` (`useForm` without `mode`), and `:448` (`if (step === 1 && !(await trigger())) return;`).

## Fix

Set `mode: "onTouched"` (or `reValidateMode` with `mode: "onChange"`) on `useForm`, or call `trigger(name)` in each field's `onChange` once it has an error. The amount and "Books begin" fields benefit the same way.

**Acceptance:** in the steps above, the message disappears as soon as the field holds `USD`. A unit or harness test covers clearing.
