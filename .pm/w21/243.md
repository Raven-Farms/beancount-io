# VoiceOver reads ledger rows by name only: Browse ledgers never says Private or Public, and an unavailable example gives no reason

**Severity:** minor. **Estimate:** 20 minutes. Owner: mobile. A3: each row sets an explicit `accessibilityLabel`, which replaces its children, so the visible description, the Private/Public line and the unavailable status are never read.

Code-level at `main` `4ba42392a`.
- **Browse ledgers rows:** "Open {name}" only (`mobile/src/screens/ledger-selection/index.tsx:280`). The visibility line at `:316` and the description are skipped, so on Starred and Yours a VoiceOver user can't tell private from public ledgers.
- **Drawer rows:** `item.fullName` only (`ledger-drawer.tsx:927`). In the guest drawer, an unavailable example reads "open_ledger/nvidia, dimmed", with no "Unavailable" or connection-error reason (`:941`, `example-tabs.tsx:44`).
- **Guest example cards** (`example-selector.tsx:59`) skip the description and the unavailable reason too.

## Fix

Build each label from the name plus visibility, description and status, in the visible order, or drop the label and let the children be read.

**Acceptance:** a Browse ledgers row reads "Open qa/my-book, Private, Household budget", and an unavailable example reads its reason. Source checks cover the three sites.
