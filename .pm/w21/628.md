# Open Account joins "Credit Card" into "CreditCard" only when a root is pasted in front; typed on its own, the same words are refused

**Severity:** low. **Estimate:** 15 minutes. Owner: mobile. A3: `open-account-screen/account-name.ts:116-128` (`peelTypedRoot` → `splitPrefillAccountName` → `joinPrefillWords` at `:74`), run on every change (`open-account-screen.tsx:457-462`). w21/255's space-joining applies only when a root is peeled off, and the field uses `autoCapitalize="words"`.

Native (iPhone 17e at `47c043676`; nothing saved): Accounts ▸ + ▸ paste "Credit Card" shows the error "Use only letters, numbers, and hyphens in account names." and Done is disabled. Clearing and pasting "Assets:Credit Card" shows "CreditCard" with "Will be created as Assets:CreditCard" and Done enabled. Under `tsx`, "Bank:credit card" is refused while "Assets:Bank:credit card" becomes `Assets:Bank:CreditCard`.

## Fix

Apply the same word joining (or the same refusal) to the typed name whether or not a root is present.

**Acceptance:** "Credit Card" and "Assets:Credit Card" give the same result. Unit cases are added.
