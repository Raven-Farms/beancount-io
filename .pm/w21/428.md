# Regression from w21/276: file-editor error rows without a line are now announced as "dimmed" by VoiceOver

**Severity:** minor (accessibility; the same defect w21/287 fixed for Version). **Estimate:** 10 minutes. Owner: mobile. A3: `ledger-file-editor-screen/index.tsx:268` sets `disabled={err.lineno == null}` on the error row's `TouchableOpacity`. RN merges that into `accessibilityState.disabled` (`TouchableOpacity.js:280-285`), so VoiceOver adds "dimmed" (TalkBack "disabled") to what is plain error text. `__tests__/error-row-hint.test.ts` pins the `disabled` prop.

Code-level at `main` `669120634`.

## Fix

Render line-less rows as an accessible plain `View` (as `setting/list-item.tsx:131-154` does), or drop `disabled` and keep a no-op `onPress`, and update the test pin.

**Acceptance:** a line-less error row is read as text, not "dimmed".

## Dedupe

This is a regression from w21/276; w21/287 set the pattern. Searched `.pm/**` for dimmed, errorRow and "error row".
