# If the ledger's metadata fails to load, Open Account's Done stays grey forever with no message or retry (Add Budget handles this)

**Severity:** low. **Estimate:** 10 minutes. Owner: mobile. A3 (code-level at `main` `47c043676`, proven under `tsx`): `open-account-screen.tsx:224` never reads `error` from `useLedgerMeta`. `openAccountSubmitState` (`account-name.ts`) with `openAccounts: undefined` returns `canSubmit: false`, and the currency stays "No currency" (`:275-280`). The form previews "Will be created as Assets:Bank:Checking" but Done never enables, with no explanation. Add Budget includes `metaError` in `metaSettled` and shows a load error (`add-budget-screen.tsx:245`). Not run natively (it needs a cold-cache metadata failure).

## Fix

Show a load error with Retry when the metadata fails, as Add Budget does.

**Acceptance:** a metadata failure shows an error with Retry, and Retry recovers. A test covers it.
