# "Like it? Give it a review" opens a web store page in an in-app browser that can't take a review (and errors on the simulator)

**Severity:** minor. **Estimate:** 15 minutes. Owner: mobile. A3: `setting/main-content.tsx:160-168` opens `https://apps.apple.com/us/app/id1527950512` (fixed to the US storefront) or the Play web listing with `WebBrowser.openBrowserAsync`. Web listings have no write-review action, and an in-app browser doesn't hand off to the store app. `expo-store-review` is a dependency (`package.json:67`) but is never imported. Both URLs answer 200 (Apple via a 301 to the slugged URL).

**Natively observed (2026-10-21, iPhone 17e, `main` `41253a6e3`):** Settings ▸ "Like it? Give it a review" opens an in-app Safari view showing **"Safari cannot open the page because the address is invalid."**, from the redirect toward the App Store scheme the simulator lacks. On a device it shows the web listing without a review action, by code reading.

## Fix

Use `StoreReview.requestReview()` when it's available. Otherwise open `itms-apps://apps.apple.com/app/id1527950512?action=write-review` or `market://details?id=io.beancount.android` with `Linking.openURL`, and fall back to the https URL.

**Acceptance:** on a device, the row opens the store's write-review sheet.
