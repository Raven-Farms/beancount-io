# The file editor's shortcut keys mostly read as just "Insert": the symbols aren't spoken, ⇥ is a glyph name, and the date is raw ISO

**Severity:** low. **Estimate:** 15 minutes. Owner: mobile. A3: `components/keyboard-accessory-bar/index.tsx:106-116` labels each key `t("keyboardAccessoryInsert", {symbol: btn.label})` (buttons from `utils.ts:34-45`). Under `tsx` the labels are "Insert 2026-10-22", "Insert *", "Insert !", `Insert ""`, "Insert :", "Insert USD", "Insert ⇥", "Insert -", "Insert #" and "Insert ^". At VoiceOver's default punctuation level, "!", `""`, ":" and "-" are most likely not spoken, so four keys read as just "Insert, button". Code-level at `main` `18664fa5e`; the spoken output is derived from the props (and proven under `tsx` where a builder is involved), not from a VoiceOver run.

## Fix

Give each key a spoken name ("Insert today's date", "Insert cleared flag", "Insert pending flag", "Insert quotes", "Insert colon", "Insert tab", "Insert minus", "Insert tag", "Insert link"), translated.

**Acceptance:** each key has a distinct, pronounceable label in every locale. A parity test covers the keys.
