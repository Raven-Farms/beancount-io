# Home's net-worth chart stays a loading skeleton forever when its first load fails, with no Retry (the pattern w21/239 fixed on account detail)

**Severity:** minor-to-moderate. It hits fresh installs, new sign-ins and ledgers never opened on the device, on the most-seen card. **Estimate:** 15 minutes. Owner: mobile. A3: `home-screen.tsx:170-172` sets `chartError = Boolean(balanceSheetError) && !balanceSheet`, and `account-charts-card.tsx:215` renders `LoadingTile` for `loading || error`, the code 239 removed from `BalanceChartCard`. With an error and no data, the skeleton shows indefinitely. The stale banner (`:173-177`) needs cached data, so it stays hidden too, and only pull to refresh recovers.

Code-level at `main` `62533363c`. Not driven natively; it needs an offline first load.

## Fix

Split the loading and error branches, and show `CardLoadFailure` with a Retry that refetches the balance sheet, as on Reports, Accounts and account detail.

**Acceptance:** a failed first load of Home's chart shows a failure card with Retry.
