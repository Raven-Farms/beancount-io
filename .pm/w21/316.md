# VoiceOver can't read or step through the balance charts on Home and account detail

**Severity:** minor-to-moderate (accessibility). It breaks `mobile/AGENTS.md`'s rule that charts carry a summarizing label. **Estimate:** 45 minutes. Owner: mobile. A3: the interactive line chart's plot exposes no `accessible`, label, `adjustable` role or actions. VoiceOver reads the headline and change row, then skips the curve, and a one-finger drag is a VoiceOver navigation gesture, so a VoiceOver user can't reach any earlier month. w21/018 (done) says the balance charts carry summaries, but only the headline and change row are read.

Code-level at `main` `2e850e737`: `mobile/src/common/d3/interactive-line-chart.tsx:768-857`. There are no accessibility props on the plot; `git log -S accessible` shows it never had any. `account-charts-card.tsx`, `balance-chart-card/index.tsx` and `SegmentedPages` add none either.

## Fix

- Make the chart container `accessible` with `accessibilityRole="adjustable"`, a range summary label (first and last month and value, low and high), and an `accessibilityValue` naming the selected point ("Mar 2026, $X, +$Y since start").
- Use increment and decrement actions that step the same scrub index the header follows, and reset it on blur.
- Add a test asserting these props.

**Acceptance:** VoiceOver reads a summary, and swiping up and down steps through months with the headline following.
