# File editor: Enter turns tab indentation into spaces and there's no way to type a tab, breaking Makefiles and tab-indented Python; "" replaces a selection instead of wrapping it

**Severity:** minor. **Estimate:** 20 minutes. Owner: mobile. A3: the editor sets `indentUnit.of("  ")`, so new lines always indent with spaces. There is no Tab binding (no `indentWithTab`), so a hardware Tab moves focus, and the ⇥ accessory button inserts two spaces and appears only for `.bean` files.

Code-level at `main` `57826d105`. Under Node:
- Enter on `all:\n\tbean-check main.bean` gives 4 spaces, and `make` then fails with "missing separator".
- A tab-indented Python block followed by a spaces line raises `IndentationError`.
- Separately, with text selected, the `""` shortcut replaces the selection with `""` (`code-editor.tsx:438-445`) instead of wrapping it.

## Root cause

`mobile/src/components/code-editor/code-editor.tsx:160` (`indentUnit`) and `:194` (keymap), plus `keyboard-accessory-bar/utils.ts:36, 39`.

## Fix

Derive the indent unit from the document (a tab when its lines start with `\t`), add `indentWithTab`, and offer a Tab button for non-Beancount files. Make pair shortcuts wrap a non-empty selection.

**Acceptance:** Enter in a tab-indented Makefile inserts a tab, and `""` on a selection wraps it. Unit tests are added.

## Dedupe

Searched `.pm/**` for indentUnit, indentWithTab, tab and the accessory shortcuts; nothing matched.
