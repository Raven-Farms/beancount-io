# Create Ledger's Review shows the name with the user's capitals ("MyBook"), but Create makes "mybook", and Review never shows Private/Public

**Severity:** minor. **Estimate:** 15 minutes. Owner: mobile. A3: Review renders `{slugPreview || nameValue}` (`mobile/src/screens/create-ledger-screen/create-ledger-screen.tsx:784`), and `ledgerSlugPreview` (`ledger-name.ts:19-22`) returns null whenever the slug equals `name.trim().toLowerCase()`. Submit sends `slugifyLedgerName(values.name)` (`:402`), and the server only accepts `^[a-z0-9_-]{1,100}$` (`backend-v2/src/shared/ledger-slug.ts:4`).

Code-level at `main` `dcac808bc`. In the reviewer's tsx run, `MyBook`, `Family`, `My-Book` and `HOUSEHOLD_2026` show unchanged on Review (and on the name step with no "Will be created as …" hint), but are created as `mybook`, `family`, `my-book` and `household_2026`. Review's own text says "This is exactly what will be created". Not exercised natively (no ledger creation in this run).

## Fix

Show `slugifyLedgerName(nameValue)` on Review, make the name-step hint's no-change test `slug !== name.trim()` so a case-only change gets the hint, and add a visibility line (Private/Public) to Review.

**Acceptance:** "MyBook" shows "Will be created as mybook" and Review shows "mybook" plus its visibility. Unit cases are added.
