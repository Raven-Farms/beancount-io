# A glob `include "y/*.bean"` pulls dotfiles (`y/.hidden.bean`) into hosted balances, which bean-check and `bea` skip

**Severity:** low (needs hidden .bean files in an included folder). **Estimate:** 10 minutes. Owner: ledger. A3: `file-map-loader.ts` (`BEAN_FILE_RE = /\.(bean|beancount)$/`) loads dotfiles into the engine's file map, and rustledger's glob matches them. Python's glob skips leading-dot names. Compared at `main` `1ec9cb250`: bundled `@rustledger/wasm` 0.24.0 against Python Beancount 3.2.3 with beanquery 0.2.0, on the same text. With `y/a.bean`, `y/B.bean` and `y/.hidden.bean`, rustledger loads all three and Beancount loads two. A hidden draft or template counts in hosted figures but not locally.

## Fix

Leave dotfiles out of glob matches (or out of the file map), matching Beancount.

**Acceptance:** `y/.hidden.bean` isn't included by `y/*.bean`. A test covers it.
