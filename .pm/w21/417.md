# Home's "Latest Updates" renders a header over a blank card when the feed comes back empty (any RSS outage, or an offline self-hosted server)

**Severity:** minor. **Estimate:** 10 minutes. Owner: mobile. A3: `home-screen/components/feed-card.tsx:143-157` has no empty branch. The backend returns `[]` on any RSS fetch failure and caches that per locale (`backend-v2/src/features/gitea/feed/service/feed-service.ts:332-334`). `selectCardLoadState({loading:false, hasData:true})` is `"ready"`, so the card shows neither a failure nor a skeleton, and `items.map([])` draws nothing.

Code-level at `main` `6d8c869b2`. Not run natively; it needs the server's feed to fail.

## Fix

Add an empty-state line ("No updates right now"), or hide the card when it has no items.

**Acceptance:** with an empty feed, Home shows no bare "Latest Updates" header.
