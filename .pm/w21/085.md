# Open Account offers only operating currencies, so a EUR or stock account can't be constrained to its commodity; after a failed first load the default sticks at "No currency"

**Severity:** moderate. **Estimate:** 30–45 minutes. Owner: mobile. A3:

1. **The currency list is too narrow.** The disposable QA ledger has `option "operating_currency" "USD"`, and the probe added an open EUR account holding 150 EUR. Open Account → Currency offers only **"No currency"** and **"USD"**. So the user can't open an EUR bank account, or `Assets:Broker:VTI`, constrained to its commodity. A ledger with no `operating_currency` option gets only "No currency". `ledgerMeta` already fetches the full `currencies` list, and nothing reads it.
2. **A stuck default.** The default is set once, as soon as meta stops loading. If the first meta read fails on a cold cache, the currency becomes `""`, and `currencyInitialized` stays true. So when the `cache-and-network` refetch brings `["USD"]`, the field still reads "No currency". Saving then writes an `open` with no constraint.

Environment: iPhone 17e simulator (iOS 27.0), dev build 1.20261002.50, `main` at `ea411704b`. Case 1 was reproduced natively: Accounts ＋ → Currency, with the EUR fixture appended. Nothing was saved, and the ledger was restored byte-for-byte to `f1a0b83c`. Case 2 is code-level: it needs a cold-cache network failure.

## Root cause

- `mobile/src/common/ledger-meta-utils.ts:65` sets `currencies = data.options.operating_currency`. The full `data.currencies` is ignored.
- The picker (`open-account-screen.tsx:292-295`) and the default (`:250-255`, `currencies[0]` behind a one-shot `currencyInitialized`) both use that list.

## Fix

- Offer `data.currencies`, with operating currencies first, then the rest sorted, and keep `operating_currency[0]` as the default.
- Set the default once meta has actually loaded, i.e. data present, not just `!loading`. The default can then still apply after a failed first read.

**Acceptance:**
- In a ledger with USD as operating currency plus EUR and VTI, the picker lists USD, EUR and VTI, with USD as the default.
- A mocked failed-then-successful meta read ends with USD selected.
