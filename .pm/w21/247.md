# w21/111's fix double-scales the drawer's line heights at AX2: each line is about twice as tall, and wrapped names split far apart

**Severity:** moderate (regression). At AX2 the drawer is now mostly empty space, with fewer rows on screen than before. **Estimate:** 20 minutes. Owner: mobile. A3: `scaleLineHeights` multiplies each fixed `lineHeight` by `fontScale`, assuming "Dynamic Type scales `fontSize` but not a point `lineHeight`". React Native already does that scaling on iOS, so the line height is scaled twice (`lineHeight × fontScale²`):
- Fabric: `RCTAttributedTextUtils.mm:229-232`, `lineHeight * RCTEffectiveFontSizeMultiplierFromTextAttributes(...)`.
- Paper: `RCTTextAttributes.mm:141`.

Reproduced natively on the iPhone 17e simulator (iOS 27.0) at `main` `4b40d3039` (includes `fd9033f38`), at AX2 (`accessibility-large`), light mode, with the drawer open from Home:
- The selected "mcp-agent-eval" row wraps to "mcp-agent-" and "eval", about **111 pt** apart. "Ledgers" grows from about 13 to 28 px cap height (×2.15), and 24 × 2.15² ≈ 111. The row is about 236 pt tall.
- "example" and the owner header are spaced the same way. "Browse ledgers" leaves its compass icon stranded below the first word.
- At the default size the drawer is unchanged.

## Root cause

- `mobile/src/common/theme/dynamic-type.ts` (`scaleLineHeights`) scales again what the renderer already scales.
- It is applied by `useDrawerStyles()` in `mobile/src/components/ledger-drawer/ledger-drawer.tsx:332-339`.
- The original w21/111 clipping therefore had another cause. Look at containers that cap the text box at AX2, for example the `maxFontSizeMultiplier` / `allowFontScaling` combination or the row's `minHeight` with a fixed inner height.

## Fix

Revert `scaleLineHeights` for the drawer. Re-diagnose w21/111's clipping against the real cause, using the simulator's view inspector or `automation_find_view` frames of the clipped labels. If a line height must be adjusted at all, use `maxFontSizeMultiplier` on the Text rather than pre-scaling the number.

**Acceptance:**
- At AX2, drawer names and headers render whole with normal line spacing; the selected row's two lines sit about one line height (about 50–55 pt) apart.
- Default size is unchanged.
- A source check rejects multiplying `lineHeight` by `fontScale` in theme helpers.
