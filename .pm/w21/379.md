# Commit detail renders every diff line at once (no virtualization or size cap), so opening a large commit stalls the screen

**Severity:** moderate. **Estimate:** 45 minutes. Owner: mobile. A3: `commit-detail-screen.tsx:338-353` draws the diff with a `FlatList` set to `scrollEnabled={false}`, inside a horizontal ScrollView inside a vertical ScrollView. `VirtualizedList._onLayout` takes its own content-sized height as the viewport, so it renders batches until every row exists. RN also skips its nested-list warning when scrolling is disabled. The parse at `:219` is not memoized. Under `tsx`, a commit adding 20,000 lines gives `parseDiff` 20,006 rows, all rendered, and the horizontal scroller is as wide as the longest line. The dashboard's diff viewer switches to virtual scrolling above 500 lines (`dashboard/src/common/components/diff-viewer/diff-viewer.tsx:15`). Mobile has no limit.

Code-level at `main` `4e51c752c`. Not run natively; it needs a multi-thousand-line commit.

## Fix

Make the diff the screen's single vertical `FlatList`, with the summary and the file list as `ListHeaderComponent`. Memoize the parse. Above a threshold, collapse each file to "Diff too large (N lines)" with a show-anyway button.

**Acceptance:** opening a 20,000-line commit stays responsive and renders only visible rows.
