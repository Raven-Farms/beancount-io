# The shared Picker and text-input dialogs ignore VoiceOver's escape gesture, and their titles aren't headings

**Severity:** minor. **Estimate:** 10 minutes. Owner: mobile. A3: the Picker's `Modal` (`components/picker/index.tsx:388-397`) has only `onRequestClose`, which does not handle the iOS two-finger-scrub escape. The same goes for `components/text-input-modal/index.tsx:209-229`. The Picker serves Language, Theme, the Add Budget interval and currency, and the Open Account root and currency; the text-input modal serves New Ledger File and Delete account. Their titles (`picker/index.tsx:416`, and the modal title) have no `accessibilityRole="header"`. The menu (`menu-button/index.tsx:190-199`), the valuation sheet and the drawer already wire up `onAccessibilityEscape`.

Code-level at `main` `5a4e27da4` against React Native 0.86 (Fabric) sources in `mobile/node_modules`. Not exercised with VoiceOver, which this simulator setup can't drive.

## Fix

Add `onAccessibilityEscape={handleCancel}` / `{onCancel}` on the content view, and `accessibilityRole="header"` on both titles.

**Acceptance:** with VoiceOver, scrubbing dismisses both dialogs as Cancel would, and each title is read as a heading.
