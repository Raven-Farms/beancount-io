# The file editor's Save, its error rows, and Reload / Back to Files aren't announced as buttons

**Severity:** minor (accessibility). **Estimate:** 15 minutes. Owner: mobile.

Code-level at `main` `7f85628b8`. None of these sets `accessibilityRole="button"`:
- Save in the header (`mobile/src/screens/ledger-file-editor-screen/index.tsx:697-711`). Edit Transaction's Save does, at `edit-transaction-screen.tsx:477`.
- Error rows (`:255-258`). They jump to a line, and rows without a line number are tappable no-ops.
- Reload and Back to Files on the unavailable state (`:781-803`).

## Fix

Add the button role. Give error rows with a line a hint ("Jump to line N"), and make rows without one non-interactive.

**Acceptance:** VoiceOver reads "Save, button", "…, line 12, button, Jump to line 12", and the unavailable actions as buttons. A source check covers them.
