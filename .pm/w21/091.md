# The file editor's error rows say "line N" in English in every language

**Severity:** minor. Untranslated chrome in all 12 non-English locales, including Persian (right-to-left). **Estimate:** 15 minutes. Owner: mobile. A3: the banner header is translated with plural forms ("1 ошибка"), but each row's location is a hard-coded English template.

Code-level at `main` `d7a950d7f`.

## Root cause

`mobile/src/screens/ledger-file-editor-screen/index.tsx:263-267` renders `` {`line ${err.lineno}`} ``. No translation key exists.

## Fix

Add a key such as `ledgerEditorErrorLine: "line {{line}}"` to every locale file, and render `t("ledgerEditorErrorLine", { line: err.lineno })`. Also check the row's accessibility label.

**Acceptance:** with the app in Русский or فارسی, an error row's location is translated. The locale key-parity test passes.
