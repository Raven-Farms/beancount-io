# Account search misses accounts containing "İ" (Turkish dotted capital I): "bank" doesn't find "İşBank"

**Severity:** minor. **Estimate:** 15–20 minutes. Owner: mobile. A3: Turkish bank names often start with İ (İş Bankası, İNG). `"İ".toLowerCase()` is two UTF-16 units (`i` + U+0307). The picker's matcher compares `text[i]` and `lowerText[i]` index by index, so every character after an İ is compared against its neighbour, and lowercase queries stop matching. The account then looks absent, and the picker offers **Create** for an account that already exists.

Environment: `main` at `bc1e013ff`, dev build `io.beancount.ios` 1.20261002.50 on iPhone 17e (iOS 27.0). QA account, synthetic disposable ledger `mcp-agent-eval` with `2026-01-01 open Assets:Qa20261020İşBank USD` (engine accepted it; restored byte-for-byte afterwards).

## Repro (observed)

1. New Transaction → tap the first posting's account. The browse list shows **Assets:Qa20261020İşBank**.
2. Type `bank` in Search accounts. Results: **Assets:Bank:Savings** and **Assets:Bank:Checking** only. `Qa20261020İşBank` isn't listed, although its leaf ends in "Bank".

Reproduced with the shipped `filterAccounts("bank", ["Assets:İşBank","Assets:ZiraatBank"])` under Node, which returns only `ZiraatBank`. `fuzzyMatch("bank","Assets:İşBank")` is `0`.

## Root cause

`mobile/src/common/account-search.ts:50-84`: `substringIndex` and `fuzzyMatch` index `text` and `text.toLowerCase()` with the same offset. That holds only when lowercasing preserves length. For "İ" (and a few other code points) it doesn't, so the indexes drift by one after the first such character.

## Fix

Lowercase per character (`text[i].toLowerCase()`, comparing its first code unit or the full lowered string against a lowered pattern char), or fold both sides with a length-preserving map (`toLocaleLowerCase("tr")` is also length-changing, so avoid it). Alternatively, build `lowerText` with a parallel index map. Add the İ case to the account-search tests.

**Acceptance:** `bank`, `iş` and `İş` all find `Assets:…İşBank`. Existing ranking tests are unchanged.
