# "Upload failed. Please try again." offers no way to try again: Retake throws the photo away

**Severity:** moderate. After a network blip, the only options are Cancel or Retake. Retake discards the photo and opens the live camera, even if the photo came from the library. If the paper receipt is gone, the scan is lost. **Estimate:** 20 minutes. Owner: mobile. A3: the error state renders only `onCancel` and `onRetake` (which sets `shot` to null). The workflow could re-run `startCapture` with the current `shot`, but nothing offers it. w2/m30/t004 left "retry UX" out of scope.

Code-level at `main` `f7bcaa7de`. A native repro without AI quota is possible by turning off the host network before Upload; that wasn't done here because it would disrupt other sessions.

## Where (`mobile/src/screens/receipt-capture-screen/`)

- `receipt-capture-screen.tsx:77-81` (`handleRetake`)

## Fix

Add a "Try again" button on upload and parse failures that re-runs the workflow with the same `shot`. Keep Retake as the secondary choice.

**Acceptance:** with the network off, Upload → "Upload failed" → network on → Try again uploads the same photo without retaking.
