# Ledger error text (Notifications, the transaction detail banner) and the Entry Context source can't be copied

**Severity:** low. **Estimate:** 15 minutes. Owner: mobile. A3: `notifications-screen.tsx:193` (inside a pressable row with no `onLongPress`), the detail banner's text (`transaction-detail-screen.tsx:703`) and the Entry Context source (`entry-context/index.tsx:312`) are plain non-`selectable` `Text`, with no Clipboard action. In the same app the metadata line (`transaction-detail-screen.tsx:805`) and the commit diff (`commit-detail-screen.tsx:196`) are selectable. So users can't copy an error to search for it or to paste to someone, or copy an entry's source to duplicate it.

Code-level at `main` `3440909ec`.

## Fix

Make the Entry Context source and the banner text `selectable`. On Notifications rows, add an `onLongPress` that copies the message plus `file:line` with `expo-clipboard` and shows the existing "Copied" toast.

**Acceptance:** each of the three texts can be copied.
