## Objective

Give the CLI the same preset catalog as a generated, drift-checked copy so local and hosted creation build the same books.

## Context

- `bea init` (`cli/src/cli/commands/init.py`, engine in `cli/src/bea_engine/initiating.py`) writes a fixed `Personal ledger` chart today and must keep accepting any syntactically valid currency when no preset is passed (ADR021).
- `bea cloud ledger create` (`cli/src/cli/commands/cloud/ledger/`) sends only name, description, and privacy today.
- Packages must not import each other; the CLI holds a generated copy with a drift check, per ADR021.

## Steps

1. Generate the CLI's catalog copy from the t001 source and add the drift check to the CLI's checks.
2. Add preset selection to `bea init`, building files through the same fixture expectations.
3. Send `setup` and `requestId` from `bea cloud ledger create`.

## Files

- `cli/src/cli/commands/init.py`
- `cli/src/bea_engine/initiating.py`
- `cli/src/cli/commands/cloud/ledger/app.py`
- `cli/src/cli/commands/cloud/ledger/manager.py`

## Acceptance criteria

- [ ] `bea init` with `personal@1` produces files whose accounting results match the hosted fixture.
- [ ] Editing the canonical catalog without regenerating fails the drift check.
- [ ] `bea init` without a preset behaves exactly as before, including non-ISO currency symbols.

## Out of scope

- Local-to-hosted transfer of existing ledgers (deliberately excluded; see the anti-goal on half-self-hosted seams in `.pm/DO_NOT_DO.md`).

## Evidence (2026-10-20)

- Catalog copy at `cli/src/bea_engine/setup_catalog.json` + `setup_currencies.json`, byte-identical in content to the canonical backend catalog; `cli/tests/test_setup_catalog_drift.py` fails on drift when the canonical file is present and covers all eight preset ids.
- `bea init --preset/--title`: the frontend validates the preset and its opening accounts from the engine's catalog copy and passes the flags through; the engine (`initiating.answer_preset`) builds the preset chart with the hosted builder's semantics (day-before opening post, boundary assertion). `cli/tests/test_init_preset.py` covers a known EUR opening, unknown-preset and wrong-account refusals, and that no-preset init keeps the fixed chart.
- `bea cloud ledger create --preset/--title/--currency/--date`: REST client regenerated through the sanctioned `make spec-sync && make codegen` (never hand-edited); every create sends a fresh `requestId`. `cli/tests/test_cloud_create_preset.py` asserts the wire body.
- Gate: `make check-all` — lint, format, mypy, and deadcode pass; the test suite passes except `test_price.py::TestManagedLoad::test_seventeenth_url_is_an_unavailable_source`, which fails identically on the untouched base commit in this environment (verified in a clean worktree at `45ddc33f8`) and does not touch any code this task changed. `docs/REFERENCE.md` regenerated with `make docs` for the new options.
