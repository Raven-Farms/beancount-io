# Name Journal row controls after their entry: 60 identical "Toggle postings" buttons that also hide the posting count

**Severity:** minor (accessibility; WCAG 2.4.6, 4.1.2). **Estimate:** 35–50 minutes including a rendered-name test. **Owner:** `dashboard` (`features/journal/components/journal-table.tsx`, journal locales). **A2:** the Journal is the most-used ledger page. A screen-reader user tabbing through it hears "2017-09-08, button" then "Toggle postings, collapsed, button" for every row. Nothing says whose postings, and the visible posting count ("16") that sighted users read on the toggle is replaced by the label.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `ce83f82b`. QA-owned headless Chromium, 1440×1000, en-US. Read-only.

On `/ledger/open_ledger/example/journal` (page 1, rows 1–60 of 1044):

- `getByRole('button', { name: 'Toggle postings' })` matches **60** visible buttons, one per row. Each has `aria-expanded="false"` but no `aria-controls` and no description.
- Each row's first control is a button named only by its date (`"2017-09-08"`, `"2017-09-07"`, …). It opens Entry Context. Same-day entries produce identical names (e.g. two `"2017-09-04"` buttons for the BANK FEES and Uncle Boons rows).
- Rows have no row header (`tbody th[scope=row]` count 0), so a table-navigating reader gets no entry identity from the row either.
- The toggle visibly shows the posting count (e.g. `16` for Hoogle Payroll), but `aria-label` overrides the button's content, so that count is not announced.

## Root cause

- `journal-table.tsx:249–256`: the postings `<Button>` sets `aria-label={t("journal.togglePostings")}`, a fixed string that overrides its visible count.
- `journal-table.tsx:407–417`: the date `<button>` (opens the entry) has only `{formatDateISO(directive.date)}` as content.

## Fix

- Postings toggle: an interpolated name that keeps the count and identifies the entry, e.g. "Show 16 postings for 2017-09-07 Hoogle Payroll" / "Hide …" (or keep a short label and add `aria-describedby` pointing at the row's payee/narration cell). Add `aria-controls` to the expanded postings region when rendered.
- Date button: "Open entry 2017-09-04 BANK FEES Monthly bank fee" (date plus payee/narration, truncated sensibly), so same-day entries differ.
- New keys in all 15 locales. Keep the visible layout, w3/467's narrow-row count, and w4/133's forced-colors pressed states.

Acceptance: on the example journal, no two row controls share an accessible name. Each toggle's name includes its posting count and entry, and each date button's name includes its entry. A rendered test with two same-day entries asserts distinct names and the count. Dashboard gates pass.

## Dedupe

Searched `.pm/**` for "Toggle postings"/`togglePostings`, journal row names, and journal table semantics. w4/046 (done) removed dead keys (`togglePostings` kept), w3/116 used the toggle only to expose amounts, w3/m40 (done) concerned the **account** journal's Units column and its table roles, and w3/467 fixed the narrow-row count clipping. None names the main Journal's row controls after their entry.
