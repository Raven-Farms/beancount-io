# In Persian, amounts render as "USD 33.71-": isolate signed amounts from the right-to-left layout

**Severity:** major (a debit visually reads with its sign moved to the far end, in a financial table). **Estimate:** 40–55 minutes including an RTL render test. **Owner:** `dashboard` (journal posting amounts `features/journal/components/journal-table.tsx` + `journal-description/utils.ts` `formatAmountWithCurrency`, the Accounts and account-journal balance cells, Holdings cells; ideally one shared amount element). **A2:** Persian is a shipped locale with a real RTL layout (w4/076). In it, every signed amount in the Journal, Accounts, account pages and Holdings is reordered by the bidi algorithm. The currency jumps in front of the number and the minus sign drops to the end, which is easy to misread as a positive figure.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `2d8fe4ba`. QA-owned headless Chromium, 1440×1000, `?lang=fa` (`<html lang="fa" dir="rtl">`), public `open_ledger/example`. Read-only.

The element's text is `-33.71 USD`, with computed `direction: rtl` and `unicode-bidi: normal`, and no `dir="ltr"`/`<bdi>` ancestor.

## Root cause

Amount strings are plain text inside cells that inherit the document's `direction: rtl`. A string beginning with a weak `-` and digits, followed by a Latin unit, is reordered under the RTL paragraph direction. No shared amount element applies `dir="ltr"` / `unicode-bidi: isolate`, so each table renders amounts raw (e.g. `JournalAmounts` → `formatAmountWithCurrency` in `journal-table.tsx:55–69`).

## Fix

Route these amounts through the same formatter path the statements use (leading U+200E, locale digits), or render every number+unit amount inside an isolated LTR run, e.g. `<bdi dir="ltr">` or a `tabular-nums [direction:ltr] [unicode-bidi:isolate]` utility on a single shared amount component, and use it in the journal postings, account journal, Accounts table, and Holdings cells. Keep cell alignment logical (end-aligned in both directions, per w4/177), keep the English rendering byte-identical, and don't isolate whole rows (account names and Persian text must still flow RTL).

Acceptance: with `?lang=fa`, every listed surface shows `-33.71 USD`-ordered amounts (sign leading, unit trailing), and the sweep above reports 0 unisolated amount elements. A rendered test under `dir="rtl"` asserts the amount element's isolation. Dashboard gates pass.
