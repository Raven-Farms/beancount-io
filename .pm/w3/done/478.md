# Ledger switcher: include the current ledger in its accessible name, and name its popover

**Severity:** minor (accessibility; WCAG 2.5.3 Label in Name, 4.1.2 Name, Role, Value). **Estimate:** 20–30 minutes including a rendered-name test. **Owner:** `dashboard` (`common/components/ledger-layout/ledger-switcher.tsx`, dashboard-page locales). **A2:** the sidebar switcher is how every ledger page tells you which ledger you're in. Its visible text is the ledger name, but assistive tech hears only "Select a ledger, combobox, collapsed". A voice-control user who says "click example" (what they see) gets nothing, and a screen-reader user can't hear which ledger is current without opening it.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `ab0e5d72`. QA-owned headless Chromium, 1440×1000, en-US, signed in. Read-only (navigation only).

1. On `/ledger/<owner>/example/journal`, the sidebar control shows the text **"example"**. In the DOM it is `role="combobox"`, `aria-haspopup="dialog"`, `aria-expanded="false"`, `aria-label="Select a ledger"`. `getByRole('combobox', { name: 'Select a ledger' })` matches; `getByRole('combobox', { name: 'example' })` matches **0**.
2. Open it. The popover is `role="dialog"` with **no** `aria-label`/`aria-labelledby`. It contains a listbox whose first option is the owner row ("Go to puncsky's account") followed by the ledgers. The current ledger is correctly marked `aria-current`, but nothing is announced on the closed trigger.

Working controls: selecting another ledger navigates and clears the previous ledger's journal filters (w3/m35/t008 holds). The owner option deliberately opens the profile.

## Root cause

`ledger-switcher.tsx:240–242`: the trigger sets `aria-label={t("page.dashboard.selectLedger")}`, which replaces its visible content (the current ledger name) as the accessible name. `PopoverContent` at `:251` renders Radix's `role="dialog"` without a name.

## Fix

Name the trigger so it starts with the visible text, e.g. `aria-label` "example — switch ledger" via a new interpolated key `page.dashboard.switchLedgerFrom` = "{ledger} — switch ledger" (all 15 locales). Or drop the `aria-label` and expose "Select a ledger" through `aria-describedby`. Give `PopoverContent` `aria-label={t("page.dashboard.selectLedger")}`. Keep the current-ledger `aria-current`, the owner option, and w3/m35's switch behaviour.

Acceptance: the closed trigger's accessible name contains the visible ledger name, and the open popover is a named dialog. A rendered test asserts both. Dashboard gates pass.

## Dedupe

Searched `.pm/**` for "Select a ledger", `selectLedger`, ledger switcher, and label-in-name. w3/m35/t008 (done) stopped a switch from showing the previous ledger's data, w4/088 aligned sidebar current-page links, and w0/015 sized the switcher's targets. None changes the switcher's accessible name or names its popover.
