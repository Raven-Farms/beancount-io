# Give the Balance Sheet and Income Statement over-time charts a readable data table

**Severity:** minor (accessibility; WCAG 1.1.1 Non-text Content, 1.3.1). **Estimate:** 40–55 minutes reusing the Account report's `ChartPeriodTable`. **Owner:** `dashboard` (`features/reports/balance-sheet/`, `features/reports/income-statement/`, shared with `features/reports/account/chart-period-table.tsx`). **A2:** the default view of both statements is a canvas chart ("Net Worth" / "Net Profit" over time). A keyboard or screen-reader user gets only its title. The month-by-month values exist only as canvas pixels and hover tooltips, unlike the Account report and Budget, which already expose them.

## Live reproduction

Production `https://beancount.io`, 2026-10-16, local main at the time of filing. QA-owned headless Chromium, 1440×1000, en-US, public `open_ledger/example`. Read-only.

The active tab panel (`[role=tabpanel][data-state=active]`) on each default view:

| Route | Panel text | Tables | Disclosures |
| --- | --- | --- | --- |
| `/account/Assets:US:BofA:Checking` (control) | "Account Balance … Period data" | 1 | "Period data" |
| `/balance-sheet` → Net Worth | "Net Worth — Track example net worth across different commodities over time" | **0** | **none** |
| `/income-statement` → Net Profit | "Net Profit — Track example net profit across different commodities over time" | **0** | **none** |

The statements' hierarchy tabs (Assets/Income Hierarchy …) give period **totals**, not the per-interval series the chart plots.

## Root cause

w4/112 (done, `c0bfd00a`) added `ChartPeriodTable` for the Account report only (`features/reports/account/index.tsx:543,582`), and w4/107 did the same for Budget. The statement over-time charts render `ReactECharts` with no text alternative.

## Fix

Under each statement's over-time chart, render the same keyboard-reachable "Period data" disclosure. Use one row per plotted interval and one column per plotted unit, with the values the chart draws (from the same series, so the table and canvas can't disagree). Label it after the chart title. Apply it to every over-time chart tab on both pages (Net Worth / Assets / Liabilities / Equity, Net Profit / Income / Expenses). Respect the selected interval, conversion and time filter, and the statements' sign conventions (`features/reports/AGENTS.md`).

Acceptance: on both default views, a "Period data" disclosure opens a named table whose rows match the chart's series for the selected period. A rendered test asserts row count and one value against the chart option. Dashboard gates pass.

## Dedupe

Searched `.pm/**` for period data, chart table alternatives, and Net Worth / Net Profit chart accessibility. w4/112 (Account charts) and w4/107 (Budget actuals) are done and scoped to their own pages. w4/086 gave the Overview Net Worth card Chart/Table toggles, and w0/030 its table semantics. None covers the statement pages' over-time charts.
