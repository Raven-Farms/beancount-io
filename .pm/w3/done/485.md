# Give folder views in Files a page heading and a title that names the folder

**Severity:** minor (accessibility; WCAG 1.3.1, 2.4.2 Page Titled, 2.4.6). **Estimate:** 20–30 minutes including a rendered test. **Owner:** `dashboard` (`features/ledger-editor/directory-browse/`, `routes/ledger.$ledgerOwner.$ledgerName.files.tree.$branch.$.tsx`). **A2:** a screen-reader user who opens a folder lands on a page with no heading, and every folder's tab title is the same "Files - <ledger>". On the root folder, the only `<h1>` is the README's own title, so heading navigation announces the README as if it were the page.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `dcf0e38c`. QA-owned headless Chromium, 1440×1000, en-US. Public `open_ledger/microsoft` (folders `FY2020`…`FY2025`). Read-only.

| Route under `/ledger/open_ledger/microsoft/` | Headings | `document.title` |
| --- | --- | --- |
| `files/blob/main/FY2024/FY2024.bean` (control) | `h1` "Files › FY2024 › FY2024.bean" | FY2024/FY2024.bean · Files - microsoft |
| `files/blob/main/README.md` (control) | `h1` "Files › README.md" | README.md · Files - microsoft |
| `files/tree/main` | only the rendered README's: `h1` "Microsoft Corporation (MSFT) F…", then its `h2`s | Files - microsoft |
| `files/tree/main/FY2024` (no README) | **none** | **Files - microsoft** |

The folder view shows a visual breadcrumb ("Files · FY2024", as buttons), Git Clone, Version History, Back, and the listing, but none of it is a heading.

## Root cause

The file viewer renders its breadcrumb as the page `<h1>` (`file-editor/components/ledger-file-view/text-file-view.tsx:179`); `features/ledger-editor/directory-browse/` has no heading element at all. The tree route's `head` is the generic `createLedgerHead(args, "ledgerFiles", …)` with no path, so every folder shares the root's title.

## Fix

Render the directory breadcrumb as the page `<h1>` in the folder view, mirroring the file view ("Files › FY2024"). Demote the embedded README's headings below it (render README `h1` as `h2`, or wrap the README in a labelled region), so the page has exactly one page-level `h1`. Include the folder path in the tree route's title ("FY2024 · Files - microsoft"). Keep `noIndex`, the breadcrumb buttons, and the listing unchanged.

Acceptance: `files/tree/main` and `files/tree/main/FY2024` each have exactly one `h1` naming the folder, the README's headings sit below it, and the subfolder's title includes `FY2024`. A rendered test covers root-with-README and subfolder-without-README. Dashboard gates pass.
