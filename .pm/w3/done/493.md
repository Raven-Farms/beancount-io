# Remove macOS display and shell assumptions from the CLI gate harness

**Severity:** minor (development verification). **Estimate:** 20–30 minutes. **Owner:** `cli` tests. **A1:** the native CLI gate must verify documented commands and preserved file permissions reliably before publishing generated-client adoption for [w3/490](./490.md).

## Evidence

The 2026-10-15 `make check-all` run while adopting 490's generated OpenAPI descriptions had 6,619 passing tests, two failures, and two platform skips. The changed client descriptions do not affect either failing path.

- `tests/test_docs_examples.py::test_doc_examples[USAGE.md]`: the final bare `bea query` correctly exits 2 and prints its expected usage message, but the harness cannot find its ERR-trap marker. Independent reproduction with `/usr/bin/false` and the actual USAGE fence shows macOS Bash 3.2 can tail-exec the final external command under `bash -c`; its reported LINENO also differs from the harness's assumed one-based script-file origin.
- `tests/test_write_keeps_file_metadata.py::test_acl_xattrs_and_flags_survive_on_macos[add]`: the deny-read ACL is present, but `ls -le` displays the nobody principal's UUID rather than its resolved name. The test mistakes this display difference for lost security metadata. A focused rerun passes without source changes.

## Fix and acceptance

Make the documentation runner prove the exact failing command across installed Bash versions without changing stdin or accepting an early failure just because its exit status matches. Prefer executing a temporary script file over compensating for one shell's line offset; test the actual final-command trap, earlier same-status failures, and pipeline behavior. Keep scratch files cleaned on success/failure.

Compare the real macOS ACL principal/permissions independently of account-name rendering; keep xattr/flags checks. Prove the guard still rejects a deliberately omitted ACL copy. Do not change ledger-writing behavior, skip either case, or weaken expected failure coverage. Run the full native CLI gate against the unmodified canonical OpenAPI pin. Ship this prerequisite separately, then resume 490's generated adoption and its gate.
