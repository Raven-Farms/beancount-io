# Making a private ledger public is one unconfirmed click: the Ledger Settings "Private Ledger" switch publishes the whole ledger immediately

**Severity:** minor, privacy-sensitive. **Estimate:** 30–45 minutes including dialog tests. **Owner:** `dashboard` (`features/ledger-data/settings/visibility-section/index.tsx`, settings locales). **A2/A3:** a private ledger holds someone's complete finances: every transaction, balance, file and its git history. On Ledger Settings, the **Private Ledger** switch makes it public the moment it flips, whether by a mouse slip or a stray Space while tabbing through the page. Public ledgers are readable by anyone, listed on the owner's profile, and given indexable SEO heads, so the exposure can be cached by crawlers before the owner notices. Deleting one transaction asks for confirmation (w3/m41), and so does deleting a file. Publishing everything doesn't.

## Evidence

Local HEAD source, with the control observed live (signed-in owner, synthetic ledger, `/ledger/<owner>/<ledger>/settings`). **The switch was not toggled.**

- The page shows "Visibility · Private Ledger · Your ledger is private. Only you and collaborators can access it." with `switch "Private Ledger" [checked]`.
- `visibility-section/index.tsx:108–121`: `onCheckedChange={handleVisibilityChange}`, which calls `setIsPrivate(checked)` and immediately sends `updateLedgerVisibility({ private: checked })`. There's no confirmation step, delay or undo. On failure it reverts with a toast. On success the ledger is public, and the same section then shows the shareable URL and embed code.
- The switch is an ordinary Radix switch in the page's tab order, so Space or Enter toggles it like any checkbox.
- Every comparable control in the dashboard confirms first: revoking a token (`user-settings/pages/api-keys/api-key-revoke-dialog.tsx`), deleting an SSH key (`ssh-keys/key-delete-dialog.tsx`), removing a collaborator or leaving a ledger (`collaboration/components/collaborator-row.tsx`), deleting the account (type-your-username, `danger-zone-section.tsx`), deleting a transaction (w3/m41) or a file.

## Fix

Confirm only the private → public direction. Open an alert dialog naming what becomes visible ("Anyone with the link, and search engines, will be able to see this ledger's transactions, balances, files and history"), with **Make public** as an explicit, non-default action and **Cancel** focused by default. Public → private stays one click, since it reduces exposure. Optionally show a short "Undo" toast after publishing. Keep the existing read-only behavior for non-admins. Make the same check in any other publish entry point (the Create Ledger dialog's Private switch is a deliberate choice at creation and can stay as is).

Acceptance: flipping the switch off on a private ledger opens the confirmation and sends no mutation until **Make public** is chosen. Cancel and Escape leave it private, with focus returned to the switch. Re-privatizing needs no confirmation. Component tests cover both directions and keyboard activation. Dashboard gates pass.

## Dedupe

Searched `.pm/**` (including `done/`) for visibility switch, make public, private toggle and confirmation terms. w3/466 made the settings read-only for non-admins, w0/013 gave the switch an accessible name, and w3/m41 added confirmation for deleting a transaction. None covers confirming publication. Present at HEAD.

---

**Resolved 2026-10-17** — On Ledger Settings, turning the **Private Ledger** switch off on a private ledger now opens an alert dialog: "Make this ledger public?", explaining that anyone with the link, and search engines, will be able to see its transactions, balances, files and history. **Cancel** takes the initial focus, and no mutation is sent until **Make public** is chosen. Cancel or Escape leaves the ledger private and returns focus to the switch. Making a public ledger private stays one click. Read-only behaviour for non-admins and the Create Ledger dialog's switch are unchanged. Three new strings in all 15 visibility locales. Component tests cover the confirmation with no mutation until confirmed and the exact `private: false` variables after it, Cancel and Escape (still private, focus on the switch, nothing sent), Space on the focused switch, and one-click re-privatizing. The original section fails the four confirmation cases while the re-privatize control passes. An optional Undo toast was not added. Dashboard format, lint (including dead code), tests (6,069 passed, one skipped), build and a public-tree secret scan passed, shipped in `99b67279` (`dashboard`).
