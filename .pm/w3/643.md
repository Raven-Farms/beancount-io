# Smart Import can't read semicolon-delimited CSV: European bank exports silently go to paid AI parsing, then hit "requires AI-powered parsing" for a .csv once the quota is gone

**Severity:** major. Free-plan users can't import a standard EU bank CSV, and paid users' AI quota is spent without their knowing. **Estimate:** 45–60 minutes including parser tests. **Owner:** `dashboard` (`features/importer/hooks/use-csv-parser.ts` `parseCSVRecords`, `hooks/use-multi-stage-parser.ts`, importer locales). **A2:** most European banks export `;`-separated CSV with comma decimals (`Datum;Empfänger;Verwendungszweck;Betrag` / `-4,50`). w0/007's acceptance promised that "EU (`;`-delimited `1.000,00`, `-4,50`) fixtures parse deterministically without the LLM fallback". Its resolution changed amount parsing only, and the record parser still splits on commas. Every such file therefore fails client parsing and falls through, with no prompt, to the server's AI `ParseFile`, which is billed against the account's monthly AI tokens. When the quota runs out, the same CSV is refused with a premium upsell that tells the user to "Use CSV Format".

## Live reproduction

Local HEAD (`yarn dev`, pointed at the production API), QA owner on the free plan, its disposable synthetic ledger, 2026-10-17. File `qa-20261017-eu.csv`:

```text
Date;Payee;Description;Amount
2026-09-03;qa-20261017-eu-comma;qa-20261017 comma decimal;-4,50
2026-09-04;qa-20261017-eu-thousand;qa-20261017 thousand;-1.000
```

1. While the account still had quota, uploading it produced a normal-looking preview (`-4.5`, `-1000`) with no sign that AI was used. The network shows `GenerateTempAssetUploadUrl` + `ParseFile`, the server LLM path. Over the run, the account's AI usage rose from 19,713 to 21,723 of 20,000 tokens, with these imports as the only AI-parsed uploads.
2. Once over quota, uploading the same file: `ParseFile` → `RESOURCE_LIMIT_REACHED "AI CFO Token limit reached. Maximum: 20000, Current: 21723…"`, and the page shows **"Premium Feature Required — Current file type requires AI-powered parsing … OR Use CSV Format — CSV files can be parsed for free without premium access."**
3. Control, same session: a comma-delimited CSV (`qa-20261017-plain.csv`) previews instantly ("1 Valid") with no server parse.

Local check with HEAD's own function: `parseCSVRecords` on the EU file returns the header as **one column** (`["Date;Payee;Description;Amount"]`) and splits `-4,50` into two fields at the decimal comma. No `;`-delimited fixture exists in `hooks/__tests__/use-csv-parser.test.ts`.

## Root cause

- `use-csv-parser.ts` `parseCSVRecords` treats only `,` as a field separator, with no delimiter detection.
- `use-multi-stage-parser.ts`: when the client parse yields `validCount === 0` (and no `blockLlmFallback`), it calls `llmParser.parseFile` with no confirmation, so a parser limitation silently becomes a metered AI call.
- The upload step's error for `RESOURCE_LIMIT_REACHED` reuses the non-CSV "file type requires AI-powered parsing" copy, which is wrong for a `.csv`.

## Fix

1. Detect the delimiter from the header record (`,`, `;`, tab; require a recognized header such as Date/Payee/Description/Amount), and parse with it. Keep RFC 4180 quoting. Comma-decimal amounts then reach the existing `resolveDecimalConvention` logic w0/007 added. Two open items cover that path: w3/644 (its preview flags them invalid) and w3/564 (Import submits the raw token, so `-1.000` is written as one unit). Land those with or before this one, or the newly parsed EU files inherit both.
2. Make the LLM fallback for a `.csv` explicit: if client parsing fails, show why (for example "Couldn't read these columns") and offer "Parse with AI (uses AI tokens)" as a choice, never automatically.
3. When AI parsing is refused for quota, say so plainly ("You've used this month's AI tokens") and keep the free CSV path visible. Don't tell a CSV uploader to "use CSV format".

Acceptance: the EU file above previews two rows (`-4.50`, `-1000`) with **no** `ParseFile` request, on any plan and at any quota. Tab- and comma-delimited files still parse. An unreadable CSV shows the explicit AI choice and sends nothing until it's chosen. Parser tests cover `;` and tab with quoted fields and comma decimals. Dashboard gates pass.
