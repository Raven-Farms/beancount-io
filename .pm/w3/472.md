# Name repeated row and card actions after their target: Accounts "More actions", token "Revoke", Budget "Update Budget"

**Severity:** minor (accessibility; WCAG 2.4.6 Headings and Labels). **Estimate:** 40–55 minutes across three components, with component tests. **Owner:** `dashboard` (`features/ledger-data/accounts/index.tsx`, `features/user-settings/pages/api-keys/api-key-revoke-dialog.tsx`, `features/ledger-data/budget/budget-chart-card.tsx`). **A2:** a screen-reader or voice-control user hears several identical buttons, two of them doorways to destructive actions (Delete account, Revoke token), with nothing to say which account, token, or budget each one acts on. This is the same defect w0/028 fixed for Budget history Delete, on three more surfaces.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `ce83f82b`. QA-owned headless Chromium, 1440×1000, en-US, ledger owner and account holder. Read-only: one menu was opened with the keyboard and dismissed. No Close, Delete, Revoke, or budget update was performed.

Visible buttons sharing one accessible name (`getByRole('button')`, grouped by name):

| Route | Name | Count | Target it acts on |
| --- | --- | --- | --- |
| `/ledger/<owner>/<ledger>/accounts` | **More actions** | 5 (of 62 rows; only closable/deletable accounts get one) | the row's account (menu: Close / Delete) |
| `/settings/api-keys` | **Revoke** | 2 (one per active token) | that token |
| `/ledger/<owner>/<ledger>/budget` | **Update Budget** | 2 (one per budget card) | that card's account and currency |

None has `aria-describedby` or `aria-labelledby` pointing at its row or card, so each name is the whole announcement.

## Root cause

- `features/ledger-data/accounts/index.tsx:174–182`: the `AccountActions` trigger's only name is `<span className="sr-only">{t("common.moreActions")}</span>`.
- `features/user-settings/pages/api-keys/api-key-revoke-dialog.tsx:47`: the trigger text is `t("userSettings.apiKeyRevoke")`.
- `features/ledger-data/budget/budget-chart-card.tsx:365`: the button text is `t("page.budget.budgetAddEntry")` ("Update Budget").

## Fix

Keep the visible text and icons. Add row- or card-specific accessible names through new interpolated keys in all 15 locales:
- "Actions for {account}"
- "Revoke token {name}"
- "Update budget for {account} ({currency})"

Alternatively, point `aria-describedby` at the row's or card's title. Account names and budget account+currency are unique per page. Token names may repeat, so append the token's creation date or a short id when two names match, as w0/028 did with a position. Keep w3/m23's focus return to the Accounts trigger, and the Revoke confirmation dialog. The single editor-level `common.moreActions` (`ledger-editor/file-editor/components/non-text-file-views.tsx:142`) can stay as it is.

Acceptance: on each route above, every repeated button's accessible name identifies its target, and names are unique on the page. Focus return after Close/Delete/Revoke is unchanged. Component tests assert the names for two rows or cards per surface. Dashboard gates pass.

## Dedupe

Searched `.pm/**` for "More actions"/`moreActions`, Revoke, and Update Budget/`budgetAddEntry`. w3/m23 (done) restored focus to the Accounts trigger, w3/m25 (done) kept row actions working inside the table, w4/069 is the MCP `manageApiKeys` schema, and w0/028 named Budget history Delete only (its live "Delete" ×3 on production is deployment lag). None names these triggers after their targets.
