# Name each dashboard ledger "Settings" menu after its ledger

**Severity:** minor (accessibility; WCAG 2.4.6). **Estimate:** 15–20 minutes. **Owner:** `dashboard` (`features/ledger-list/pages/dashboard-page/components/dashboard-sidebar.tsx`, dashboard-page locales). **A2:** on `/ledger`, every owned ledger in the sidebar has a menu button for Edit Ledger / Delete Ledger. A screen-reader or voice-control user hears one "Settings" per ledger, with nothing to tell them which ledger each one edits or deletes. This is the dashboard counterpart of w3/472, which fixed Accounts, Budget and token actions.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `79a58268`. QA-owned headless Chromium, 1440×1000, signed in with three owned ledgers. Read-only: menus were opened with the keyboard and dismissed; nothing was edited or deleted.

On `/ledger`, the sidebar's ledger menu triggers (`button[aria-haspopup=menu]`) are named **"Settings"**, "Settings", "Settings". Each opens "Edit Ledger / Delete Ledger" for a different ledger. The Delete confirmation does name the ledger ("Are you sure you want to delete "example"?"), but the trigger doesn't.

## Root cause

`dashboard-sidebar.tsx:165`: `aria-label={t("common.settings")}` on every ledger's `DropdownMenuTrigger`, unchanged on current main after w3/472.

## Fix

Use an interpolated name such as `page.dashboard.ledgerSettingsFor` = "Settings for {ledger}" (all 15 locales). Ledger names are unique per owner, so no suffix is needed. Keep the icon and menu, and the Delete Ledger focus return to this button (`settingsTriggerRef`).

Acceptance: each trigger's accessible name includes its ledger name, and names are unique. A component test asserts two names. Dashboard gates pass.

## Dedupe

w3/472 (done, `79a58268`) named the repeated Accounts, token Revoke and Budget actions, and didn't touch the dashboard sidebar. w3/488 (open) covers Edit Ledger focus return from this same menu. Searched `.pm/**` for dashboard ledger Settings and `common.settings` names: no other item.
