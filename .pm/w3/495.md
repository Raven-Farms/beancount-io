# Give the Overview's Income vs Expenses, Distribution and Cash Flow charts a readable data alternative

**Severity:** minor (accessibility; WCAG 1.1.1 Non-text Content). **Estimate:** 45–60 minutes reusing the shared `reports/components/chart-period-table.tsx`. **Owner:** `dashboard` (`features/reports/overview/components/`: income-expenses chart, distribution pies, cash-flow Sankey). **A2:** the Overview is a ledger's landing page. Four of its five charts give a keyboard or screen-reader user only a title and a one-line description. Every value (each interval's income and expense, each asset's share, each Sankey flow) exists only as canvas pixels and hover tooltips.

## Live reproduction

Production `https://beancount.io`, 2026-10-16, local main `ecf00ddf`. QA-owned headless Chromium, 1440×1000, en-US, public `open_ledger/example/?time=2016`. Read-only.

Text inside each chart card outside the canvas:

| Card | Text outside the canvas |
| --- | --- |
| Net Worth (control) | "82,450.228 USD … +4,460.716 USD from previous month …" plus a Chart/Table toggle (w4/086, w0/030) |
| Income vs Expenses | title, "Bar chart comparing total income and expenses for each interval in the selected period.", unit note; **no values, no table** |
| Assets Distribution | title, "Visual representation of … assets composition"; **no values, no table** |
| Liabilities Distribution | title, description; **no values, no table** |
| Cash Flow (Sankey) | title, "Money flow from income sources to expenses and investments", unit note; **no values, no table** |

None of these canvases sits in a labelled `role="img"`, and none of the cards contains a `table`, `details` or list.

## Root cause

The statements got a shared "Period data" table in w3/494 (`e6138e44`, now `features/reports/components/chart-period-table.tsx`), and the Account report in w4/112. The Overview cards still render `ReactECharts` alone.

## Fix

Give each card a keyboard-reachable alternative generated from the same series the chart draws:
- **Income vs Expenses:** the shared period table (interval, income, expenses, net).
- **Distributions:** a breakdown table (account, amount, share of total).
- **Cash Flow Sankey:** a flows table (from, to, amount).

Use a Chart/Table toggle like Net Worth's, or a "Period data" / "Breakdown" disclosure. Respect the selected time filter, conversion and units note. Keep the charts unchanged.

Acceptance: on `/ledger/<owner>/<ledger>` each of the four cards exposes a named table whose rows match its chart for the selected period. A rendered test per card asserts one row against the chart option. Dashboard gates pass.
