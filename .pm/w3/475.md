# Ledger Gallery: keep the search in the URL so Back restores it, and announce the result count

**Severity:** minor. **Estimate:** 30–40 minutes including a rendered test. **Owner:** `dashboard` (`features/ledger-list/pages/gallery-page/index.tsx`, its locales, `routes/ledger-gallery.tsx`). **A2:** the gallery is search-only: it lists nothing until 2 characters are typed. A visitor who opens a result and presses Back returns to an empty page and must retype. Screen-reader users get no announcement of how many ledgers matched, or that none did.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `ce83f82b`. QA-owned headless Chromium, 1440×1000, en-US, signed in. Read-only.

1. `/ledger-gallery` shows the heading and the combobox "Search for ledgers and navigate to them. Type at least 2 characters to search." Type `example`: 5 options appear (`SearchLedgers`). The combobox semantics are right: `aria-expanded="true"`, `aria-controls`, and `aria-activedescendant` moves with ArrowDown.
2. ArrowDown, Enter opens `/ledger/open_ledger/stock-example` (for query `stock`).
3. Press browser Back. The URL is `/ledger-gallery`, the search box is **empty**, and **0** results show. Reloading with results showing also loses the query; nothing in the URL carries it.
4. Throughout, no live region in the page announces "5 ledgers found" or "No ledgers match". The only live region present is a global one, and it stays empty.

## Root cause

`gallery-page/index.tsx:47` keeps the query in component state (`useState("")`) and navigates away at `:92` without recording it. `routes/ledger-gallery.tsx` has no `validateSearch` for a `q` parameter. The result list has no polite status text.

## Fix

Add `validateSearch` for `q` (trimmed string, optional) to `/ledger-gallery`. Initialize the input from it, and write it back with `navigate({ search, replace: true })` on a short debounce, so Back and reload restore the results. Keep the existing `/gallery` → `/ledger-gallery` redirect passing search through. Add a visually hidden `role="status"` line for "{count} ledgers found", "No ledgers match {query}" and "Type at least 2 characters", in all 15 locales. Keep the combobox keyboard behaviour unchanged.

Acceptance: search `stock`, open the result, press Back → the input shows `stock` and the result is listed. `/ledger-gallery?q=example` loads with 5 results. The status text updates on each settled search. A rendered test covers restore-from-URL and the announcements. Dashboard gates pass.
