## Objective

Define how an open reconciling item is recorded in the ledger so it survives across periods: stable identity, first-seen date, and disposition.

## Context

- ADR020 binds: a newly observed item is not necessarily newly originated, so age is unknown when history is absent; a suspected cause is never reported as confirmed; identity must survive a changed statement row order.
- Builds on w2/m48's coverage preflight; gated on its closeout so the two reconcile changes do not collide.

## Steps

1. Define the register's stored fields and where they live in the ledger, following the suite's config-block and metadata conventions in `skills/AGENTS.md`.
2. Define item identity from stable source attributes, immune to row reordering.
3. Add fixtures: an item carried across two periods, and one first observed with no history.

## Acceptance criteria

- [ ] Reordering statement rows never changes an item's identity.
- [ ] An item with no history records unknown age, not an invented first-seen date.
