# Preview plain-text files that have an extension outside the allowlist (CSV, TOML, OFX, QIF…) instead of "Unsupported file format"

**Severity:** minor. **Estimate:** 30–45 minutes including utility tests. **Owner:** `dashboard` (`features/ledger-editor/shared/lib/utils.ts` `isTextFile` / `getFileType` / `getFileLanguage`). **A2:** ledgers keep bank exports and tooling next to their `.bean` files. A 196-byte `pyproject.toml` in a public showcase ledger, or any `statement.csv`, `.ofx` or `.qif` an importer user commits, opens to "Unsupported file format" with no way to read it, though it is plain text.

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `ecd0997a`. QA-owned headless Chromium, 1440×1000, en-US. Public ledgers, read-only.

## Root cause

`utils.ts:93–120` `isTextFile` accepts a fixed extension list (txt, md, json, yaml/yml, xml, html, css, js/ts/tsx/jsx, py, java, c/cpp/h, sql, sh/bash, beancount/bean) plus w2/m7's well-known basenames (`TEXT_BASENAMES`, `:53+`). Everything else falls to `UnknownFileView`. Missing are the formats a ledger repo most often holds: `csv`, `tsv`, `ofx`, `qfx`, `qif`, `toml`, `ini`, `cfg`, `conf`, `log`, `env.example`. Unknown dotfiles also have their whole name treated as the "extension" in the message (`(verify-m15)`). w2/m7's t001 named a content-sniff fallback, but the shipped check is allowlist-only.

## Fix

Add the ledger-relevant text extensions above to `isTextFile` and map them in `getFileLanguage` (csv/tsv → plaintext or a CSV mode; toml/ini → their Monaco languages where available). Then add the fallback w2/m7 planned: for an unknown extension or dotfile under a size cap (e.g. 1 MB), sniff the decoded content (valid UTF-8, no NUL bytes) and render it as read-only text. Keep `UnknownFileView` for real binaries. Keep images/PDF routing and download behaviour.

Acceptance: `pyproject.toml`, a `.csv`, an `.ofx`/`.qif` and an unknown small text dotfile render as text, and a binary file (e.g. `.zip`) still shows the unsupported view. Unit tests cover the new extensions and the sniff fallback (text vs NUL-containing content). Dashboard gates pass.

## Dedupe

Searched `.pm/**` for "not supported for preview", `isTextFile`, `TEXT_BASENAMES`, unsupported file format, CSV/TOML preview. w2/m7 (done) fixed **extensionless** files (LICENSE, Makefile, Dockerfile, `.gitignore`) and states "`UnknownFileView` only for true binaries" as its outcome. Extension-bearing text formats and unknown dotfiles still miss that outcome. No other item covers them.
