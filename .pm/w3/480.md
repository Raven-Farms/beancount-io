# Escape doesn't close the mobile navigation sheet once focus is on a menu item: an invisible tooltip swallows it

**Severity:** minor (keyboard; WCAG 2.1.2-adjacent, dialog dismissal). **Estimate:** 20–30 minutes including a rendered keyboard test. **Owner:** `dashboard` (`common/components/ui/sidebar.tsx`). **A2:** on phones and narrow windows, the ledger navigation is a modal sheet. A keyboard or switch user who tabs to "Accounts" and presses Escape sees nothing happen. Only a second press closes the sheet, so it reads as "Escape is broken".

## Live reproduction

Production `https://beancount.io`, 2026-10-15, local main `74313ef0`. QA-owned headless Chromium, **390×844**, en-US. Public `open_ledger/example/journal`. Read-only.

1. Focus **Toggle Sidebar** and press Enter. The sheet opens as a named dialog ("Sidebar") with focus on the ledger switcher. Pressing Escape *here* closes it and returns focus to Toggle Sidebar (control).
2. Reopen, press Tab three times (focus on the "Accounts" link), then press Escape. **The sheet stays open** (`[role=dialog]` count 1) and focus stays on Accounts. The same happens with focus on the "Advanced" button.
3. Press Escape again and the sheet closes.

What the first Escape does: while a menu item is focused, two tooltip layers for "Accounts" are mounted but invisible (`display`/client rects 0). The first Escape removes them (tooltip count goes 2 → 0); only the second reaches the sheet. Pointer dismissal (overlay click) and the Close button work.

## Root cause

`common/components/ui/sidebar.tsx:776–784` (`SidebarMenuButton`) always wraps the button in a Radix `Tooltip` and hides its content with `hidden={state !== "collapsed" || isMobile}`. A `hidden` `TooltipContent` still opens on focus and registers as a dismissable layer. Radix dismisses the topmost layer on Escape, which is the invisible tooltip, not the sheet.

## Fix

Don't mount the tooltip when it can't be shown. When `state !== "collapsed" || isMobile`, return the bare button, and keep `Tooltip` only for the collapsed desktop rail. Keep the collapsed-rail tooltips, the mobile opener focus return (`mobileOpenerRef`), and the sheet's Close button unchanged.

Acceptance: at 390px, with focus on any sheet item (link, button, or menu action), a single Escape closes the sheet and returns focus to Toggle Sidebar. In the collapsed desktop rail, tooltips still appear on focus and a single Escape still dismisses them. A rendered test covers both. Dashboard gates pass.
