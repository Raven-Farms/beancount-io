Expected: accepting a suggestion keeps a coherent input focus position so normal Tab navigation advances once. The [WAI-ARIA combobox guidance](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) treats the editable input as the focus owner for a listbox suggestion. The selected value and listbox semantics themselves are correct here.
