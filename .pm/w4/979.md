# Keep an Entry Context draft through a cache refresh

**Severity:** minor, follow-up to [m49](./done/m49/README.md). **Estimate:** 45–60 minutes, dashboard. **A2:** a reader editing a ledger entry should not lose the draft because another write refreshed the cache.

`EntryContextPanel` (`dashboard/src/features/journal/components/entry-context-panel.tsx`) handles a refetch badly:
- It returns `<EntryContextLoading />` whenever its context query is `loading`, and an error view whenever it has `error`, even when data is already shown.
- `EntryContextMain` also resets `sourceText` whenever `data.slice` changes.

Every write clears the whole Apollo cache (`useApolloCacheClear`), so a refetch unmounts an open, edited Entry Context editor and throws its draft away. That breaks the `dashboard/AGENTS.md` rule "never swap an already shown page or editor for a loading or error view on `loading && data` or `error && data`".

m49 locks each Entry Context dialog while its own write is pending, so that write cannot reach a later draft. The browser Back button is still open, though. Journal, Account and Overview have no route blocker, so a reader can leave during a save and open another entry on the next page. When the old save lands, its cache clear refetches that entry's context and the loading swap drops the new draft. Any other write that clears the cache while an entry is being edited does the same. Code reading suggests the path; it has not been reproduced in a browser.

Repair:
- Show the loading view only on `loading && !data`, and the error view only on `error && !data`.
- Report a failed refresh with `useRefreshFailedToast`, as LedgerLayout and LedgerFileView do.
- Do not overwrite an edited `sourceText` when a refetched `slice` arrives. A clean editor should still take the new source.
- Keep stale-SHA refusal, copy recovery and the pending lock unchanged.

Acceptance:
- A real-Apollo regression evicts the cache while a dirty Entry Context is open, and the exact draft stays mounted.
- A clean editor shows the refreshed source.
- A failed refetch keeps the draft and offers Try again.
- Verify natively at both widths.
- Dashboard format:check, lint, test and build pass.
