## Source and bounded repair

`dashboard/src/common/lib/editor/monaco-beancount-actions.ts:47–52` applies the whole-file formatting through executeEdits without placing any Undo stops around the operation. The installed Monaco declaration (`monaco.d.ts:6241–6256`) explicitly documents that executeEdits records edits but pushes no Undo stop, and exposes pushUndoStop for that purpose. The result can join the preceding text edit, as witnessed above.

Give an actual formatting change its own Undo group, isolated from preceding and following typing, using the editor's existing Undo boundaries. Preserve the formatting output, decimal text, selection/caret, normal Undo/Redo and no-change behavior. Do not reset the model, replace its entire history, implement another Undo stack or add a dependency/API. Toggle Comment and the other built-in actions are passing compatibility controls.

There are two production entrypoints to this shared function: the Cmd/Ctrl+D command registered by registerEditorShortcuts for TextEditor, and EditModeToolbar's **Align Amounts** menu item. The shortcut is live reproduced; the menu is source-traced scope and should share the same repair.
