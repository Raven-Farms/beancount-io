## Cause and bounded repair

`dashboard/src/features/ledger-editor/create-file/index.tsx:146–179` awaits createFileMutation and refreshDirectory, then unconditionally sets allowNavigationRef.current=true and invokes navigateToTree. That closure retains the old ledger/directory navigation. The departure guard at:109–118 permits explicit Leave, but nothing revokes this old operation's right to navigate after the page is left or unmounted. The installed TanStack useNavigate implementation delegates its stable callback to router.navigate; it does not cancel an old async handler's eventual call on component unmount. Both the real route transition and the source trace agree.

Scope successful automatic departure to the same still-current creation journey that submitted the request. Once the user explicitly leaves, a late acknowledgement/refetch may update the correct file/directory data but must not replace their current route. Preserve a fresh later creation journey if the user returns before an older response finishes. Audit route-param changes as well as unmounting; do not let an old directory/ledger closure take over another creation view. Do not treat route departure as proof that an already authorized server operation was undone, retry the write, or navigate globally on every mutation completion.

Keep ordinary foreground success navigating once, current pending input/Cancel locks through the create-plus-refetch interval, safe-name/collision checks, permissions, exact UTF-8 bytes and [248](./248.md)'s distinction between write success and a failed folder refresh. No persistent draft store, global navigation manager, backend/API change or new dependency is needed.

Acceptance: exercise the real CreateFilePage/router/mutation lifecycle with native Leave during a held create; completion keeps Journal current. Add a held post-ack folder-refresh departure case and a leave/return/new-draft case so an obsolete completion cannot redirect the later journey. Preserve ordinary foreground success, failed-create retry and dirty Stay/Leave behavior. Run dashboard format:check, lint, test and build when implementing. Only the pre-transport create hold was live tested here; the other timing/param cases are regression scope.
