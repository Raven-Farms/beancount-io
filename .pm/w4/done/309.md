## Cause and bounded repair

`dashboard/src/features/importer/lib/import-config-draft.ts:41–52` correctly excludes invalid rows from configuration/submission. buildImportConfigFormValues constructs only those valid transactions. `components/steps/configure/transaction-config-form.tsx:123–148` watches an edit and replaces the workflow draft with toImportConfigDraft of that reduced form. The helper at import-config-draft.ts:100–114 serializes only current form transaction IDs, losing the temporarily invalid row's earlier saved selected=false. When repaired, buildImportConfigFormValues finds no prior choice and defaults selected=true. `preview/editable-preview-row.tsx:94–102` explicitly keeps row.id through the amount edits, so this is an existing row losing history, not a new identity or shifted array position.

Retain prior choices for every row ID still present in the active file's full preview, including temporarily invalid rows; keep invalid rows out of the active form/submission. Reconcile a reduced configuration edit with those retained choices, rather than replacing them with only the eligible subset. Prune choices when a row is actually removed and clear them on new file/ledger/reset/finish as before. Repaired rows with saved history restore that choice; rows with no history retain the current explicit defaults. Always take date/payee/amount values from the latest validated preview. No durable storage, parser policy, API or dependency change is needed.

Acceptance: drive the real wizard through the four steps, with a source edit while the excluded row is invalid, then repair; row2 remains unchecked and the changed source remains. Cover the same path for a saved target choice, actual deletion/new-file reset, direct repair without an intermediate configure edit and current validation/submission guards. A separate fresh390 control starts with row2 invalid and never configured, then repairs it: default selected=true and empty target are correct and must remain. Run dashboard format:check, lint, test and build when implementing.
