Bounded synchronous local shadows preserve already spent volume during outage/recovery, refuse live-map saturation, ignore stale replies, and stop exhausted-user token rotation before allocating new entries. Anonymous family classification handles case/trailing aliases and separates device polling. REST own-admission refusals include Retry-After. Verified session jti metadata is trusted only after signature and row validation; secret-prefix logging removed. Redis raw waits are 1s/128 retained calls, native queues 256, socket/connection/init deadlines 2s with reconnect; atomic Lua counters repair missing expiry and strict cache writes propagate errors. Six old-behavior regressions failed; 88 focused API/recovery tests, 92 identity/introspection tests and 51 Redis tests including real pause/loss/restart passed. Final native gate: 365 suites / 6248 tests passed, typecheck, lint, agent guidance and unchanged OpenAPI passed.
