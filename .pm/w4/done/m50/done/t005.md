## Verification

**Regression files:**
- `report-read-retry.test.tsx` is a `describe.each` over Trial Balance, Balance Sheet, Income Statement, Cash Flow and Account Journal. Each runs a real `ApolloClient` whose link fails the first target read and holds later ones.
- `commodities-read-retry.test.tsx` runs the same sequence on Commodities.

**Each case asserts:**
- a failed read shows Try Again;
- a keyboard retry is busy and a second Enter sends nothing;
- a rejected retry is handled, with Try Again enabled and focused;
- a successful retry removes the error;
- every retry repeats the first read's variables.

**Revert checks:**
- With the original six callers, `ReportErrorState` and `QueryView`, all six cases fail.
- With the pre-move `QueryView` and Commodities, the Commodities case fails.

**Existing suites pass unchanged:** classified messages, Cash Flow reconciliation, Account pagination and empty states, QueryView's loading-priority contract, Budget.

**Gates:** dashboard format:check, lint (one existing importer warning, not this change), build, and `yarn test`: 653 files, 6804 passed, 1 skipped.
