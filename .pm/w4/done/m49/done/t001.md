## Objective

Do not accept source edits that the in-flight submitted snapshot cannot retain.

## Context

See [the milestone](../README.md) and [reproductions](../FINDINGS.md). Owning code is features/journal/components/entry-context-panel.tsx and entry-context-dialog.tsx, with their existing tests and route callers.

## Steps

1. Give actual Monaco input and its change path a coherent isSaving/isDeleting policy, preserving readable source, pending feedback, exact snapshots and one in-flight Save. A retained-newer-edit approach must keep dirty state honest. Preserve failure recovery and read-only/generated-source semantics.

## Acceptance criteria

- [x] Verify the stated transition using the actual owning component/session and record evidence and limits.
- [x] Preserve the milestone's exact source, pending guards, intentional dirty exits and error/retry controls.

## Out of scope

Backend/API changes, actual hosted writes for tests, persistent drafts, unrelated editor redesign and new dependencies.

## Verification

**Fix (`entry-context-panel.tsx`):**
- `EntryContextMain`'s save runs through the shared `usePendingAction`, so a second Save, Enter or Space is refused while one is in flight. Delete does the same through its own instance.
- While either write is pending, the Monaco editor is `readOnly` and ignores changes. The source stays readable, Save shows its spinner and Delete is disabled.
- A failed save keeps the exact current source and its dirty state. Focus parks on the dialog while Save is disabled and returns to Save on failure.

**Native check:** 1440/390, local build plus fixture API, with every UpdateLedgerEntrySourceSlice held in the browser:
- Text typed after Save (`qa-m49-later`) never reaches the model.
- The one captured request carries the earlier text only.
- After an aborted save, the draft is intact and Save is focused. Space sends exactly one retry with identical source.

**Regression (`entry-context-pending-save.test.tsx`):** real Apollo, real dialog and panel. A held save refuses typing, and a failed save keeps the draft and retries the current source once.
