## Objective

Run /simplify over this milestone's changed code while preserving the verified quantity/cash contracts.

## Acceptance criteria

- [x] Reuse existing source-aware formatting and ISO classification; avoid duplicate commodity policies or a new wrapper hierarchy.

## Verification — 2026-10-22

`/simplify` ran four parallel reviewers (reuse, simplification, efficiency, altitude). Altitude confirmed the depth: an opt-in digit count on the shared formatter keeps one ISO-versus-commodity rule. Consumer-side branches would duplicate the policy, a double cannot carry real digits, and computed Budget values have no source string.

**Applied:**
- **Formatter cache.** A module-level `Intl.NumberFormat` cache (`numberFormat`) for the commodity path and the ISO path. `toLocaleString` with options built a new formatter per call, which a daily All-time Budget table paid thousands of times. NumberFormat has no time-zone state, so caching it is safe.
- **`showAmount`.** One `useCallback` replaces six repeated `formatNum(…) + currency` expressions in the Budget card. The chart memo depends on it instead of on `formatNum` and the unused `displayCurrency`.
- **Budget digits.** `group.amount` was dropped from the digit scan, since it is always one of the history amounts. The number/commodity split is kept so a dotted commodity name such as `VBR.X` cannot be counted as decimals.
- **Comments.** The `fractionDigits` JSDoc and the Budget comment are shorter, the hierarchy inline comment is gone, and the out-of-date `formatQuantity` doc is updated.
- **Tests.** Duplicate grouping, inversion and repeated tooltip cases are folded.

**Skipped:**
- Memoizing `quantityDigits`. It is a number, and `chartData` is rebuilt every render anyway.
- Retiring the now-parallel `useFormatQuantity` and its three chart callers. It would change ISO output (minor units) outside this milestone's two consumers, so it is recorded as follow-up work.

The suites, the revert check and the gates are re-run after these edits ([t005](./t005.md)).
