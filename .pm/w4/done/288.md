# Keep DatePicker's calendar shortcut out of IME composition

**Minor · dashboard · 35 minutes.** A2: an input-method candidate-selection key must not open a calendar and terminate date composition. Production beancount.io, 2026-10-20, owned isolated headless Chromium 155, English/System theme, authenticated QA account, fresh 1440×1000 and 390×844 contexts. Only unsaved Open Account dates on `<qa-owner>/<synthetic-ledger>` were edited. Local main `ae674baeb`; full deployment revision unverified.

## Reproduction and control

Open `/ledger/<qa-owner>/<synthetic-ledger>/accounts?action=open-account`, focus Open Date and clear its local draft. Through a page-scoped Chromium CDP session, start Input.imeSetComposition with text `2016-09-20`, selectionStart/End 10. The field contains that preedit text, retains focus and has no calendar grid.

Dispatch ArrowDown through Input.dispatchKeyEvent. Captured events include trusted compositionstart/input and a trusted keydown with **isComposing=true, keyCode=40**. At both widths the calendar opens, focus moves to a calendar button, the field normalizes to 09/20/2016 and its composition terminates. ArrowDown should remain available to the active input method instead of invoking this application shortcut.

A fresh narrow ordinary-key control has isComposing=false and correctly opens the same calendar on ArrowDown. This ordinary behavior must remain. No Open Account submit or other write action was invoked; a context-local mutation guard recorded zero attempts. Browser-engine composition was exercised, not a physical OS input-method session. See [286](./286.md) for the composition-event contract; [287](./287.md) covers Gallery's independent keyboard handler.

## Cause and bounded repair

`dashboard/src/common/components/ui/date-picker.tsx:196–201` prevents default and calls setOpen(true) whenever key is ArrowDown. It does not check the native KeyboardEvent's composition state. Popover autofocus then moves editing focus into the calendar, ending composition. This handler is separate from both shared Combobox and Gallery, so their guards cannot repair it.

Leave the input method's composing keys alone: do not prevent its default action, open the calendar or move focus while composition is active. After compositionend, ordinary ArrowDown must still open the calendar and provide its existing keyboard access. Preserve the canonical civil-date contract, locale ordering, strict validation, held invalid/empty drafts and ordinary calendar selection. No dependency, API, global keyboard framework or OS setting change is needed.

Acceptance: the actual DatePicker with a composing ArrowDown (native isComposing=true) retains input focus and no calendar popup; after compositionend, ordinary ArrowDown opens it. Include a valid and incomplete preedit, retain ordinary date entry/blur and calendar controls, and keep the existing Apia/civil-day and invalid-draft regressions. Repeat browser-engine composition at desktop/narrow widths and run dashboard format/lint/test/build.

The shared picker is used by Journal Transaction/Balance/Note/Open Account, Accounts OpenAccountDialog, Budget AddBudgetDialog and ReceiptReviewForm. Only Accounts Open Date was live exercised. Other forms, physical OS IMEs, other engines/locales and the repaired build remain unverified; no submission, incorrect stored date or duplicate request is claimed.
