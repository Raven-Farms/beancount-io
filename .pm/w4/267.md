## Cause and bounded repair

`features/reports/trial-balance/trial-balance-content.tsx:112–154` decorates Equity/Liabilities/Income roots with the display-only inverted flag, then passes those roots to `computeTrialBalanceReconciliation`. At `lib/trial-balance-summary.ts:34–39`, that helper reverses each flagged root before summing. The result is labelled Reconciliation Difference at content lines161–162. It sums typographically positive credits instead of the producer's signed accounting balances.

Compute the exact per-unit reconciliation from the same scoped, filtered raw root balanceChildren/balance values, independently of the inverted presentation flag. Keep the requested credit-sign presentation on ordinary rows. Reuse exact sumBalanceRecords; do not total all visible descendants, add different units together, round through Number, alter backend balances, silently force zero or disable the user's display option. Preserve current period/account/filter, conversion, zero/closed-account handling, empty states and genuine nonzero per-unit differences. This is a dashboard consumer repair; REST/GraphQL/MCP producer balances need no change. The helper has one production caller, TrialBalanceContent; no other report or export should change, and Trial Balance still has no new Export action.

The existing helper test at `lib/__tests__/trial-balance-summary.test.ts:31–40` gives credit roots positive raw amounts plus inverted=true and calls that a balanced ledger. Actual API credits in this reproduction are negative. Add a raw-sign regression with Equity−50/Liabilities−30/Income−20/Assets60/Expenses40 and both display settings; both must reconcile to zero while ordinary rendered credit cells follow the preference. Also retain genuine nonzero, empty and multi-unit checks, plus a rendered content/browser control with the actual ledger option. Run dashboard format/lint/test/build when implementing. No new dependency or cross-package import is needed.
