## Cause and repair

`dashboard/src/common/components/ui/dialog.tsx:48–72` forwards Content props to Radix without protecting active composition at onEscapeKeyDown. Installed react-use-escape-keydown/dist/index.mjs:4–14 listens at document capture and matches only event.key. react-dismissable-layer/dist/index.mjs:59–67 invokes onDismiss unless onEscapeKeyDown prevented default. Thus ordinary Input handlers run too late to stop the wrapper's default dismissal. OpenAccountDialog's handleDialogOpenChange at ledger-data/accounts/open-account-dialog.tsx:111–114 then intentionally resets the closed form.

Prevent this default dialog dismissal for a composing native key at the shared DialogContent integration. Preserve caller-provided onEscapeKeyDown ownership/default prevention and nested overlay behavior, normal noncomposing Escape, explicit Close/Cancel, outside interactions, focus return and existing pending-write rules. Do not add draft persistence, change the intended reset after an ordinary close, disable IME or patch installed dependencies. [291](./291.md) owns a separate file-editor document handler with an EditContext lifecycle; its observed isComposing=false host needs its own repair. [284](./284.md) owns pending account-write draft lifetime, not this no-submit Escape.

There are23 production feature files using shared DialogContent: Accounts open/close/delete, Budget, Journal New Entry/entry context/export/standalone entry, collaboration forms, ledger danger settings, dashboard sidebar dialogs, user profile/subscription/plan/cancel/danger dialogs, API-key creation, SSH-key create/delete, file creation, non-text file actions and file-edit mode. Only Accounts Open Account's composing failure is live exercised; the other consumers are shared-source compatibility scope. Sensitive dialogs were not operated. Sheet/Popover have separate wrappers and are not claimed repaired by this note.

Acceptance: use the real Dialog/Radix composition in meaningful tests. A composing Escape with isComposing=true/keyCode27 must leave the actual input/dialog/draft mounted and avoid onOpenChange(false); ordinary Escape afterwards still closes and resets. Cover a caller escape callback/default prevention, nested overlays, focus return and Close/Cancel controls. Include the actual Accounts route reopen proof and one other editable Dialog consumer; verify desktop/narrow with trusted browser composition, then run dashboard format/lint/test/build.
