# Give the ledger's out-of-date Refresh button an accessible name

**Severity:** minor (accessibility, name/role/value). **Estimate:** 15–25 minutes, dashboard. **A2:** a screen-reader or voice-control user must be able to identify the action that refreshes a ledger changed in another client.

## Reproduce

Production `https://beancount.io`, 2026-10-20, English/light, QA-owned headless isolated Chromium 155.0.8059.85, synthetic-ledger owner. Reproduced on Journal at 390×844 and after a fresh reload at 1440×1000. Local main `c5e4cd11a`; deployed `main-D9qWGMxD.js`, full deployed SHA unverified. No response substitution or artificial feature gate.

1. Keep a ledger page open while another client commits a change. The real manual CSV import and subsequent byte-exact restoration during this QA run supplied two distinct real commits.
2. Let the normal 30-second latest-commit poll observe the changed revision. An outlined refresh-arrow button with an orange dot appears beside Help and the user/settings control.
3. The accessibility snapshot exposes only **button**, with no name. Exactly one button has an empty accessible name and zero buttons match `/refresh/i`. Its DOM has no `aria-label`, `aria-labelledby`, `title` or text; the only child graphic is the refresh icon.
4. Focus the actual button. The tooltip reads **Out of date — click to refresh**, but Radix associates that text through `aria-describedby`. The accessible **name** remains empty before and after focus. A description does not provide a voice-control name or distinguish the action in a button list.

Working control: activating the button still refreshes data and removes the indicator. In the desktop repeat, fresh-load Journal before restoring the file, wait for the next normal poll, and repeat the same name/focus check. Neighbouring Toggle Sidebar, Help, Filters and Settings controls remain named. All QA ledger writes were restored to the original hash; no entries or errors remain.

## Cause and bounded repair

`dashboard/src/common/components/ledger-layout/ledger-out-of-date-indicator.tsx:49–57` renders an icon-only Button without a name. Line 59 places the existing localized `common.outOfDateRefresh` message only in TooltipContent. The shared tooltip wrapper forwards Radix behavior; it does not convert a tooltip description into the button's name.

Give this button an explicit localized name using the existing refresh message, keeping the tooltip, icon/dot, polling, revision comparison and cache refresh behavior. Its sole production owner is `layout-header.tsx:223`, shared across ledger routes; Journal was independently reproduced, while other routes are a searched blast radius. No API, dependency or new translation key is required.

Acceptance: render the real indicator through an initial/current revision and then a changed revision with the real button/tooltip primitives. Assert a named Refresh action before hover and after keyboard focus, including a non-English catalog; activation must retain its refresh-and-dismiss behavior, and no action exists when the revision is current. Recheck the live desktop/narrow poll journey. Actual screen-reader speech and voice-control software were not exercised. Run dashboard format/lint/test/build when implementing.
