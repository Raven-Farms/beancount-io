## Objective

Allow the popup's own scroll region to receive ordinary wheel input inside the parent modal.

## Acceptance criteria

- [x] DatePicker in Open Account and Account Combobox in the narrow Filter Sheet scroll natively to their final date/option.
- [x] Use a bounded integration that preserves the outer modal lock and existing caller events; do not globally bypass document scroll protection.
- [x] Preserve the Combobox's nonmodal input focus/typing and its existing available-height sizing. Desktop standalone wheel scrolling stays correct.
- [x] Check scroll boundaries, keyboard focus-induced scrolling, dismissal/focus return and other shared Popover consumers for regressions. Do not claim untested physical-touch support.
