## Objective

Update all picker integrations so accepted dates reach existing API payloads as the same `YYYY-MM-DD` day without local-Date re-interpretation.

## Steps

1. Update Journal Transaction/Balance/Note/Account, Accounts Open Account, Budget Add Budget and Receipt Review forms to the shared contract.
2. Audit schemas, defaults, reset/reopen, calendar and receipt-prefill adapters and every final date serializer.
3. Keep pending/error handling, permissions and API fields unchanged; retain strict required/invalid state.

## Acceptance criteria

- [ ] All seven forms retain exact date-only values through validation and prepared writes, including skipped-day typed and prefilled cases.
- [ ] No invalid/empty date falls back to a previous value or Today.
- [ ] No service/schema or cross-package change is introduced.
