# The importer paywall says "Upgrade to Premium" while recommending Growth

Found by w1/m39/t011. The importer's paywall (`dashboard/src/features/importer/components/steps/upload/parse-error-display.tsx`) titles its upgrade option `importer.error.upgradeToPremium` ("Upgrade to Premium"). Since w1/m39/t009, its button recommends the next tier up (`getNextTier(tier)`), so a Premium user who has used up the AI allowance is offered Growth under a Premium heading.

**Fix:** title the option with the recommended plan's name, for example "Upgrade to {plan}" using `tierInfoByKey(next.key).labelKey`, in all 15 dashboard locales. Retire `importer.error.upgradeToPremium`. Pin the heading for a Free user and a Premium user in the paywall's tests.

---

**Resolved 2026-10-19.** The paywall's heading names the plan its button recommends: `importer.error.upgradeToPlan` ("Upgrade to {plan}"), with the plan from `getNextTier(tier)`. When no higher self-serve plan exists, it reads `importer.error.upgradePlan` ("Upgrade your plan"). The retired `importer.error.upgradeToPremium` is removed, and both new keys are in all 15 importer locales. `upload-step-ai-offer.test.tsx` now renders translation parameters, and pins "Upgrade to Premium" for a Free user and "Upgrade to Growth" for a Premium user.
