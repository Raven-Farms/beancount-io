## Objective

Replace `manageLedgers`, `manageLedgerCollaborators`, and `managePullRequests` with one tool per operation (nine tools).

## Context

- `src/features/ai-agent/api/mcp-lifecycle.ts`, `mcp-collaborators.ts`, and `mcp-pull-requests.ts` (the `operation` enums).
- These tools' verbs are not pinned by name in the frozen baseline, so no rename map is needed. Check before relying on that.
- `scope-enforcement.test.ts` and `mcp-unexpected-error-masking.test.ts` use `manageLedgers` as their admin-tool example.

## Steps

1. Register create, update, and delete ledger; update collaborator, remove collaborator, and leave ledger; create, approve, and reject pull request. Each gets its own schema and annotations.
2. Rebind the verb rows and update the tests that used the grouped names.

## Result (2026-10-18)

- **Nine tools replace three:** `createPullRequest`, `approvePullRequest`, `rejectPullRequest`, `createLedger`, `updateLedger`, `deleteLedger`, `setLedgerCollaborator`, `removeLedgerCollaborator`, and `leaveLedger`. Each is built by `operationTool()` in `mcp-tools.ts`, which fixes the shared executor's `operation`. Each publishes exactly REST's input for that operation plus the ledger target: `LIFECYCLE_OPERATION_SCHEMAS`, `COLLABORATOR_OPERATION_SCHEMAS`, and `PULL_REQUEST_OPERATION_SCHEMAS` reuse `ledgerCreateInput`, `collaboratorUpdateInput`, `pullRequestCreateInput`, and the rest. Annotations follow ADR 019's table.
- **Parity:** the nine verb rows bind to their own tools and now carry their canonical PDP actions on MCP. None was pinned by name in the frozen baseline.
- **Tests:** the lifecycle, collaborator, and pull-request parity suites call MCP through a `perOperation()` helper. Their assertions are unchanged, and unknown operations, missing fields, and undeclared arguments are still refused (138 tests). Scope tests that used `manageLedgers` as the gate-enforced admin example now use `listBankConnections`, which has no single PDP action.
- **Docs:** `docs/mcp.md` (pull requests, ledger lifecycle, collaborator table) and `docs/api-parity.md`.
- **Gates:** `tools/list` measured at 87.4 KB, so the budget moves to 90 KB. The tool count is 39. Backend-v2 typecheck, lint, and test (5591) pass, with no OpenAPI drift.
