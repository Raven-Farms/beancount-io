# Two dashboard events are missing from the event taxonomy

Found by w1/m39/t011 while checking that every billing event is documented (they all are). `dashboard/src/common/analytics/events.ts` declares two events that `dashboard/docs/event-taxonomy.md` does not list:

- `changelog_release_opened` (`surface: "dashboard"`), fired from `features/ledger-list/components/whats-new.tsx`;
- `legacy_mobile_auth_completed` (`flow: password | otp | one_time_token`), fired from `common/providers/react-native-bridge-provider/legacy-auth-bridge.ts`.

**Fix:** add both to the taxonomy's event table, giving each its params and the question it answers. Then consider a test that fails when an `events.ts` name is missing from the taxonomy, so the next one cannot drift.

---

**Resolved 2026-10-19.** `dashboard/docs/event-taxonomy.md` lists `legacy_mobile_auth_completed` (next to `login`) and `changelog_release_opened` (next to `bql_query_executed`), each with where it fires, its params and the question it answers. `src/common/analytics/__tests__/event-taxonomy.test.ts` reads every event `AnalyticsEvents` declares (23 today, with a floor of 15) and fails when one has no taxonomy row, so the next event cannot drift. A mutation that removes a row fails it.
