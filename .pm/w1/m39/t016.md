## Objective

Turn on t010's server-side `purchase` event in production. t004 has already enabled `invoice.paid` on the live webhook.

## Context

- The backend sends nothing and logs nothing until both variables are set (`backend-cluster/backend-v2/src/config/config.ts`, `analytics`).
- Split from t004 on 2026-10-18: the worker did t004's Stripe steps through the Stripe CLI, but it has no GA4 admin access and cannot reach the production environment. Production's backend is not deployed through `bex.yaml`.

## Steps

1. In GA4, create a Measurement Protocol API secret on the dashboard's production data stream.
2. Set it as `GA_MEASUREMENT_PROTOCOL_SECRET` in the production backend's environment. Set `GA_MEASUREMENT_ID` to the same stream's ID; the Compose files take it from `VITE_GA_MEASUREMENT_ID`.
3. Check that the property's reporting identity uses User-ID, so the event joins the dashboard journey.
4. Restart the backend.
