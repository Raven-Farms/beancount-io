# Stop selling the $99.99 Premium yearly price through Checkout

PRFAQ005 decision 3 prices new Premium yearly subscriptions at $143.88. Since w1/m39/t005 the dashboard offers only that price, and `changePlan` refuses the $99.99 price as a target (it is `retired` in `SUBSCRIPTION_CONFIG`). Subscribers already on it keep it.

`createSubscriptionSession` still accepts the $99.99 price, because the marketing pricing page sells it today (m39 README, pricing-page compatibility). That page is served outside this repository.

**When the pricing page sells $143.88:** have `createSubscriptionSession` refuse a retired price, as `resolveTargetPlan` does. Keep the price in `SUBSCRIPTION_CONFIG` so existing subscribers still resolve to Premium, and update the resolver test that pins the $99.99 checkout.
