## Objective

Prove that historical test data cannot corrupt paid-plan resolution or another customer's cache, and that removal of the test tenant preserves legitimate billing and quota behavior.

## Context

Prior single-client happy-path tests missed the cross-client defect. Existing tests live with the stripe resolver/service/operations, admin routes, paid-customer model and dashboard settings. Backend billing operations retain their documented browser/session-only protocol exceptions; do not invent MCP billing adapters to satisfy a nonexistent surface requirement.

## Steps

1. Fill gaps left by task-local tests: permutations of old-dev/new-live rows, Organization live prices, supported legacy prices, unknown prices, multiple active plans, expired/canceled subscriptions, provider failures and foreign customer IDs.
2. Assert database effects, not only mock call presence: renewal cache updates exactly one matching binding and leaves unrelated rows unchanged. Prove repair preview is write-free and apply is bounded, reversible and idempotent; cover t011 cohort pagination, checkpoints, unresolved users and concurrent-write protection.
3. Exercise the real GraphQL billing adapter and account/profile/quota boundaries with controlled dependencies; assert effective limits agree with settings fixtures and the CLI-consumed profile contract. Cover rejected retired inputs and preserved coupon-enabled checkout.
4. Run normal backend `yarn typecheck`, `yarn test`, `yarn generate-v1-openapi`; review generated drift. Run dashboard `yarn typecheck`, `yarn test`, `yarn test:translations`, `yarn build` and package formatting checks on changed files.
5. Verify no live provider writes occur in automated tests. Diagnose any unrelated failures against a clean baseline; do not weaken timing assertions, mock ownership away or change compiler semantics just to get green.
