## Objective

Replace the two bank dispatchers with one tool per operation (eight tools), keeping each operation's service call, authorization, dry-run support, and error envelope.

## Context

- `src/features/ai-agent/tools/bank-import-tool.ts` (`importDescription`, `connectionDescription`, and the executors).
- `src/features/ai-agent/api/mcp-tools.ts`, plus the `manageBankImport` and `manageBankConnection` rows in `src/server/api/op-class.ts`.
- Eight frozen baseline rows bind to these two names: `Mutation.syncPlaidTransactions`, `submitPlaidTransactionsToLedger`, `deletePlaidTransactions`, `unlinkPlaidItem`, `reconcilePlaidAccounts`, `updatePlaidAccountMapping`, `updatePlaidAccountCurrency`, `refreshPlaidItemStatus`.
- `tools-only-journey.test.ts` drives the bank flow through tools alone (ADR 019 D7). It must still pass with the new names.

## Steps

1. Register one tool per operation, with a schema holding only that operation's fields, `dry_run` where the operation supports it, and its own annotations.
2. Rebind each verb row. Add the eight rows to an explicit, commented old→new rename map in `parity-baseline.test.ts`; the fixture is not edited.
3. Update the bank tests and the tools-only journey.

## Result (2026-10-18)

- **Eight bank tools replace the two grouped ones:** `syncBankTransactions`, `importStagedBankTransactions`, `discardStagedBankTransactions`, `reconcileBankAccounts`, `mapBankAccount`, `setBankAccountCurrency`, `refreshBankConnection`, and `unlinkBankConnection`. Each is built by `bankTool()` in `mcp-tools.ts` over the shared executors. It publishes only its own fields from `BANK_OPERATION_SCHEMAS` (required where the operation needs them) and its own description and annotations per ADR 019's table. The grouped descriptions and input schemas are gone; the executor input types derive from the per-operation schemas.
- **Parity:** the eight `VERB_TABLE` rows bind to their own tools and now carry their canonical PDP action on MCP too. `parity-baseline.test.ts` gains the explicit `RENAMED_ON_MCP` map; the fixture is unedited.
- **Behavior change:** `mapBankAccount`, `setBankAccountCurrency`, and `refreshBankConnection` publish no `dry_run`, so passing one (even `false`) is refused as an undeclared argument (BAD_USER_INPUT). A missing required field is now refused by schema validation, with the field named in the message.
- **Served text:** the `listBankConnections` and `listStagedBankTransactions` descriptions, the `bank-transactions/unsynced` resource description, the bank-import prompt, and `docs/mcp.md` (tool table and bank workflow) name the new tools. These t006 items were pulled forward so this ship is green.
- **Gates:** `tools/list` measured at 77.7 KB, so the budget moves to 80 KB. The tool count is 33. The scope-gate examples that relied on grouped dispatchers now use `setLedgerStar` and `listBankConnections`, which have no single PDP action.
- **Checks:** backend-v2 `yarn typecheck`, `yarn lint`, and `yarn test` (5580 passed); no OpenAPI drift.
