## Objective

Remove the code paths that only existed for grouped tools, and set the size and count gates from measurement.

## Context

- `op-class.ts`: `claim(..., groupedDispatcher)` and the "a grouped tool declares its most privileged branch" scope rule for `securitySchemes`.
- `rate-limit.ts` and the op index: "first row's verb for a shared tool id".
- `op-class-coverage.test.ts` (tool count) and `mcp-tool-list.test.ts` (`tools/list` byte budget).

## Steps

1. Delete grouped-only branches once no tool has more than one verb, and add a guard that no tool has an `operation` enum.
2. Measure the new `tools/list` size and tool count, and set both gates with the measurement in a comment.

## Files

- backend-cluster/backend-v2/src/server/api/op-class.ts
- backend-cluster/backend-v2/src/server/api/rate-limit.ts
- backend-cluster/backend-v2/src/server/api/__tests__/mcp-tool-list.test.ts
- backend-cluster/backend-v2/src/server/api/__tests__/op-class-coverage.test.ts

## Acceptance criteria

- [x] No grouped-dispatcher code remains, and a test fails if a tool reintroduces an `operation` discriminator.
- [x] Both gates are set from a recorded measurement.

## Out of scope

- Shrinking descriptions to win back bytes beyond what the gate needs.

## Result

- No tool selects an operation any more. Four tools still span several verbs without a selector: `getLedgerContext` and `checkLedger` read several in one call, `listBankConnections` reads connections and accounts, and `setLedgerStar` sets a state with its `starred` flag. Deleting `claim`'s mixed-action branch would therefore fail at load, so it stays, renamed from `groupedDispatcher` to `spansVerbs` with a comment naming those tools. The security-scheme rule ("most privileged verb") and the rate-limit bucket (the first row's verb) serve the same tools and stay. Comments that described grouped dispatchers in `op-class.ts` and `mcp-tools.ts` now describe the per-operation shape.
- New guard in `mcp-tool-list.test.ts`: no tool's input schema has a property named `operation`, `op`, `action`, `verb`, `command`, or `method`, at the top level or inside batch items. Adding `files[].operation` back to the three file tools fails it, naming each path.
- `tools/list` measured 96,458 bytes across 43 tools; the size gate moves from 100 KiB to 96 KiB, with the measurement in its comment. The tool count gate stays at 43 (set in t004 with its history).
- Gates: `yarn typecheck`, `yarn lint`, `yarn test` (5,595 tests), and `yarn generate-v1-openapi` with no drift.
