# `bea list price -c HOOL -c AAPL` says "the quote currency belongs in --amount", but `list price` has no `--amount`

**Trivial · cli · 5m · A1.** Real CLI QA, 2026-10-16, HEAD `56b3a3ad`, checkout `bea 0.3.1`, macOS 26.5.1.
The w5/238 hint is meant for `add price`, where users sometimes repeat `-c`
for the base and quote currency. It is attached to any command named
`price`, which includes `bea list price`. No product fix implemented.

```sh
bea -f /abs/main.bean list price -c HOOL -c AAPL
```

Actual: exit 2, `Conflicting values for one option: -c 'HOOL' and -c 'AAPL'.
Pass it once. Both name the commodity being priced; the quote currency belongs
in --amount.`

Control: `list commodity -c HOOL -c USD` gives the plain refusal.

Expected: the plain refusal for `list price`.

Cause: `cli/src/cli/single_value.py:31-35` adds the hint when the command's
name is `price`.

Fix: add the hint only when the parent command is `add`.

Dedupe: w5/238 (done) added the hint; open w5/473 covers `-c` whitespace.

Acceptance: `list price` gives the plain refusal; `add price` keeps the hint.
A test pins both.
