# An empty `--into ''` or `--rules ''` is treated as the working directory, so the error is about a directory ("Create it and add an include directive", "Is a directory") rather than an empty option

**Trivial · cli · 10m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12.
Both commands already exit 2, which is the right code, but the message
is wrong. `Path('')` resolves to the current directory, so the user is
advised to create the ledger's own directory as an include, or told that
the rules file is a directory. Sibling empty values such as
`--default-account ''` and `--pad-from ''` get a direct refusal. No
product fix implemented. Superseded by 387's shared fix (empty path
values); keep this note only for the message wording.

Use the fixture and environment from [385](./385.md), with
`Expenses:Food` open.

```sh
bea -f /absolute/books/main.bean add transaction X --date 2026-01-08 -p 'Expenses:Food 1 USD' -p Assets:Cash --into ''
bea -f /absolute/books/main.bean import s.csv --csv date=Date,payee=Payee,narration=Narration,amount=Amount --account Assets:Cash --rules ''
```

Actual:

- `--into ''` exits 2 with `Write destination /absolute/books is not
  included by /absolute/books/main.bean. Create it and add an include
  directive to the root first.`
- `--rules ''` exits 2 with `Cannot read rules file /absolute/books:
  [Errno 21] Is a directory: '/absolute/books'.`

Reproduced twice by the hunter and once by me.

Control: `--default-account ''` and `--pad-from ''` exit 2 with `Invalid
account ''`.

Expected: an empty path option should exit 2 naming the option, for
example `--into is empty`, in line with w5/239's rule for empty values.

Cause: `--into` reaches `cli/src/bea_engine/ledger/write.py:155` and
resolves against the root directory. `--rules` is opened as `Path('')`.

Fix: refuse empty or blank `--into` and `--rules` values at the option
layer. Check whether `--config` and the other path options need the same
treatment. No dependency change.

Blast radius: `add *`, bulk add and `import` with `--into ''`, and
`import --rules ''`.

Dedupe: this is the w5/239 family. w3/335 covers a blank `-a`, and
w5/305 covers a blank balance argument. None covers empty path options.

Acceptance: both commands exit 2 with a message naming the empty
option. A test pins it.
