# `beancount-reconcile` says "the last row's balance is the ending balance", which is wrong for newest-first exports; the tie-out then reports an unexplained residual and blames the sign mapping

**Trivial · skills · 10m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12.
Many banks export newest-first. The skill reads the ending balance from
the last row, which in such a file is the opening deposit, so the
tie-out fails. No product fix implemented.

Use the environment from [359](./359.md) with `Assets:Checking`, and
`ck.csv` in newest-first order:

```text
Date,Description,Debit,Credit,Balance
05/31/2026,MONTHLY FEE,12.00,0.00,3383.80
05/15/2026,CARD PAYMENT,50.00,,3395.80
05/05/2026,ACME PAYROLL,,2500.00,3445.80
05/03/2026,TRADER JOES #123,54.20,,945.80
05/01/2026,OPENING DEPOSIT,,1000.00,1000.00
```

Import it with `--csv
'date=Date,narration=Description,debit=Debit,credit=Credit,sign=bank'
--account Assets:Checking --date-format '%m/%d/%Y' --apply`. The ledger
is correct at 3,383.80. Take the ending balance from the last row as the
skill says (1,000.00) and run the tie-out recipe.

Actual: the residual is `-2383.80`, so the assertion is withheld as
unexplained. The sanity walk fails, and the doc blames the sign mapping.
Reproduced twice by the hunter. I checked the skill text myself.

Control: the same file oldest-first gives a last-row balance of 3,383.80,
a residual of `0.00`, and a passing `check`.

Expected: the ending balance is the running balance on the latest-dated
row, and the cross-check walk runs in date order.

Cause: `skills/.claude/skills/beancount-reconcile/references/statement-formats.md:21`
("the last row's balance is the ending balance").

Fix: reword it to "the balance on the latest-dated row (exports are
often newest-first); walk the running balance in date order".
Optionally, add a newest-first running-balance eval.

Blast radius: `beancount-reconcile` on any newest-first export with a
running-balance column.

Dedupe: searched `.pm/**`, including `done/`, for running balance,
newest-first and "last row's balance". The only hits are mobile notes
(w4/036, w4/037, w4/053, w3/130, w3/189).

Acceptance: the doc names the latest-dated row. A newest-first fixture
reconciles with residual `0.00`.
