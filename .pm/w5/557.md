# The missing-price summary says "CAD → EUR has no price before 2026-01-01" for cash that is never valued through a cost currency; a later period correctly says "no EUR price at any date"

**Trivial · cli · 15m · A1.** Real CLI QA, 2026-10-16, HEAD `be9ef4f2`, checkout `bea 0.3.1`, macOS 26.5.1. Gap in w5/126.
USAGE gives the dated wording to "a holding valued through its cost
currency". The summary picks the dated form whenever any two-leg route
exists in the price map. Cost-less cash, and a lot whose cost currency is
already the target, never take that route. The dated message tells the user
that a quote from 2026-01-01 on would be enough, which is false. No product
fix implemented.

`b1.bean`:

```beancount
option "operating_currency" "EUR"

2025-12-01 open Assets:CAD CAD
2025-12-01 open Equity:Opening

2025-12-02 * "Open"
  Assets:CAD  1000.00 CAD
  Equity:Opening

2026-01-01 price CAD 0.75 USD
2026-01-01 price USD 0.90 EUR

2026-02-01 * "Deposit"
  Assets:CAD  10.00 CAD
  Equity:Opening
```

```sh
bea -f /abs/b1.bean balance -t 2025-12 --allow-errors
bea -f /abs/b1.bean balance -t 2026-02 --allow-errors
bea --json -f /abs/b1.bean report balance-sheet -t 2025-12
```

Actual: the first prints `CAD → EUR has no price before 2026-01-01; earlier
rows shown in CAD`; the second `CAD has no EUR price at any date; shown in
units`; the third exits 1 with the dated sentence in `details`. A `5 HOOL
{90.00 EUR}` lot with `price HOOL 120 USD` and `price USD 0.90 EUR` behaves
the same.

Control: w5/126's fixture (ACME at USD cost in a EUR ledger) gets the dated
wording correctly.

Expected: the dated wording only when an unvalued holding carries a cost in
the intermediate currency (and that currency is not the target); otherwise
"no EUR price at any date".

Cause: `_routed_since` (`cli/src/bea_engine/report.py:616-636`), called from
`_price_summary_lines` (`:650`), checks the price map but not which lots carry
a cost.

Fix: pass the unvalued positions' cost currencies and require one to equal
the route's intermediate currency.

Dedupe: w5/126 (done) noted "the summary sees the price map, not which lots
carry a cost" as a known limit.

Acceptance: the `-t 2025-12` runs say "no EUR price at any date" for both
fixtures; w5/126's case is unchanged. A test pins it.
