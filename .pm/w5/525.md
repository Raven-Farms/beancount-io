# Two import refusals drop the remembered-settings notes IMPORTING.md promises: an unreadable settings directory on a flag-free run, and a bad date on a remembered or header-read run

**Minor · cli · 15–20m · A1.** Real CLI QA, 2026-10-16, HEAD `d16aea3e`, checkout `bea 0.3.1`, macOS 26.5.1. Gap in w5/141, 215 and 282.
IMPORTING.md says that an unreadable `importers/` directory adds a note
(`Cannot read remembered import settings in <directory>`) that is also in
the JSON `notes`. It also says that "A failure with no preview, on a run
whose column mapping was remembered or read from the header row, lists those
settings notes first in the error details". A bad amount does list the
note; these two refusals raise before the notes are built. No product fix
implemented.

`main.bean` with `Assets:Checking` and `Expenses:Uncategorized` open;
`aug.csv` = `Date,Description,Amount` / `2026-08-01,COFFEE,-3.00`. One
import with `--account Assets:Checking` remembers the header.

```sh
chmod 000 "$BEA_CONFIG_DIR/importers"; bea -f /abs/main.bean --json import aug.csv; chmod 755 "$BEA_CONFIG_DIR/importers"
printf 'Date,Description,Amount\n2026-08-99,COFFEE,-3.00\n' > aug2.csv; bea -f /abs/main.bean --json import aug2.csv
printf 'Date,Description,Amount\n2026-08-01,COFFEE,-3.0x\n' > aug3.csv; bea -f /abs/main.bean --json import aug3.csv
```

Actual: (1) exit 2, `Read a column mapping from the header row… but not
which account the export belongs to. Add --account…`, with no `details` and
nothing saying the settings could not be read (the same happens when the
remembered importer file was moved). (2) exit 2, `Row 1 (line 2): cannot
parse date '2026-08-99'…`, with no details. (3) exit 2 with the amount error
and `details: ["Using settings remembered from aug.csv for aug3.csv: …"]`.

Expected: (1) carries the unreadable-settings (or missing-importer) note;
(2) lists the remembered-settings note first, as (3) does.

Cause: `cli/src/cli/commands/import_.py:788-798` raises the missing-account
refusal with `inferred_notes` only, and `:807-823` raises the date error,
both before `config_notes` and the settings note are merged (`:851-874`).

Fix: build and attach the settings notes before these refusals.

Dedupe: searched `Cannot read remembered import settings`. w5/141, 215 and
282 (done) are the fixes this extends.

Acceptance: (1) and (2) carry the notes in text and JSON. Tests pin both.
