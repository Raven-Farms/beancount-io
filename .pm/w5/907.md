# Stop telling XCD importers that the currency has no minor unit

**Trivial · cli · 5–10m · A1/A2.** Real CLI QA, 2026-10-21, checkout
`bea 0.3.1`, HEAD `a04d9c8c0`, Darwin 25.5.0 arm64, frontend Python 3.13.3.
An otherwise successful XCD import carries an incorrect currency warning.
Default amounts remain correct. No product fix implemented.

Synthetic `/abs/books/main.bean`:

```beancount
option "operating_currency" "XCD"
2024-01-01 open Assets:Cash XCD
2024-01-01 open Expenses:Food XCD
```

`/abs/books/bank.csv`:

```csv
Date;Description;Amount
2024-02-01;Adjustment;-650.000
```

From `/abs/books`, closed stdin/no TTY, isolated absolute `BEA_CONFIG_DIR`
and `XDG_CACHE_HOME`, `BEA_NO_UPDATE_NOTIFIER=1`, with inherited `BEA_FILE`
and `BEA_TOKEN` removed:

```sh
bea --json --no-input -f /abs/books/main.bean import /abs/books/bank.csv --account Assets:Cash --default-account Expenses:Food --csv date=Date,narration=Description,amount=Amount
# On the same pristine fixture, apply:
bea --json --no-input -f /abs/books/main.bean import /abs/books/bank.csv --account Assets:Cash --default-account Expenses:Food --csv date=Date,narration=Description,amount=Amount --apply
```

Both exit 0. The JSON `data.notes` contains:
`Column 'Amount' reads '-650.000' as -650.000 XCD, but XCD has no minor
unit and the dots likely group thousands (-650000). Pass --csv
decimal=comma if these are whole amounts.` Human preview says the same.
Preview preserves ledger/CSV bytes; apply writes one −650.000 XCD
withdrawal. Fresh BQL returns −650.000 and check passes. The finding is the
false currency fact and consequent advisory, not a changed default amount.

Expected: XCD gets the same behavior as other currencies with two minor-unit
digits. The ISO 4217 maintenance agency's current
[SIX List One XML](https://www.six-group.com/dam/download/financial-information/data-center/iso-currrency/lists/list-one.xml),
published 2026-09-17 and fetched for this QA run, identifies XCD/East
Caribbean Dollar with `CcyMnrUnts` **2** in all eight country entries. The
source download is linked from [SIX's currency-code reference](https://www.six-group.com/en/products-services/financial-information/market-reference-data/data-standards.html).

Twice-fresh controls, through both `amount=` and a zero-filled
`debit=Debit,credit=Credit` pair:

- XCD preview/apply warns as above, despite writing/querying −650 exactly.
- Replace XCD with USD: the same amounts write/query correctly without the
  no-minor-unit warning.
- Replace it with ISK: the warning remains appropriate and is still shown.
- Keep XCD but explicitly choose `decimal=point`: no warning and the same
  correct amount. Human XCD previews reproduced twice too.

Cause: `_ZERO_DECIMAL_CURRENCIES` in
`cli/src/bea_engine/csv_mapper.py:84–105` mistakenly includes XCD at :101.
`CsvImporter._dot_ambiguity` (:1403–1426) uses this set, and
`_dot_ambiguity_note` (:291–311) asserts the currency has no minor unit.
`importing.py:313–314` forwards that note to both frontend renderers. The
set is used only for this advisory. Comparing its entries against the
downloaded current list found XCD as its sole mismatch; the other listed
codes have minor-unit value 0, and no current zero-minor-unit code is missing.

Fix: remove XCD from this advisory's zero-decimal set. Preserve explicit
decimal choices, the genuine ISK warning, and the existing parsed amounts.
No dependency, registry-fetching feature, backend or API change is needed.

Dedupe: whole-board XCD/zero-decimal searches and current milestone review
found no open coverage. Completed [753](./done/753.md), commit `0e1a09e0b`,
introduced the constant and advisory; its ISK behavior remains correct.
Open [906](./906.md) concerns normalization before decimal inference, while
this case already imports correctly and needs only the currency fact fixed.

Acceptance: default XCD previews/applies in both column layouts omit the
false warning and retain −650.000 exactly; USD, ISK and explicit-point
controls remain unchanged. Pin real CLI coverage. Sanitized evidence is
under ignored `.tmp/qa-2026-10-20-cli-loop-pass8-80df309f/`:
`repro_xcd_minor_unit_notice.py`, `xcd-minor-unit-results.json`,
`six-list-one.xml`, `six-currency-controls.json` and `captures/xcd-notice-*.json`.
