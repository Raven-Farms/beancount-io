# `bea list transaction --flag txn` is refused, although USAGE says `list` filters follow `add`'s flag grammar, which includes `txn`

**Trivial · cli · 10m · A1.** Real CLI QA, 2026-10-16, HEAD `d16aea3e`, checkout `bea 0.3.1`, macOS 26.5.1. Gap in w5/340.
USAGE: "a flag is one of `* ! & # ? %`, a capital letter, or `txn`; … `list`
filters follow the same grammar". `add --flag txn` writes `txn`. A user who
adds with it cannot filter with it. No product fix implemented.

```sh
bea -f /abs/main.bean list transaction --flag txn
```

Actual: exit 2, `Error: --flag 'txn' is not a transaction flag; use one of *
! & # ? % or a capital letter, such as '!'.`

Expected: `txn` is accepted and matches the same entries as `--flag '*'`
(Beancount reads `txn` as `*`).

Cause: `cli/src/cli/commands/list.py:600` validates against a flag set
without `txn`.

Fix: accept `txn` and normalize it to `*` before filtering.

Dedupe: no `.pm` match for `--flag txn`; w5/340 (done) set the shared
grammar.

Acceptance: `--flag txn` lists the `*` transactions. A test pins it.
