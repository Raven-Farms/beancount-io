# `ingest extract` checks its arguments too late: `-e DIRECTORY` ends in a 46-line `IsADirectoryError` traceback, and `-o` into an unwritable directory exits 1 after every importer has run, not 3 (gap in w5/279 and w5/438)

**Trivial · cli · 10m · A1.** Real CLI QA, 2026-10-17, HEAD `d75811df`, checkout `bea 0.3.1`, macOS 26.5.1.
Uses the inspected minimal ingest script from w5/704. No product fix
implemented.

1. **`-e DIR`.** `bea ingest extract --config ingest.py -e /abs/books
   downloads/bank-jan.csv` exits 1. stderr holds a 46-line traceback ending
   `IsADirectoryError: [Errno 21] Is a directory: '…/books'`. USAGE says
   passing a directory "exits 2 with a hint to select its root ledger file";
   `bea -f /abs/books check` does.
2. **`-o` into a read-only directory.** `bea ingest extract --config ingest.py
   downloads -o /abs/rodir/e.bean` (directory mode 555) prints each `… OK`
   line, then exits 1 with `Error: Could not open file '…/rodir/e.bean':
   Permission denied`. An existing mode-444 file gives the same. USAGE
   "Output destinations" (around line 198) names `ingest extract -o` and says
   an unwritable destination is "exit **3**". `query -o …/rodir/q.txt` exits
   3, `Cannot write …: the directory … is not writable. Nothing was written.`

Cause: `_forward` (`cli/src/cli/commands/ingest.py:68-91`) runs
`guard_forwarded_output`, `_refuse_output_over_inputs` and
`has_unreadable_include` (`:87`), which returns false for a directory. It
never checks that `-e` is a regular file, and never runs
`output.check_output_destination`/`require_writable_destination`, which
`treeify` and `example` do.

Fix: before launching the script, refuse a non-file `-e` with exit 2 (with
`DIR/main.bean` as the hint), and run the writable-destination checks on
`-o` (exit 3).

Dedupe: w5/279 (done) listed `ingest extract -o` in its blast radius but
fixed only `price export` and `example`; w5/138, 250 and 438 (done) fixed the
doctor, query and unreadable-include siblings.

Acceptance: case 1 exits 2 with the hint and no traceback; case 2 exits 3
before any importer runs.
