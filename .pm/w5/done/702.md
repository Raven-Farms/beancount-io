# A proxy that closes or never answers the CONNECT makes `cloud ledger create`, `delete` and now `logout` exit 4 "outcome unknown", though the tunnel never opened (gap in w5/519)

**Trivial · cli · 15m · A1.** Real CLI QA, 2026-10-17, HEAD `733ea312`, checkout `bea 0.3.1`, macOS 26.5.1. Simulation: a local CONNECT proxy stub that logs the request line and closes. Follow-up to w5/519 and w5/521 (done).
w5/519 made a refused tunnel (407, 403, 502) "Could not reach the server",
exit 1, because the request never left the proxy. A proxy that drops the
CONNECT gets a different classification. No product fix implemented.

With `BEA_API_URL=https://api.qa.invalid HTTPS_PROXY=http://127.0.0.1:<port>`:

- `BEA_TOKEN=qa-fake-token bea --json cloud ledger create newbook` exits 4:
  `Creating ledger 'newbook' did not complete cleanly (RemoteProtocolError).
  The outcome is unknown…`.
- `-y cloud ledger delete qa/books` gives the same.
- With a stored credential, `cloud logout` exits 4: `…the server's answer to
  the revocation was lost or unreadable (RemoteProtocolError)…`. Before
  `315af713`, logout exited 1 with "Could not reach the server".
- With a proxy that never answers, create waits about 30 s, then exits 4
  (`ReadTimeout`).
- The proxy log shows only `CONNECT api.qa.invalid:443 HTTP/1.1`.

Control: `cloud ledger show qa/books` through the same proxy exits 1 `Could
not reach the server (RemoteProtocolError)`. A 407 answer gives exit 1
(`ProxyError`) for all three writes.

Expected: exit 1 "Could not reach the server" when the CONNECT never got a 2xx
(USAGE:316: a write that never connected sent nothing).

Cause: the never-connected tuples (`cli/src/cli/commands/cloud/ledger/
app.py:78`, `generated/ledger.py:97` from `scripts/gen_cloud_commands.py:209`,
`cloud/app.py:116`) list only `ConnectError`, `ConnectTimeout` and
`ProxyError`. httpcore reports a CONNECT that is closed or unanswered as
`RemoteProtocolError` or `ReadTimeout`.

Fix: treat a transport error raised before the tunnel is established as never
connected, for example by wrapping the proxy transport to tag the CONNECT
phase.

Dedupe: w5/519 and 521 (done) are the parents.

Acceptance: the three writes through a closing proxy exit 1. A test pins one
of them.
