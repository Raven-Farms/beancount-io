# `bea --help` truncates five command summaries with `...` again (regression of w1/m15/t005)

**Minor · cli · 15–20m · A1.** Real CLI QA, 2026-10-12, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS. Cosmetic.
The closed task w1/m15/t005 has the acceptance "No line in `bea --help`
ends with `...`." Commands added since have first lines over the limit, and
no test pins the bullet. No product fix implemented.

No fixture. Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME,
BEA_NO_UPDATE_NOTIFIER=1, no inherited BEA_FILE/BEA_TOKEN, closed stdin, no
TTY.

```sh
bea --help | grep '\.\.\.$'
```

Actual: five command rows (besides the usage line):

```text
  price    Inspect managed price includes (status, refresh, export), or...
  example  Generate an example Beancount history (delegates to...
  treeify  Render a hierarchical column as an ASCII tree (delegates to...
  ingest   Run Beangulp identify/extract/archive via the user's ingest...
  engine   Manage the managed Beancount engine and optional accounting...
```

A worker saw the same on a PTY at 80 and 200 columns.

Control: the commands the task originally shortened (`init`, `import`,
`query`, `ask`, `cloud`) print in full.

Expected: the closed acceptance quoted above.

Cause: first docstring lines longer than the short-help limit used at
`cli/src/cli/main.py:213`: `cli/src/cli/commands/price.py:21`,
`example.py:33`, `treeify.py:99`, `ingest.py:32`, `engine.py:19`.

Fix: shorten the five first lines and add a test that no root-help command
row ends with `...`. No behaviour change.

Blast radius: root help text. Subcommand groups also truncate some rows,
which the acceptance does not cover.

Dedupe: board search for help truncation and `get_short_help` finds only
the closed m15 task.

Acceptance: `bea --help | grep -c '\.\.\.$'` counts only the usage line.
Only macOS and the checkout were exercised.

---

**Resolved 2026-10-13** — The first help lines of five root commands were shortened so `bea --help` prints each summary whole: the docstrings in `cli/src/cli/commands/price.py`, `example.py` and `treeify.py`, and the group help in `ingest.py` and `engine.py`; the generated `cli/docs/REFERENCE.md` was refreshed to match. The `ingest` prerequisite ("Requires 'bea engine enable beangulp'.") moved from the summary into a second paragraph of `bea ingest --help` rather than being dropped, and the `price` summary no longer lists `status, refresh, export`, which the body of `bea price --help` still describes. The new `cli/tests/test_root_help_rows_untruncated.py` reads every root command row at 80 and 200 columns and asserts none ends with `...`, pins the five new summaries, checks the originally shortened ones (`init`, `import`, `query`, `ask`, `cloud`) as the control, and checks the ingest prerequisite still appears; 8 of its 9 cases fail with the source change reverted. Subcommand-group rows, which the note's acceptance does not cover, are unchanged. Only macOS was exercised. `make check-all` passed. Shipped in `f086a5c2` (`cli`).
