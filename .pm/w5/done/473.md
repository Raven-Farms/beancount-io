# `bea list price|commodity -c " HOOL"` passes validation, then matches nothing: "No prices found.", exit 0

**Minor · cli · 10–15m · A1.** Real CLI QA, 2026-10-16, HEAD `8195088f`, checkout `bea 0.3.1`, macOS 26.5.1. Gap in the w5/340 fix.
w5/340 made a `-c` value that can never match exit 2 with the commodity
grammar. The check strips and upper-cases the value, but the raw value is
forwarded, so a stray space (common when an agent quotes a value it built)
passes the check and then filters everything out. An empty answer with exit
0 reads as "this commodity has no prices". No product fix implemented.

Disposable `main.bean` with `2026-01-07 price HOOL 55.25 USD` and the
accounts it needs. Isolated config/cache, closed stdin.

```sh
bea -f /abs/main.bean list price -c " HOOL"
bea -f /abs/main.bean list price -c "HOOL "
bea --json -f /abs/main.bean list price -c "HOOL "
bea -f /abs/main.bean list commodity -c " usd"
```

Actual: exit 0 and `No prices found.` (JSON `"data": []`).

Control: `-c HOOL` and `-c hool` list the price; `-c "HO OL"` exits 2.

Expected: the stripped value is what is matched (HOOL is listed), or the
padded value is refused with exit 2. Validation and filtering must use the
same value.

Cause: `cli/src/cli/commands/list.py:344` validates `currency.strip().upper()`
but forwards `currency` unchanged; the engine compares it unstripped
(`cli/src/bea_engine/ledger/reader.py:389`, `:508`).

Fix: strip the value before forwarding (or in the engine).

Blast radius: `list price`, `list commodity`, and any other list type that
takes `-c`; check whether `balance`/`report` currency options share the
pattern.

Dedupe: w5/340 (done) covers comma, space-inside and multi-sigil values
only. No note covers surrounding whitespace.

Acceptance: the four commands list HOOL/USD (or exit 2). A test pins it.

---

**Resolved 2026-10-16** — Shipped in `c23c201c` (`cli`). `cli/src/cli/commands/list.py` now forwards the stripped `-c` value it validated, so `list price -c " HOOL"`, `-c "HOOL "` (text and JSON) and `list commodity -c " usd"` list HOOL and USD; `-c "HO OL"` still exits 2. Only `list` takes `-c` as a filter: `add price`/`add commodity` and `init` take it as input, and `add price -c " HOOL"` already exits 2 with the commodity grammar. `tests/test_list_currency_whitespace.py` pins the four padded spellings, which fail without the fix, and the inner-space refusal.
