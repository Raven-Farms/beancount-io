# With `TERM` unset or unknown to terminfo, the query shell pages every result, even one row, and waits at `(END)` for `q`

**Minor · cli · 10–15m · A1.** Real CLI QA, 2026-10-16, HEAD `f29eb957`, checkout `bea 0.3.1`, macOS 26.5.1. Interactive shell on a PTY.
Upstream's screen-height lookup returns 0 when the terminal type cannot be
found, and the pager treats 0 as "always page". `TERM` is often unset in
containers, under `ssh -T`, or for new terminal emulators not yet in the
system terminfo (`xterm-ghostty`). `bean-query` never pages. No product
fix implemented.

```sh
env -u TERM bea -f /abs/main.bean query
# beanquery> SELECT 1 AS one LIMIT 1
```

Actual: the screen shows `one`, `---`, `1`, `(END)`, and the shell blocks
until `q`. `TERM=xterm-ghostty` does the same, with `more` warning about an
unknown terminal type.

Control: `TERM=xterm-256color` (and `TERM=dumb`) print the row and return to
the prompt.

Expected: a result that fits prints directly; with an unknown height, no
paging.

Cause: `get_screen_height()` (`beancount/utils/misc_utils.py`) returns 0
without terminfo; the shell's pager (reached via `cli/src/bea_engine/query.py:908`,
see w5/585) pages when the height is 0.

Fix: measure the window with `shutil.get_terminal_size`/`os.get_terminal_size`
(or disable paging when the height is unknown). The w5/585 fix may cover
this if paging is turned off.

Dedupe: searched `TERM=`, `terminfo`, `(END)`. No match.

Acceptance: with `TERM` unset, a one-row result returns to the prompt. A PTY
test pins it.

---

**Resolved 2026-10-17** — The behaviour was fixed by w5/585 (`e5f626b7`), which starts both bea query shells with Beanquery's pager off. With `TERM` unset or unknown to terminfo, a result now prints and the prompt returns, where upstream's 0 screen height had paged everything. Shipped in `d80d7034` (`cli`): the PTY test the note asks for. `tests/test_query_shell_unpaged.py` now runs the session with `TERM` unset and `TERM=xterm-ghostty`, beside `dumb`. Each case prints a 12-row result, returns to the prompt and exits on `.exit`. The unset case hangs at the pager against the code from before w5/585. `make check-all` passed.
