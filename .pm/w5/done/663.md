# Under `check_commodity` with `--allow-errors`, a refusal blames the currency the ledger already lacked and files the truly new one as tolerated, so following its advice leads to a second refusal (from the w5/153 fix)

**Minor · cli · 15m · A1.** Real CLI QA, 2026-10-16, HEAD `5a0cdcb4`, checkout `bea 0.3.1`, macOS 26.5.1.
USAGE: `--allow-errors` tolerates existing errors and refuses introduced ones.
check_commodity errors carry no line. w5/153 matched them to the
before-load by error class plus a placeholder. An existing EUR error whose
account text changed therefore leaves a "moved" credit, and the new CHF
error, sorting first, takes it. No product fix implemented.

```beancount
plugin "beancount.plugins.check_commodity"

2026-01-01 commodity USD
2026-01-01 open Assets:Bank
2026-01-01 open Assets:Zed
2026-01-01 open Equity:Opening

2026-01-02 * "Fund"
  Assets:Zed  100 EUR
  Equity:Opening
```

(The ledger already lacks a `commodity EUR`.)

```sh
bea --file /abs/main.bean add transaction FX --date 2026-01-05 -p "Assets:Bank 100 CHF @ 1.05 EUR" -p "Assets:Bank -105 EUR" --allow-errors
```

Actual: exit 1, `The change would introduce 1 new ledger error(s)`, naming
`Missing Commodity directive for 'EUR' in 'Assets:Bank'` and advising `bea add
commodity … --currency EUR`. In `--json`, the real new error (`… for 'CHF' …`)
is in `ledger_warnings`. Adding EUR and retrying is refused again, now for CHF.

Control: with a new currency that sorts after EUR (GBP), the blame is correct.

Expected: the refusal names CHF as new and lists EUR as tolerated.

Cause: `_moved_error_key` (`cli/src/bea_engine/ledger/write.py:2283-2297`) keys
unanchored errors as `(class, "<check_commodity>")`; `_preexisting_errors`
(`:2258`) spends the moved credit on whichever error sorts first.

Fix: key unanchored check_commodity errors by the missing currency (already
computed by `_MISSING_COMMODITY` / `missing_before`, `write.py:1601-1617`).

Dedupe: w5/153 and 398 (done) are related.

Acceptance: the command names CHF and tolerates EUR. A test pins it.
