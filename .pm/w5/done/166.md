# `ingest archive` without `-o` files documents beside a symlinked script's target, not beside the script

**Minor · cli · 15–20m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, Beangulp 0.2.0, macOS.
When `ingest.py` beside the ledger is a symlink to a shared script, `bea
ingest archive` moves the statements into the shared script's directory
instead of the ledger's. Running the same script with stock Beangulp
files them beside the link. Documents are moved, not lost, and `--dry-run`
shows the path. No product fix implemented.

In `/absolute/a4`, create `shared/ingest.py` containing the importer below
followed by

```python
if __name__ == "__main__":
    beangulp.Ingest([Bank()])()
```

```python
import csv, datetime
from decimal import Decimal
import beangulp
from beancount.core import data, amount

class Bank(beangulp.Importer):
    @property
    def name(self): return "bank"
    def identify(self, filepath): return filepath.endswith(".csv")
    def account(self, filepath): return "Assets:Checking"
    def date(self, filepath): return datetime.date(2026, 8, 31)
    def filename(self, filepath): return "bank.csv"
    def extract(self, filepath, existing):
        out = []
        with open(filepath, newline="", encoding="utf-8") as fh:
            for i, row in enumerate(csv.DictReader(fh), 2):
                meta = data.new_metadata(filepath, i)
                units = amount.Amount(Decimal(row["Amount"]), "USD")
                out.append(data.Transaction(meta, datetime.date.fromisoformat(row["Date"]), "*", row["Payee"], row["Narration"], frozenset(), frozenset(), [
                    data.Posting("Assets:Checking", units, None, None, None, None),
                    data.Posting("Expenses:Misc", -units, None, None, None, None)]))
        return out
```

Then `books/ingest.py` as a symlink to `../shared/ingest.py`,
`books/dl/a.csv`:

```csv
Date,Payee,Narration,Amount
2026-08-02,Cafe,Coffee,-5.25
```

and `books/main.bean`:

```beancount
option "operating_currency" "USD"
2026-01-01 open Assets:Checking USD
2026-01-01 open Expenses:Misc USD
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY. cwd `/absolute/a4`.

```sh
bea -f books/main.bean ingest archive --config books/ingest.py books/dl
```

Actual: exit 0; stderr reports the destination
`/absolute/a4/shared/Assets/Checking/2026-08-31.bank.csv`. Nothing is
created under `books/`.

Control: the same layout with `books/ingest.py` as a regular file files
to `/absolute/a4/books/Assets/Checking/2026-08-31.bank.csv`. A worker ran
the symlinked script directly with the engine's Python (`python ingest.py
archive dl`), which files beside the link under `books/`.

Expected: the archive help says the default destination "is assumed to be
directory in which the ingest script is located", and `--config` "defaults
to ingest.py beside the ledger"; `bea ingest` describes itself as
forwarding to Beangulp's own CLI, so it should match it.

Cause: `cli/src/cli/commands/ingest.py:41,52` call `.resolve()` on the
script path, dereferencing the link before spawning; Beangulp derives the
default destination from the script path it was started with.

Fix: make the path absolute without following links, or pass `-o` with
the script's lexical directory when archive has no destination. No
dependency or API change.

Blast radius: `ingest archive` with a symlinked script; any script that
reads files relative to its own path sees the resolved location too (not
run).

Dedupe: board search for ingest with symlink, resolve and archive finds
w5/068 (extract `-o` onto source or script), w5/087 and w5/159; none
covers the archive destination.

Acceptance: the command files the statement under `books/Assets/…`; the
regular-file control is unchanged. Only macOS and the checkout were
exercised.

---

**Resolved 2026-10-13** — `bea ingest` no longer dereferences a symlinked ingest script before spawning it: `_ingest_script` in `cli/src/cli/commands/ingest.py` now makes the path absolute without following links, both for `--config` and for the `ingest.py` found beside the ledger or in the current directory, so Beangulp derives its default archive destination from the link's directory as it does when the script is run directly. The new `cli/tests/test_ingest_archive_symlinked_script.py` runs the real `ingest archive` command without `-o` from the parent directory against a script symlinked to a shared copy and against a regular-file control, each with an explicit `--config` and with the default beside the ledger, and asserts the statement lands under `books/Assets/...` and nothing is created beside the shared target. The two symlink cases fail with the fix reverted; the two regular-file controls pass either way. The same change means a script that reads files relative to its own path now sees the link's location too, matching stock Beangulp. Only macOS was exercised. `make check-all` passed. Shipped in `4091ccd7` (`cli`).
