# `bea doctor context|region|linked DIR LOCATION` suggests `bea doctor context DIR/main.bean` without the location, so the pasted remedy exits 2 with `Missing argument 'LOCATION'`

**Trivial · cli · 10m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12.
[w5/138](./done/138.md) added a hint to `bea doctor` for a directory
passed where a ledger file is expected. The hint keeps only the first
operand. For `context`, `region` and `linked`, which take a second
operand, the suggested command is incomplete, and pasting it as printed
gets upstream's usage error. No product fix implemented.

Use the split ledger from [343](./343.md) (any directory holding a
`main.bean` works) and the same environment.

```sh
bea doctor context '/absolute/my books' 3
bea doctor context '/absolute/my books/main.bean'
```

Actual:

- The first command exits 2 with `Ledger path '/absolute/my books' is a
  directory; expected a ledger file. Pass its root ledger instead, for
  example bea doctor context '/absolute/my books/main.bean'.`
- Pasting that line exits 2 with `Usage: bean-doctor context [OPTIONS]
  FILENAME LOCATION … Error: Missing argument 'LOCATION'.`
- `region` drops `REGION` the same way, and `linked` builds the same
  truncated hint.

Reproduced by the hunter in two rounds and once by me.

Control: `bea doctor lex DIR` suggests a line that pastes and runs (exit
0). `bea doctor context '/absolute/my books/main.bean' 3` works.

Expected: a remedy printed as a copyable command should run as printed.
It should keep the remaining operands and options, as `format`'s remedy
does, for example `bea doctor context '/absolute/my books/main.bean' 3`.

Cause: `cli/src/cli/commands/doctor.py:95-111` builds `bea doctor {op}
{hint}` from `positionals[0]` and drops `positionals[1:]` and every
option.

Fix: rebuild the argument list with the directory operand replaced, for
example `shlex.join(["bea", "doctor", op, *before, str(hint), *after])`.
No dependency change.

Blast radius: the `bea doctor context`, `region` and `linked` hints when
the first operand is a directory.

Dedupe: searched `.pm/**`, including `done/`, for "is a directory;
expected a ledger file" and `doctor context`. w5/138 added the hint and
tested only the exit code. None covers the dropped operands.

Acceptance: `bea doctor context DIR 3` suggests `bea doctor context
DIR/main.bean 3`, quoted, and pasting it exits 0. `region` and `linked`
keep their operands the same way. A test pins the full hint. Only macOS
and the checkout were exercised.

---

**Resolved 2026-10-15** — `_refuse_directory_ledger` (`cli/src/cli/commands/doctor.py`) rebuilds the suggested command from the whole argument list with only the directory operand replaced, quoted with `shlex.join`. `bea doctor context DIR 3` now suggests `bea doctor context 'DIR/main.bean' 3`, which runs when pasted (exit 0); `region` and `linked` keep their operands the same way. `cli/tests/test_doctor_directory_hint_operands.py` pins the full hint for all three operations and pastes the `context` one; all 4 cases fail with the fix reverted. Only macOS was exercised. `make check-all` passed. Shipped in `be58ea8b` (`cli`).
