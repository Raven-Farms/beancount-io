# Three printed remedies still drop `--file` or `--json`: import's "declare it first: bea add commodity …" (twice), the BQL hints "Run bea query .tables" / ".help", and `bea check FILE`'s "run bea --file FILE check" (gaps in w5/619, w5/198 and w5/500)

**Minor · cli · 10–15m · A1.** Real CLI QA, 2026-10-17, HEAD `8a64f3768`, checkout `bea 0.3.1`, macOS 26.5.1.
w5/619 and w5/303 say a printed remedy names the ledger, and IMPORTING says
remedy lines carry `--file` "so it acts on the right books wherever it is
pasted". No product fix implemented.

From a directory holding `books/main.bean` (and no `main.bean`):

1. **Commodity.** `bea --file books/main.bean import eur.csv --csv
   date=Date,amount=Amount,narration=Description,currency=EUR --account
   Assets:Checking` exits 2 with `… or declare it first: bea add commodity
   --date YYYY-MM-DD --currency EUR.`. A `€` amount cell gives `(after bea add
   commodity --date YYYY-MM-DD --currency EUR)`. Pasted, the command fails "No
   ledger file", or writes to a `./main.bean` decoy if one exists, and the
   import is still refused (hunter's run).
2. **BQL hints.** `bea --file books/main.bean query 'SELECT nope FROM
   postings'` ends with `Run bea query .tables to list what you can query.`, and
   `.bogus` gives `Run bea query .help …`. Pasted, both fail "No ledger file"
   and lose `--json` when it was given.
3. **`check FILE`.** `bea --json check books/main.bean` says `run bea --file
   books/main.bean check.`, dropping `--json` (and `-v`/`--auto` when given).
   The hinted command exits 0 with no JSON envelope (hunter's run).

Control: `add`'s own remedies carry `--file` (w5/619).

Expected: each remedy is the full command for the same ledger and mode.

Cause:
- Hard-coded strings at `cli/src/bea_engine/csv_mapper.py:1129` and `:1203`, and
  `cli/src/bea_engine/query.py:820` and `:2185`.
- `cli/src/cli/commands/check.py:209` drops the other arguments.

Fix: build them with `bea_command(ledger)`, keeping `--json` and the typed
options.

Dedupe: w5/619, 198 and 500 (done) are the parents.

Acceptance: each pasted remedy runs against `books/main.bean` and works.
