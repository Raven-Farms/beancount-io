# `bea -f DIR format --check` answers with a remedy that rewrites the directory

**Minor · cli · 15m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS.
Asking for a read-only check with a directory passed through `--file` is
refused with advice to "run bea format -i DIR". Following it formats
every ledger file under the directory in place, including files no
ledger includes — after the user asked only to check. No product fix
implemented.

Create `/absolute/work/books/main.bean` and
`/absolute/work/books/sub/notes.beancount`, each:

```beancount
2020-01-01 open Assets:Cash USD
2020-01-01 open Equity:O USD
2020-01-02 * "x"
  Assets:Cash 1 USD
  Equity:O
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, cwd `/absolute/work`.

```sh
bea -f books format --check
bea format -i /absolute/work/books
```

Actual: the first exits 2: `Ledger path '/absolute/work/books' (from
--file) is a directory; expected a ledger file. To format this directory,
run bea format -i /absolute/work/books.` The second — the advice —
exits 0 with `2/2 file(s) formatted.`; both files' contents changed.

Control: `bea format --check books` exits 1, lists the file that would
change and modifies nothing. A worker saw the same `-i` advice for
`--dry-run` and under `--json`.

Expected: `docs/USAGE.md` says `--check` and `--dry-run` write nothing.
The remedy should keep the mode asked for: `bea format --check
/absolute/work/books`.

Cause: `cli/src/cli/commands/format.py:376-382` hard-codes `-i` in the
message whatever mode flags were given.

Fix: carry the requested mode into the message and print the same flags
with the directory as a positional argument. No dependency or API
change.

Blast radius: this one message.

Dedupe: board search for "To format this directory" finds nothing;
w3/done/444 covers `--file DIR format -i` being accepted, not this hint.

Acceptance: the refusal for `--check` suggests `bea format --check DIR`,
and for `--dry-run` suggests `--dry-run DIR`; `-i` appears only when
`-i` was requested. Only macOS and the checkout were exercised.

---

**Resolved 2026-10-13** — The refusal for a directory passed through the global `--file` in `cli/src/cli/commands/format.py` no longer hard-codes `-i`: it now prints the command with the directory as a positional argument and the same mode, output and alignment flags that were given, so `bea -f DIR format --check` suggests `bea format --check DIR`, `--dry-run` suggests `bea format --dry-run DIR`, and `-i` appears only when `-i` was requested. The hint sentence was reworded from "To format this directory, run ..." to "Name the directory as an argument instead: ...", and a refusal with no mode flag suggests plain `bea format DIR` rather than adding `-i`. `cli/tests/test_format_global_file.py` pins the remedy for each mode in human and `--json` output, runs the printed `--check` and `--dry-run` remedies to confirm they list both files and leave the tree byte-identical, and covers the bare and `--output` cases; 10 cases fail with the source change reverted. Only macOS was exercised. `make check-all` passed. Shipped in `ef455190` (`cli`).
