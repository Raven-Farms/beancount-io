# On an included leaf, `bea list` counts the "run with --file ROOT" hint as an error: "Ledger has 3 error(s)" above two errors and the hint

**Trivial · cli · 5–10m · A1.** Real CLI QA, 2026-10-16, HEAD `bea189ec`, checkout `bea 0.3.1`, macOS 26.5.1. Follow-up to w5/348.
`balance`, `report` and `query` on the same file say `2 error(s)`. No product
fix implemented.

`main.bean`: `option "operating_currency" "USD"`, `include "accounts.bean"`,
`include "2024/*.bean"`; `accounts.bean` opens `Assets:Cash USD` and
`Expenses:Food USD`; `2024/jan.bean` holds one lunch transaction using both.

```sh
bea -f /abs/2024/jan.bean list transaction
bea -f /abs/2024/jan.bean balance
```

Actual: `list` exits 1 with `Ledger has 3 error(s). Pass --allow-errors to
report anyway.`, then the two unknown-account errors and the `jan.bean is
included by …; Run with --file …/main.bean` hint. `balance` says `2
error(s)`.

Expected: `2 error(s)` in both.

Cause: `cli/src/cli/output.py:961-966` appends the hint to `formatted` before
`len(formatted)` is counted.

Fix: count the errors before appending the hint.

Dedupe: w5/348 (done) added the hint.

Acceptance: `list` says `2 error(s)`. A test pins it.
