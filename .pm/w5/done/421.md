# Shell completion: options with a fixed set of values (`--format`, `--shell`, `--booking`, `--flag`, `engine enable`, the `price` verbs) complete as file names, and fish is offered fragments of wrapped help (`match)`, `answers`) as candidates

**Trivial · cli · 15–20m · A1 (fish part A2).** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1. Driven through the Click/Typer completion protocol. Nothing was installed or sourced.

Two small completion defects. No product fix implemented.

1. Several options that take a fixed set of words are plain `str` options
   validated by hand, so completion falls back to `_files`. The options
   that use `click.Choice`, such as `--sort`, `report -i` and `import
   --duplicates`, do complete their values.
2. For fish, Typer renders each candidate's help through Rich, which
   wraps at 80 columns when stdout is not a terminal. bea's longer option
   help therefore spills onto extra lines with no tab, and fish shows
   those lines (`match)`, `answers`) as completion candidates.

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
`COLUMNS`, and closed stdin.

```sh
env _TYPER_COMPLETE_ARGS='bea query --format ' _BEA_COMPLETE=complete_zsh bea
env _BEA_COMPLETE=complete_fish _TYPER_COMPLETE_FISH_ACTION=get-args _TYPER_COMPLETE_ARGS='bea list transaction --' bea
```

Actual:

- The first prints `_files`. So do `bea --shell `, `add open --booking
  `, `add transaction --flag `, `engine enable ` and `price ` (no
  `status`/`refresh`/`export`).
- The second prints, among the `value<TAB>help` lines, the bare lines
  `match)` and `answers`.

The hunter reproduced both twice, and I reproduced both once. With
`COLUMNS=300` the fish output has no extra lines.

Expected: a fixed vocabulary completes to its values (`text`, `csv`,
`beancount`; the shells; the booking methods; the flags; the extras; the
price verbs). Fish gets exactly one candidate per line, whatever the
width.

Cause:

- Plain `str` options with hand validation, for example
  `cli/src/cli/main.py:282` (`--shell`) and
  `cli/src/cli/commands/query.py` (`--format`). `price` is a single
  passthrough command (`cli/src/cli/commands/price.py:20`).
- Typer's fish formatter (`typer/_completion_classes.py:178-180`) renders
  help through Rich (`typer/rich_utils.py:751-754`) at the console width.

Fix:

- Add `autocompletion` callbacks returning the valid values, keeping the
  current validation messages.
- When `_BEA_COMPLETE` is set, give Rich a wide width, for example through
  `TERMINAL_WIDTH`, before Typer runs.
- No dependency change.

Blast radius: interactive users of shell completion, and fish users for
the second part. The fish part is A2 because whether fish exports
`COLUMNS` to the completion process was not confirmed in a live fish
session.

Dedupe: searched `.pm/**`, including `done/`, for completion and fish.
w5/122 covers only `--show-completion` with a broken pipe.

Acceptance: `bea query --format <TAB>` offers the three formats, and the
other options listed offer their values. The fish candidates for `bea
list transaction --` contain no line without a tab at the default width.
A test drives the completion protocol for both.

---

**Resolved 2026-10-15** — the fixed-vocabulary options now carry
completion callbacks. `cli.completion.fixed_values` serves `query
--format` (text, csv, beancount), `--shell` (the five shells), `add open
--booking` (the six methods) and `add transaction --flag` (`*`, `!`).
`engine enable` completes the manifest's optional features, and a
`PriceCommand` class offers `status`, `refresh` and `export` (with their
help) as `price`'s first word, leaving later words to bean-price. Each
completes as zsh `_arguments` values instead of `_files`, and a prefix
narrows them. For fish, the entry point (`cli/src/cli/entry.py`) sets
`TERMINAL_WIDTH` while `_BEA_COMPLETE` is set, so Typer's Rich-rendered
help no longer wraps onto bare lines. `bea list transaction --` gives
fish one tab-separated candidate per line at the default width. Pinned by
`cli/tests/test_completion_fixed_values.py`, which drives the completion
protocol and fails without the fix. Not confirmed in a live fish session.
