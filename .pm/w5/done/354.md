# `bea price status` warns "Run bea price status to inspect the source." while it is itself running `price status`, and repeats the error its table already shows

**Trivial · cli · 10m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12.
When a managed price include is unavailable, every read prints a load
warning that ends "Run bea price status to inspect the source.". `price
status` prints that warning too, so the warning tells the user to run the
command they just ran. The status table below it then shows the same
error (`unavailable … no cached revision`). No product fix implemented.

Create `/absolute/books/main.bean`:

```beancount
option "operating_currency" "USD"
include "https://beancount.io/prices/BTC-USD"
2026-01-01 open Assets:Cash USD
```

Use the environment from [352](./352.md).

```sh
bea --offline -f /absolute/books/main.bean price status
```

Actual: exit 0. Stderr shows `…/main.bean:2: managed price source
unavailable: include "https://beancount.io/prices/BTC-USD" in
…/main.bean:2: no cached revision. Run bea price status to inspect the
source.` Then the table prints `BTC-USD unavailable - - - 0 no cached
revision`. `--json price status` prints the same stderr line. Reproduced
twice by the hunter and once by me.

Control: `bea --offline -f … check` prints the same warning, and there
the pointer to `price status` is useful.

Expected: `price status` is where the source is inspected. Its output
should not point back at itself, and should not repeat what its table
already says. Other commands should keep the hint.

Cause: `cli/src/bea_engine/managed_load.py:755` always appends "Run bea
price status to inspect the source." to the unavailable-source load
error. `price status` (and `price refresh`) replay that load error.

Fix: when the command is `price status` or `price refresh`, drop the
warning, since the table covers it, or at least drop the hint. No
dependency change.

Blast radius: `price status` and `price refresh` output whenever a
managed include is unavailable.

Dedupe: searched `.pm/**`, including `done/`, for "Run bea price status".
w3/433 and w3/387 show this line in their repros but fixed only
punctuation and `None` text. None covers the self-reference.

Acceptance: on the fixture, `price status` prints the table without the
self-referencing hint. `check` still prints the hint. A test pins both.
Only macOS and the checkout were exercised.

---

**Resolved 2026-10-15** — `_answer` (`cli/src/cli/commands/price.py`) takes `table_covers_sources`. `price status` and `price refresh` pass it, and the managed-source "unavailable … Run bea price status to inspect the source." load warning is left out of their output, since the table's row already names the source and its cause. Other load errors are still shown, and `check` and the reads keep the pointer. On the fixture, `price status` prints just the table (`BTC-USD unavailable … no cached revision`) in text and JSON. `cli/tests/test_price_status_no_self_hint.py` pins status (text and JSON) and the `check` control; the status case fails with the fix reverted. Two `test_price.py` cases pinned the warning on `price status` stderr and now check the table instead (`check` keeps the stderr assertion). Only macOS was exercised. `make check-all` passed. Shipped in `31e30053` (`cli`).
