# `bea doctor <op> DIRECTORY` dumps a raw upstream traceback

**Minor · cli · 20m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS.
Passing a directory where `doctor` expects a ledger prints a Python
traceback from the engine's `bean-doctor` and exits 1, where `bea check`
gives a one-line usage error and exit 2. No product fix implemented.

Create a directory `/absolute/books/books/` containing `main.bean` with the
single line `2026-01-01 open Assets:Cash`.

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY, cwd `/absolute/books`.

```sh
bea doctor lex books
```

Actual: exit 1; stderr is a traceback starting `Traceback (most recent
call last):` through the engine's `bin/bean-doctor` and click, ending
`IsADirectoryError: [Errno 21] Is a directory: '/absolute/books/books'`.
A worker saw the same from `parse`, `print-options`, `missing-open`,
`display-context`, `directories` and `context`.

Controls: `bea -f books check` exits 2 with `Ledger path 'books' (from
--file) is a directory; expected a ledger file. Point --file to its root
ledger, for example --file books/main.bean.` `bea doctor lex
books/main.bean` exits 0.

Expected: `docs/USAGE.md` assigns exit 2 to bad arguments and a missing
target; a directory operand should get the same one-line message `check`
gives, with no traceback.

Cause: upstream's ledger argument accepts any existing path, and
`cli/src/cli/commands/doctor.py:185,207,222,312,351` forward it unchecked;
the pre-flight helpers skip their checks when the path is not a file.

Fix: in each forwarder, when the ledger operand exists and is a directory,
raise the usage error `check` uses. No dependency or API change.

Blast radius: the seven forwarded operations above plus `dump-lexer`;
`linked`, `region` and `roundtrip` were not tried with a directory.

Dedupe: board search for `IsADirectoryError` and "Is a directory" finds
w5/120 (unreadable or directory include) and w3/382 (`linked` traceback); a
directory as the doctor ledger is unfiled.

Acceptance: `bea doctor lex books` exits 2 with one line naming the
directory and no traceback, for each forwarded operation; the file control
is unchanged. Only macOS and the checkout were exercised.

---

**Resolved 2026-10-13** — `bea doctor` now checks the ledger operand before forwarding and raises a one-line usage error (exit 2) when it is a directory, with a hint naming the directory's `main.bean` or `main.beancount` (`cli/src/cli/commands/doctor.py`). This covers every ledger-taking operation including `dump-lexer`, `linked`, `region` and `roundtrip`. The regression test runs the real command for all eleven operations (thirteen cases fail with the fix reverted) and pins the file-operand and `list-options` controls; `docs/USAGE.md` states the behaviour. Only macOS was exercised. `make check-all` passed. Shipped in `1a23dd72` (`cli`).
