# Hosted ledger: an authored price below an ignored line holding a `"` (an org-mode heading) loses to the managed feed

**Minor · backend-cluster/ledger · 20–30m · A1.** Follow-up from w5/476 (CLI fix `fe055bff`).
`collectLedgerPricePairs` (`backend-cluster/ledger/src/foundation/managed-prices/managed-price-overlay.ts`)
masks strings with `STRING_OR_COMMENT_RE = /"(?:[^"\\]|\\.)*"|;[^\n]*/gu`, the regex the
CLI used before w5/476. A line Beancount's lexer ignores outright (starting `*`, `:`, `#`
or a flag character `!&?%`, per `lexer.l`) can hold a `"` that opens no string, such as
`* Prices for the 12" binder`. The regex pairs that quote with the next one in the file
and masks every line between them as string content. An authored price in that span is
then not collected, so the feed's same-day point is not shadowed.

Found by reading the code, not reproduced against a hosted ledger. Also check whether a
leading byte-order mark reaches this scan: the CLI's collector missed a price on line 1
of a BOM-prefixed file.

Fix: match an ignored line whole before a quote can open a string (the CLI's
`^[*:#!&?%][^\n]*` alternative, multiline), and drop a leading BOM if files can carry
one.

Acceptance: a unit test in `managed-price-overlay.test.ts` collects the pair from
`* Prices for the 12" binder\n2026-09-10 price BTC 70000 USD\n2026-09-12 * "Later"\n`,
and a price inside a multi-line string is still not collected.

---

**Resolved 2026-10-17** — Shipped in `c5f801b5e` (`backend-cluster/ledger`).
- `collectLedgerPricePairs` (`managed-price-overlay.ts`) now matches a line Beancount's lexer ignores, starting `*`, `:`, `#` or `!&?%`, whole before a quote can open a string (`^[*:#!&?%][^\n]*`, multiline), as the CLI does since w5/476. It also drops a leading byte-order mark, so a price on line 1 is read.
- `managed-price-overlay.test.ts` collects the pair from `* Prices for the 12" binder\n2026-09-10 price BTC 70000 USD\n2026-09-12 * "Later"\n` and from a BOM-prefixed file. Both fail without the fix. The existing case for a price inside a multi-line string still passes, uncollected.
- Not reproduced against a hosted ledger; found by reading the code.
- The package's `yarn lint`, `yarn typecheck`, `yarn build` and `yarn test` passed (1318 tests).
