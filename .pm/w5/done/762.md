# `price export` leaves out a local plugin module that Beancount finds through an included file's `option "insert_pythonpath"`, and exits 0 for a snapshot that fails `check` (gap in w5/094)

**Minor · cli · 10m · A1.** Real CLI QA, 2026-10-17, HEAD `227d5a25b`, checkout `bea 0.3.1`, macOS 26.5.1. Gap in w5/094 (done).
USAGE:1702 says `price export` "snapshots a self-contained copy for stock
tools", and USAGE:1720 says a plugin module beside the root is copied under
`insert_pythonpath`. No product fix implemented.

The `books/` directory holds three files:
- `main.bean`: `option "operating_currency" "USD"`, `include "settings.bean"`,
  `plugin "myplug"`, and opens for `Assets:Checking USD` and `Equity:Opening`
- `settings.bean`: `option "insert_pythonpath" "TRUE"`
- `myplug.py`: a no-op plugin (`__plugins__ = ["noop"]`)

```sh
bea -f /abs/books/main.bean check
bea --offline -f /abs/books/main.bean price export
bea -f /abs/books/main-export/main.bean check
```

Actual:
- The source checks clean (exit 0).
- The export exits 0 with `Exported 2 files to …/main-export.`, holding only
  `main.bean` and `settings.bean`.
- The snapshot fails `check` with `1 error(s)`. `bean-check` reports
  `ModuleNotFoundError: No module named 'myplug'` (hunter's run).

Control: with the option line moved into `main.bean`, `myplug.py` is copied
and the snapshot checks clean (hunter's run).

Expected: copy the module, or refuse the export naming it (w5/094's
acceptance).

Cause: `cli/src/bea_engine/managed_load.py:1583-1594` reads only the root's
`insert_pythonpath` and searches only `snapshot.root.parent`. Beancount merges
`pythonpath` across includes, and the load cache already uses
`options["pythonpath"]`.

Fix: plan modules from every directory in `options["pythonpath"]`, or refuse
naming any plugin resolved from a ledger-tree directory the export does not
copy.

Dedupe: w5/094 and 327 (done) cover root-only cases.

Acceptance: the export includes `myplug.py` (or exits non-zero naming it),
and the snapshot checks clean.

---
**Resolved 2026-10-19** — `price export` plans plugin modules from every `options["pythonpath"]` directory (Beancount merges it across includes), copying in-tree modules and refusing naming out-of-tree ones; shipped in `afa183e64` (`cli`)
