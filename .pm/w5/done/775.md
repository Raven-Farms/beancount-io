# Two roots including one leaf (`main.bean` and `main-backup.bean` both include `2026.bean`): a write is still judged against whichever sorts first, so the true balance is refused and a false one written with exit 0, and the refusal never says which root judged it (w5/578 addendum, not implemented)

**Major · cli · 15–20m · A1.** Real CLI QA, 2026-10-17, HEAD `3fe1ca1ff`, checkout `bea 0.3.1`, macOS 26.5.1. Carries forward the w5/578 addendum (2026-10-17), whose resolution says "ask when ambiguous" was not implemented.
No product fix implemented.

- `main.bean`: opens `Assets:Cash`, `Expenses:Food` and `Equity:Opening`, books
  a 100 USD opening, then `include "2026.bean"`, then a 30 USD 2026-01-20
  dinner.
- `main-backup.bean`: the same first seven lines, without the dinner.
- `2026.bean`: `; 2026`.

```sh
bea --file 2026.bean add balance -a Assets:Cash --amount '70 USD' --date 2026-02-01
bea --file 2026.bean add balance -a Assets:Cash --amount '100 USD' --date 2026-02-01
bea --file main.bean check
```

Actual:
- The true 70 exits 1 (`expected 70 USD != accumulated 100 USD (30 too
  much)`), with no note saying which root judged it.
- The false 100 exits 0 after `2026.bean is included by …/main-backup.bean;
  the write goes to 2026.bean…`.
- `check` on `main.bean` then fails on it.

Expected (the addendum's acceptance): exit 2 listing both includers and
asking for `--file ROOT --into LEAF`, with the reroute note shown on refusals
too.

Cause: `including_root` (`cli/src/bea_engine/ledger/write.py:1321`) returns the
first includer in sorted `*.bean` order (`-` sorts before `.`).
`cli/src/cli/engine/launch.py` (around `:449-459`) relays the engine's stderr
note only on success.

Fix: when more than one top-level root includes the leaf, refuse with exit 2
listing them; relay the reroute note on refusals.

Dedupe: w5/578 (done) holds the original addendum; w5/709 (open) is a
different two-root reporting issue.

Acceptance: both commands exit 2 naming `main.bean` and `main-backup.bean`. A
test pins it.

---

**Resolved 2026-10-19** — writes through a twice-included leaf exit 2 listing both roots with the `--file`/`--into` recipe, and refusals relay the reroute note naming the judging root, shipped in `560514d4b` (`cli`)
