# With `implicit_prices` and `unique_prices`, a second same-day FX trade (or a price that disagrees with an implied one) is refused with a bare `Disagreeing price entries` at an existing line (incomplete fix of w5/397)

**Minor · cli · 15–20m · A1.** Real CLI QA, 2026-10-16, HEAD `5a0cdcb4`, checkout `bea 0.3.1`, macOS 26.5.1.
w5/397's acceptance: a `unique_prices` conflict names the plugin, the proposed
quote and the line holding the existing quote. The fix covers written
`price` lines only. With `implicit_prices`, every `@` posting implies a price,
so two FX trades on one day at different rates (very common) conflict, and
bea relays Beancount's bare error. No product fix implemented.

```beancount
option "operating_currency" "USD"
plugin "beancount.plugins.implicit_prices"
plugin "beancount.plugins.unique_prices"
2026-01-01 open Assets:Cash USD
2026-01-01 open Assets:Euro EUR
2026-01-01 open Equity:Opening USD
2026-01-02 * "Fund"
  Assets:Cash 1000 USD
  Equity:Opening
2026-01-05 * "FX"
  Assets:Euro 100 EUR @ 1.08 USD
  Assets:Cash -108 USD
```

```sh
bea --file /abs/main.bean add transaction FX2 --date 2026-01-05 -p "Assets:Euro 10 EUR @ 1.09 USD" -p "Assets:Cash -10.90 USD"
bea --file /abs/main.bean add price --date 2026-01-05 --currency EUR --amount "1.10 USD"     # also with --force
```

Actual: exit 1, `The change would leave the ledger invalid; nothing was
written.` with only `…/main.bean:10: Disagreeing price entries`. Line 10 is the
existing trade; there is no "Proposed append" label, no plugin name, and no
mention that the quote is implied. A written price plus an existing trade
fails the same way.

Control: a conflict with a written `price` gets the w5/397 message (exit 2).

Expected: name `unique_prices`, the two quotes (1.08 and 1.09 USD per EUR on
2026-01-05), and where each comes from ("implied by the transaction at
main.bean:10"). Note that `--force` cannot help while the plugin is loaded.

Cause: `_price` (`cli/src/bea_engine/ledger/adding.py`) checks only written
prices; `validate_candidate` has no hint for `UniquePricesError`.

Fix: add a write-loop hint for `UniquePricesError`, naming the plugin, the
quotes and their origins.

Dedupe: w5/397 (done) is the parent.

Acceptance: both commands give the explained refusal. A test pins it.
