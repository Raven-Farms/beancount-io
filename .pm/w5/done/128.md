# `--meta` stores identifiers as arithmetic results, strips leading zeros, and drops text after `;`

**Minor (silent data alteration, exit 0) · cli · 30–40m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`),
checkout `bea 0.3.1`, macOS.
A bare `--meta key:value` is handed to Beancount's parser, which evaluates
arithmetic, normalises numbers and discards comments. An invoice number
`2024-001` is stored as `2023`, a zip code `02134` as `2134`, a phone
number `555-1234` as `-679`, and a memo loses everything after a
semicolon. The command exits 0 and the ledger passes `check`. No product
fix implemented.

Create disposable `/absolute/books/main.bean`:

```beancount
option "operating_currency" "USD"
2026-01-01 open Assets:Checking USD
2026-01-01 open Expenses:Food
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY.

```sh
bea -f /absolute/books/main.bean add transaction "Dinner" --date 2026-02-01 \
  -p "Expenses:Food 40 USD" -p Assets:Checking \
  --meta 'invoice:2024-001' --meta 'zip:02134' --meta 'phone:555-1234' \
  --meta 'memo:12 ; split with Bob' --meta 'share:1/3'
```

Actual: exit 0, `Added 1 transaction`, and the ledger gains

```beancount
2026-02-01 * "Dinner"
  invoice: 2023
  zip: 2134
  phone: -679
  memo: 12
  share: 0.3333333333333333333333333333
  Expenses:Food  40 USD
  Assets:Checking
```

A worker saw the same on `add commodity` (`cusip:0123456` → `123456`)
and for `12-25` → `-13`, `24/7` → `3.428…`, `1,000` → `1000`,
`;comment` → an empty value, and `5USD` → the amount `5 USD`.

Control: `--meta 'invoice:"2024-001"'` writes `invoice: "2024-001"`. A
worker confirmed `count:3` stays the number 3, `card:4111 1111` stays a
string, and the bulk JSON form `"meta": {"invoice": "2024-001", "zip":
"02134"}` writes quoted strings.

Expected: `docs/USAGE.md` says "Bare text such as `note:hello` or
`receipt:IMG_1234.jpg` becomes a string. Valid native numbers, booleans,
dates and amounts retain their types". An expression, a zero-padded code and
text with a trailing comment are not a native number as the user typed it:
the stored value should be the typed text unless the whole value is one plain
literal. Reference numbers are the commonest metadata there is.

Cause: `cli/src/bea_engine/ledger/adding.py:899-902` (`_parse_metadata`)
parses `key: <raw>` with Beancount and stores whatever comes back; the
grammar evaluates number expressions, `Decimal` drops leading zeros, and
the lexer discards `; …` as a comment.

Fix: keep the typed result only when the raw text is itself one canonical
literal — a plain decimal without redundant leading zeros, `NUMBER
CURRENCY`, a date, TRUE/FALSE/NULL — and otherwise store the raw text as a
string. Fix with w5/082, which is the same function. No dependency or API
change.

Blast radius: `add transaction` and `add commodity`, the two callers.

Dedupe: board search for `--meta` typing finds w5/082 (a leading `#` and
the `name:` key), w3/235 (`count:3` as a number is intended) and w3/347,
w1/164 (date validation); none covers arithmetic, leading zeros or `;`
truncation.

Acceptance: the fixture command writes the five values as the quoted strings
typed; `count:3`, `rate:1.25`, `due:2026-03-01`, `fee:5 USD` and
`ok:TRUE` keep their types; quoted values are unchanged. A regression test
reads the values back through `list` and BQL. Only macOS and the checkout
were exercised.

---

**Resolved 2026-10-13** — `_parse_metadata` in `cli/src/bea_engine/ledger/adding.py` now keeps Beancount's typed reading of an unquoted `--meta` value only when the typed text is itself one plain literal: a decimal without redundant leading zeros, `NUMBER CURRENCY`, a date, or a boolean. Anything the grammar would compute, normalize or truncate (`2024-001`, `02134`, `555-1234`, `1/3`, `1,000`, text with `;`) is stored as the string typed, for `add transaction` and `add commodity`. The regression test reads the values back through `list` and BQL (two cases fail with the fix reverted) and pins the typed, quoted and bulk-JSON controls. Beyond the note's examples, a leading `+` and a trailing-dot number are now text. `docs/USAGE.md` states the rule. `make check-all` passed. Only macOS was exercised. Shipped in `379630cb` (`cli`).
