# A file in the `option "documents"` folder dated before an account's open makes `add open` fail with an untraceable message: `main.bean:0`, a line that does not exist yet, and no mention of the document file

**Minor · cli · 10m · A1.** Real CLI QA, 2026-10-17, HEAD `227d5a25b`, checkout `bea 0.3.1`, macOS 26.5.1.
No product fix implemented.

`main.bean`: `option "documents" "docs"`, `option "operating_currency" "USD"`, and
opens for `Assets:Cash USD` and `Equity:Opening USD`. The files
`docs/Assets/Cash/2026-01-05.receipt.pdf` and
`docs/Assets/Card/2025-12-01.old.pdf` exist.

```sh
bea -f /abs/main.bean add open --date 2026-01-01 --account Assets:Card
```

Actual: exit 1, with the file unchanged:

```
Error: The change would leave the ledger invalid; nothing was written.
  …/main.bean:0: Invalid reference to inactive account 'Assets:Card' Account opened 2026-01-01 at …/main.bean:6. Correct the document date or edit that directive; for new books use bea init --date YYYY-MM-DD.
```

Line 6 is the unwritten proposed open, which has no "Proposed append" label.
There is no document directive to edit, and neither the PDF nor the
`documents` option is named.

Control: `add open --date 2025-12-01 --account Assets:Card` exits 0, and `list
document` shows the file as generated (hunter's run).

Expected: a message naming `docs/Assets/Card/2025-12-01.old.pdf` and the
`option "documents"` line, suggesting an open date on or before 2025-12-01 or
moving the file.

Cause: `cli/src/bea_engine/ledger/write.py` (around `:1710-1748`) gives the
auto-discovered `Document` (meta = root file, line 0) the generic remedy, and
`_plugin_origin` does not recognize documents-option entries.

Fix: for a `Document` generated by the documents option, name its file and the
option, and label the error as caused by the proposed entry.

Dedupe: w5/393 and 216 (done) are different; w5/666 (open) item 1 is related
in spirit.

Acceptance: the refusal names the PDF and gives the date remedy. A test pins
it.

---
**Resolved 2026-10-19** — the inactive-account refusal for an auto-discovered `Document` names the file and the `option "documents"` line and offers moving it (written directives keep their wording); shipped in `9b3497807` (`cli`)
