# `-p 'Assets:Cash 10/0-5 USD'` is no longer refused as division by zero; it leaks Python's `SystemError: <class 'decimal.Decimal'> returned a result with an exception set` (regression from w5/489)

**Minor · cli · 10m · A1.** Real CLI QA, 2026-10-16, HEAD `06e9ca0f`, checkout `bea 0.3.1`, macOS 26.5.1. Follow-up to w5/489 (done, `277ffac7`).
USAGE: "A literal zero divisor (`100/0`) is refused as a usage error before it
reaches the engine". To let futures currencies like `/0J` through, w5/489
added `-` to the lookahead's excluded characters. But `-` is also the
subtraction operator, so `10/0-5` now reaches Beancount's arithmetic and
fails with a raw `SystemError`. No product fix implemented.

```sh
bea -f /abs/main.bean add transaction X --date 2026-01-05 -p 'Assets:Cash 10/0-5 USD' -p 'Assets:Brokerage'
bea --json -f /abs/main.bean add balance --date 2026-01-06 -a Assets:Cash --amount '10/0-5 USD'
```

Actual: exit 2, nothing written, with detail `--posting 1: SystemError: <class
'decimal.Decimal'> returned a result with an exception set` (the same for `add
balance`, bulk rows, `10/-0-5`, `10/0.0-5`, `{10/0-5 USD}` and `@ 10/0-5 USD`).

Before the fix: `Division by zero in 'Assets:Cash 10/0-5 USD'…`.

Control: `10 / 0 -5 USD`, `10/0+5 USD` and `1 / 0 USD` are still refused, and
`1 /0J {100 USD}` writes.

Expected: the division-by-zero refusal for every literal zero divisor, while
`/0J` and `/0-J` stay currencies.

Cause: the lookahead `(?![\d.A-Z'_-])` in `cli/src/cli/amounts.py:61` and
`cli/src/bea_engine/amounts.py:139`.

Fix: skip the match only when a currency token follows, i.e. a letter
eventually follows `[A-Z0-9'._-]*` (for example `(?![\d.]|[A-Z0-9'._-]*[A-Z])`).

Dedupe: searched `SystemError`, `exception set`; w5/010, 057 and 489 (done)
are related; w5/565 is the `format` path.

Acceptance: the commands above give the division-by-zero refusal; `/0J` still
writes. A test pins both.

**Resolved 2026-10-18** — Shipped in `04c2d7719` (`cli`). Both frontend and engine amount guards distinguish slash-prefixed currencies by the letter required in their token, so subtraction immediately after a literal zero no longer evades the zero-divisor refusal. Twenty command regressions cover signed/decimal zero divisors in transaction units, balances, costs, prices and bulk rows, assert the located division-by-zero diagnostic without Python errors, and preserve the ledger. Reverting both guards makes all twenty fail; the nonzero arithmetic control passes. Expanded futures controls write and check `/0J` and `/0-J`. Forty-six focused tests and `make check-all` passed (7,406 tests, 2 skipped). Tracked-content gitleaks passed; full-directory scan retained the same 72 ignored local runtime/build/cache findings.
