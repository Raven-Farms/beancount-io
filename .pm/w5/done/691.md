# After `init` creates a ledger not named `main.bean`, its "Record purchases with bea add transaction" line runs against no ledger, and the resulting error says to run `bea init books` (gap in w5/114)

**Minor · cli · 10m · A1.** Real CLI QA, 2026-10-17, HEAD `101b89e3`, checkout `bea 0.3.1`, macOS 26.5.1. Gap in w5/114 (done).
w5/114 made init's printed commands act on the new ledger, but it adds
`--file` to the add/import line only when `BEA_FILE` is set. The `Next:` line
next to it already switches to `--file` whenever the new file is not
`./main.bean`. No product fix implemented.

In an empty directory:

```sh
bea --no-input init ledger.beancount --currency USD --date 2026-08-01
bea add transaction "Coffee" --date 2026-08-02 --posting "Expenses:Dining 4.50" --posting "Assets:Checking"
```

Actual: init exits 0 and prints `Next: bea --file ~/…/ledger.beancount check`,
then `Record purchases with bea add transaction, or preview a bank export with
bea import.` Running that add exits 2: `No ledger file at 'main.bean' (from the
working directory). … To start new books, run bea init books --currency USD.`
Following that hint creates a second, empty ledger. `init sub/ledger.bean`,
`init sub/main.beancount` and `bea --file x.bean init` print the same plain
`bea` line.

Control: with `BEA_FILE` set, the same init prints `bea --file
…/ledger.beancount add transaction`. `init books` prints `cd … && bea check`,
after which plain `bea` works.

Expected: the add/import line uses the same `--file` (or `cd`) form as the
`Next:` line, so each printed command acts on the new ledger.

Cause: `cli/src/cli/commands/init.py:199` sets `bea` to the plain command
unless `BEA_FILE` is set; `:200-201` already pick `--file` for any other file
name. The missing-ledger hint (`cli/src/cli/context.py:157,162`) checks child
directories for default names only (`_child_ledger`, `:54`), so a
`ledger.beancount` in the working directory goes unmentioned.

Fix: build the add/import line from the same decision as `Next:`. Optionally,
have the missing-ledger hint name a single `*.bean`/`*.beancount` in the
working directory.

Dedupe: w5/114 (done, `BEA_FILE` only) and w5/219 (done, child directories)
are the parents; no open note covers this.

Acceptance: after `init ledger.beancount`, the printed add command writes to
that ledger. A test pins the line for a non-default name.
