# Import echoes its `--csv` and `--date-format` settings unquoted, so the paste-back line breaks on any column name with a space

**Minor · cli · 30m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS.
`bea import` prints the column mapping it inferred as a ready-to-paste
option string. Bank headers such as "Posting Date" and "Transaction
Description" contain spaces, and the echo does not quote them, so pasting
the line back fails with "unexpected extra argument(s)". No product fix
implemented.

Create disposable `/absolute/books/main.bean`:

```beancount
option "operating_currency" "USD"
2020-01-01 open Assets:Checking USD
2020-01-01 open Expenses:Uncategorized
```

`/absolute/books/bank2.csv`:

```csv
Posting Date,Transaction Description,Amount
03/13/2024,Coffee Shop,-4.50
03/14/2024,Grocer,-20.00
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY, cwd `/absolute/books`.

```sh
bea -f main.bean import bank2.csv --account Assets:Checking
bea -f main.bean import bank2.csv --account Assets:Checking --csv date=Posting Date,amount=Amount,narration=Transaction Description --date-format %m/%d/%Y
```

Actual: the first exits 0 and prints `Read the column mapping from the
header row: --csv date=Posting Date,amount=Amount,narration=Transaction
Description --date-format %m/%d/%Y. Pass --csv to override.` The second
— that text pasted back — exits 2: `Got unexpected extra argument(s)
(Date,amount=Amount,narration=Transaction Description)`.

Control: with the value quoted by hand (`--csv 'date=Posting
Date,amount=Amount,narration=Transaction Description'`) the preview
works. A worker saw the same in the ambiguity example ("For example:
--csv date=Posting Date,…"), for a date format with spaces (`--date-format
%d %b %Y`), for a remembered `--rules` path containing a space, and in
JSON `data.notes`.

Expected: the code's own comments say the echoed spec "pastes back
verbatim". "posting date", "transaction date" and "transaction
description" are built-in header synonyms, so spaced names are the
normal case.

Cause: the notes in `cli/src/cli/commands/import_.py` (the ambiguity
example near `:98`, the header-row echo near `:574`, the remembered and
discarded settings lists, and the `--date-format` advice) interpolate
values into f-strings unquoted.

Fix: build each echoed fragment as an argument list and render it with
`shlex.join`, as the `format` and write-path hints already do; keep the
sentence's full stop outside the command. No dependency or API change.

Blast radius: every inferred, remembered or discarded-settings note, in
text and JSON.

Dedupe: w3/done/281 introduced the paste-ready `--csv` line; board
search for "pastes back", "Posting Date" and "unexpected extra argument"
finds nothing else.

Acceptance: the echoed line for the fixture reads `--csv 'date=Posting
Date,amount=Amount,narration=Transaction Description' --date-format
%m/%d/%Y` and pastes back successfully in bash and zsh; space-free
headers are unchanged. Only macOS and the checkout were exercised.

---

**Resolved 2026-10-13** — `bea import` now renders every option value it echoes as a shell word in `cli/src/cli/commands/import_.py`: the inferred header-row line, the ambiguity example, the remembered, updated and discarded settings lists, the unusable remembered `--rules` note and the `--date-format` mismatch advice all go through `shlex`, so the fixture prints `--csv 'date=Posting Date,amount=Amount,narration=Transaction Description' --date-format %m/%d/%Y` in text and in JSON `data.notes`. A detected separator keeps its existing `delimiter=';'` spelling and is joined onto the quoted columns (`--csv 'date=Posting Date,…',delimiter=';'`) rather than being re-quoted, and space-free headers, formats and paths are echoed exactly as before. The regression test `cli/tests/test_import_echo_pastes_back.py` splits each echoed line the way a shell does and feeds it back to the command, covering the inferred line in text and JSON, a semicolon-separated export, the ambiguity example, and remembered and discarded settings with a spaced date format and a `--rules` path containing a space; five of its six cases fail with the fix reverted and the space-free control passes either way. The quoted line was also pasted back through real bash and zsh. Only macOS was exercised. `make check-all` passed. Shipped in `1dcfb349` (`cli`).
