# `bea init` on a terminal asks all three questions before refusing a target it cannot create (a file, a read-only parent, a dangling link), and `--currency 12` is still refused as "Invalid value: …" without naming the option (incomplete fix of w5/588)

**Minor · cli · 10m · A1.** Real CLI QA, 2026-10-17, HEAD `46a722c5c`, checkout `bea 0.3.1`, macOS 26.5.1. PTY for the interactive case. Follow-up to w5/588 (done).
w5/588 made every option be checked before the first question, and USAGE
says invalid command-line options still fail with exit 2. No product fix
implemented.

1. **Target checked last.** With `i4/notes` a regular file, `bea init
   /abs/i4/notes` on a PTY asks `Operating currency [USD]:`, `Earliest date you
   will record …:` and `Checking opening balance …:`, then exits with `Cannot
   create a ledger in …/notes: …/notes is a file, not a directory.`. A
   mode-555 parent (`ro/books`, exit 3) and a dangling-link parent
   (`dl/books`) are also refused only after the three answers (hunter's runs).
2. **`--currency` wording (trivial).** `bea --no-input init /abs/pb --currency 12`
   exits 2 with `Error: Invalid value: Invalid operating currency: '12'. Use a
   symbol such as USD or EUR.`, unlike `--date '2026-13-01': …`, which names its
   option.

Control: an existing `main.bean` and a `$HOME` path are refused before any
prompt.

Expected: target problems are refused before the first question, with the
same messages, and the currency refusal names `--currency`.

Cause: `cli/src/cli/commands/init.py` (around `:122-140`) checks only
`exists()` and the sibling ledger before prompting. `_make_parent` runs in the
engine afterwards (`cli/src/bea_engine/initiating.py:134`). `_currency()` raises
`typer.BadParameter` outside Click's option handling (around `init.py:170`).

Fix: check the nearest existing ancestor (directory, writable, not a broken
link) up front, and wrap the currency error as `--currency …`.

Dedupe: w5/588 (done) is the parent; w5/580, 090, 793, 795 cover the messages
themselves.

Acceptance: the three targets are refused before any prompt; `--currency 12`
names the option.

---

**Resolved 2026-10-20** — `init` now checks the nearest existing ancestor of the ledger's directory before the first question, with the engine's own messages. A regular file there (`…/notes is a file, not a directory`) and a dangling link (`… is a broken symbolic link to …`) exit 2. An unwritable directory exits 3, as `Cannot create …/ro/books: the directory …/ro is not writable.` or, for an existing directory, the staging refusal. A symbolic-link loop or anything unstatable is still left to the engine's check. `--currency` is validated with the other options and names itself: `--currency '12': Invalid operating currency: '12'. Use a symbol such as USD or EUR.` `tests/test_init_target_before_prompts.py` drives the three targets on a PTY and pins the currency message (all four fail at HEAD).
