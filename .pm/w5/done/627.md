# The no-importer hint now lists a QIF or OFX file's first line (`!Type:Bank`, `OFXHEADER:100`) or a mis-split header as "its columns" (regression from w5/470)

**Trivial · cli · 10m · A1.** Real CLI QA, 2026-10-16, HEAD `83bba7bb`, checkout `bea 0.3.1`, macOS 26.5.1. Follow-up to w5/470 (done).
w5/470 made the no-importer refusal list the file's real columns. It lists
whatever single cell the header reader returns, so a non-CSV export or a
wrongly split header is presented as one column with a mapping template.
Before the fix the hint made no claim about columns. No product fix
implemented.

Ledger opening `Assets:Checking` and `Assets:Savings`; `bank.qif` =
`!Type:Bank` / `D02/01/2026` / `T-1.00` / `PA` / `^`; `bank.ofx` starting
`OFXHEADER:100`; `semi.csv` = `When;What;HowMuch` / `2026-02-01;A;-1,00`.

```sh
bea -f /abs/main.bean import bank.qif --account Assets:Savings
bea -f /abs/main.bean import bank.ofx --account Assets:Savings
bea -f /abs/main.bean import semi.csv --account Assets:Savings --delimiter ','
```

Actual: exit 2 with `… map the columns directly. Its columns are:
!Type:Bank. Name them with --csv date=COLUMN,…`; likewise `Its columns are:
OFXHEADER:100.` and `Its columns are: When;What;HowMuch.` (an OFX 2 file lists
`<?xml version="1.0" …?>`).

Control: `--csv auto --delimiter ','` on `semi.csv` explains the delimiter
(`…looks semicolon-, tab-, or pipe-separated but was read as one column…`).

Expected: a column list only when the header splits into several cells. A
one-cell header gets either no list or the delimiter explanation; a file
that looks like QIF/OFX gets "this is not a CSV export; choose a Python
importer with --config".

Cause: `_unread_header_hint` (`cli/src/cli/commands/import_.py:163-181`) lists
`read_header`'s result without the single-cell check used at `:240`.

Fix: reuse the single-cell check; recognize QIF/OFX headers.

Dedupe: w5/470 (done) is the parent; w5/531 (open) covers invisible BOM and
zero-width characters.

Acceptance: the three commands give the right advice. A test pins them.

---

**Resolved 2026-10-17** — Shipped in `b2f7ed2fe` (`cli`).
- `_unread_header_hint` (`cli/src/cli/commands/import_.py`) lists columns only for a header of several cells.
- A file whose first line looks like QIF (`!Type:`) or OFX (`OFXHEADER:`, `<?xml`, `<OFX>`) is called "… looks like a QIF (an OFX) file, not a CSV export, so it has no columns to map: use a Python importer that reads it."
- A one-cell header holding another separator gets w5/622's delimiter explanation, through a shared `_unsplit_header`, for example "semi.csv's header was read as one column ('When;What;HowMuch') with delimiter ',', but it looks semicolon-separated".
- `tests/test_import_hint_one_cell_header.py` pins QIF, OFX (SGML and XML) and the unsplit header; all 4 fail without the fix.
- `make check-all`: 7231 passed. One failure was the known `test_release` `uv sync` 120 s timeout; it failed once more on a rerun and passed on the third.
