**Trivial · cli · 15m · A1.** Real CLI QA, 2026-10-17, HEAD `94c872026`, checkout `bea 0.3.1`, macOS 26.5.1. Follow-ups to w5/624, 627, 628 and 623 (done).
No product fix implemented.

1. **Upstream names (gap in w5/624).** `bea doctor roundtrip` (no file) exits 2
   with `Usage: bean-doctor roundtrip [OPTIONS] FILENAME` / `Try 'bean-doctor
   roundtrip --help' for help.`. `bea treeify --nosuch` says `treeify failed (exit
   2): treeify: error: unrecognized arguments: --nosuch`. `directories`,
   `missing-open`, `region`, `linked`, and doctor on a BOM ledger also leak
   upstream names (hunter's runs). Cause: only `run_native`/`check_native`
   rename. The captured doctor paths do not, and `_renamed` matches only
   `Usage: `, not argparse's `usage:`.
2. **QIF/OFX headers (gap in w5/627).** `bea -f /abs/main.bean import bank.qif
   --csv auto --account Assets:Savings` says `Its columns are: !Type:Bank. Name
   them with --csv …`. An OFX file says `OFXHEADER:100`, and an explicit
   mapping gives "lacks". With no `--csv`, the same file gets "looks like a QIF
   file, not a CSV export".
3. **NaN blamed (gap in w5/628).** `query "SELECT round(number, 30) AS r"`
   exits 1 with `Decimal arithmetic failed … a NaN or infinite value cannot be
   ordered, compared or used in arithmetic. Filter it out with WHERE …`. No NaN
   is involved; the result needs more than 28 digits. `decimal('1e30') % 7`
   behaves the same (hunter's run). Cause: `cli/src/bea_engine/query.py`
   (around `:918`) maps every `InvalidOperation` to the NaN sentence.
4. **Repeated cloud options (sibling of w5/623).** Against a local stub, `bea
   --json cloud ledger list --page 1 --page 3 --limit 5 --limit 9` sends
   `?page=3&limit=9` with exit 0. `cloud ledger clone me/x --dir a --dir b`
   clones into `b` (hunter's run). `create` now refuses repeats.

Fix: rename upstream program names on every relay path; apply the QIF/OFX
check on the `--csv auto`/mapping paths; give the NaN wording only for
non-finite operands; register `list` and `clone` as `SingleValueCommand`.

Dedupe: w5/624, 627, 628 and 623 (done) are the parents; w5/680 (open) covers
`--limit 0`.
