# Human success paths emit raw terminal controls; init's piped follow-up hint silently drops them and names the wrong directory

**Minor · cli · 40–60m · A1/A2.** Real CLI QA, 2026-10-20, checkout
`bea 0.3.1`, HEAD `c8d8f6ad3`, Darwin 25.5.0 arm64, frontend Python 3.13.3.
Reproduced twice with fresh synthetic paths through redirected output and
real PTYs. Ordinary-path controls repeated twice. No product fix implemented.

Use a fresh disposable `/abs/case`, isolated absolute
`BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, `BEA_NO_UPDATE_NOTIFIER=1`, no inherited
`BEA_FILE`/`BEA_TOKEN`, closed stdin and `--no-input`. This Python snippet
spells the filename's ESC byte explicitly and follows the actual printed
hint with the checkout's `bea` on PATH:

```python
import os, subprocess
from pathlib import Path
case = Path('/abs/case')
case.mkdir(parents=True, exist_ok=True)
bea = Path('/abs/checkout/cli/.venv/bin/bea')
env = os.environ.copy()
for key in ('BEA_FILE', 'BEA_TOKEN'):
    env.pop(key, None)
env.update(BEA_CONFIG_DIR=str(case/'config'), XDG_CACHE_HOME=str(case/'cache'),
           BEA_NO_UPDATE_NOTIFIER='1', PATH=str(bea.parent)+os.pathsep+env.get('PATH',''))
books = case / ('books' + '\x1b[2J')
created = subprocess.run(
    [str(bea), '--no-input', 'init', str(books), '--currency', 'USD', '--date', '2024-01-01'],
    cwd=case, env=env, input='', text=True, capture_output=True, timeout=15)
print(created.returncode, repr(created.stdout), repr(created.stderr))
hint = next(line[6:] for line in created.stdout.splitlines() if line.startswith('Next: '))
followed = subprocess.run(['sh', '-c', hint], cwd=case, env=env, input='',
                          text=True, capture_output=True, timeout=10)
print(followed.returncode, repr(followed.stderr))
```

Actual: init exits 0 and creates `books<ESC>[2J/main.bean`. Its `Created ...`
line contains raw byte `1B` followed by `[2J`, the terminal's display-erasure
sequence. In redirected output, the `Next:` command has instead lost that
sequence: it says to `cd .../books && bea check`. Following the exact printed
line exits **1**, `cd: .../books: No such file or directory`. The direct
command below exits 0, proving creation succeeded and the hint names a
different path:

```python
subprocess.run([str(bea), '--json', '--file', str(books/'main.bean'), 'check'],
               cwd=case, env=env, input='', capture_output=True, timeout=10)
```
