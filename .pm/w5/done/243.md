# `--offline`, `--strict` and `--strict-prices` placed after the command get no "place it before the command" hint

**Minor · cli · 5–10m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS. Cosmetic.
Seven global options get a placement hint when written after the command;
these three do not, although the docs show `bea --offline balance`. No
product fix implemented.

Fixture: any valid ledger at `/absolute/books/main.bean`.

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY, cwd `/absolute/books`.

```sh
bea -f main.bean balance --offline
bea -f main.bean balance --json
```

Actual: the first exits 2 with only `Error: No such option: --offline`.
The control exits 2 with `Error: No such option: --json Place --json
before the command, for example: bea --json list transaction.` A worker
saw the bare message for `--strict` and `--strict-prices` too, and the
hint for `-f`, `--file`, `--no-input`, `--yes`, `-y` and `--debug`.

Expected: `docs/USAGE.md`: "Global options come before the command"; the
same hint for every global option.

Cause: the examples table at `cli/src/cli/errors.py:211-219` lists seven
spellings and omits these three.

Fix: add `--strict`, `--offline` and `--strict-prices` to that table. No
dependency or API change.

Blast radius: error text only.

Dedupe: board search for "No such option" with these flags, and "before
the command", finds nothing.

Acceptance: each of the three, placed after a command, prints the
placement hint with a runnable example. Only macOS and the checkout were
exercised.

---

**Resolved 2026-10-13** — The examples table behind the misplaced-global-option hint in `cli/src/cli/errors.py` now lists `--strict`, `--offline` and `--strict-prices`, so each of them written after a command exits 2 with "Place <option> before the command, for example: ..." like the other seven spellings. The examples are `bea --strict balance`, `bea --offline balance` and `bea --strict-prices check`. The regression test `cli/tests/test_global_option_placement_hint.py` runs the real command for each of the three, checks the hint, then runs the printed example and expects exit 0; it also pins the `--json` control text and that an unknown option still gets no placement hint. With the source change reverted, 3 of its 4 cases fail. Error text only; no option, help or doc changes. Only macOS was exercised. `make check-all` passed. Shipped in `6d527bdd` (`cli`).
