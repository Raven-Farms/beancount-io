# Under `option "booking_method" "AVERAGE"`, `add open` silently creates an account that can never sell, and the sale refusal says to edit an open directive that has no booking keyword (gap in w5/162)

**Minor · cli · 10m · A1.** Real CLI QA, 2026-10-17, HEAD `227d5a25b`, checkout `bea 0.3.1`, macOS 26.5.1. Gap in w5/162 (done).
No product fix implemented.

```
option "operating_currency" "USD"
option "booking_method" "AVERAGE"
2026-01-01 open Assets:Checking USD
2026-01-01 open Income:Gains USD
2026-01-02 * "seed"
  Assets:Checking  1000.00 USD
  Income:Gains
```

```sh
bea -f /abs/main.bean add open --date 2026-01-01 --account Assets:Avg
bea -f /abs/main.bean add transaction buy --date 2026-02-01 -p "Assets:Avg 1 HOOL {10 USD}" -p Assets:Checking
bea -f /abs/main.bean add transaction buy --date 2026-02-02 -p "Assets:Avg 1 HOOL {20 USD}" -p Assets:Checking
bea -f /abs/main.bean add transaction sell --date 2026-02-03 -p "Assets:Avg -1 HOOL {}" -p "Assets:Checking 15 USD" -p Income:Gains
```

Actual:
- The first three commands exit 0 with no warning, and the open is written
  as `2026-01-01 open Assets:Avg`.
- The sale exits 1: `AVERAGE method is not supported. Beancount cannot reduce
  a position in an account opened with "AVERAGE" booking; edit that
  account's open directive to use FIFO, LIFO, HIFO, STRICT or NONE.` The open
  has no booking keyword; the option line is the cause.

Control: `add open --booking AVERAGE` exits 2 ("an account opened with it can
never reduce a position", w5/162). With `option "booking_method" "FIFO"`,
every command exits 0.

Expected: `add open` refuses or warns when it would inherit AVERAGE, and the
sale refusal names the `option "booking_method"` line (or says to add an
explicit booking to the open).

Cause: `cli/src/bea_engine/ledger/writer.py` (around `:384-393`) checks only an
explicit `--booking`. The remedy is hard-coded at
`cli/src/bea_engine/ledger/write.py:1705-1708`.

Fix: check the effective booking (the open's own, or `options["booking_method"]`)
in both places.

Dedupe: w5/162 (done) covers `--booking AVERAGE`.

Acceptance: `add open` under the AVERAGE option warns or refuses; the sale
hint names the option line. Tests pin both.
