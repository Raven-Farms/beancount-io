# Three help and doc text slips: forwarded usage errors say "Try 'bean-check --help'" (not installed), `cloud login --help` omits `$XDG_CONFIG_HOME/bea`, and USAGE's `treeify` example draws duplicate root branches

**Trivial · cli · 15m · A1.** Real CLI QA, 2026-10-16, HEAD `e2565f3b`, checkout `bea 0.3.1`, macOS 26.5.1.
No product fix implemented.

1. **Upstream program names in usage errors.** `bea check --nosuch`, `bea
   doctor lex`, `bea doctor context main.bean` and `bea example --nosuch` exit
   2 with `Try 'bean-check --help' for help.` (`bean-doctor lex --help`,
   `bean-example --help`); `ingest` says `Try 'ingest.py extract --help'`. None
   of these programs is on PATH, and USAGE says users do not install the
   `bean-*` tools. Expected: `Try 'bea check --help'` and so on. Cause:
   `run_native` (`cli/src/cli/engine/launch.py:113-133`) passes upstream's
   stderr through, and `check_native` (`:293`) keeps it. Fix: rewrite the
   `Usage:`/`Try '…'` lines to the bea command.
2. **Config path in login help.** `bea cloud login --help` says credentials go
   under "$BEA_CONFIG_DIR, default ~/.config/bea"; the real order
   (`cli/src/cli/config.py:24-45`, USAGE's environment table) is
   `$BEA_CONFIG_DIR`, else `$XDG_CONFIG_HOME/bea`, else `~/.config/bea`. With
   `XDG_CONFIG_HOME` set, files land there. USAGE's cloud paragraph (around
   line 1808) has the same omission. Fix the docstring
   (`cli/src/cli/commands/cloud/app.py:26`) and that paragraph.
3. **USAGE treeify example.** `bea query "SELECT account, sum(position) GROUP BY
   account" > balances.txt; bea treeify < balances.txt` (around lines 466-467)
   draws roots in result order. On a ledger with several accounts per root
   they repeat (`Assets, Income, Expenses, Assets, …`), because GROUP BY is
   unordered. Fix: add `ORDER BY account` to the example.

Dedupe: w5/005 and 002 quote the upstream text in passing; the XDG notes
(w5/021, 176, 392) do not cover login help; no treeify note mentions
ordering.

Acceptance: each of the three reads as described. Tests pin item 1.
