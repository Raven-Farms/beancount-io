# The remembered-settings line prints `--csv` twice when an encoding is in force, so pasting it runs a different mapping

**Minor · cli · 15–20m · A1.** Real CLI QA, 2026-10-12, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS. Fix with [195](./done/195.md).
The line that echoes remembered settings as flags emits `--csv <columns>`
and then a second `--csv encoding=cp1252`. Pasted back, the last `--csv`
wins: the remembered column mapping is discarded, a mapping inferred from
the header is used instead, and that inferred mapping is saved over the
remembered one. The line also omits `--account`. No product fix
implemented.

Create disposable `/absolute/books/main.bean`:

```beancount
option "operating_currency" "USD"
2026-01-01 open Assets:Checking USD
2026-01-01 open Assets:Savings USD
2026-01-01 open Expenses:Food
2026-01-01 open Expenses:Uncategorized
```

```sh
printf 'Date,Description,Amount\n2026-01-05,Caf\xe9 Z\xfcrich,-3.00\n' > jan.csv   # cp1252
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME (fresh), BEA_NO_UPDATE_NOTIFIER=1,
no inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY, cwd `/absolute/books`.

```sh
bea -f main.bean import jan.csv --csv date=Date,amount=Amount,payee=Description,encoding=cp1252 --account Assets:Savings
bea -f main.bean import jan.csv
bea -f main.bean import jan.csv --csv date=Date,amount=Amount,payee=Description --date-format %Y-%m-%d --default-account Expenses:Uncategorized --csv encoding=cp1252 --account Assets:Savings
```

Actual: the second command prints `Using remembered settings for jan.csv:
--csv date=Date,amount=Amount,payee=Description --date-format %Y-%m-%d
--default-account Expenses:Uncategorized --csv encoding=cp1252.` The third
(that text pasted, plus the account) prints `Read the column mapping from
the header row: --csv date=Date,amount=Amount,narration=Description,
encoding=cp1252 …`: the payee mapping has been replaced by an inferred
narration mapping.

Control: a single `--csv
date=Date,amount=Amount,payee=Description,encoding=cp1252` keeps the payee
mapping. A worker confirmed that for UTF-8 files the echoed line has one
`--csv` and pastes back byte for byte.

Expected: `docs/IMPORTING.md`: the line lists "every setting in force",
and "Anything read this way is printed as the equivalent flags".

Cause: `cli/src/cli/commands/import_.py:564-565` appends `--csv
encoding=…` as a second option after `:555` has emitted the columns;
`--account` is never emitted.

Fix: emit one `--csv <columns>,encoding=<codec>` and include `--account`.
No dependency change.

Blast radius: the echoed settings line for any remembered mapping with an
encoding.

Dedupe: w5/195 covers unquoted values in the same line; it does not cover
the duplicated option or the missing account.

Acceptance: the echoed line, pasted verbatim, reproduces the same preview
and leaves the remembered mapping unchanged. Only macOS and the checkout
were exercised.
