# Path-typed options and arguments turn `''` into `.` (the working directory): `bea format -i ''` rewrites the ledgers under the cwd and `bea price export -o ''` writes a snapshot into it, both with exit 0

**Minor · cli · 20–30m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12.
Typer converts `''` to `Path('')`, and `str(Path(''))` is `'.'`, so an
empty path value is never seen as empty. Two commands then write without
being asked:

- `format -i ''` reformats every ledger under the current directory.
- `price export -o ''` exports into the current directory.

The bare `format -i`, by contrast, is refused, and `price export
--output=` (empty) is refused too. The other path options give
misleading directory messages. [386](./386.md) covers the message for
`--into`/`--rules` only. This note covers the general cause and the
unrequested writes. No product fix implemented.

Use a directory holding an unformatted `main.bean`, for example one whose
postings are aligned `Assets:Cash      5 USD` / `Equity:O  -5 USD`. Use
isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, and closed stdin.

```sh
cd /absolute/books && bea format -i ''
cd /absolute/empty && bea -f /absolute/books/main.bean price export -o ''
bea --file '' list transaction
bea -f /absolute/books/main.bean add transactions --from ''
bea init '' --currency USD --date 2026-01-01
```

Actual:

| Command | Exit | Result |
|---|---|---|
| `format -i ''` | 0 | `formatted: …/main.bean`, `1/1 file(s) formatted.`, and the file hash changes |
| `price export -o ''` | 0 | `Exported 1 file to ..`, with `main.bean` written into the cwd |
| `--file ''` | 2 | `Ledger path '.' (from --file) is a directory` |
| `--from ''` | 2 | `Transactions path '.' (from --from) is a directory` |
| `doctor lex ''` | 2 | a directory hint |
| `import ''`, `ingest --config ''` | 2 | `… not found: /absolute/cwd` |
| `init ''` | 0 | initializes the cwd, or exits 4 if a ledger exists |

I reproduced the format, export and directory-message cases. The hunter
reproduced every row at least once and the writes twice.

Control: `bea format -i` with no path exits 2 with `Name the files to
format`. `price export --output=` exits 2 with `bea price export --output
needs a directory.`

Expected: w5/239's rule, which `docs/USAGE.md` applies to `--account`,
`--time` and `--conversion`. An empty value exits 2 naming the option,
and nothing is written.

Cause:

- Typer `Path` conversion in:
  - `format` paths (`cli/src/cli/commands/format.py:48-51`), where
    `_named` (`:370`) filters `if str(path)` and `'.'` passes;
  - the global `--file` (`cli/src/cli/main.py:265`);
  - `add transactions --from` (`cli/src/cli/commands/add.py:591`);
  - the `--into`, `--rules`, `--config` and `import` source options.
- In `price export`, the empty check (`cli/src/cli/commands/price.py:136-139`)
  covers only the `--output=` spelling, not `-o ''` (`:133-135`).

Fix:

- Add a shared Click callback or `Path` parameter type that refuses `''`,
  and blank values, with `UsageError` naming the option, before
  conversion.
- Apply it to every path option and argument, keeping `-` where it is
  documented as stdin or stdout.
- Refuse an empty `-o` in `price export`.
- No dependency change.

Blast radius: every Path-typed option and argument. The writes affect
`format -i`, `price export` and `init`, and are triggered by a template
or script whose path variable is unset.

Dedupe: searched `.pm/**`, including `done/`, for `'.' (from`, "empty
path" and `Path('')`. 386 covers the `--into`/`--rules` messages only,
and w4/122 and w3/196 are unrelated dashboard notes. None covers the
writes.

Acceptance: each command above exits 2 naming the empty option, and no
file changes. `format -i` with real paths and `price export -o DIR` are
unchanged. A real-command test covers `format -i ''`, `price export -o
''` and `--file ''`.
