# Three query export slips: `--spreadsheet-safe` leaves tag/link cells and header cells starting with `-`/`=` untouched, an empty `PRINT -o` on a ledger with a validity option writes an options-only file (regression of w5/102), and `query -o ''` calls the working directory a directory

**Trivial · cli · 10m · A1.** Real CLI QA, 2026-10-17, HEAD `4375177a4`, checkout `bea 0.3.1`, macOS 26.5.1.
No product fix implemented.

1. **Spreadsheet-safe gaps.** On a transaction tagged `#-neg` and linked
   `^-lnk`, `query -f csv --spreadsheet-safe "SELECT payee, tags, links,
   joinstr(tags) AS jt, -number"` writes `Shop,-neg,-lnk,'-neg,-12.50`. The
   `tags` and `links` cells and the `-number` header are not prefixed; a header
   alias such as `AS "=HYPERLINK(1)"` is not either (hunter's run). The help
   says text cells starting with `= + - @`, tab or CR get `'`, and USAGE exempts
   only numbers and amounts. Cause: `_inert_formula` applies only when `value` is
   a `str` (`cli/src/bea_engine/query.py`, around `:1540`), and the header is
   not checked.
2. **Empty PRINT file (regression of w5/102).** On a ledger with `option
   "booking_method" "FIFO"`, `query -o y.bean "PRINT FROM year = 2025"` (no
   rows) writes a 31-byte `y.bean` holding `option "booking_method" "FIFO"`, and
   stdout prints the same line. USAGE (around :739-741) promises an empty file,
   as an empty `SELECT -o` writes. Cause: `_render_beancount` (around `:1475`)
   writes the w5/474 option preamble before checking for rows.
3. **Empty `-o`.** `query -o '' "SELECT 1"` exits 2 with `--output must be a file
   path, not a directory (/abs/cwd).`, and `treeify -o ''` says `(.)`. USAGE says
   an empty value "exits 2 naming it instead of meaning the working
   directory", and `format -o ''` does so. Cause: `query --output` is a plain
   `str` option, which the w5/387 check does not reach.

Fix: neutralize joined set cells and header cells; write the preamble only
when rows follow; apply `refuse_empty_path` to `query`/`treeify` `--output`.

Dedupe: w1/147 (done) introduced the flag; w5/102 and 474 (done) are the
parents of 2; w5/387 and 389 (done) are the parents of 3.

Acceptance: each item behaves as above.
