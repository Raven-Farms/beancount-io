# Fiscal-quarter refusals give wrong guidance: a hard-coded "Report the whole fiscal year (FY2027)" for any year, the first `fiscal-year-end` declaration cited when a later one is in effect, and a `balance FY2026-Q1` hint suggesting a period that is then refused (gap in w5/329)

**Minor · cli · 10m · A1.** Real CLI QA, 2026-10-17, HEAD `f28d154ff`, checkout `bea 0.3.1`, macOS 26.5.1. Gap in w5/329 (done).
No product fix implemented.

1. **Hard-coded year.** With `custom "fava-option" "fiscal-year-end" "04-05"`,
   `bea -f /abs/q1.bean report income-statement -t FY2020-Q3` is refused with
   `Report the whole fiscal year (FY2027), or name the months by calendar
   dates.`. The hunter got the same text for FY2031 and FY2026.
2. **Wrong declaration.** `q2.bean` declares `"03-31"` on line 3 and `"04-05"` on
   line 4.
   - `-t FY2026-Q1` says `fiscal year ends on 04-05 (custom "fava-option"
     "fiscal-year-end" at …/q2.bean:3)`, but line 3 reads `"03-31"`.
   - The `04-05` in effect is line 4: `-t FY2026` reports 2025-04-06 to
     2026-04-06.
   - With an invalid `"06-31"` first and a valid `"03-31"` later, `-t FY2026` is
     refused, though the later value is the one in effect, as in Fava (hunter's
     run).
3. **Bad hint.** `bea -f /abs/q1.bean balance FY2026-Q1` exits 0 with `For the
   period FY2026-Q1, pass -t FY2026-Q1.`, and that period is then refused with
   exit 2 (hunter's run).

Expected: guidance that names the fiscal year containing the requested
quarter and the declaration actually in effect, and no hint for a period bea
refuses.

Cause (`cli/src/bea_engine/report.py`):
1. The text is a literal (`:514`).
2. The declaration lookup (around `:497-507`) takes the first declaration,
   while Fava keeps the last valid one, and `_require_fiscal_year_end` (`:519`)
   refuses on any invalid declaration.
3. `_period_terms` (`:468`) parses terms without the ledger's fiscal year end.

Fix: derive the FY label from the request, cite the last valid declaration,
refuse only when that one is invalid, and give `_period_terms` the fiscal year
end.

Dedupe: w5/329 (done) added the text.

Acceptance: each of the three cases gives correct guidance.
