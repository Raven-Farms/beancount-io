# `bea query --source` dumps a ~200-line traceback (exit 1) for any amount of 10^12 units or more, where `--file` answers

**Minor · cli · 20–30m · A1.** Real CLI QA, 2026-10-16, HEAD `8195088f`, checkout `bea 0.3.1`, macOS 26.5.1.
One trillion VND is roughly 40,000 USD, so a Vietnamese or Indonesian
household ledger reaches this quickly. `bea check` passes the ledger and
`--file` answers the query. The one-shot `--source` path, which hands the
query to upstream, lets the exception escape to Typer's boxed traceback,
although bea promises no traceback without `--debug` (w5/424). No product
fix implemented.

Disposable `main.bean`:

```beancount
option "operating_currency" "VND"
2026-01-01 open Assets:Bank VND
2026-01-01 open Equity:Opening VND
2026-01-02 * "Opening"
  Assets:Bank  1000000000000 VND
  Equity:Opening
```

Isolated `BEA_CONFIG_DIR`/`XDG_CACHE_HOME`, `BEA_NO_UPDATE_NOTIFIER=1`, closed stdin.

```sh
bea query --source /abs/main.bean "SELECT account, sum(position) GROUP BY account"
```

Actual: exit 1, empty stdout, 207 lines of boxed traceback on stderr,
ending `InvalidOperation: [<class 'decimal.InvalidOperation'>]`. `SELECT
decimal('NaN')` through `--source` gives the same with a `TypeError`. At the
interactive `--source` prompt it prints `error:` and a raw traceback, then
continues.

Control: `bea -f /abs/main.bean query "…same…"` prints `Assets:Bank
1000000000000 VND` and exits 0.

Expected: one `error:` line naming the failure, the `--debug` hint, and exit
1, as the other `--source` failures print; or the answer, since `--file`
manages it.

Cause: upstream `DisplayContext.quantize` sets `ctx.prec` to the fractional
digits + 12, so a 13-digit integer overflows it. bea's `ResultContext`
works around that on the `--file` path only. `source_query`
(`cli/src/bea_engine/main.py:625-645`) catches only `EngineError`,
`BrokenPipeError` and `OSError`; `native_one_shot` catches only
`BeanqueryError`.

Fix: catch any other exception in `source_query` and print it as one
`error:` line plus the `--debug` hint (full traceback under `--debug`), exit
1. Optionally render `--source` through the same `ResultContext` so the
query answers.

Blast radius: `query --source` one-shot and its shell; any upstream
exception other than `BeanqueryError`.

Dedupe: searched `InvalidOperation`, `trillion`, `VND`, `--source` with
traceback. w5/259 and w3/274 fixed specific exception types; w5/424 added
the hint elsewhere.

Acceptance: the command above prints no traceback without `--debug` (or
answers). A test pins it.
