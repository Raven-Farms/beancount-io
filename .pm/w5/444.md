# Misspelled options lose Click's "Possible options" suggestion (`No such option: --acount` with nothing more), and unknown subcommands or common aliases (`report bs`, `list account`, `bea help`) get a bare "No such command" with no next step

**Trivial · cli · 15m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12.
Click computes close matches for unknown options, as in `No such option:
--acount (Possible options: --account)`. bea rebuilds the message with
`str(exc)`, which drops them. Misspelled commands keep Click's "Did you
mean". Common names from other tools and docs (`bs`, `is`, `pnl`,
`accounts`, `txn`, `help`) get no suggestion and no pointer to `--help`.
No product fix implemented.

Use any small ledger. Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME,
BEA_NO_UPDATE_NOTIFIER=1, and closed stdin.

```sh
bea -f /absolute/books/main.bean list transaction --acount Food
bea -f /absolute/books/main.bean report bs
bea help
bea lsit                                   # control
```

Actual:

- `--acount` exits 2 with only `No such option: --acount`, in text and
  JSON. `--narraton`, `--from-dat`, `--tagg`, `--limt` and `--jsn` behave
  the same way.
- `report bs` exits 2 with `No such command 'bs'.`. `report is`, `report
  pnl`, `list txn`, `list account` and `bea help` do the same.

Reproduced twice by the hunter and once by me (`--acount`, `report bs`).

Control: `bea lsit` gives "Did you mean 'list'?". `report balance_sheet`
gives "Did you mean 'balance-sheet'?".

Expected: keep Click's possibilities for options. For unknown commands
with no close match, point to `bea <group> --help`. Optionally map
well-known aliases (`bs` → `balance-sheet`, `is`/`pnl` →
`income-statement`, `accounts` → `list open`) to a "Did you mean".

Cause: `to_bea_error` (`cli/src/cli/errors.py:228`) builds the message
from `str(exc)` instead of `exc.format_message()`.

Fix: use `format_message()` (keeping the w5/243 placement hint), and add
a `--help` pointer plus the alias suggestions for "No such command". No
dependency change.

Blast radius: every misspelled option or unknown subcommand, which is a
common case for new users and agents.

Dedupe: searched `.pm/**`, including `done/`, for "No such option",
"Possible options", "No such command" and alias. w5/243 and 416 cover
placement hints only. None covers this.

Acceptance: `--acount` prints `(Possible options: --account)`. `report
bs` suggests `balance-sheet` or `--help`. `bea help` points to `bea
--help`. A test pins the option case.
