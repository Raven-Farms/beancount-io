# `bea list` accepts a `--tag`, `--link`, `--flag` or `-c` filter value that can never be one token (`trip,work`, `#trip#work`, `x`, `USD,EUR`) and answers "No transactions found." with exit 0, while `add` refuses the same value with exit 2

**Minor · cli · 15–20m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12.
[w5/064](./done/064.md) made a sigil-only `--tag '#'` exit 2 instead of
returning an empty result. A value that can never name a tag, link, flag
or commodity still gets the empty result with exit 0:

- `trip,work`, `trip work` or `#trip#work` as one `--tag`;
- `inv-1,inv-2` as one `--link`;
- `x` as a `--flag`;
- `USD,EUR` as one `-c`.

A script or agent that packs several values into one comma-separated
argument, as many CLIs allow, cannot tell "no such rows" from "malformed
filter". The writers already refuse every one of these values with exit 2
and name the token grammar. No product fix implemented.

Create disposable `/absolute/books/main.bean`:

```beancount
option "operating_currency" "USD"
2026-01-01 open Assets:Cash USD
2026-01-01 open Expenses:Food USD
2026-01-05 * "Diner" "dinner" #trip #work ^inv-1
  Expenses:Food  12.00 USD
  Assets:Cash
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, and closed stdin.

```sh
bea -f /absolute/books/main.bean list transaction --tag 'trip,work'
bea -f /absolute/books/main.bean list transaction --tag '#trip#work'
bea --json -f /absolute/books/main.bean list transaction --link 'inv-1,inv-2'
bea -f /absolute/books/main.bean list transaction --flag x
bea -f /absolute/books/main.bean list price -c 'USD,EUR'
bea -f /absolute/books/main.bean add transaction X --date 2026-01-06 -p 'Expenses:Food 1 USD' -p Assets:Cash --tag 'trip,work'
```

Actual:

- The four `list transaction` runs each exit 0 with `No transactions
  found.` (JSON: `"data": []`). `list price -c 'USD,EUR'` exits 0 with
  `No prices found.`
- The `add` run exits 2 with `--tag: 'trip,work' is not one tag or link;
  use only letters, digits and - _ / . after an optional leading # or ^
  …`. `add … --flag x` exits 2 naming the flag grammar.
- The ledger is unchanged.

Reproduced by the hunter in two fresh directories, and again by me in a
third.

Control: `--tag trip --tag work` lists the transaction. A sigil-only
`--tag '#'` exits 2 (w5/064).

Expected: `docs/USAGE.md` says "Tags, links, flags and commodities are
written as bare tokens, so each value must be exactly one … Repeat the
option for several values. A space, a second sigil … a comma (`-c
EUR,GBP`) … is refused with exit **2** naming the option". `list` already
refuses blank filters because a silent empty result hides a template or
shell mistake. A filter value that cannot be one token is the same
mistake. It should exit 2, naming the option and the grammar, with a
"repeat --tag for several tags" hint when the value contains a comma or a
space.

Cause:

- `_run` (`cli/src/cli/commands/list.py:299-315`) only calls
  `refuse_blank_filter`, after removing the sigil.
- The `--flag` check (`list.py:555-556`) only tests the length.
- The token validators `require_tag_or_link`, `require_commodity` and
  `_FLAGS` (`cli/src/bea_engine/ledger/text.py:120-150`) are used only by
  writers.

Fix: in `list`, validate `--tag`/`--link` bodies with the writer grammar
after removing one sigil, `--flag` against `_FLAGS` plus `txn`, and `-c`
with the commodity check. Exit 2 naming the option, with the
repeat-the-option hint. `--search` and `-a` are substrings by design and
stay unchanged. No dependency change.

Blast radius: `list transaction` (`--tag`, `--link`, `--flag`) and `list
price`/`list commodity` (`-c`), in text and JSON.

Dedupe: searched `.pm/**`, including `done/`, for "comma" together with a
tag or filter, "never match", `--tag` with list, and "not one tag".
Related notes cover adjacent cases:

- w5/064: sigil-only values.
- w5/238 and w5/311: repeated options.
- w3/335: a blank `-a`.

None covers a non-blank filter value that cannot be one token.

Acceptance: on the fixture, the four `list transaction` commands and
`list price -c 'USD,EUR'` exit 2 naming the option, and `--tag trip --tag
work` still lists the row. A real-command test covers a comma, a space, a
doubled sigil, an invalid flag and a comma-joined currency, in text and
JSON. Only macOS and the checkout were exercised.
