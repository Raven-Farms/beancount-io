# Closed-account hints: `add open` on a closed account refuses with "an account opens once" without naming the close, `doctor missing-open` says to "reopen the account" (Beancount has no reopen), and a duplicate `add close` gets upstream's bare message, or blames the close already in the file

**Minor · cli · 10–15m · A1.** Real CLI QA, 2026-10-17, HEAD `955c0274e`, checkout `bea 0.3.1`, macOS 26.5.1.
No product fix implemented.

`b.bean` (11 lines) opens `Assets:Old USD` on 2026-01-01, funds it, and has
`2026-02-01 close Assets:Old` on line 11. `broken.bean` is the same plus a
2026-03-05 posting to `Assets:Old`.

1. `bea doctor missing-open /abs/broken.bean` advises `move the open earlier,
   reopen the account, or fix the postings.`
2. `bea -f /abs/broken.bean add open --date 2026-03-01 -a Assets:Old -c USD
   --allow-errors` exits 1 with `Duplicate open directive for Assets:Old` /
   `Assets:Old is already opened at …/broken.bean:3; an account opens once.`.
   The close on line 11 is never named. With `-c EUR` the hint suggests
   editing the open to `USD,EUR`, which leaves the account closed (hunter's
   run).
3. `add close --date 2026-03-01 -a Assets:Old` on `b.bean` exits 1 with only
   `Proposed append (not written): Duplicate close directive for
   Assets:Old`. With `--date 2026-01-25` it says `…/b.bean:11: Duplicate close
   directive for Assets:Old`, which points at the existing close and invites
   deleting it.

Control: a posting after the close names both the open and the close; a
duplicate `add open` names the existing open.

Expected:
- When the account is closed, the duplicate-open hint names the close
  (`closed 2026-02-01 at b.bean:11`) and says to remove it or date it later.
- `missing-open` says "move the close later".
- A duplicate close names the existing one (`already closed 2026-02-01 at
  b.bean:11; an account closes once — edit that close's date`), with the
  proposal labeled.

Cause: `_duplicate_open_hint` (`cli/src/bea_engine/ledger/write.py:2237`) looks
only at opens, and there is no duplicate-close branch. The doctor remedy is
hard-coded (`cli/src/cli/commands/doctor.py:645`).

Fix: look up the close in `_lifecycles` for both hints, and reword the doctor
remedy.

Dedupe: w5/139 (done) wrote "reopen"; w5/488 (done) and w5/658 (open) cover
other duplicate-open cases.

Acceptance: each of the three commands names the close and the right remedy.
