# `format -i` scans the directory once per file, so a flat directory of thousands of ledger files formats in quadratic time

**Minor (marginal trigger) · cli · 15–20m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`),
checkout `bea 0.3.1`, macOS arm64.
In-place formatting sweeps for abandoned staging files before each file it
handles, and each sweep lists the whole directory. With thousands of files in
one directory — one file per day, say — the command takes 17 seconds for
4,000 files even when nothing needs rewriting, where `format --check` takes
1.6. No product fix implemented.

Generate `/absolute/books`:

```sh
mkdir inc; python3 -c "
import sys;N=int(sys.argv[1]);open('main.bean','w').write('2000-01-01 open Assets:Bank USD\n2000-01-01 open Expenses:Food USD\ninclude \"inc/*.bean\"\n')
for i in range(N): open(f'inc/f{i:04d}.bean','w').write(f'2020-01-01 * \"t{i}\"\n  Expenses:Food  1 USD\n  Assets:Bank\n\n')" 4000
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY.

```sh
bea format --check /absolute/books
bea format -i /absolute/books
```

Actual: `--check` exits 0 in 1.6 s. `-i` exits 0 with `0/4001 file(s)
formatted.` after 17.4 s. With 1,000 files the two take 0.5 s and 1.6 s. A
worker measured 1.4 / 4.0 / 15.0 s for 1,000 / 2,000 / 4,000 files, twice.

Expected: time proportional to the number of files, as `--check` shows.

Cause: `cli/src/bea_engine/ledger/formatting.py:80` calls
`write.sweep_abandoned_candidates(file.parent)` inside the per-file loop,
and that function (`cli/src/bea_engine/ledger/write.py:247`) globs the
whole directory. A worker's profile at 2,000 files: 2,001 sweeps, 3.7 of
5.0 s.

Fix: sweep each distinct parent directory once before the loop. No
dependency or API change.

Dedupe: board search for `sweep_abandoned` finds nothing; w1/087 (done) was
`format --check` over include chains, a different path.

Acceptance: `format -i` on the 4,000-file fixture finishes within about
twice the `--check` time, and abandoned staging files are still swept. Only
macOS and the checkout were exercised.
