# A bulk row with `cost: {"number_total": "1500"}` and no currency is refused as "a field holds a line break or a value that is not one token", instead of naming the missing currency

**Trivial · cli · 10m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12.
The structured `Cost` model accepts `number_total` without `currency`.
The row then renders as `{# 1500}`, which Beancount cannot parse, and
the generic one-directive check reports a line break or multi-token
value. The row has neither. [w5/211](./done/211.md)'s resolution says
this case "was not examined". No product fix implemented.

Use any USD ledger with `Assets:Brk` and `Assets:Cash` open, with the
environment from [381](./381.md). Create `a.json`:

```json
[{"date":"2026-01-03","narration":"b","postings":[{"account":"Assets:Brk","units":{"number":"10","currency":"AAPL"},"cost":{"number_total":"1500"}},{"account":"Assets:Cash","amount":"-1500 USD"}]}]
```

```sh
bea -f /absolute/books/main.bean add transactions --from a.json
```

Actual: exit 1 with `Row 1: This row would be written as 0 directive(s);
a field holds a line break or a value that is not one token (Beancount:
syntax error, unexpected RCURL, expecting CAPITAL or CURRENCY).`.
Reproduced twice by the hunter (text and JSON) and once by me.

Control: adding `"currency": "USD"` writes the row. A per-unit `"number":
"150"` without a currency also writes.

Expected: name the field and the fix, for example `Row 1,
postings.0.cost: a total cost needs "currency"`. This would match the
shorthand's own error, which already says to use "number_total" and
"currency" together.

Cause: the `Cost` model (`cli/src/bea_engine/ledger/models.py:111-116`)
does not require `currency` with `number_total`. The rendered text fails
the generic check in `cli/src/bea_engine/ledger/write.py:1840-1853`.

Fix: add a model validator that requires `currency` whenever
`number_total` is set. No dependency change.

Blast radius: bulk `add transactions` rows with a structured total cost.

Dedupe: w5/211 flags it as unexamined, and w3/414 and w3/416 are other
cost-spec cases. No open note covers it.

Acceptance: the row is refused with a field-named message about the
missing currency, and per-unit cost without a currency still writes. A
test pins both.
