# An include glob that crosses a directory the user cannot list silently drops its files: `bea check` exits 0, and balances and `format --check` leave those files out

**Minor · cli · 15–20m · A1.** Real CLI QA, 2026-10-17, HEAD `9eece8ad`, checkout `bea 0.3.1`, macOS 26.5.1. Sibling of w5/274 and w5/523 (done).
w5/274 made a directory walk refuse an unlistable subdirectory, and w5/523
made format name an unreadable included file. An include *glob* through an
unlistable directory is still dropped without any message. That is
upstream's glob behavior too, but it lets `bea check` report success on a
ledger that is missing files. No product fix implemented.

`GL/main.bean`:

```
option "operating_currency" "USD"
2026-01-01 open Assets:Cash USD
2026-01-01 open Equity:Opening
include "txns/**/*.bean"
```

`GL/txns/2026/a.bean` holds a 1 USD transaction to `Assets:Cash`, and
`GL/txns/2025/b.bean` holds a 2 USD one. Then run `chmod 000 GL/txns/2025`.

```sh
bea -f /abs/GL/main.bean check
bea -f /abs/GL/main.bean balance Assets
bea format --check /abs/GL/main.bean
```

Actual: `check` exits 0. `balance` shows `Cash 1 USD` (3 USD while the
directory is readable). `format --check` considers only `a.bean`, with no
unreadable-include line.

Control: `bea format --check /abs/GL/txns` exits 2 with `Could not read
…/txns/2025: Permission denied` (w5/274).

Expected: `check`, reads and `format` fail and name the directory the glob
cannot list, as the directory walk does.

Cause: `_include_matches` (`cli/src/cli/output.py:403-417`) expands with
`glob.glob(..., recursive=True)`, which drops the `PermissionError`. The
loader does the same, so `has_unreadable_include` (`:446`) never fires.

Fix: under a glob's static prefix, walk with an `onerror` hook (as w5/274's
walk does) and report an unlistable directory as an unreadable include, in
the closure check that `check`, reads and `format` share.

Dedupe: w5/274 covers directory arguments; w5/120 and w5/523 cover matched
files. No note covers include globs.

Acceptance: with the directory at mode 000, all three commands exit nonzero
naming `txns/2025`. A test pins `check`.
