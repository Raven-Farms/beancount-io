# With a SOCKS proxy in the environment (`ALL_PROXY=socks5://…`), every `bea cloud` command exits 1 with httpx's "`pip install httpx[socks]`" advice, even for a host listed in `no_proxy`

**Minor · cli · 15m · A1.** Real CLI QA, 2026-10-16, HEAD `d16aea3e`, checkout `bea 0.3.1`, macOS 26.5.1. Client-environment issue; local stub API.
Corporate and VPN setups export `ALL_PROXY=socks5://…`. httpx builds a
transport for every proxy in the environment when the client is created, and
raises `ImportError` when `socksio` is missing. It does this even when the
API host is excluded by `no_proxy`. bea passes the library text through as
an unexpected crash, with a `--debug` hint, and the remedy it shows (`pip
install`) cannot fix a Homebrew or `uv tool` install. No product fix
implemented.

```sh
ALL_PROXY=socks5://127.0.0.1:1080 bea cloud ledger list
all_proxy=socks5h://127.0.0.1:1080 no_proxy=127.0.0.1,localhost bea --json cloud status
```

Actual: exit 1, `Error: Using SOCKS proxy, but the 'socksio' package is not
installed. Make sure to install httpx using \`pip install httpx[socks]\`.
Pass --debug before the command for a traceback.` (JSON category
`validation`). No request reaches the API, including the `no_proxy` case.

Control: without `ALL_PROXY`, exit 0. `NO_PROXY='*'` also exits 0.

Expected: a refusal with a remedy that works for bea, e.g. exit 2: `SOCKS
proxies (ALL_PROXY=socks5://…) are not supported by bea; unset
ALL_PROXY/all_proxy for bea, or use an HTTP(S) proxy.` Supporting SOCKS
(adding `socksio`) is the alternative; it adds a dependency and needs the
maintainers' approval.

Cause: `bearer_client`/`make_client` (`cli/src/cli/api/client.py:77`,
`:84-89`) construct the httpx client with the environment's proxies; the
`ImportError` reaches `to_bea_error` (`cli/src/cli/errors.py`) as an
unexpected error. `bea ask` and managed price fetches likely share the
path.

Fix: catch that `ImportError` at client construction and raise a
`UsageError` naming the variable; check the price fetcher and `ask` too.

Dedupe: no `.pm` match for `socks`, `ALL_PROXY` or proxy errors.

Acceptance: both commands exit 2 with the remedy, and no "pip install" or
`--debug` hint is shown. A test pins it.
