# `bea add custom --help` folds its Examples list into one paragraph, splitting `--value` from its argument

**Trivial · cli · 10m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, Python 3.13.3.
The `add custom` docstring lists four `--value` examples, one per line.
Click's plain help re-wraps them into a single paragraph, so the examples
run together and a line can break between `--value` and its quoted
argument. `add transaction`'s examples render correctly because each one
is its own paragraph. No product fix implemented.

No ledger is needed. Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME,
BEA_NO_UPDATE_NOTIFIER=1, and closed stdin.

```sh
COLUMNS=120 bea add custom --help
COLUMNS=60 bea add custom --help
```

Actual: exit 0. At width 120 the help shows:

```text
  Examples:   --value 'text:hello'   --value 'number:1000'   --value
  'amount:500 USD'   --value 'account:Assets:Cash'
```

Reproduced at both widths, and again in a fresh process.

Control: `bea add transaction --help` prints each example on its own
indented line.

Expected: one example per line, as in the source, so each can be read and
copied whole.

Cause: `cli/src/cli/commands/add.py:462-475`. Help is rendered with
`rich_markup_mode=None` (`cli/src/cli/main.py:235`, `add.py:30`), so
Click's `wrap_text` re-wraps every paragraph not marked `\b`. "Examples:"
and its four lines form one paragraph. `add_transaction` (`add.py:168-175`)
avoids this by separating its examples with blank lines.

Fix: put a `\b` line before the list, or blank lines between the examples.
Optionally show complete invocations, since `--date` and `--type` are
required. Run `make docs` if the generated reference changes. No
dependency change.

Blast radius: `add custom --help` only. A scan of every command docstring
with examples found no other run-on list.

Dedupe: board searches for "Examples:", "reflow" or "rewrap" with help,
and `add custom --help` found nothing.

Acceptance: `bea add custom --help` prints each `--value` example on its
own line at widths 60 and 120. A test asserts that
`--value 'amount:500 USD'` appears unbroken on one line. Only macOS and
the checkout were exercised.
