# A corrupt or unreadable remembered-importer record blocks a plain CSV import with exit 2 ("Cannot read the saved importer path; select one with --config FILE."), naming neither the file nor a working remedy

**Minor · cli · 15m · A1/A2.** Real CLI QA, 2026-10-16, HEAD `595daa2f`, checkout `bea 0.3.1`, macOS 26.5.1.
The ledger's record in `importers/` remembers a Python importer path. A
remembered path that no longer exists degrades with a note (w5/141), and a
corrupt remembered-CSV record reads as no memory. A record that is truncated,
of the wrong shape or unreadable instead stops every flag-free CSV import.
The advice to pass `--config FILE` (write a Python importer) is wrong for a
CSV. IMPORTING.md says to delete "the ledger's record in `importers/`" and
that the refusal names its path; this one does not. w1/105's rule is "stale
local state must not block imports". No product fix implemented.

`stmt.csv`: `Date,Amount,Description` / `2024-02-01,-5.00,Coffee`. The record
`$BEA_CONFIG_DIR/importers/<sha256(realpath main.bean)>.json` holds `{"config":
"/x` (or `{}`, `[]`, `{"config": 5}`, or is mode 000).

```sh
bea -f /abs/main.bean import stmt.csv --account Assets:Bank
```

Actual: exit 2, `Error: Cannot read the saved importer path; select one with
--config FILE.` (JSON category `usage`); nothing written, record untouched.

Control: a readable record naming a missing importer imports by header
inference (exit 0, with a note); `--csv auto` imports.

Expected: a corrupt record is treated like a missing path (a note naming the
record file, then the usual fallbacks: `importers.py` beside the ledger, the
header row). A record that cannot be read because of permissions at least
names its path and mentions `--csv auto`.

Cause: `_config_available` (`cli/src/cli/commands/import_.py:120-125`) turns
every read or parse failure into one pathless `UsageError`; it runs for every
flag-free CSV import (`:748`).

Fix: as above.

Dedupe: searched `saved importer path`. w5/215's resolution kept this error
for a record that cannot be read; the corrupt-JSON case and the wording were
not considered.

Acceptance: the truncated and `{}` records import by header inference with a
note naming the record; the mode-000 record's refusal names the path. Tests
pin them.
