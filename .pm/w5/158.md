# `bea query -o out.json` without `--json` writes an ASCII text table into the `.json` file, exit 0

**Minor · cli · 15m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS.
`--json` is a global flag that must come before the command, so `bea query
… -o out.json` is an easy slip. It exits 0 and fills the `.json` file with
a text table no JSON parser accepts. The same slip with `.tsv` is refused.
No product fix implemented.

Create disposable `/absolute/books/main.bean`:

```beancount
2026-01-01 open Assets:Cash USD
2026-01-01 open Expenses:Food USD

2026-01-05 * "Café" "Lunch"
  Expenses:Food  12.00 USD
  Assets:Cash
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, no TTY, cwd `/absolute/books`. Closed stdin.

```sh
bea -f main.bean query "SELECT account, sum(position) GROUP BY account" -o c.json
```

Actual: exit 0, empty stdout and stderr. `c.json` begins:

```text
   account     sum(position)
-------------  -------------
```

Control: `-o e.tsv` exits 2: `--output e.tsv looks like TSV; pass --format
csv (or rename the file) so the destination is not an ASCII text table.` A
worker saw `.csv` and `.CSV` infer CSV, `.JSON` behave like `.json`, and
`--json … -o c.json` write the envelope.

Expected: refuse or infer, as the sibling suffixes do. A `.json`
destination without `--json` should exit 2 pointing at `bea --json query …
-o FILE`.

Cause: `cli/src/cli/commands/query.py:215-223` knows only `.csv` and
`.tsv`.

Fix: add the `.json` suffix to the refusal, with the `--json` remedy. No
dependency or API change.

Blast radius: `bea query -o` with a `.json` name, any case.

Dedupe: board search for "looks like TSV" and `.json` with text table or
suffix finds w3/done/324 (`.csv`/`.tsv`) and w1/done/146 (`.tsv` under
`--json`); neither mentions `.json`.

Acceptance: the command exits 2 naming `--json` and writes no file; `bea
--json … query … -o c.json` is unchanged. Only macOS and the checkout were
exercised.
