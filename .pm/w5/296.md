# `bea price export` writes into a new directory that the ledger's own `*/…` include glob reads back, and the default `<ledger>-export/` destination does it too

**Minor · cli · 30–45m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, Python 3.13.3.
When a ledger includes files through a wildcard directory part (`include "*/*.bean"`),
`bea price export` into a directory that does not exist yet passes the
include-glob guard from [072](./done/072.md). It writes
`main-export/main.bean` (the default destination) or `snap/main.bean`
(`-o snap`) and exits 0. The next load reads that copy as part of the
books, so every directive appears twice: `check` exits 1 with
`Duplicate open directive`, and `balance` refuses. A directory that already
exists is refused correctly. No product fix implemented.

Create disposable `/absolute/books/main.bean`:

```beancount
option "operating_currency" "USD"
2026-01-01 open Assets:Bank USD
2026-01-01 open Equity:Opening
include "*/*.bean"
```

and `/absolute/books/2026/01.bean`:

```beancount
2026-01-02 * "Open"
  Assets:Bank  100.00 USD
  Equity:Opening
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY, cwd `/absolute/books`,
and a pristine copy for each case.

```sh
bea -f main.bean price export
bea -f main.bean check
bea --json -f main.bean price export -o snap
```

Actual:

- `price export` exits 0 with `Exported 2 files to /absolute/books/main-export.`
- `check` then exits 1 with
  `/absolute/books/main-export/main.bean:2: Duplicate open directive for Assets:Bank`.
- `-o snap` behaves the same way: exit 0 with
  `"files": ["snap/2026/01.bean", "snap/main.bean"]`.

Reproduced in three fresh runs.

Control: after `mkdir snap`, the same `-o snap` exits 2 with
`Cannot export: snap/main.bean would become part of the ledger being
exported — its include pattern /absolute/books/*/*.bean matches that path.
… Nothing was written.`

Expected: `docs/USAGE.md` › Output destinations, which covers
`price export --output`, refuses a destination that "would become part of
the ledger once written: a path that does not exist yet but that one of
the ledger's `include` patterns matches". 072's resolution checks "each
file `price export` plans to write". Whether the directory already exists
should not change the answer, and the default destination should never be
claimed by the ledger.

Cause: `cli/src/bea_engine/managed_load.py:1033-1042` checks each planned
file with `_included_new_file` (`cli/src/bea_engine/ledger/write.py:266-275`).
That function matches the leaf name with `fnmatch` but expands the
pattern's directory part with `glob.glob(parent)` against the disk as it
is now. `/absolute/books/*` does not list `snap/` or `main-export/` until
the export creates them. 072's resolution recorded this limit only for
recursive globs; it applies equally to a single-level `*/`.

Fix: match planned paths against each include pattern lexically, without
requiring the directories to exist: `*` matches one path component, `**`
any depth, and the hidden-file rule is kept. The default destination and a
new `-o DIR` are then refused with exit 2 before anything is written. No
dependency or API change.

Blast radius: `price export`, both the default destination and `-o`, on any
ledger whose include pattern has a wildcard directory part (`*/*.bean`,
`20*/*.bean` that matches the destination name, `**/*.bean`). `query -o`,
`format -o`, `treeify -o` and `ingest extract -o` require the parent to
exist, so the guard sees it there. `example -o` shares the helper and was
not run.

Dedupe: searched the board for `price export`, "include pattern",
"would have to create", `main-export` and `-export/`, and ran
`git log -S "would become part of the ledger"`.

- w5/072 (fixed in `bddbd867`): this case is its stated limit, scoped
  there to recursive globs only.
- w4/171, w4/172, w3/412: escapes and links.
- w3/436: existing files.
- w5/094, w5/189–191, w5/247: other export defects.

None is open, and none covers a single-level directory glob with a new
destination.

Acceptance: on the fixture, `bea price export` and
`bea price export -o snap` each exit 2 naming the include pattern, create
no directory, and leave `bea check` at exit 0. A real-command regression
test covers the default destination, a new `-o` directory under both
`*/*.bean` and `**/*.bean`, and a new directory that no pattern reaches
(still written). Only macOS and the checkout were exercised.
