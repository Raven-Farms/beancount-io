# `MANAGED_PRICE_ORIGINS=https://beancount.io/` (trailing slash, capital letter or explicit `:443`) refuses the default origin's includes, and the refusal names a different origin

**Trivial · cli · 15m · A1.** Real CLI QA, 2026-10-16, HEAD `0864aeed`, checkout `bea 0.3.1`, macOS 26.5.1.
The allowlist entries are compared as raw strings, so the trailing slash a
browser copy usually carries refuses every include from the very origin it
names. The hosted ledger service normalizes the same setting with
`URL.origin` (`backend-cluster/ledger/src/config.ts:68-83`), so the two
disagree. No product fix implemented.

`main.bean`: `include "https://beancount.io/prices/BTC-USD"` and an open.

```sh
MANAGED_PRICE_ORIGINS=https://beancount.io/ bea --offline -f /abs/main.bean check
MANAGED_PRICE_ORIGINS=https://Beancount.io bea --offline -f /abs/main.bean check
MANAGED_PRICE_ORIGINS=https://beancount.io:443 bea --offline -f /abs/main.bean check
```

Actual: each refuses the include: `… is not an allowed managed price source:
origin https://beancount.io is not allowlisted.`, naming the origin the user
did allow. A port mismatch is reported without the port (`origin
http://127.0.0.1`), and an IPv6 origin without brackets (`http://::1`).

Control: `MANAGED_PRICE_ORIGINS=https://beancount.io` accepts the include
(offline it is then only unavailable).

Expected: entries are normalized to `scheme://host[:non-default-port]`
(lower-case host, default port dropped, trailing `/` ignored), and the
refusal names the computed origin exactly.

Cause: `cli/src/bea_engine/managed_load.py:210-214` only strips whitespace
from the entries; `cli/src/bea_engine/managed_prices.py:125-130` compares raw
strings and builds the message from the hostname without port or brackets.

Fix: normalize entries the way the hosted config does; render the origin
with `host[:port]` as the URL has it.

Dedupe: the `MANAGED_PRICE_ORIGINS` notes (w5/070, 092, 100, 187–192, 285,
377–379, 408, 423) concern feeds and test setups; none covers the entry
format.

Acceptance: the three spellings accept the include; the message for a real
mismatch shows port and brackets. A test pins it.
