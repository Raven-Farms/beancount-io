# Common bank-export framing (a preamble, an Excel `sep=;` line, a header repeated per page, a footer line) cannot be imported without hand-editing, and each refusal gives advice that cannot work; a duplicated column name is offered a `--csv` line that is then refused

**Minor · cli · 20–30m · A1.** Real CLI QA, 2026-10-17, HEAD `0e9729be5`, checkout `bea 0.3.1`, macOS 26.5.1.
IMPORTING.md:116-117 allows only a BOM and blank lines before the header.
w1/152 (done) deferred non-blank preamble support as "a separate
enhancement", which was never filed. No product fix implemented.

All cases use `bea --file /abs/main.bean import FILE --account Assets:Checking`.

1. **Preamble.** `pa.csv` starts `Account Number: ****1234`, `Statement Period:
   …`, a blank line, then `Date,Description,Amount` and a row. It exits 2 with
   `Its columns are: Account Number: ****1234. Name them with --csv
   date=COLUMN,…`. With `--csv date=Date,amount=Amount,narration=Description`
   it says `The mapping names column 'Date' for date, which pa.csv lacks.`,
   though the file has it on line 4.
2. **`sep=;` first line** (an Excel export) gives `Its columns are: sep=, .`
   (hunter's run).
3. **Repeated header.** `Date,Description,Amount` again on line 3 gives exit 2:
   `Row 2 (line 3): cannot parse date 'Date' in column 'Date' … pass
   --date-format with the file's strptime format…`.
4. **Footer.** `End of statement` (or `Total,,1995.50`) as the last line gets
   the same `--date-format` advice for `'End of statement'`.
5. **Duplicate column name.** `Date,Description,Amount,Description` gets
   `Several columns could be narration (Description, Description); none was
   chosen. For example: --csv date=Date,amount=Amount,narration=Description`.
   Pasting that exits 2 with `Column 'Description' appears 2 times in the
   header … Rename the duplicates`.

Control: blank lines before the header and blank trailer rows are skipped and
counted.

Expected: a way to name the header line (or skip leading lines), and
refusals that say what is wrong ("line 1 is not a header", "line 3 repeats
the header — remove it", "line N is not a data row"). A repeated header line
could simply be skipped. For identical column names, advise renaming instead
of offering an example.

Cause:
- `open_records` (`cli/src/bea_engine/csv_mapper.py`, around `:885-901`, and
  its frontend twin) takes the first non-blank record as the header.
- The date refusal text is in `cli/src/cli/commands/import_.py` (around
  `:892-897`).
- `infer_mapping` offers an identical name as the example
  (`cli/src/cli/csv_mapper.py`, around `:390-395`).

Fix: add a `--csv header=N` (or `skip=N`) key, skip exact header repeats,
word the date refusal for a non-date first cell, and drop the example for
identical names.

Dedupe: w1/152 (done) deferred preamble support; w5/612 (open) covers the
canned `date=Date,…` hint; w5/003 (done) introduced the example.

Acceptance: each fixture either imports (with the new key or the skipped
repeat) or is refused with advice that works when followed.
