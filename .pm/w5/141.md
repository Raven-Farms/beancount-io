# A remembered importer path that no longer exists blocks both `importers.py` beside the ledger and the plain CSV import

**Minor · cli · 20–30m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS.
After one successful `--config` run, moving or deleting that importer file
makes every flag-free `bea import` on the ledger exit 2 — including a plain
CSV import that needs no importer and a ledger that now has a valid
`importers.py` beside it. No product fix implemented.

Create disposable `/absolute/books/main.bean`:

```beancount
option "operating_currency" "USD"
2026-01-01 open Assets:Checking USD
2026-01-01 open Expenses:Uncategorized USD
2026-01-01 open Equity:Opening USD
2026-01-02 * "Open" "Opening balance"
  Assets:Checking  5000.00 USD
  Equity:Opening
```

`/absolute/books/old/imp.py`: any working importer that recognises `.txt`
files (for example one whose `identify` returns
`str(f).endswith(".txt")` and whose `extract` returns one balanced
transaction on `Assets:Checking`). `/absolute/books/a.txt`: one line.
`/absolute/books/s.csv`:

```csv
Date,Description,Amount
2026-02-02,Grocer,-20.00
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY, cwd `/absolute/books`.

```sh
bea -f main.bean import a.txt --config old/imp.py
mv old/imp.py old/imp_moved.py; cp old/imp_moved.py importers.py
bea -f main.bean import a.txt
bea -f main.bean import s.csv --account Assets:Checking
```

Actual: the first command exits 0. The last two exit 2:

```text
Using importers from /absolute/books/old/imp.py (remembered)
Error: Importer configuration not found: /absolute/books/old/imp.py
```

Control: `bea -f main.bean import s.csv --csv auto --account
Assets:Checking` exits 0 and previews the row.

Expected: `docs/IMPORTING.md` says "without a saved path, the CLI uses
`importers.py` beside the root ledger", and that a remembered `--rules`
path that is missing "degrades to a warning … rather than failing". A
saved importer path that is gone should be treated the same way: a note,
then the `importers.py` and header-row fallbacks.

Cause: `cli/src/cli/commands/import_.py:35-40` (`_config_available`)
returns the remembered path whenever the record exists, without checking
the target; that also suppresses header inference at `:459`.

Fix: when the remembered config is not a file, emit a note, ignore it and
continue to the fallbacks; at least name `--config` and `--csv auto` in the
error. No dependency or API change.

Blast radius: any ledger whose importer file was moved, renamed or deleted
after one successful run.

Dedupe: board search for "Importer configuration not found" and stale or
saved importer path finds w2/done/025 (unrelated input errors), w5/131 (CSV
options dropped when an importer is selected) and w5/done/003; none covers
a dangling remembered path.

Acceptance: both flag-free commands succeed with a stderr note that the
remembered importer is missing (the first using `importers.py`, the second
the header row); the `--csv auto` control is unchanged. A real-command
regression test covers both. Only macOS and the checkout were exercised.
