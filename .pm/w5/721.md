# The NFD `--into` spelling that created a file is refused the second time ("spelled in another letter case or Unicode form", exit 2), for `add` and `import --apply` (regression from w5/536)

**Minor · cli · 10m · A1.** Real CLI QA, 2026-10-17, HEAD `cc6b52ed`, checkout `bea 0.3.1`, macOS 26.5.1 (APFS). Regression from w5/536 (done, `c3a5a33c`).
w5/536 makes a new `--into` file take the NFC name. Once that file exists,
the same NFD spelling no longer maps to it, and the respelling guard refuses
it. A script, or a path pasted from Finder (which gives NFD), works on the
first run and fails on every run after. No product fix implemented.

`main.bean` is `option "operating_currency" "EUR"`, `include
"Ausgaben/*.bean"`, and opens for `Assets:Checking EUR` and `Expenses:Food
EUR`. `Ausgaben/` is empty. `$NFD` is `März.bean` in NFD.

```sh
bea -f /abs/main.bean add transaction x1 --date 2026-02-01 -p 'Expenses:Food 1 EUR' -p Assets:Checking --into "Ausgaben/$NFD"
bea -f /abs/main.bean add transaction x2 --date 2026-02-01 -p 'Expenses:Food 1 EUR' -p Assets:Checking --into "Ausgaben/$NFD"
```

Actual:
- Run 1 exits 0 and creates `Ausgaben/M\xe4rz.bean` (NFC).
- Run 2 exits 2: `Write destination …/Ausgaben/März.bean is the ledger file
  …/Ausgaben/März.bean spelled in another letter case or Unicode form. Pass
  --into 'Ausgaben/März.bean' as the file is named on disk. The two differ
  only in Unicode form; the file's name is NFC. Nothing was written.`
- A repeated `import … --into "Ausgaben/$NFD" --apply` fails the same way
  (hunter's run).
- Before `c3a5a33c`, both runs exited 0 into one file.

Expected: the spelling that created the file keeps writing to it.

Cause: `destination()` (`cli/src/bea_engine/ledger/write.py:47`) NFC-normalizes
the leaf only when the target does not exist. On APFS the NFD lookup finds
the NFC file, so the NFD spelling is kept, and the respelling guard (around
`:188`/`:224`) refuses it.

Fix: when the typed leaf is not NFC and its NFC form names the existing file,
use the NFC name, as creation does. Keep the refusal for a case-only
respelling.

Dedupe: w5/536 and 434 (done) are the parents.

Acceptance: both runs land in `März.bean` (NFC). A test pins the second run.
