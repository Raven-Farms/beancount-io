# Shadowing a managed feed point whose metadata follows an indented comment leaves orphaned indented lines: every command fails with `unexpected INDENT`, and `bea add price` refuses a valid quote

**Minor · cli · 15–20m · A1.** Real CLI QA, 2026-10-16, HEAD `0864aeed`, checkout `bea 0.3.1`, macOS 26.5.1. Synthetic local feed server.
When a ledger price shadows a feed point, bea comments out the feed's price
line and walks the following metadata lines to comment them too. The walk
stops at the first line that is not `key: value`, so an indented comment
ends it and the metadata below is left indented under a comment. The feed
itself is valid Beancount and checks clean until something shadows it.
No product fix implemented.

Feed `K2` (served from an allowlisted origin):

```text
; alias: K2
; commodity: XC
; quote: USD
2026-10-15 price XC 10 USD
    ; provider note
  observed-at: "2026-10-16T12:00:00Z"
```

`main.bean`: `include "<origin>/prices/K2"` and `2026-01-01 open Assets:Cash USD`.

```sh
bea -f /abs/main.bean check                                  # exit 0
bea -f /abs/main.bean add price --date 2026-10-15 -c XC --amount '12 USD'
```

Actual: the add exits 1 with `The change would leave the ledger invalid;
nothing was written.` and `…effective….beancount:5: syntax error, unexpected
INDENT`. Adding the same price by hand makes every command fail with that
error. USAGE says a supplied quote shadows the managed point without
`--force`.

Control: the same feed without the indented comment accepts the add, and
the effective file comments out both lines.

Cause: `cli/src/bea_engine/managed_load.py:197-200`: the loop runs only while
`_METADATA_LINE_RE` matches.

Fix: comment out every following indented line up to the next line at column
0 (or the next directive). Alternatively, have the validator (see w5/478)
refuse indented comments inside a point.

Blast radius: any feed that interleaves indented comments with a point's
metadata.

Dedupe: searched `unexpected INDENT`, `shadowed`. No match.

Acceptance: the add writes the price, and `check` passes with both lines
commented out of the effective feed. A test pins it.
