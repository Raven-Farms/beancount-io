# The ask skill's `anomalies`, `recurring-candidates` and `merchant-history` recipes count postings, not transactions: a $260 split purchase never flags, and a monthly charge with a tax line counts twice

**Minor · skills · 20–30m · A1.** Real CLI QA, 2026-10-16, HEAD `66aeb02e`, checkout `bea 0.3.1`, macOS 26.5.1. Same root cause w5/356 fixed for the close flag sweep.
`beancount-ask/references/bql-recipes.md` calls the anomalies section
"unusually large transactions". It reads `n` in `recurring-candidates` as
charges ("n ≈ months-in-ledger"), and reports creep per charge. BQL returns
one row per posting, so split transactions are invisible to the threshold.
Recurring merchants are over-counted. That includes the one-transaction
splits the migrate skill's `split-purchase` recipe writes.

Fixture: NETFLIX on 2026-04-15, 05-15 and 06-15, each `Liabilities:Card
-16.89`, `Expenses:Entertainment:Streaming 15.49`, `Expenses:Taxes:Sales
1.40`. Plus:

```beancount
2026-05-28 * "BEST BUY" "Monitor + cable"
  Liabilities:Card                   -260.00 USD
  Expenses:Entertainment:Streaming    150.00 USD
  Expenses:Food                       110.00 USD
```

Run each recipe verbatim with `bea --file … --json --no-input query`.

Actual: `anomalies` (threshold 200) returns `[]`. `recurring-candidates` gives
NETFLIX `n=6` and BEST BUY `n=2`. `merchant-history` lists 15.49 and 1.40 as
separate dated charges.

Control: `… GROUP BY id, date, payee, narration HAVING sum(number(weight)) >
200` returns the 260.00 purchase. Counting distinct `id` per merchant gives
NETFLIX 3.

Expected: one row per transaction in all three recipes.

Fix: group by `id` (as w5/356 did) in the three recipes, keeping the `<!--
recipe: … -->` markers; add a split-transaction case to
`skills/scripts/test_beancount_skills.py`.

Dedupe: searched `anomal`, `count(date)`, `per posting`; w5/356 and 358 (done)
are the related fixes.

Acceptance: on the fixture, anomalies returns the BEST BUY purchase, NETFLIX
has n=3, and merchant history shows three charges of 16.89 (or 15.49 with
the tax shown separately and stated). Recipe tests pin it.
