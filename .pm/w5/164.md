# `list transaction` prints a table wider than the terminal when each row fits on its own

**Minor · cli · 15–20m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS.
On an 80-column terminal, `bea list transaction` prints 106-column lines
that wrap, when one row has a long payee and another a long narration.
The fit check measures each row by itself, but the table pads every
column to its widest cell. No product fix implemented.

Create disposable `/absolute/books/main.bean`:

```beancount
option "operating_currency" "USD"
2026-01-01 open Assets:Checking
2026-01-01 open Expenses:Food

2026-01-20 * "Amazon Marketplace Payments WA" "Books"
  Expenses:Food  45.25 USD
  Assets:Checking

2026-01-21 * "Cafe" "Flat white and a croissant x 2"
  Expenses:Food  10.00 USD
  Assets:Checking
```

Run on a pseudo-terminal 80 columns wide, isolated HOME, BEA_CONFIG_DIR
and XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, cwd `/absolute/books`:

```sh
bea list transaction --account Expenses:Food
```

Actual: exit 0; every line is 106 columns:

```text
DATE        FLAG  PAYEE                           NARRATION                       MATCHING POSTING AMOUNTS
2026-01-21  *     Cafe                            Flat white and a croissant x 2  Expenses:Food: 10.00 USD
2026-01-20  *     Amazon Marketplace Payments WA  Books                           Expenses:Food: 45.25 USD
```

Control: the same command at 76 columns takes the shrink path and prints
exactly 76-column lines (`Flat w...`, `Amazon Marketplace...`).

Expected: no line over the terminal width; w1/m15/t004's acceptance was
that in an 80-column pseudo-terminal no line of `bea list transaction`
exceeds 80 characters.

Cause: `cli/src/cli/commands/list.py:238` tests each row's own cell
widths against the terminal width; `output.table` then pads columns to
the widest cell across rows.

Fix: compare the padded table width (per-column maxima including
headers, plus separators) against the terminal width. No dependency or
API change.

Blast radius: `list transaction` on a terminal, with or without
`--account`; piped output is unaffected.

Dedupe: board search for `_transaction_table`, terminal width and narrow
terminal finds w1/m15/t004 (the feature, done), w1/106 (CJK width, done)
and w5/149 (report tree padding); none covers the fit check.

Acceptance: at 80 columns no output line exceeds 80 display columns for
the fixture; the 76-column output is unchanged. Only macOS and the
checkout were exercised.
