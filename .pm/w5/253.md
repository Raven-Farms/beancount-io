# `bea query 'help print'` fails with `TypeError: … got 'NoneType'` (the w3/done/299 crash, for the other overridden statement)

**Minor · cli · 10–15m · A1.** Real CLI QA, 2026-10-12, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS.
w3/done/299 fixed `help select`, which crashed because `bea`'s override of
the statement handler had no docstring. The `PRINT` handler is overridden
the same way and was not covered: `help print` exits 1 with the same
`TypeError`, although `.help` lists `print` as a topic. No product fix
implemented.

Create disposable `/absolute/books/main.bean`:

```beancount
option "operating_currency" "USD"
2020-01-01 open Assets:Cash USD
2020-01-01 open Equity:Opening-Balances

2020-01-01 * "seed"
  Assets:Cash               100 USD
  Equity:Opening-Balances  -100 USD
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY, cwd `/absolute/books`.

```sh
bea -f main.bean query 'help print'
```

Actual: exit 1.

```text
Error: TypeError: expected string or bytes-like object, got 'NoneType' Pass --debug before the command for a traceback.
```

Control: `bea -f main.bean query 'help select'` exits 0 and prints the
SELECT help. A worker saw the same error for `.help print` under `--json`
(category `validation`) and a raw traceback at the interactive prompt.

Expected: the PRINT help text and exit 0; w3/done/299's acceptance was
that statement help "prints … and exits 0 in one-shot mode".

Cause: `cli/src/bea_engine/query.py:733` overrides `on_Print` with a
comment but no docstring; line 746 restores only `on_Select.__doc__`.
Upstream builds each help topic from the subclass method's docstring.

Fix: copy the upstream docstring for every overridden statement handler
(loop over them), and add a regression that runs every topic `.help`
lists. No dependency or API change.

Blast radius: `help print` one-shot, under `--json`, and in the shell.

Dedupe: board search for "help print", `on_Print` and `NoneType` finds
w3/done/299 (the `select` half) and unrelated `NoneType` items (w5/074,
w5/172); no open follow-up.

Acceptance: every topic listed by `.help` prints its help and exits 0.
Only macOS and the checkout were exercised.
