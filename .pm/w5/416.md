# A global option placed after a forwarded command (`check`, `doctor`, `treeify`, `example`, `price status`) gets upstream's bare "No such option" with no "Place it before the command" hint

**Trivial · cli · 15m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12.
[w5/243](./done/243.md) made every misplaced global option on
bea-owned commands explain itself ("Place --offline before the command,
for example: bea --offline balance"). Forwarded natives return their own
parser's refusal, which carries no hint. The same applies to `-f`,
`--file`, `--yes`, `--no-input`, `--strict`, `--offline`, `--json` and
`--debug`. No product fix implemented.

Use any ledger. Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME,
BEA_NO_UPDATE_NOTIFIER=1, and closed stdin.

```sh
bea -f /absolute/books/main.bean check --offline
bea -f /absolute/books/main.bean doctor lex /absolute/books/main.bean --json
bea treeify bal.txt --json
bea example --seed 1 -o /absolute/ex.bean --debug
bea -f /absolute/books/main.bean price status --strict
bea -f /absolute/books/main.bean balance --offline          # control
```

Actual: each forwarded command exits 2 with upstream's message, for
example `Error: No such option '--offline'.`, `treeify: error:
unrecognized arguments: --json`, or `No such option '--debug'. Did you
mean '--date-begin'?`. `price status` says `takes no arguments; got:
--strict`. The control prints the placement hint. Reproduced twice by the
hunter and once by me (`check`, control).

Expected: `docs/USAGE.md` says global options come before the command,
and w5/243 set the rule that each misplaced global option gets the hint.
Forwarded commands should follow it.

Cause: the hint is added only to bea's own Click usage errors
(`cli/src/cli/errors.py:210-228`). Native refusals are passed through
(`check`, `doctor`), wrapped (`treeify`, `example` through
`launch.check_native`), or given their own message (`price status`).

Fix: before forwarding, scan the native argv for global options that the
native does not define itself, excepting `check --json`/`--version` and
`ingest archive -f` (see 413). Raise the same hint. No dependency change.

Blast radius: users of `check`, `doctor`, `treeify`, `example` and `price
status` who put global options last.

Dedupe: w5/243 (done) covers bea-owned commands, and 413 covers `query
-f`/`ingest archive -f`. None covers forwarded natives.

Acceptance: each forwarded command above prints the placement hint with
exit 2. Native-defined options still work. A test pins `check --offline`.
