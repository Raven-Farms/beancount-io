# `bea doctor context`/`region` with a bare line number find nothing when the ledger path goes through a symlink, and the error names the real path the user never typed (regression from w5/568)

**Major · cli · 10–15m · A1.** Real CLI QA, 2026-10-17, HEAD `b9427aca2`, checkout `bea 0.3.1`, macOS 26.5.1. Regression from w5/568 (done, `ac4ca692b`).
USAGE:464 documents `bea doctor context main.bean 22   # a bare line number
means the root file`. w5/568's acceptance asks for "the same answers through
the link as through the real path". Every ledger under macOS `/tmp` or `/var`
also has a realpath that differs from its name, so this likely affects them
too (inference, not run). No product fix implemented.

`real/main.bean` opens `Assets:Cash` and `Expenses:Food` and holds one
transaction on line 4. `link` is a symlink to `real`.

```sh
bea doctor context link/main.bean 4
bea doctor region link/main.bean 4:6
```

Actual:
- `context` exits 1 with `No entry could be found before
  …/real/main.bean:4`.
- `region` exits 1 with `doctor region matched no entries for '4:6' in
  link/main.bean.`
- A symlinked root file (`books/main.bean -> ../shared/main.bean`) does the
  same (hunter's run).
- Before `ac4ca692b` both answered (hunter's run on the pre-fix tree).

Control: `doctor context real/main.bean 4` answers. Through the link,
`main.bean:4`-style locations and `doctor linked link/main.bean 4` work.

Expected: a bare line number through the link answers as through the real
path.

Cause: `_as_named` (`cli/src/bea_engine/scoped.py:79`) remaps only the loader's
filename. Upstream `context` and `resolve_region_to_entries` still build the
bare-line location from click's `resolve_path=True` FILENAME, the real path.
The entries now carry the link path, so the text compare fails.

Fix: pass upstream the named absolute path as FILENAME too, or compare
location filenames by realpath. Add a bare-line case to
`tests/test_doctor_symlinked_ledger.py`.

Dedupe: w5/568 (done) is the parent; w3/403 is unrelated.

Acceptance: both commands answer through the link. A test pins it.
