# `report -a <account>` also counts accounts whose names merely start with it when the account's leaf is CJK, Thai, a combining mark or an emoji: `-a Expenses:Food:中餐` adds in `Expenses:Food:中餐厅`, with wrong totals and exit 0 (gap in w5/292 and w5/203)

**Major · cli · 10–15m · A1.** Real CLI QA, 2026-10-17, HEAD `701764c5a`, checkout `bea 0.3.1`, macOS 26.5.1. Gap in w5/292 and 203 (done).
USAGE:1558-1559 says "A value spelled as an account name matches that account
and its children only, so `Expenses:Food` does not pick up
`Expenses:FoodTruck`". w5/203 made bea accept every account name Beancount
loads, including these. No product fix implemented.

```
option "operating_currency" "USD"
2024-01-01 open Assets:Bank USD
2024-01-01 open Expenses:Food:中餐 USD
2024-01-01 open Expenses:Food:中餐厅 USD
2024-02-01 * "lunch"
  Expenses:Food:中餐  5.00 USD
  Assets:Bank
2024-02-02 * "restaurant"
  Expenses:Food:中餐厅  7.00 USD
  Assets:Bank
```

```sh
bea --json -f /abs/main.bean report income-statement -a 'Expenses:Food:中餐'
```

Actual: `check` exits 0. The report exits 0 with `"net_profit": {"USD":
"-12.00"}`, and its tree has both `中餐 5.00` and `中餐厅 7.00`. `query … WHERE
account = 'Expenses:Food:中餐'` gives 5.00. A Thai leaf behaves the same:
`-a Expenses:Kค่า` picks up `Expenses:Kค่าX` (hunter's run). `trial-balance`,
`balance-sheet` and `overview` share the filter.

Control: `-a Expenses:Food` on an `Expenses:Food`/`Expenses:FoodTruck` ledger
shows Food only.

Expected: −5.00, for the account and its children only.

Cause: `account_predicate` (`cli/src/fava/core/filters.py:442`, around `:462`)
treats a value as an account name only when `account.is_valid(value)`. That
regex refuses names with letter-other leaves, combining marks or emoji,
which then fall through to an unanchored case-insensitive regex search.

Fix: decide "spelled as an account name" with the loader rule bea already
has (`_loads_as_account`, `cli/src/bea_engine/ledger/text.py:393`), and match
those by component.

Dedupe: w5/292 and 203 (done) are the parents; w5/616 (open) covers valid
names matching mid-name, a different gate.

Acceptance: the fixture reports −5.00. A test pins a CJK and a Thai leaf.
