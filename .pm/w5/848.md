# `bea ask`'s write tool tells the model whether any local path exists, without approval and even in `--print` mode: a `document` directive for a missing file gets "File does not exist", an existing one gets "Write skipped" (security-relevant: filesystem information reaches the hosted model)

**Minor · cli · 10m · A1.** Real CLI QA, 2026-10-17, HEAD `4bd8c6ec7`, checkout `bea 0.3.1`, macOS 26.5.1. Simulation: a local AI-proxy stub with a fake token; the stub's request log shows what bea sent back to the model.
USAGE says one-answer and non-interactive mode "never apply AI-proposed
writes". They don't, but the validating dry run still runs, and its outcome
goes to the model. No product fix implemented.

`bea --file /abs/main.bean ask q --print </dev/null`, with the stub calling
`write_directive` with `2024-01-20 document Assets:Cash "<path>"`:

- `/etc/hosts`: the model receives `Write skipped (non-interactive mode does not
  support writes).`
- `/nonexistent/qa/file.pdf`: the model receives `Write rejected; nothing was
  written: … File does not exist: "/nonexistent/qa/file.pdf"…`. The hunter's
  run also showed the ledger's absolute directory.

Both runs exit 0 with empty stderr, and the ledger is unchanged. In an
interactive session, the missing-path case shows no panel and tells the user
nothing. That is one bit of filesystem existence per tool call, up to ten
calls per question, without the user seeing anything.

Expected: when no confirmation is possible, return "Write skipped" before any
validation. In interactive mode, refuse document paths outside the ledger
tree, or show rejections to the user too.

Cause: `write_directive` runs the engine dry run before checking
`perm.confirm_fn is None` (`cli/src/cli/ask/agent.py`, around `:457-461`), and
returns the validation error verbatim to the model.

Fix: skip the dry run in non-interactive mode, and scope document paths (or
surface rejections) in interactive mode.

Dedupe: w3/451 and 452 (done) note only that `--print` never writes.

Acceptance: both `--print` cases send the model the same "Write skipped"
text. A test pins it.
