# `add transaction --json` answers that `add transactions` cannot replay: a units-less posting comes back as `"number": null` (refused with pydantic's float advice), and `{# 5 USD}` / `{100 # USD}` come back as plain total or per-unit costs that replay unbalanced

**Minor · cli · 15–20m · A1.** Real CLI QA, 2026-10-17, HEAD `0f2118d8e`, checkout `bea 0.3.1`, macOS 26.5.1.
USAGE (Investment postings) says the units, cost and price shapes in `add
transaction --json` output are valid `add transactions` input, so a returned
posting pipes back unedited. No product fix implemented.

The ledger opens `Assets:Brokerage`, `Assets:Cash USD` and `Expenses:Food USD`.
Each answer's `data.directive` is fed to `add transactions --from FILE` on a
pristine copy.

1. `-p 'Assets:Brokerage HOOL {100 USD}' -p 'Assets:Cash -200 USD'` exits 0. The
   answer has `"units": {"number": null, "currency": "HOOL"}`. Replay exits 1
   with `Row 1, postings.0.units.number: Decimal input should be an integer,
   float, string or Decimal object`. That advice invites floats, which bulk
   refuses, and the amount shorthand cannot spell this posting.
   `Expenses:Food USD` and `Assets:Euro @ 1.08 USD` behave the same (hunter's
   runs).
2. `2 HOOL {# 5 USD}` is answered as `cost {"number": null, "number_total":
   "5"}`, the same as `{{5 USD}}`. Replay writes `{0 # 5 USD}` and fails
   `does not balance` (hunter's run).
3. `2 HOOL {100 # USD}` is answered as `cost {"number": "100",
   "number_total": null}`. Replay writes `{100 USD}` and fails (hunter's run).

Control: `2 HOOL {100 USD}` replays and exits 0. `list transaction --json`
replays cleanly for every other cell the hunter tried.

Expected: the bulk schema can express a number left open (units with no
number, and per-unit or total cost interpolation), or `-p` refuses these
forms and points to a replayable spelling.

Cause: `models.Amount.number` is required (`cli/src/bea_engine/ledger/models.py`,
around `:90-94`), while the answer emits MISSING as `null`. A null per-unit
number plus a total reads as a total cost (`writer.py`, around `:344`).

Fix: add explicit "interpolated" markers to the schema, or refuse at input.

Dedupe: w1/092 and w5/211 (done) cover other replay shapes.

Acceptance: the three answers replay to the same entry, or the adds are
refused with a replayable alternative.
