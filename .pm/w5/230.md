# CSV `meta` cells are Python reprs: `Decimal('1E-8')`, `datetime.date(2026, 1, 7)`, `True`

**Minor · cli · 20–30m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS. Owner call: extends w1/done/145.
Selecting a whole metadata dictionary in CSV output prints Python's repr of
it, with `Decimal('1E-8')` and `datetime.date(...)` inside. A CSV consumer
cannot parse that, and the docs say query CSV never prints `1E-8`. Scalar
metadata lookups and JSON are clean. Stock `bean-query` prints the same
repr. No product fix implemented.

Create disposable `/absolute/books/main.bean`:

```beancount
option "operating_currency" "USD"
2026-01-01 open Assets:Wallet
2026-01-01 open Expenses:Fees
2026-01-05 * "Exchange" "Withdrawal fee"
  fee-rate: 0.00000001
  quantity: 2.50
  settled: 2026-01-07
  cleared: TRUE
  fee-paid: 0.00000050 BTC
  memo: "ok"
  Expenses:Fees   0.00000050 BTC
    lot-size: 3
  Assets:Wallet  -0.00000050 BTC
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY, cwd `/absolute/books`.

```sh
bea -f main.bean query "SELECT account, meta, entry.meta AS entry_meta" -f csv
```

Actual: exit 0.

```text
account,meta,entry_meta
Expenses:Fees,{'lot-size': Decimal('3')},"{'fee-rate': Decimal('1E-8'), 'quantity': Decimal('2.50'), 'settled': datetime.date(2026, 1, 7), 'cleared': True, 'fee-paid': 0.00000050 BTC, 'memo': 'ok'}"
```

Control: `bea -f main.bean query "SELECT entry_meta('fee-rate'),
entry_meta('settled'), entry_meta('cleared'), meta('lot-size')" -f csv`
prints `0.00000001,2026-01-07,TRUE,3`. A worker saw `--json` return
`{"fee-rate": "0.00000001", "settled": "2026-01-07", "cleared": true, …}`
for the same column.

Expected: `docs/USAGE.md` lists "query JSON and CSV" among outputs that
spell amounts in fixed-point (`0.00000001`, never `1E-8`). The cell should
carry the same typed values the JSON path produces.

Cause: `cli/src/bea_engine/query.py:864` returns
`str(_user_metadata(value))`, the repr of a dict of raw Python values.

Fix: build the cell from the JSON-ready walk the JSON path uses
(fixed-point decimals, ISO dates, `TRUE`/`FALSE`, empty for null), for
example as compact JSON. No dependency change; the cell's shape changes.

Blast radius: CSV to stdout and `-o`, and the text table, for any
dict-typed column (`meta`, `entry.meta`, the `meta` column of `#entries`
and `#commodities`).

Dedupe: w1/done/145 removed `filename`/`lineno` from these cells and
accepted "CSV matches the text cell", with a string-only fixture, so typed
values were not considered; w1/done/053 promised no exponent in query CSV;
w5/179 is the frozenset repr in text tables. The owner may treat this as an
extension of 145 or as accepted upstream behaviour.

Acceptance: the CSV cell contains no `Decimal(`, `datetime.` or exponent
form, and parses as the same values the JSON output gives; scalar lookups
are unchanged. Only macOS and the checkout were exercised.
