# `bea example` and `bea treeify` report upstream usage errors as exit 1

**Minor · cli · 20m · A1.** Real CLI QA, 2026-10-10, HEAD `97600b74`, checkout `bea 0.3.1`, Beancount 3.2.3, macOS. A bad option or argument to these two
forwarding commands exits 1 — the ledger/validation category — while the
message itself quotes upstream's exit 2. A script branching on the documented
category is told the ledger is at fault. No product fix implemented.

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY. No ledger is needed:

```sh
bea example --nosuch
bea example --seed abc
printf 'x\n' | bea treeify --nosuch
```

Actual: each exits 1, for example `Error: bean-example failed (exit 2):
Error: No such option '--nosuch'.` and `treeify failed (exit 2): …
unrecognized arguments`. Repeated twice.

Controls: `bea check --nosuch`, `bea doctor lex --nosuch main.bean` and
`bea example --date-begin 2026-01-01 --date-end 2025-01-15` all exit 2.

Expected: `docs/USAGE.md` Exit codes — 2 is "Bad arguments", 1 is a ledger
or validation error. Exit 2.

Cause: `cli/src/cli/engine/launch.py:228-243` (`check_native`) raises a
plain `BeaError`, which exits 1, for any nonzero upstream status.

Fix: when the captured upstream status is 2 — the usage status of both Click
and argparse — raise `UsageError`; leave other statuses as they are. No
dependency or API change.

Blast radius: the callers of `check_native`, `example.py` and
`treeify.py`. Related and unfixed: `bea example -o nodir/x.bean` exits 1
after generating, where `format -o` and `treeify -o` refuse a missing
parent directory with exit 2 first.

Dedupe: board search for "failed (exit 2)", unrecognized arguments and
`check_native` finds w1/086 (the example date-range guard) and w5/061
(treeify regex options), both specific inputs; none covers the general
mapping.

Acceptance: the three commands exit 2 in text and under `--json` (category
`usage`); a real generation failure still exits 1. Only macOS and the
checkout were exercised.
