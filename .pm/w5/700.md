# A `BEA_API_URL` host that httpx's IDNA check rejects passes bea's URL check: `cloud logout` then deletes the stored credential without sending anything, and other cloud commands fail as unexpected errors (gap in w1/059 and w5/521)

**Minor · cli · 10–15m · A1.** Real CLI QA, 2026-10-17, HEAD `733ea312`, checkout `bea 0.3.1`, macOS 26.5.1. Follow-up to w5/521 (done, `315af713`).
The USAGE environment table says a `BEA_API_URL` that is not an `http(s)://`
URL with a host is a usage error (exit 2). w5/521 made logout keep the
credential when the URL is malformed. A host that `urlsplit` accepts but
httpx's IDNA check rejects gets past both. No product fix implemented.

With a stored `credentials.json` and no `BEA_TOKEN`:

1. `BEA_API_URL=http://xn--qa.example.invalid bea --json cloud logout` exits 1
   with `Removed the local credential, but server revocation failed: Codepoint
   U+0090 at position 1 of '\x90' not allowed. The session may still be
   valid…`. `credentials.json` is deleted. httpx raised the error while it
   built the request, so no request was ever sent.
2. A pasted zero-width space,
   `BEA_API_URL=$'https://api.example.invalid\u200b' bea --json cloud logout`,
   exits 1 with `Invalid IDNA hostname: 'api.example.invalid\u200b'. Pass
   --debug before the command for a traceback.` (`validation`). The
   credential is kept.
3. A trailing no-break space with `BEA_TOKEN` set makes `bea cloud ledger
   list` fail the same way.

Control: `BEA_API_URL=htps://api.example.invalid bea --json cloud logout` exits
2 (`usage`) and keeps the file.

Expected: all three exit 2 with `BEA_API_URL must be an http(s) URL with a
host…`, and the credential is kept.

Cause:
- `_http_url` (`cli/src/cli/settings.py:27-39`) checks only `urlsplit`.
- In logout, the request-time `ValueError` falls into the broad `except
  Exception` branch, and `clear_credentials()` (`cli/src/cli/commands/cloud/
  app.py:145`) runs anyway.

Fix:
- Also parse the value with `httpx.URL(value)` and read `.host`, so IDNA and
  `InvalidURL` errors become the usage error.
- In logout, delete the credential only after a transport-level attempt.

Dedupe: searched `IDNA`, `punycode`, `xn--`, `InvalidURL`; no hits. w1/059
(done) added the validator.

Acceptance: the three commands exit 2, and case 1 keeps `credentials.json`.
Tests pin cases 1 and 2.
