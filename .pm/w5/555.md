**Trivial · skills · 10–15m · A1.** Real CLI QA, 2026-10-16, HEAD `66aeb02e`, checkout `bea 0.3.1`, macOS 26.5.1.

(IMPORTING.md), and updated only IMPORTING.md. `dedup.md` is the documented
grammar the skills and importer-author importers follow: `<date>|<amount>|
<description>|<source-account>`, with the amount in units only. `bea` still
accepts the units-only id as a lookup key, so the CLI side is backward
compatible. The gap runs the other way: the skills' exact-match layer, and
importers that compute ids from `dedup.md`, compare id strings and will not
recognize ids `bea` wrote for lots.

`Assets:Broker:AAPL 10 AAPL {100 USD}` and `Assets:Broker:Cash -1000 USD`,
no id; `account()` is `Assets:Broker:AAPL`.


grammar gives `…|10 AAPL|…` → `f2a99c69eaf85163`.
