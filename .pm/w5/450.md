# A URL include that is not an allowed managed price source (`include "https://example.com/x.bean"`, or `…/prices/BTC-USD?x=1`) silently loads a local file whose path spells the URL (`./https:/example.com/x.bean`), counting its entries as the user's own; `check` exits 0

**Minor · cli · 15m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12. Offline only. No network traffic occurred.

USAGE says a URL include "is a registered price request, not a general
remote include: only allowlisted origins and exact `/prices/<ALIAS>`
paths resolve". A refused URL is skipped by the managed loader and then
handed to Beancount's file glob. The glob resolves it relative to the
ledger's directory and collapses `//`, so `https://example.com/x.bean`
becomes `./https:/example.com/x.bean`.

When no such local file exists, the user gets an accurate "File glob …
does not match" error. When one exists, it loads silently. Its entries,
prices or transactions, become part of the books, and `price status`
says there are no managed includes. [449](./449.md)'s flow, following
bea's own "create the directory" advice, creates exactly such
directories. No product fix implemented.

Create `main.bean`:

```beancount
option "operating_currency" "USD"
include "https://example.com/x.bean"
2026-01-01 open Assets:Cash USD
2026-01-01 open Equity:O USD
```

and a local file `https:/example.com/x.bean` beside it, holding one 8 USD
Cash transaction. Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME,
BEA_NO_UPDATE_NOTIFIER=1, and closed stdin.

```sh
bea --offline -f /absolute/books/main.bean check
bea --offline -f /absolute/books/main.bean balance Cash
```

Actual:

- `check` exits 0, and `balance Cash` shows 8 USD.
- The hunter's `include "https://beancount.io/prices/BTC-USD?x=1"`
  variant loaded a local `price BTC 999999 USD` as an ordinary (not
  `generated`) price. `price status` reported no managed includes, and
  `price export` copied the file, rewriting the include as a local path.

Reproduced twice per variant by the hunter and once by me (example.com).

Control: with no local `https:` directory, the same include exits 1 with
`File glob "https://example.com/x.bean" does not match any files`.

Expected: any include whose target is a URL either resolves as an allowed
managed source, or fails with its refusal reason (for example "is not an
allowed managed price source: it must not carry a query string"). It is
never matched against local files.

Cause: `cli/src/bea_engine/managed_load.py:656-660` does `continue` for a
URL that `parse_managed_price_url` refuses. The include then falls
through to upstream's glob. The `RefusedUrl.detail` built in
`cli/src/bea_engine/managed_prices.py:99-138` is discarded.

Fix: for includes matching `is_url_include_target`, report the refusal
detail as a load error at the include line, and never pass them to the
file glob. No dependency change.

Blast radius: ledgers with a mistyped or non-allowlisted URL include and
a matching local path, which 449's advice can create. Foreign entries
silently enter the books.

Dedupe: 449 covers `--into` a URL. 377-379, 408, 409 and 423 cover the
price feed and its cache. None covers refused URLs resolving locally.

Acceptance: on the fixture, `check` exits 1 naming the include and the
refusal reason, and the local file is not loaded. A missing-file URL
include gives the same refusal. A test pins both.

Addendum (CLI QA r95, 2026-10-14): this also bypasses the frontend's
`-o` guard and loses data. With the fixture above, `bea format
main.bean -o "https:/example.com/x.bean"` exits 0 and replaces the
loaded file with the root's text, so its transaction is gone. Reproduced
on two copies by the hunter. The frontend walker skips every
`_REMOTE_INCLUDE` (`cli/src/cli/output.py:303`, `:379-382`), while the
loader falls back to the local glob. `format -i` likewise leaves that
loaded file unformatted. `query -o` and the cache guard refuse
correctly, because they use the engine closure. The fix above (never
glob URL includes) removes the disagreement. Until it lands, this is a
data-loss path.
