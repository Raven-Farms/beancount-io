# `balance` and `report` silently drop every account whose root comes from an include's own `name_*` option: `check` passes and `query` shows the balance, but the trial balance and balance sheet leave it out and no longer balance

**Minor · cli · 20m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12.
Beancount applies `name_*` options per file while parsing, so an include
that sets `option "name_assets" "Aktiva"` can open and post to
`Aktiva:Bank`, and the ledger loads cleanly. The reports group accounts
under the root file's five roots. `Aktiva:Bank` belongs to none of them,
so it is discarded without a note. The trial balance and balance sheet
then omit a real balance and no longer sum to zero, while `query` and
`list` show it. This is the reverse of 462, where the root renames and
the include does not. No product fix implemented.

Create disposable `main.bean`:

```beancount
option "operating_currency" "USD"
include "inc.bean"
2026-01-01 open Assets:Cash USD
2026-01-01 open Equity:O USD
```

and `inc.bean`:

```beancount
option "name_assets" "Aktiva"
2026-01-01 open Aktiva:Bank USD
2026-01-02 * "x"
  Aktiva:Bank 5 USD
  Equity:O
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, and
closed stdin.

```sh
bea -f /absolute/books/main.bean check
bea -f /absolute/books/main.bean balance
bea -f /absolute/books/main.bean query "SELECT account, sum(position) GROUP BY account"
```

Actual: `check` exits 0, as does stock `bean-check`. `balance` shows
Assets `—` and Equity `-5 USD`, with no Aktiva section and no note. JSON
`ledger_valid: true`. `report trial-balance` and `balance-sheet` do the
same. `query` shows `Aktiva:Bank 5 USD`. Reproduced twice by the hunter
and once by me.

Expected: every balance appears in the reports, or the report warns. For
example: "1 account outside this ledger's roots is not shown:
Aktiva:Bank (its root comes from `option "name_assets"` in inc.bean,
which Beancount applies only while parsing that file)", in text and in
JSON.

Cause: the report tree (`cli/src/bea_engine/report.py`, via the vendored
Fava tree) is built from the root options' five roots. Accounts under any
other root are dropped without a check.

Fix: after building the tree, compare it with all accounts that have
postings. Report leftovers in their own section, or as a warning
(`ledger_warnings` or `data.unrooted_accounts`). Optionally, have `check`
flag includes whose `name_*` options differ from the root. No dependency
change.

Blast radius: split ledgers whose includes set `name_*` options, for
example after merging a localized file. Reports silently omit balances.

Dedupe: 462 (the reverse direction, writes refused), 402, w5/080, w1/157
and w5/154 cover foreign-root messages on writes and imports. None covers
reports dropping balances.

Acceptance: on the fixture, `balance` and `report balance-sheet` show
`Aktiva:Bank 5 USD`, or warn naming it, in text and JSON. A test pins it.
