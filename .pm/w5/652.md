# `bea price export` assigns an external include and an in-tree `_shared/01-x.bean` to the same destination: one overwrites the other, the report says "Exported 3 files" for 2, and the snapshot fails `check`, exit 0

**Major · cli · 20–30m · A1.** Real CLI QA, 2026-10-16, HEAD `87ad7af8`, checkout `bea 0.3.1`, macOS 26.5.1.
USAGE: the export produces a self-contained copy and refuses "a plan that
collides with itself". An include outside the ledger directory is relocated
to `_shared/NN-<name>`. The slot is chosen without checking whether an
in-tree file already has that path. No product fix implemented.

`books/main.bean`:

```beancount
option "operating_currency" "USD"
include "_shared/01-acc.bean"
include "../outside/acc.bean"
2026-01-02 * "x"
  Assets:Internal  1.00 USD
  Assets:External
```

`books/_shared/01-acc.bean`: `2026-01-01 open Assets:Internal USD`.
`outside/acc.bean`: `2026-01-01 open Assets:External USD`.

```sh
bea --file main.bean check                        # exit 0
bea --file main.bean price export -o /abs/snap
bea --file /abs/snap/main.bean check
```

Actual: the export prints `Exported 3 files to /abs/snap.` and exits 0, but
`snap/` holds 2 files. `snap/_shared/01-acc.bean` holds only the external
open, and `snap/main.bean` includes `_shared/01-acc.bean` twice; `--json`
lists that path twice. The snapshot's `check` exits 1 with `Duplicate filename
parsed` and an unknown account. An in-tree `_SHARED/01-acc.bean` on APFS
behaves the same. A `--force` re-export where `txns/2026.bean` is a symlink
to `../main.bean` exits 0 with `snap/main.bean` holding the leaf's text.

Control: without the in-tree `_shared/01-acc.bean`, the export is correct.

Expected: relocation slots avoid every planned destination (case-folded), and
a plan in which two sources map to one destination is refused (exit 2) before
anything is written.

Cause: `cli/src/bea_engine/managed_load.py:1203-1204` builds
`target/"_shared"/f"{n:02d}-{name}"` without consulting the planned
destinations; the self-collision check (`:1280-1287`) compares parent and file
only, not equal or case-folded destinations.

Fix: allocate `_shared` slots against the taken set (as `_free_feed_path`
does, case-folded); refuse duplicate destinations by resolved identity.

Dedupe: searched `_shared`; w4/171, w5/058, 189 and 191 (done) cover other
collisions.

Acceptance: the fixture exports three files and the snapshot checks with exit
0. Tests pin it and the case variant.
