# `bea treeify` after w5/570: with renamed roots, a colon in a narration still takes the account column and garbles the tree; and the new lookahead makes treeify quadratic in line length (40k-char line ~17 s, 100k 52 s, was 0.1 s) (incomplete fix of w5/570)

**Minor · cli · 10–15m · A1.** Real CLI QA, 2026-10-17, HEAD `b9427aca2`, checkout `bea 0.3.1`, macOS 26.5.1. Follow-up to w5/570 (done, `f8d3149e4`).
w5/414 promises renamed-root support, and w5/570 fixed the narration-colon
case for English roots only. No product fix implemented.

1. **Renamed roots.** `q.txt` is `bea query "SELECT narration, account,
   position"` output from a ledger with `option "name_assets" "Aktiva"` and
   `option "name_income" "Ertraege"`:

   ```
       narration             account         position
   ------------------  -------------------  ----------
   NYSE:IBM Dividende  Aktiva:Depot:Cash     10.00 USD
   NYSE:IBM Dividende  Ertraege:Dividenden  -10.00 USD
   ```

   `bea treeify q.txt` exits 0 with `` `-- NYSE `` / `` `-- IBM Dividende
   Aktiva:Depot:Cash `` and a second row that loses `NYSE:IBM`, which is the
   w5/570 symptom. The same input with English roots draws the account tree.
2. **Quadratic time (new with the fix).** A file of `Assets:Cash  10 USD`
   followed by one 40,000-character line of `x ` takes 17.5 s. The hunter
   measured 52 s for 100,000 characters, against 0.1 s before the fix.
   Single-line JSON piped from `bea --json query …` is a real trigger.

Expected: the account column is chosen by its matches whatever the root
names, in linear time.

Cause: `_ACCOUNT_PATTERN` (`cli/src/cli/commands/treeify.py:36-38`) blocks the
any-root match only when an English-root account follows on the line. Its
lookahead `(?!.*(?<!\S)ENGLISH_ROOT:)` rescans to the end of the line at every
start position.

Fix: decide the column once per input (for example, prefer the column whose
matches share a root set or have more components), outside the per-position
regex.

Dedupe: w5/570 and 414 (done) are the parents.

Acceptance: fixture 1 draws the Aktiva/Ertraege tree; the 100k-character line
finishes in under a second. Tests pin both.
