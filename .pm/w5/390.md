# `bea example` accepts any date span: `--date-begin 0001-01-01` runs for a minute and `--date-end 9999-12-31` for about three, then each fails with an upstream class name (`decimal.InvalidOperation`, `OverflowError`), exit 1

**Minor · cli · 15m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12.
`example`'s pre-check refuses an inverted range and one shorter than 31
days with exit 2, "before upstream dies on it". It sets no lower year
bound and no span ceiling. A span of thousands of years is passed to
`bean-example`, which runs for minutes and then crashes. The user waits
and gets a Python class name. No product fix implemented.

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1,
and closed stdin.

```sh
bea example --seed 1 --date-begin 0001-01-01
bea example --seed 1 --date-end 9999-12-31
```

Actual:

- `--date-begin 0001-01-01` runs for about 60 s, then exits 1 with
  `Error: bean-example failed (exit 1): decimal.InvalidOperation:
  [<class 'decimal.InvalidOperation'>]`. I reproduced this in 60 s, and
  the hunter did twice.
- `--date-end 9999-12-31` runs for about 165 s, then exits 1 with
  `OverflowError: date value out of range` (reproduced by the hunter).
- Nothing is written, and no process is left behind.

Control:

- `--date-begin 2000-01-01 --date-end 2026-01-01` exits 0 in 2 s.
- Inverted or short ranges exit 2 at once.
- `--date-begin 1969-12-31` exits 1 quickly with bea's own validation
  sentence.

Expected: `docs/USAGE.md` says "`bea example` exits 2 before generating
when its date range is inverted or shorter than 31 days", and the guard
exists to refuse a range bean-example cannot generate. A range it cannot
generate in reasonable time should be refused the same way, with exit 2
naming the bound, and no class name should reach the user (w3/298,
w5/089).

Cause: `_check_date_order` (`cli/src/cli/commands/example.py:155-191`)
checks order and `_MIN_SPAN_DAYS` (`:148`) only.

Fix:

- Add a lower bound on `--date-begin` (1970, given the pre-1970
  validation failure) and an upper bound on the span or on
  `--date-end`, both with exit 2 and the limits named.
- Map any remaining upstream exception to bea wording.
- No dependency change.

Blast radius: `bea example` with extreme `--date-begin`/`--date-end`,
for example a typo like `0026-01-01`.

Dedupe: searched `.pm/**`, including `done/`, for `example` together
with date range, `InvalidOperation` and span. w1/086 (inverted or short
ranges), w5/275 (non-ISO), w5/136, w3/298, w5/089 and w3/336 cover other
cases. None covers huge spans.

Acceptance: both commands exit 2 at once, naming the bound. A 26-year
range still generates. A test pins the bounds.
