# `bea price export`, `example` and `treeify` do not list their own `--force`/`--output` options in `--help` or REFERENCE.md

**Minor · cli · 20–30m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS. Docs.
Options that `bea` itself adds to forwarded commands are parsed by hand,
so they appear in neither `--help` nor the generated reference, although
error messages tell the user to pass them. No product fix implemented.

Fixture: any valid ledger at `/absolute/books/main.bean`.

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, closed stdin, no TTY, cwd `/absolute/books`.

```sh
bea price export --help | grep -c -- '--force'
bea example --help | grep -c -- '--force'
bea treeify --help | grep -c -- '--force'
grep -c 'price export' cli/docs/REFERENCE.md
bea -f main.bean price export --bogus
```

Actual: the four counts are all 0. The last command exits 2 with `bea
price export takes only --output, --allow-errors and --force; got:
--bogus.`, confirming the options exist.

Control: `REFERENCE.md` lists `--force` for `add balance` and `add price`,
which are ordinary declared options. A worker confirmed `price export -o
DIR`, a second export refused with "pass --force", and `example -o F`
refusing an existing file with "Pass --force to overwrite".

Expected: `cli/AGENTS.md` describes REFERENCE.md as generated for every
flag, and `docs/USAGE.md` documents these options; help should list what
the command accepts.

Cause: the flags are read from the raw argument list
(`cli/src/cli/commands/price.py:122-142`, `example.py:15-29`,
`treeify.py:19,101-124`), so the help renderer and
`scripts/gen_reference.py` see no parameter.

Fix: add a short "bea options" paragraph to each command's help (export:
`--output/-o DIR`, `--force`, `--allow-errors`; example and treeify:
`--force`) and regenerate the reference. No behaviour change.

Blast radius: help and reference text only.

Dedupe: board search for `price export --help` and `--force` with
example/treeify finds w2/done/020 (forwarded commands showed an empty
help; fixed by appending upstream help). This is what that fix could not
cover.

Acceptance: the four counts are nonzero and the help text matches the
options the commands accept. Only macOS and the checkout were exercised.
