# `bea --json format … -o /dev/stdout` puts ledger text and the JSON envelope on the same stdout, exit 0

**Minor · cli · 10m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`), checkout `bea 0.3.1`, macOS.
`--json format -o -` is refused because it would mix ledger text into the
JSON on stdout. The device spellings `/dev/stdout` and `/dev/fd/1` are
not, so stdout carries the formatted ledger followed by the envelope and
cannot be parsed. No product fix implemented.

Create disposable `/absolute/books/main.bean`:

```beancount
2026-01-01 open Assets:Cash USD
2026-01-01 open Expenses:Food USD

2026-01-05 * "Café" "Lunch"
  Expenses:Food  12.00 USD
  Assets:Cash
```

Use isolated BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, no
inherited BEA_FILE/BEA_TOKEN, no TTY, cwd `/absolute/books`. Closed stdin.

```sh
bea --json format main.bean -o /dev/stdout
```

Actual: exit 0. stdout begins `2026-01-01 open Assets:Cash USD` and ends
with the `{"bea": "0.3.1", …}` envelope; `json.loads` fails at the first
character.

Control: `bea --json format main.bean -o -` exits 2: `In --json mode,
--output - would mix formatted ledger text into the JSON on stdout. Name a
file with --output FILE, or drop --json to write the text to stdout.` A
worker saw `/dev/fd/1` behave like `/dev/stdout`, and `--json query … -o
/dev/stdout` emit only the envelope.

Expected: `docs/USAGE.md` says "In `--json` mode … stdout carries the
envelope and nothing else … `-o -` is refused there for the same reason —
it names the stream the envelope already owns". The device paths name the
same stream.

Cause: `cli/src/cli/commands/format.py:548` refuses only the literal `-`;
`query` already keeps a set of stdout spellings
(`cli/src/cli/commands/query.py`, `_STDOUT_PATHS`).

Fix: use the same set in `format`'s JSON destination check and its
stdout branch. No dependency or API change.

Blast radius: `--json format` with `-o /dev/stdout` or `/dev/fd/1`, file
and stdin input.

Dedupe: board search for `/dev/stdout` finds w1/done/103, which made the
device paths work but did not cover the `--json` mix.

Acceptance: the command exits 2 with the same refusal as `-o -`; plain
`bea format -o /dev/stdout` still writes text. Only macOS and the checkout
were exercised.
