# A period given as `balance`'s positional filter (`bea balance 2026-01`), or to `report -a`, prints "No accounts match 2026-01." with exit 0 and no hint that `-t` was meant

**Trivial · cli · 10m · A1.** Real CLI QA, 2026-10-14, HEAD `bce2c992`, checkout `bea 0.3.1`, macOS 26.5.1, engine Python 3.12.
`balance`'s positional arguments are account substrings, and the period
is `-t`. A user coming from hledger (`balance -p 2026-01`), or typing
`bea balance 2026-01`, gets an empty answer that looks valid: "No
accounts match 2026-01." with exit 0. The same applies to `2026`,
`2026-01-05` and `FY2026`, and to `report balance-sheet -a 2026-01`. No
product fix implemented.

Use a ledger with Food transactions in January 2026. Use isolated
BEA_CONFIG_DIR/XDG_CACHE_HOME, BEA_NO_UPDATE_NOTIFIER=1, and closed
stdin.

```sh
bea -f /absolute/books/main.bean balance 2026-01
bea -f /absolute/books/main.bean balance -t 2026-01        # control
```

Actual: the first command exits 0 with heading `account: 2026-01` and
`No accounts match 2026-01.`. JSON gives `account_filter: "2026-01"` and
`account_filter_empty: true`. Reproduced twice by the hunter and once by
me (`2026-10`).

Control: `-t 2026-01` shows the January balances.

Expected: when an unmatched filter term parses as a `-t` value (a year,
`YYYY-MM`, a date, `FYyyyy`, or a range), the note should add "did you
mean `-t 2026-01`?". The exit code can stay 0.

Cause: `cli/src/cli/commands/report.py:153-154` prints only `No accounts
match …`. The positional is declared at `report.py:369`, and `report -a`
shares the path.

Fix: where `account_filter_empty` is set, test each term with the
period parser and append the hint. No dependency change.

Blast radius: `balance [ACCOUNT…]` and `report * -a`, for users and
agents used to other tools' period arguments.

Dedupe: w3/292, w3/379, w1/071, w1/126, w1/132, w5/305, 341 and 340 cover
other empty-filter or encoding aspects. None covers a period passed as a
filter.

Acceptance: `bea balance 2026-01` adds the `-t 2026-01` hint, and a
non-period term (`Nope`) does not. A test pins both.
