# `doctor linked/region` print the tree with 26 decimals (`-112.50000000000000000000000000 USD`) when the scope has an interpolated leg, and ignore `display_precision` (regression from w5/101)

**Minor · cli · 15–20m · A1.** Real CLI QA, 2026-10-16, HEAD `04c94595`, checkout `bea 0.3.1`, macOS 26.5.1. Differential run against upstream `bean-doctor`.
w5/101 builds the doctor tree's display context from the maximum in-scope
precision per currency. An interpolated leg carries Beancount's full
division result (`100.00 / 3 × 3`), so its 26 digits become the column's
precision. The fix also forces maximum precision, discarding the ledger's
`display_precision`. No product fix implemented.

`main.bean`:

```beancount
2024-01-01 open Assets:Broker
2024-01-01 open Assets:Cash USD
2024-01-01 open Expenses:Food USD

2024-01-03 * "Buy" ^x
  Assets:Broker  3 HOOL {{100.00 USD}}
  Assets:Cash

2024-01-04 * "Lunch" ^x
  Expenses:Food  12.50 USD
  Assets:Cash
```

```sh
bea doctor linked /abs/main.bean ^x
```

Actual: exit 0, `Cash -112.50000000000000000000000000 USD` and `Food
12.50000000000000000000000000 USD` above `Net Income: (-12.50 USD)`; the same
with `option "display_precision" "USD:0.01"`. One `@ 1.0833 USD` conversion
pads a cents ledger's USD column to four places.

Control: upstream prints `-112.50` and `12.50`; `bea balance` shows 2 places.

Expected: interpolated legs do not widen the column, and `display_precision`
is honored.

Cause: `_context_of` (`cli/src/bea_engine/scoped.py:136-139`) reads every
posting's units, including `__automatic__` ones; `:131` forces
`Precision.MAXIMUM`; `:142-145` copy only the commas setting from the ledger's
context.

Fix: skip `__automatic__` postings (or cap at the ledger context's precision)
and carry over fixed precisions. Keep w5/101's exactness for typed amounts.

Dedupe: w5/101 and w3/352 (done) are the cause; w5/498 (open) is the
conversion rounding.

Acceptance: the command prints `-112.50 USD` and `12.50 USD`; w5/101's
fixture still agrees with `Net Income`. A test pins both.
