# `bea --version` and `--help` exit 120 with a broken-pipe message when the reader has already gone

**Minor · cli · 15–20m · A1.** Real CLI QA, 2026-10-11, HEAD `a8b75aed` (CLI unchanged since `97600b74`),
checkout `bea 0.3.1`, macOS.
Command bodies handle a closed downstream pipe silently with exit 141, as
documented. The root-level `--version`, `--help` and completion options do
not: they print `Error: [Errno 32] Broken pipe` plus Python's "Exception
ignored on flushing sys.stdout" and exit 120, a code outside the documented
table. It only happens when the reader exits without reading. No product fix
implemented.

With BEA_NO_UPDATE_NOTIFIER=1, in bash:

```sh
bea --version | true; echo ${PIPESTATUS[0]}
bea list --help | true; echo ${PIPESTATUS[0]}
```

Actual: the first prints

```text
Error: [Errno 32] Broken pipe
Exception ignored on flushing sys.stdout:
BrokenPipeError: [Errno 32] Broken pipe
120
```

Repeated twice. A worker saw the same for `--help`, `-h` and
`--show-completion`, and exit 120 with only the two flush lines for
`--json --version`.

Control: the second command prints `141` with nothing on stderr.

Expected: `docs/USAGE.md` says "a closed downstream pipe still exits 141,
both without a message" and "These five codes are the whole table."

Cause: these are eager option callbacks that run inside
`_GuardedGroup.parse_args`, whose `except Exception` at
`cli/src/cli/main.py:158` turns `BrokenPipeError` into an ordinary error;
the interpreter's shutdown flush then forces 120. The 141 handling from
w3/378 lives only in `invoke` (`main.py:168`, `:178`).

Fix: handle `BrokenPipeError` in `parse_args` the way `invoke` does,
and settle stdout before re-raising the eager option's exit. No dependency or
API change.

Dedupe: board search for broken pipe, 120 and 141 finds w3/378 (command
bodies, done) and w3/388 (Ctrl-C at prompts); neither covers the root eager
options.

Acceptance: `bea --version | true`, `--help`, `-h`,
`--show-completion` and `--json --version` exit 141 with empty stderr.
A regression test closes the pipe before the child writes. Only macOS and
the checkout were exercised.
